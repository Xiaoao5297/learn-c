# 3.2 二维数组

> 💬 **节前语：**
>
> 上一节我们学了数组，它像一排储物柜，能装很多数据。
>
> 但有些数据，一排柜子可装不下——
> 
> - 📅 **课程表**：行是星期几，列是第几节课
> - 🎯 **射击游戏地图**：行是 X，列是 Y
> - 📊 **成绩表**：行是学生，列是科目
>
> 这些数据天生是"表格状"的，有两套"坐标"。一个一维数组管不过来。
>
> 怎么办？——把"柜子"叠成"楼层"！这就是**二维数组**。
>
> 这一节，我们来学它。准备好了吗？开始吧！

## 3.2.1 二维数组是什么？

### 🎯 生动的比喻：一栋"数据大楼"

一维数组是一排柜子，二维数组就是**一栋大楼**：

```
                 第0列 第1列 第2列
              ┌──────┬──────┬──────┐
   第0行  ──→ │ 85   │ 92   │ 78   │   ← 第0行（小明）
              ├──────┼──────┼──────┤
   第1行  ──→ │ 96   │ 88   │ 91   │   ← 第1行（小红）
              ├──────┼──────┼──────┤
   第2行  ──→ │ 72   │ 65   │ 80   │   ← 第2行（小刚）
              └──────┴──────┴──────┘
```

- 用两个下标定位：`成绩[行][列]`
- 比如 `score[0][2] = 78`：第0行第2列，是小明的第三科成绩

> 📌 **本质：** 二维数组其实就是"数组的数组"——每一行，都是一个一维数组。

---

## 3.2.2 声明二维数组

### 📝 语法

```c
类型 数组名[行数][列数];
```

### 📝 例子

```c
int score[3][3];      // 3行3列的成绩表
int board[8][8];      // 8×8 的棋盘
double temp[7][24];   // 一周每天24小时的气温
```

### 🧩 拆解来看

```c
int score[3][3];
        │   │
        │   └── 列数（3列）
        └────── 行数（3行）
```

**访问元素：**

```c
score[0][0] = 85;    // 第0行第0列
score[0][1] = 92;    // 第0行第1列
score[2][2] = 80;    // 第2行第2列
```

> 📌 **行和列的下标都从0开始！**

---

## 3.2.3 初始化二维数组

### 方式一：按"行"分行写（推荐，清晰）

```c
int score[3][3] = {
    {85, 92, 78},   // 第0行
    {96, 88, 91},   // 第1行
    {72, 65, 80}    // 第2行
};
```

### 方式二：全部写在一行（编译器按顺序填）

```c
int score[3][3] = {85, 92, 78, 96, 88, 91, 72, 65, 80};
```

### 方式三：只初始化部分

```c
int a[3][3] = {{1, 2}, {3}};   // 没给的自动补 0
```

> 📌 分行写最不容易错！每个 `{ }` 代表一行。

---

## 3.2.4 遍历二维数组：嵌套循环

二维数组有"行"和"列"两个方向，遍历它要用**嵌套循环**：

```c
#include <stdio.h>

int main() {
    int score[3][3] = {
        {85, 92, 78},
        {96, 88, 91},
        {72, 65, 80}
    };
    
    // 外层循环：控制"行"
    for (int i = 0; i < 3; i++) {
        // 内层循环：控制"列"
        for (int j = 0; j < 3; j++) {
            printf("%d ", score[i][j]);
        }
        printf("\n");   // 每打印完一行，换行
    }
    
    return 0;
}
```

输出：
```
85 92 78 
96 88 91 
72 65 80 
```

### 🎯 理解执行顺序

```
i = 0:
    j = 0,1,2 → 打印第0行的 3 个数，然后换行
i = 1:
    j = 0,1,2 → 打印第1行的 3 个数，然后换行
i = 2:
    j = 0,1,2 → 打印第2行的 3 个数，然后换行
```

**口诀：外层管行，内层管列，一行打完就换行。**

---

## 3.2.5 实战：计算每个学生的总分

假设 `score[i][j]` 表示"第 i 个学生的第 j 科成绩"：

```c
#include <stdio.h>

int main() {
    int score[3][3] = {
        {85, 92, 78},   // 小明
        {96, 88, 91},   // 小红
        {72, 65, 80}    // 小刚
    };
    
    for (int i = 0; i < 3; i++) {
        int sum = 0;
        for (int j = 0; j < 3; j++) {
            sum += score[i][j];   // 把第 i 行的 3 个数加起来
        }
        printf("第 %d 个学生的总分：%d\n", i, sum);
    }
    
    return 0;
}
```

输出：
```
第 0 个学生的总分：255
第 1 个学生的总分：275
第 2 个学生的总分：217
```

> 💡 **关键思路：** 想按行统计，就把内层循环遍历"这一行"的每一列，每次统计前把 sum 清零。

---

## 3.2.6 实战：计算每科的平均分

想按"列"统计（每科的平均分），就固定列、遍历行：

```c
#include <stdio.h>

int main() {
    int score[3][3] = {
        {85, 92, 78},
        {96, 88, 91},
        {72, 65, 80}
    };
    
    // 遍历每一列
    for (int j = 0; j < 3; j++) {
        int sum = 0;
        // 固定第 j 列，遍历所有行
        for (int i = 0; i < 3; i++) {
            sum += score[i][j];
        }
        double avg = (double)sum / 3;
        printf("第 %d 科平均分：%.1f\n", j, avg);
    }
    
    return 0;
}
```

输出：
```
第 0 科平均分：84.3
第 1 科平均分：81.7
第 2 科平均分：83.0
```

> 💡 **对比一下：**
> - 按行统计：外层 i（行），内层 j（列）→ 外行内列
> - 按列统计：外层 j（列），内层 i（行）→ 外列内行
> 
> 想清楚"哪一层动得慢、哪一层动得快"，写起来就不晕了。

## 3.2.7 用数组当"表格"：打地鼠棋盘

二维数组最常见的用途就是**棋盘/表格**。比如画一个 5×5 的棋盘：

```c
#include <stdio.h>

int main() {
    // 0 表示空，1 表示有棋子
    int board[5][5] = {0};
    
    // 在第0行第0列、第2行第2列、第4行第4列放棋子
    board[0][0] = 1;
    board[2][2] = 1;
    board[4][4] = 1;
    
    // 打印棋盘
    for (int i = 0; i < 5; i++) {
        for (int j = 0; j < 5; j++) {
            if (board[i][j] == 1) {
                printf("● ");
            } else {
                printf(". ");
            }
        }
        printf("\n");
    }
    
    return 0;
}
```

输出：
```
● . . . . 
. . . . . 
. . ● . . 
. . . . . 
. . . . ● 
```

> 💡 `int board[5][5] = {0};` 会把整个数组都初始化成 0，非常常用！

## 3.2.8 二维数组的另一种初始化：字符串数组的先睹为快

二维数组也能存字符——这其实是后面要学的"多个字符串"的雏形：

```c
#include <stdio.h>

int main() {
    // 一个 3 行、每行最多 20 个字符的"字符表格"
    char names[3][20] = {
        "小明",
        "小红",
        "小刚"
    };
    
    for (int i = 0; i < 3; i++) {
        printf("第 %d 个名字：%s\n", i, names[i]);
    }
    
    return 0;
}
```

输出：
```
第 0 个名字：小明
第 1 个名字：小红
第 2 个名字：小刚
```

> 📌 这里用 `%s` 打印一整行（一个字符串）。下一节我们就会正式学习字符串啦！

## 3.2.9 本节小结

这一节我们学了：

✅ **二维数组是什么：** 像表格/棋盘，"数组的数组"，两个下标（行、列）

✅ **声明：** `int score[3][3];` 行×列

✅ **初始化：** 分行写 `{ {..}, {..}, {..} }` 最清晰

✅ **遍历：** 嵌套循环，外层行、内层列

✅ **按行统计 vs 按列统计：** 分清外层循环控制什么

✅ **棋盘应用：** 用二维数组表示格子状数据，`{0}` 全清零

> 💡 **记住：二维数组就是一张"表格"，行和列都用下标从0数起！**

### 三、改错题

**6. 以下程序想打印一个 3×3 的"乘法表矩阵"，有4个错误，请找出并改正：**

```c
#include <stdio.h>

int main() {
    int table[3][3];
    
    // 填充：table[i][j] = i * j
    for (int i = 1; i <= 3; i++) {      // 错误区①：下标越界
        for (int j = 1; j <= 3; j++) {
            table[i][j] = i * j;
        }
    }
    
    // 打印
    for (int i = 0; i < 3; i++) {
        for (int j = 0; j < 3; j++) {
            printf("%d ", table[i][j])
        }                               // 错误区②：缺分号
        printf("\n")                    // 错误区③：缺分号
    }
    
    printf("中间的值是：%d\n", table[3][3]);   // 错误区④
    return 0;
}
```
