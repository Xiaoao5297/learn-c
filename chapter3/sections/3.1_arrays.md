# 3.1 一维数组

> 💬 **节前语：**
>
> 从第1章开始，我们就用"盒子"来比喻变量：`int age = 20` 就像在一个盒子里存了 20。
>
> 但现在问题来了——如果我要存 100 个学生的成绩，难道要准备 100 个盒子吗？
>
> ```
> int s1 = 95, s2 = 88, s3 = 72 ...  写到 s100？
> ```
>
> 显然太傻了！这时候就需要**数组**——一个能装**一堆**数据的"超级大柜子"。
>
> 这一节，我们就来认识C语言的数组。准备好了吗？开始吧！

## 3.1.1 数组是什么？

### 🎯 生动的比喻：一个大柜子

想象学校走廊里的**储物柜**：

```
┌──────────────────────────────────────┐
│  储物柜（名字：scores）               │
│                                      │
│  ┌───┬───┬───┬───┬───┐              │
│  │ 95│ 88│ 72│100│ 60│   ← 每个格子的成绩 │
│  └───┴───┴───┴───┴───┘              │
│    0   1   2   3   4      ← 格子编号（下标） │
└──────────────────────────────────────┘
```

- 整个柜子有一个名字：`scores`
- 柜子里有 5 个格子，每个格子存一个整数
- 每个格子有编号：0、1、2、3、4（**从0开始！**）

### 📌 数组的定义

> **数组（Array）** = 把**多个相同类型**的数据，按顺序放在一起，用**一个名字 + 下标**来管理。

| 概念 | 说明 | 比喻 |
|------|------|------|
| 数组名 | 整个柜子的名字 | `scores` |
| 元素 | 柜子里的每个数据 | 每格里的成绩 |
| 下标（索引） | 第几个格子 | `0`、`1`、`2`... |
| 数组长度 | 一共有几个格子 | 5 |

---

## 3.1.2 声明一个数组

### 📝 语法

```c
类型 数组名[长度];
```

### 📝 例子

```c
int scores[5];        // 一个能装5个int的柜子
double heights[10];   // 一个能装10个double的柜子
char letters[26];     // 一个能装26个char的柜子
```

### 🧩 拆解来看

```c
int   scores  [5];
 │      │      │
 │      │      └── 长度：一共5个格子
 │      └───────── 数组名：柜子的名字
 └──────────────── 类型：每个格子存 int
```

> 📌 **声明数组时，长度通常是常量**（数字）。格子的类型必须一致——不能一个格子存 int、一个格子存 double。

---

## 3.1.3 访问数组：下标从0开始！

### 📝 用下标访问元素

```c
#include <stdio.h>

int main() {
    int scores[5];
    
    scores[0] = 95;    // 给第1个格子存 95
    scores[1] = 88;    // 给第2个格子存 88
    scores[2] = 72;
    scores[3] = 100;
    scores[4] = 60;
    
    printf("第一个成绩：%d\n", scores[0]);   // 95
    printf("第三个成绩：%d\n", scores[2]);   // 72
    printf("最后一个成绩：%d\n", scores[4]); // 60
    
    return 0;
}
```

输出：
```
第一个成绩：95
第三个成绩：72
最后一个成绩：60
```

### ⚠️ 超级重要：下标从 0 开始！

```
下标：   0    1    2    3    4
        ┌────┬────┬────┬────┬────┐
成绩：  │ 95 │ 88 │ 72 │100 │ 60 │
        └────┴────┴────┴────┴────┘
```

**长度是5的数组，下标范围是 0 ~ 4**（最后一个下标 = 长度 - 1）。

> 🚨 **经典错误：下标越界！**
> 
> ```c
> int scores[5];
> scores[5] = 90;   // ❌ 危险！下标只有 0~4，没有 5！
> ```
> 
> C语言**不会帮你检查越界**！访问 `scores[5]` 会读写数组**外面**的内存，轻则数据错乱，重则程序崩溃。
> 
> 这就像你往只有5个格子的柜子上硬塞第6件东西——可能会碰坏旁边的东西！

## 3.1.4 初始化数组

### 方式一：逐个赋值（先声明后赋值）

```c
int scores[5];
scores[0] = 95;
scores[1] = 88;
// ...
```

### 方式二：声明时用大括号一次给完（推荐）⭐

```c
int scores[5] = {95, 88, 72, 100, 60};
```

**自动对应：**

```
{95, 88, 72, 100, 60}
  0   1   2    3    4   ← 下标
```

### 方式三：让编译器数长度

```c
int scores[] = {95, 88, 72, 100, 60};   // 编译器自动算出长度是5
```

### 📝 其他初始化小技巧

```c
int a[5] = {1, 2, 3, 4, 5};   // 全给
int b[5] = {1, 2};            // 只给前两个，其余自动补 0
int c[5] = {0};               // 全部是 0（很常用！）

// 用循环给数组赋值
int d[10];
for (int i = 0; i < 10; i++) {
    d[i] = i * i;             // 存平方数：0, 1, 4, 9, ...
}
```

## 3.1.5 遍历数组：数组 + 循环 = 黄金搭档

要"逐个处理"数组里的元素，**几乎必须用循环**。

### 📝 遍历输出所有元素

```c
#include <stdio.h>

int main() {
    int scores[5] = {95, 88, 72, 100, 60};
    
    for (int i = 0; i < 5; i++) {
        printf("scores[%d] = %d\n", i, scores[i]);
    }
    
    return 0;
}
```

输出：
```
scores[0] = 95
scores[1] = 88
scores[2] = 72
scores[3] = 100
scores[4] = 60
```

### 🔍 遍历模板（背下来！）

```c
for (int i = 0; i < 数组长度; i++) {
    // 用 scores[i] 处理每个元素
}
```

> 💡 **为什么从 0 到 长度-1？**
> - 开始：`i = 0`（第一个下标）
> - 结束：`i < 长度`（当 i 等于长度时就该停了）
> 
> 这样写就不会越界！

## 3.1.6 实战：数组统计

### 📝 例1：求和与平均分

```c
#include <stdio.h>

int main() {
    int scores[5] = {95, 88, 72, 100, 60};
    
    int sum = 0;
    for (int i = 0; i < 5; i++) {
        sum += scores[i];    // 累加
    }
    
    double average = (double)sum / 5;
    
    printf("总分：%d\n", sum);
    printf("平均分：%.1f\n", average);
    return 0;
}
```

输出：
```
总分：415
平均分：83.0
```

> 💡 注意 `(double)sum / 5`——如果不转换类型，`415 / 5` 是整数除法，但这里想保留小数。

### 📝 例2：找最大值

```c
#include <stdio.h>

int main() {
    int scores[5] = {95, 88, 72, 100, 60};
    
    // 先假设第一个最大
    int max = scores[0];
    
    for (int i = 1; i < 5; i++) {
        if (scores[i] > max) {
            max = scores[i];    // 发现更大的，更新 max
        }
    }
    
    printf("最高分：%d\n", max);
    return 0;
}
```

输出：
```
最高分：100
```

**"找最大值"的套路（很经典）：**
```
1. 先假设第一个是最大的：max = scores[0]
2. 从第二个开始逐个比较
3. 发现有更大的，就更新 max
```

### 📝 例3：统计及格人数

```c
#include <stdio.h>

int main() {
    int scores[5] = {95, 88, 72, 100, 60};
    
    int passCount = 0;
    for (int i = 0; i < 5; i++) {
        if (scores[i] >= 60) {
            passCount++;
        }
    }
    
    printf("及格人数：%d\n", passCount);
    return 0;
}
```

输出：
```
及格人数：5
```

## 3.1.7 数组的"身份证"：sizeof

想数一数组有几个格子，可以用 `sizeof`：

```c
#include <stdio.h>

int main() {
    int scores[] = {95, 88, 72, 100, 60};
    
    // scores 总共占多少字节
    printf("整个数组占：%lu 字节\n", sizeof(scores));
    
    // 一个 int 占多少字节
    printf("一个int占：%lu 字节\n", sizeof(scores[0]));
    
    // 相除 = 元素个数
    int length = sizeof(scores) / sizeof(scores[0]);
    printf("数组长度：%d\n", length);
    
    for (int i = 0; i < length; i++) {
        printf("%d ", scores[i]);
    }
    printf("\n");
    return 0;
}
```

输出（64位系统）：
```
整个数组占：20 字节
一个int占：4 字节
数组长度：5
95 88 72 100 60
```

> 📌 **小知识：** `sizeof` 返回的是"占用多少字节（byte）"。一个 int 通常占 4 字节，5 个就是 20 字节。
> 
> 用 `sizeof(scores) / sizeof(scores[0])` 可以自动算出元素个数，**不用自己数**。
> 
> ⚠️ 但要注意：这个技巧只在**定义数组的同一个作用域**里有效（后面学了"把数组传给函数"你会理解为什么）。

## 3.1.8 数组越界：C的"自由"与"危险"

还记得我们强调下标是 0 ~ 长度-1 吗？C语言有个"传统艺能"——**它不检查你的下标**：

```c
int a[3] = {10, 20, 30};

a[3] = 999;   // ⚠️ 编译器可能只给个警告，甚至什么都不说就让你过
a[100] = 1;   // 🚨 直接读到/写到很远的内存！
```

**后果：**
- 读越界 → 拿到一堆"垃圾值"（不是你存的东西）
- 写越界 → **可能改坏别的变量**，导致奇怪的 bug
- 严重时 → 程序直接崩溃（Segmentation fault）

> 💡 **好习惯：** 每次写循环遍历数组时，都问自己一句：**我的下标会不会超过长度-1？**
> 
> 看到 `for (int i = 0; i < n; i++)` 这种写法，就是安全的标准模板。

## 3.1.9 综合示例：成绩分析

把这一节学的串起来——分析一个班的成绩：

```c
#include <stdio.h>

int main() {
    int scores[] = {85, 92, 78, 65, 100, 54, 88, 76};
    int n = sizeof(scores) / sizeof(scores[0]);
    
    // 1. 求和与平均
    int sum = 0;
    for (int i = 0; i < n; i++) {
        sum += scores[i];
    }
    double average = (double)sum / n;
    
    // 2. 找最高和最低
    int max = scores[0];
    int min = scores[0];
    for (int i = 1; i < n; i++) {
        if (scores[i] > max) max = scores[i];
        if (scores[i] < min) min = scores[i];
    }
    
    // 3. 统计及格人数
    int passCount = 0;
    for (int i = 0; i < n; i++) {
        if (scores[i] >= 60) passCount++;
    }
    
    // 输出报告
    printf("=== 成绩分析报告 ===\n");
    printf("共 %d 人\n", n);
    printf("总分：%d\n", sum);
    printf("平均分：%.1f\n", average);
    printf("最高分：%d\n", max);
    printf("最低分：%d\n", min);
    printf("及格人数：%d\n", passCount);
    printf("及格率：%.1f%%\n", (double)passCount / n * 100);
    
    return 0;
}
```

输出：
```
=== 成绩分析报告 ===
共 8 人
总分：638
平均分：79.8
最高分：100
最低分：54
及格人数：7
及格率：87.5%
```

> 📌 **注意 `%%`：** 想输出一个 `%` 字符要写两个 `%%`，所以 `%.1f%%` 表示"一位小数的百分数 + %"。

## 3.1.10 本节小结

这一节我们学了：

✅ **数组是什么：** 多个相同类型数据的"大柜子"，一个名字 + 下标管理

✅ **声明数组：** `int scores[5];`

✅ **下标从0开始：** 长度5的数组，下标是 0~4

✅ **初始化：** `int scores[5] = {95, 88, 72, 100, 60};`

✅ **遍历：** 数组 + for 循环是黄金搭档，模板 `for (i=0; i<n; i++)`

✅ **统计套路：** 求和、找最大最小、统计个数

✅ **越界危险：** C不检查下标，千万别越界！

> 💡 **记住：数组就是那个"超级大柜子"，循环就是你的"搬运工"！**

**6. 以下程序有4个错误，请找出并改正（目标是计算数组所有元素的和）：**

```c
#include <stdio.h>

int main() {
    int nums[5] = {1, 2, 3, 4, 5};
    
    int sum = 0;

```
