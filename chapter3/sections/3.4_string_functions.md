# 3.4 字符串函数与实战

> 💬 **节前语：**
>
> 上一节我们搞清楚了字符串的"真身"：**字符数组 + 结束符 `'\0'`**。
>
> 但问题来了——字符串**不能直接比、不能直接加、不能直接赋值**：
>
> ```c
> if (s1 == s2)        // ❌ 这不是比内容，是比地址！
> s3 = s1;             // ❌ 数组不能整体赋值
> ```
>
> 那平时到底怎么处理字符串？答案是 C 标准库 `<string.h>` 里的一群现成函数：`strlen`、`strcpy`、`strcat`、`strcmp`。
>
> 这一节我们就学它们，再把"多个字符串放一起""常见坑"和综合小例子一次补齐。准备好了吗？开始吧！

## 3.4.1 常用字符串函数（string.h）

处理字符串很麻烦（不能直接 `==`、`+`），好在C语言提供了现成的函数。都在 `<string.h>` 里：

| 函数 | 作用 | 例子 |
|------|------|------|
| `strlen(s)` | 求长度 | `strlen("abc")` → 3 |
| `strcpy(目标, 来源)` | 复制字符串 | `strcpy(dest, src)` |
| `strcat(目标, 来源)` | 拼接字符串 | `strcat(dest, src)` |
| `strcmp(a, b)` | 比较字符串 | 相等返回0 |

### 📝 strlen：求长度

```c
#include <stdio.h>
#include <string.h>

int main() {
    char s[] = "Hello";
    printf("长度：%lu\n", strlen(s));   // 5
    return 0;
}
```

### 📝 strcpy：复制字符串

> ⚠️ **字符串不能直接赋值！** `s2 = s1;` 是错的（数组不能整体赋值），必须用 `strcpy`。

```c
#include <stdio.h>
#include <string.h>

int main() {
    char s1[] = "Hello";
    char s2[20];       // 目标要够大！
    
    // s2 = s1;  ← ❌ 错误！数组不能这样整体赋值
    strcpy(s2, s1);    // ✅ 用函数复制
    
    printf("%s\n", s2);
    return 0;
}
```

输出：
```
Hello
```

### 📝 strcat：拼接字符串

```c
#include <stdio.h>
#include <string.h>

int main() {
    char dest[30] = "Hello";    // 目标必须留够空间！
    
    strcat(dest, " World");     // 在 dest 后面接上 " World"
    
    printf("%s\n", dest);       // Hello World
    return 0;
}
```

输出：
```
Hello World
```

> ⚠️ `strcat` 会把字符串**接在目标后面**，所以目标数组要**预留足够的空间**，否则会越界！

### 📝 strcmp：比较字符串

> ⚠️ **字符串不能直接比！** `s1 == s2` 比较的是地址而不是内容（指针的知识后面会学）。必须用 `strcmp`。

```c
#include <stdio.h>
#include <string.h>

int main() {
    char a[] = "abc";
    char b[] = "abc";
    char c[] = "abd";
    
    printf("%d\n", strcmp(a, b));   // 0（相等）
    printf("%d\n", strcmp(a, c));   // 负数（a < c）
    printf("%d\n", strcmp(c, a));   // 正数（c > a）
    
    if (strcmp(a, b) == 0) {
        printf("a 和 b 相同！\n");
    }
    return 0;
}
```

输出：
```
0
-1
1
a 和 b 相同！
```

> 💡 **记忆：** `strcmp` 返回 **0 表示相等**（正好和 `==` 的习惯相反，别搞混！）。
> 
> 判断相等要写 `if (strcmp(a, b) == 0)`，别写成 `if (strcmp(a, b))`（那表示"不相等"）。

## 3.4.2 字符串数组：装很多个字符串

还记得 3.2 节最后那个"先睹为快"吗？用**二维字符数组**可以装多个字符串：

```c
#include <stdio.h>

int main() {
    char fruits[3][20] = {
        "苹果",
        "香蕉",
        "橙子"
    };
    
    for (int i = 0; i < 3; i++) {
        printf("第 %d 个水果：%s\n", i, fruits[i]);
    }
    
    return 0;
}
```

输出：
```
第 0 个水果：苹果
第 1 个水果：香蕉
第 2 个水果：橙子
```

**理解：**
```
fruits[0] → "苹果"
fruits[1] → "香蕉"
fruits[2] → "橙子"
```

> 📌 `char fruits[3][20]` = 3 个字符串，每个最多放 19 个字符（要留一个给 `'\0'`）。
> 
> 使用 `fruits[i]` 就得到第 i 个字符串。

## 3.4.3 常见的坑

### 🚨 坑1：数组不够大

```c
char s[5];
strcpy(s, "Hello");     // "Hello" 需要 6 个字节（含'\0'）！s 只有5，越界！
```

**解决：** 数组要比最长字符串**至少多1**（留给 `'\0'`）。

### 🚨 坑2：忘了 '\0'

```c
char s[3];
s[0] = 'H';
s[1] = 'i';
// 忘了 s[2] = '\0';  ← 没结束符！
printf("%s", s);   // 会打印 "Hi" 后面跟一堆乱码！
```

### 🚨 坑3：比较和赋值用错了符号

```c
if (s1 == s2)      // ❌ 这是在比地址！
if (strcmp(s1, s2) == 0)   // ✅ 这才是比内容

s2 = s1;           // ❌ 数组不能整体赋值
strcpy(s2, s1);    // ✅ 用函数复制
```

## 3.4.4 综合示例：单词计数器

利用字符串以 `'\0'` 结尾的特性，我们**不靠 strlen**，自己统计单词里有多少个字母：

```c
#include <stdio.h>

int main() {
    char word[] = "programming";
    
    int count = 0;
    while (word[count] != '\0') {
        count++;
    }
    
    printf("单词：%s\n", word);
    printf("字母个数：%d\n", count);
    return 0;
}
```

输出：
```
单词：programming
字母个数：11
```

**再看一个"找字符"的例子：**

```c
#include <stdio.h>

int main() {
    char sentence[] = "C is fun";
    
    // 找出第一个空格的位置
    int pos = -1;
    for (int i = 0; sentence[i] != '\0'; i++) {
        if (sentence[i] == ' ') {
            pos = i;
            break;
        }
    }
    
    if (pos >= 0) {
        printf("第一个空格在第 %d 个位置\n", pos);
    } else {
        printf("没有空格\n");
    }
    return 0;
}
```

输出：
```
第一个空格在第 1 个位置
```

## 3.4.5 本节小结

这一节我们学了：

✅ **string.h 四件套：** `strlen` 长度、`strcpy` 复制、`strcat` 拼接、`strcmp` 比较（相等返回 0）

✅ **字符串不能 `==`/`=`：** 比内容用 `strcmp(...) == 0`，复制用 `strcpy`

✅ **字符串数组：** `char fruits[3][20]` 一次装多个字符串

✅ **三大坑：** 数组不够大、忘了 `'\0'`、比较赋值用错符号

✅ **综合实战：** 自己数长度、找空格——理解"字符串以 `'\0'` 结尾"有多好用

> 💡 **记住：处理字符串，凡是"比、复制、拼接"，都交给 `<string.h>` 的现成函数，别自己硬写。**

### 三、改错题

**6. 以下程序有 4 个错误（目标是打印 "Hello World"）：**

```c
#include <stdio.h>
#include <string.h>

int main() {
    char s1[] = "Hello";
    char s2[5];         // 错误区①：空间够吗？
    s2 = s1;            // 错误区②：能这样赋值吗？

    char s3[] = " World";
    strcat(s2, s3);

    if (s2 == "Hello World") {    // 错误区③：比较方式？
        printf("%s\n", s2);
    }
    printf("%s\n", s2);           // 错误区④：本意就是打印 s2
    return 0;
}
```

> 提示：数组空间要够；复制用 `strcpy`；比较内容用 `strcmp`；末尾多余的分支/判断删掉即可。
