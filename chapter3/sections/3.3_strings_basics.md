## 3.3.1 字符串的本质：字符数组 + 结束符

### 🎯 猜一猜：字符串存在哪？

在C语言里，字符串 `"Hello"` 实际上是一个**字符数组**：

```
下标：  0     1     2     3     4     5
      ┌─────┬─────┬─────┬─────┬─────┬─────┐
字符： │ 'H' │ 'e' │ 'l' │ 'l' │ 'o' │ '\0'│
      └─────┴─────┴─────┴─────┴─────┴─────┘
```

**发现了什么？**
- 5个可见字符 `H e l l o`
- 但数组长度是 **6**！
- 最后多了一个特殊的字符 **`'\0'`**（空字符）

> 📌 **`'\0'` 就是字符串的"句号"！**
> 
> 它告诉程序："字符串到这里就结束了"。程序遇到 `'\0'` 就知道后面不用再读了。
> 
> `'\0'` 的 ASCII 码是 **0**，和数字0、字符`'0'`（ASCII码48）都**不一样**！

> 📖 **术语卡：ASCII —— 字符和数字的"对照表"**
> 
> 计算机只认数字，那 `'A'`、`'a'`、`'0'` 这些字符怎么存？答案是一张**对照表**：每个字符对应一个数字编号。这张最经典的对照表就叫 **ASCII**（American Standard Code for Information Interchange）。
> 
> ```c
> 'A' → 65      'B' → 66      ...      'Z' → 90
> 'a' → 97      'b' → 98      ...      'z' → 122
> '0' → 48      '1' → 49      ...
> '\0' → 0      （空格' ' → 32，换行'\n' → 10）
> ```
> 
> **有用的小秘密：** 大写和小写字母正好差 32（65→97）。所以 `'a' - 'a' + 'A'` 能把小写变大写（第3章末尾的 toUpper 函数就用到了）！
> 
> > 注：ASCII 只覆盖英文和符号；中文用的是更现代的 **UTF-8** 编码（向下兼容 ASCII），一个汉字通常占 3 个字节。所以 `strlen("小明")` 的结果常是 6 而不是 2，这是编码原因，不是 bug。

## 3.3.2 声明和初始化字符串

### 📝 最常见的方式：直接用双引号

```c
char name[] = "小明";        // 编译器自动分配，并自动加上 '\0'
char greeting[] = "Hello";
```

编译器会自动把它展开成字符数组并加 `'\0'`。

### 📝 也可以显式写出字符数组

```c
char word[] = {'H', 'e', 'l', 'l', 'o', '\0'};   // 手动加结束符
```

> ⚠️ **如果写成 `char word[] = {'H','e','l','l','o'};`（忘了 `'\0'`），它就不是一个合格的字符串了！** 程序打印时会一直往后读，直到撞上一个碰巧是0的字节为止，可能输出一堆乱码。**一定要加 `'\0'`！**

### 🧩 拆解：单字符 vs 字符串

| 写法 | 类型 | 内存里 | 说明 |
|------|------|--------|------|
| `'A'` | `char` | 1字节：`A` | 单个字符 |
| `"A"` | 字符串 | 2字节：`A` `'\0'` | 是数组！有结束符 |

```c
char c = 'A';              // ✅ 单个字符
char s[] = "A";            // ✅ 字符串（其实包含 'A' 和 '\0'）
```

> 📌 **注意引号区别：** `'A'` 用单引号（一个字符），`"A"` 用双引号（字符串）。

## 3.3.3 打印字符串：%s

### 📝 用 %s 打印整个字符串

```c
#include <stdio.h>

int main() {
    char name[] = "小明";
    char hobby[] = "编程";
    
    printf("我叫%s，我喜欢%s！\n", name, hobby);
    return 0;
}
```

输出：
```
我叫小明，我喜欢编程！
```

### 📝 逐个字符打印：遇到 '\0' 停

```c
#include <stdio.h>

int main() {
    char word[] = "Hello";
    
    for (int i = 0; word[i] != '\0'; i++) {
        printf("%c", word[i]);
    }
    printf("\n");
    
    return 0;
}
```

输出：
```
Hello
```

> 💡 **`word[i] != '\0'` 是遍历字符串的经典写法**——读到结束符就停。

## 3.3.4 字符数组 vs 字符串的长度

### 🤔 两个"长度"不一样！

```c
char s[] = "Hello";
```

| 概念 | 值 | 怎么算 |
|------|-----|--------|
| 数组实际大小 | 6 | `sizeof(s)`，包含 `'\0'` |
| 字符串长度 | 5 | `strlen(s)`，**不含** `'\0'` |

```c
#include <stdio.h>
#include <string.h>    // strlen 需要这个头文件！

int main() {
    char s[] = "Hello";
    
    printf("数组大小：%lu\n", sizeof(s));      // 6（含'\0'）
    printf("字符串长度：%lu\n", strlen(s));    // 5（不含'\0'）
    return 0;
}
```

输出：
```
数组大小：6
字符串长度：5
```

> 📌 **`strlen`（string length）** 返回字符串中字符的个数，**不数 `'\0'`**。注意它来自 `<string.h>`。

> ⚠️ 中文的小知识：在 UTF-8 编码下，一个汉字通常占 3 个字节。所以 `strlen("小明")` 的结果通常是 6，而不是 2。这不是bug，是编码的原因。我们先不深究，用英文短字符串时最直观。

---

## 3.3.5 本节小结

这一节我们学了：

✅ **字符串本质：** 字符数组 + 结束符 `'\0'`（ASCII 0）

✅ **ASCII：** 字符和数字的对照表，`'A'=65`、`'a'=97`；大写小写差 32

✅ **声明：** `char name[] = "小明";` 编译器自动加 `'\0'`

✅ **`'A'` vs `"A"`：** 单引号一个字符、双引号是字符串（自带结束符）

✅ **打印/遍历：** `%s` 整体打印；`for (...; s[i] != '\0'; i++)` 逐字符读到结束符停

✅ **两种长度：** `sizeof`（含 `'\0'`）vs `strlen`（不含，来自 string.h）

> 💡 **记住：没有`'\0'` 就不是合格的字符串。把字符串看成"带句号的字符数组"，一切就都顺了。**
