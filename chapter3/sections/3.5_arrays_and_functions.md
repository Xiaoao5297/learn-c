## 3.5.1 普通变量 vs 数组：传法不一样！

### 🤔 先看普通变量

还记得第2章说的"值传递"吗？

```c
#include <stdio.h>

void tryChange(int x) {
    x = 999;    // 修改的是"副本"
}

int main() {
    int num = 10;
    tryChange(num);       // 把 num 的"值"复制了一份传给函数
    printf("num = %d\n", num);   // 还是 10！
    return 0;
}
```

输出：
```
num = 10
```

**原因：** `tryChange(num)` 是把 num 的**值复制一份**交给函数里的 x。函数改 x，跟外面的 num 没关系。

### 🤔 再看数组

数组传参，行为**完全不同**！

```c
#include <stdio.h>

void tryChangeArray(int arr[], int n) {
    arr[0] = 999;    // 直接改数组的第0个
}

int main() {
    int nums[3] = {1, 2, 3};
    tryChangeArray(nums, 3);
    printf("nums[0] = %d\n", nums[0]);   // 变成了 999！
    return 0;
}
```

输出：
```
nums[0] = 999
```

**数组被函数改了！**

> 🎯 **关键区别：**
> 
> - 传普通变量 → **复制一份值**（副本），函数改了不影响外面
> - 传数组 → **传的是地址**（柜子的"钥匙"），函数拿到钥匙，能直接改柜子里的东西！
> 
> 所以数组函数里一改，外面的数组就跟着变了。

> 📌 **为什么？** 因为数组可能很大（几百上千个元素），如果每次传参都"复制一整个柜子"，太浪费内存和时间。C语言干脆**只传柜子的地址**，大家共享同一份数据。
> 
> （下一章学指针后，你会彻底明白"地址"是怎么回事。）

## 3.5.2 怎么把数组传给函数？

### 📝 语法

```c
// 函数定义：参数写 类型 数组名[]
void printArray(int arr[], int n) {
    // ...
}
```

**注意两点：**
1. 参数写成 `int arr[]`（不用写长度，因为传进来的其实是地址）
2. **必须再传一个 `n`（长度）**！函数里无法用 `sizeof` 数出长度（后面解释）

### 📝 第一个例子：打印数组函数

```c
#include <stdio.h>

// 打印数组：arr 是要打印的数组，n 是它的长度
void printArray(int arr[], int n) {
    for (int i = 0; i < n; i++) {
        printf("%d ", arr[i]);
    }
    printf("\n");
}

int main() {
    int scores[5] = {95, 88, 72, 100, 60};
    int heights[3] = {170, 165, 180};
    
    printArray(scores, 5);    // 打印第一个数组
    printArray(heights, 3);   // 打印第二个数组
    
    return 0;
}
```

输出：
```
95 88 72 100 60 
170 165 180 
```

> 💡 **看到好处了吗？** 一个 `printArray` 函数，想打印哪个数组都行——只要把数组名和长度告诉它！

### 📝 调用时直接写数组名

```c
printArray(scores, 5);
        │       │
        │       └── 数组长度（必须一起给！）
        └───────── 数组名（不用加 [ ]）
```

## 3.5.3 实战：把统计功能封装成函数

### 📝 求数组元素之和

```c
#include <stdio.h>

int sumArray(int arr[], int n) {
    int sum = 0;
    for (int i = 0; i < n; i++) {
        sum += arr[i];
    }
    return sum;
}

int main() {
    int scores[5] = {95, 88, 72, 100, 60};
    
    int total = sumArray(scores, 5);
    printf("总和：%d\n", total);
    return 0;
}
```

输出：
```
总和：415
```

### 📝 找最大值（返回值和下标）

C函数一次只能返回一个值，那"最大值"和"它的位置"都想拿到怎么办？——**用数组把它带出来**：

```c
#include <stdio.h>

// 返回最大值，同时把它的下标存到 *index 指向的地方
// 这里先留个悬念：& 和 * 是下一章的指针，先照着用！
int maxArray(int arr[], int n, int *index) {
    int max = arr[0];
    *index = 0;
    for (int i = 1; i < n; i++) {
        if (arr[i] > max) {
            max = arr[i];
            *index = i;
        }
    }
    return max;
}

int main() {
    int scores[5] = {95, 88, 72, 100, 60};
    int pos;
    
    int max = maxArray(scores, 5, &pos);
    printf("最大值：%d\n", max);
    printf("它在第 %d 个位置\n", pos);
    return 0;
}
```

输出：
```
最大值：100
它在第 3 个位置
```

> 📌 **看不懂 `&pos` 和 `*index`？** 完全正常！它叫**指针**，下一章我们专门学。现在你只需要知道：**用 `&变量` 把"地址"传进函数，函数就能修改外面的变量**——这是解决"C函数只能返回一个值"的经典技巧。

## 3.5.4 修改数组：函数内部改，外面跟着变

因为传的是地址，所以函数**能直接修改原数组**。利用这个特性，我们可以写"改造数组"的函数：

### 📝 把所有元素翻倍

```c
#include <stdio.h>

void doubleAll(int arr[], int n) {
    for (int i = 0; i < n; i++) {
        arr[i] = arr[i] * 2;    // 每个元素×2
    }
}

int main() {
    int nums[4] = {1, 2, 3, 4};
    
    printf("翻倍前：");
    for (int i = 0; i < 4; i++) printf("%d ", nums[i]);
    printf("\n");
    
    doubleAll(nums, 4);    // 传入数组
    
    printf("翻倍后：");
    for (int i = 0; i < 4; i++) printf("%d ", nums[i]);
    printf("\n");
    
    return 0;
}
```

输出：
```
翻倍前：1 2 3 4 
翻倍后：2 4 6 8 
```

> 💡 **设计函数的思路：**
> - 只想"读取"数组 → 函数里别改数组，就当它是"只读"的
> - 想"修改"数组 → 放心改，外面会同步

## 3.5.5 传字符串给函数

字符串就是字符数组，传给函数一样是传地址，函数里可以随意修改：

```c
#include <stdio.h>

// 把字符串全部变成大写（只处理小写字母）
void toUpper(char s[]) {
    for (int i = 0; s[i] != '\0'; i++) {
        if (s[i] >= 'a' && s[i] <= 'z') {
            s[i] = s[i] - 'a' + 'A';    // 小写转大写的小技巧
        }
    }
}

int main() {
    char message[] = "hello world";
    
    toUpper(message);
    
    printf("%s\n", message);
    return 0;
}
```

输出：
```
HELLO WORLD
```

**注意：**
- 遍历字符串**不用传长度**！因为字符串自带 `'\0'` 结束符，遇到它就知道结束了
- 字符 `'a'` 到 `'z'` 在ASCII里是连续的，所以 `'b' - 'a' + 'A'` 就能算出对应的大写字母

## 3.5.6 为什么函数里不能用 sizeof 数长度？

还记得 3.1 节说"`sizeof` 技巧只在定义数组的地方有效"吗？现在揭晓原因：

```c
#include <stdio.h>

void test(int arr[], int n) {
    printf("函数里 sizeof(arr) = %lu\n", sizeof(arr));
    printf("函数里 sizeof(arr[0]) = %lu\n", sizeof(arr[0]));
}

int main() {
    int nums[5] = {1, 2, 3, 4, 5};
    
    printf("main 里 sizeof(nums) = %lu\n", sizeof(nums));
    
    test(nums, 5);
    return 0;
}
```

输出（64位系统）：
```
main 里 sizeof(nums) = 20
函数里 sizeof(arr) = 8
函数里 sizeof(arr[0]) = 4
```

**看到了吗？**
- main 里：`sizeof(nums)` = 20（5个int × 4字节）→ 能数出5个
- 函数里：`sizeof(arr)` = 8！这是**一个地址（指针）**的大小，跟数组有几个元素没关系

> 🎯 **结论：** 数组作为参数传进函数后，`arr` 其实已经**退化成"地址"**了——它只"记得"数组在哪，不"记得"数组多大。
> 
> 所以函数**必须额外接收一个长度参数 `n`**：
> ```c
> void printArray(int arr[], int n)   // ✅ 一定要有 n！
> ```

## 3.5.7 综合示例：班级成绩分析函数版

把 3.1 节的"成绩分析"，全部改写成函数版：

```c
#include <stdio.h>

// 函数声明
double average(int arr[], int n);
int maxValue(int arr[], int n);
int minValue(int arr[], int n);
int countPass(int arr[], int n);
void printArray(int arr[], int n);

int main() {
    int scores[] = {85, 92, 78, 65, 100, 54, 88, 76};
    int n = sizeof(scores) / sizeof(scores[0]);   // 在 main 里用 sizeof 数长度没问题
    
    printf("成绩：");
    printArray(scores, n);
    
    printf("平均分：%.1f\n", average(scores, n));
    printf("最高分：%d\n", maxValue(scores, n));
    printf("最低分：%d\n", minValue(scores, n));
    printf("及格人数：%d\n", countPass(scores, n));
    
    return 0;
}

double average(int arr[], int n) {
    int sum = 0;
    for (int i = 0; i < n; i++) sum += arr[i];
    return (double)sum / n;
}

int maxValue(int arr[], int n) {
    int max = arr[0];
    for (int i = 1; i < n; i++) {
        if (arr[i] > max) max = arr[i];
    }
    return max;
}

int minValue(int arr[], int n) {
    int min = arr[0];
    for (int i = 1; i < n; i++) {
        if (arr[i] < min) min = arr[i];
    }
    return min;
}

int countPass(int arr[], int n) {
    int count = 0;
    for (int i = 0; i < n; i++) {
        if (arr[i] >= 60) count++;
    }
    return count;
}

void printArray(int arr[], int n) {
    for (int i = 0; i < n; i++) {
        printf("%d ", arr[i]);
    }
    printf("\n");
}
```

输出：
```
成绩：85 92 78 65 100 54 88 76 
平均分：79.8
最高分：100
最低分：54
及格人数：7
```

> 💡 **发现了吗？** main 现在像一份"目录"：打印、算平均、找最大最小、数及格——每一项都是一行函数调用，清清楚楚！
> 
> 以后想加功能（比如"优秀人数"），只需再写一个小函数就行，不用动 main 的大逻辑。

## 3.5.8 本节小结

这一节我们学了：

✅ **数组传参传的是"地址"：** 函数改数组，外面的数组会跟着变

✅ **普通变量传的是"值"：** 函数改参数，不影响外面

✅ **语法：** `void printArray(int arr[], int n)`，**必须带长度参数 n**

✅ **调用：** `printArray(nums, 4)` 直接写数组名

✅ **传字符串：** `void f(char s[])`，靠 `'\0'` 判断结束，不用传长度

✅ **`&` 和 `*` 的预告：** 用它可以让函数"改外面的变量"，下一章学

✅ **sizeof 失效的原因：** 函数里的数组名已退化成"地址"

> 💡 **记住：传数组 = 给钥匙（共享柜子）；传普通变量 = 给复印件！下一章指针会让你彻底看穿这一切！**

### 三、改错题

**6. 以下程序想打印数组并求总和，有4个错误，请找出并改正：**

```c
#include <stdio.h>

void printArray(int arr[], int n) {
    for (int i = 0; i < n; i++) {
        printf("%d ", arr[i])
    }
    printf("\n");
}

int sumArray(int arr[]) {     // 错误区①：没传长度，函数里数不出大小
    int sum = 0;
    int n = sizeof(arr) / sizeof(arr[0]);   // 错误区②：这里算出来是错的！
    for (int i = 0; i < n; i++) {
        sum += arr[i];
    }
    return sum;
}

int main() {
    int nums[4] = {1, 2, 3, 4};
    printArray(nums);         // 错误区③：调用少了长度
    printf("总和：%d\n", sumArray(nums, 4));   // 错误区④：调用多了参数
    return 0;
}
```

> 提示：重点是把"长度"这个参数补对。
