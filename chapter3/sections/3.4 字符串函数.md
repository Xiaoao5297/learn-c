# 3.4 字符串函数

3.3 说明了字符串是“以 `'\0'` 结尾的字符数组”。手工处理字符数组既繁琐又容易越界，所以标准库提供了 `<string.h>`。这一节讲最常用的几个函数，以及哪些函数用起来有坑。

## 3.4.1 string.h 速览

| 函数 | 作用 | 返回值 |
|------|------|--------|
| `strlen(s)` | 求长度（不含 `'\0'`） | `size_t` |
| `strcpy(dst, src)` | 把 `src` 复制到 `dst`（不安全，见 3.4.3） | `char *` |
| `strncpy(dst, src, n)` | 最多复制 `n` 个字符（较安全，有坑） | `char *` |
| `strcat(dst, src)` | 把 `src` 拼接到 `dst` 末尾（不安全，见 3.4.6） | `char *` |
| `strcmp(a, b)` | 比较两个字符串 | 负数 / 0 / 正数 |
| `strstr(s, sub)` | 查找子串首次出现的位置 | 找到返回地址，找不到返回 `NULL` |

使用前要 `#include <string.h>`。下面逐个过一遍。

## 3.4.2 strlen：求长度

3.3.3 已经用过，这里补一个用途：配合循环逐个处理字符。

```c
// 3.4.2 strlen_chars.c
#include <stdio.h>
#include <string.h>

int main(void)
{
	char s[] = "hello";
	size_t length = strlen(s);

	printf("长度是 %zu\n", length);

	for (size_t i = 0; i < length; i++) {
		printf("s[%zu] = %c\n", i, s[i]);
	}

	return 0;
}
```

<!-- output: 3.4.2 -->
```text
长度是 5
s[0] = h
s[1] = e
s[2] = l
s[3] = l
s[4] = o
```

这里循环变量用了 `size_t`：`strlen` 的返回值和 `sizeof` 一样是这个类型，用它做下标比较时类型一致，不会产生编译警告。

## 3.4.3 strcpy：能复制，但不安全

把字符串复制进另一个数组，最直觉的函数是 `strcpy(dst, src)`：把 `src` 的内容（连同 `'\0'`）整个搬进 `dst`。

想象搬家工人把整箱书从旧柜子搬进新柜子：他们只管搬完，**从不过问新柜子装不装得下**。箱子小的时候侥幸没事，哪天书变多了，塞不下的书就砸到柜子外面去了。这就是 `strcpy` 不安全的根源。

```c
// 3.4.3 strcpy_demo.c
#include <stdio.h>
#include <string.h>

int main(void)
{
	char src[] = "hello";
	char dst[6];

	strcpy(dst, src);
	printf("dst = %s\n", dst);

	return 0;
}
```

<!-- output: 3.4.3 -->
```text
dst = hello
```

这段代码没问题，是因为 `dst` 恰好够大。危险在于：**`strcpy` 完全不检查 `dst` 装不装得下**。`src` 哪天变长，这行代码就会把多出来的字符写进 `dst` 数组外面——缓冲区溢出，3.3.4 讲过的那类灾难。

所以工程上的规矩是：**不使用 `strcpy`**（也不使用下一节的 `strcat`）。下面两节给出两个替代方案。

## 3.4.4 strncpy：有限复制，有坑

`strncpy(dst, src, n)` 最多复制 `n` 个字节，看起来安全。但它有一个著名的坑：**如果 `src` 的长度不小于 `n`，`strncpy` 不会写入 `'\0'`，`dst` 就不是合法字符串**，后续的 `printf("%s")` 会越界读下去。

所以用 `strncpy` 要自己补结束符：

```c
// 3.4.4 strncpy_demo.c
#include <stdio.h>
#include <string.h>

int main(void)
{
	char src[] = "hello world";
	char dst[6];

	strncpy(dst, src, sizeof(dst) - 1);
	dst[sizeof(dst) - 1] = '\0';

	printf("dst = %s\n", dst);
	printf("strlen(dst) = %zu\n", strlen(dst));

	return 0;
}
```

<!-- output: 3.4.4 -->
```text
dst = hello
strlen(dst) = 5
```

`sizeof(dst) − 1` 个字节放内容，最后一个字节永远自己写 `'\0'`，两行配合才安全。漏掉第二行，程序就在赌 `dst` 后面的内存恰好是 0。

## 3.4.5 snprintf：推荐的复制方式

`snprintf` 来自 `<stdio.h>`。它按格式生成字符串，并保证结尾一定是 `'\0'`：

```c
// 3.4.5 snprintf_demo.c
#include <stdio.h>
#include <string.h>

int main(void)
{
	char src[] = "hi";
	char dst[6];

	snprintf(dst, sizeof(dst), "%s", src);

	printf("dst = %s\n", dst);
	printf("strlen(dst) = %zu\n", strlen(dst));

	return 0;
}
```

<!-- output: 3.4.5 -->
```text
dst = hi
strlen(dst) = 2
```

`snprintf(dst, sizeof(dst), "%s", src)` 的含义：把 `src` 按格式写进 `dst`，最多占 `sizeof(dst)` 个字节（含 `'\0'`），放不下就截断。这个例子里 `"hi"` 只有 2 个字符，`dst[6]` 装得下；如果 `src` 是 `"hello world"` 这样的长字符串，`snprintf` 也不会写越界——它会只把前 5 个字符放进 `dst`，补上 `'\0'`，其余丢弃。一行顶 `strncpy` 加补零两行，且无坑。**初学阶段复制字符串优先 `snprintf`**。

## 3.4.6 strcat：拼接与它的风险

`strcat(dst, src)` 把 `src` 接到 `dst` 现有内容的后面。它和 `strcpy` 犯的是同一种错：不检查 `dst` 剩余空间。

```c
// 3.4.6 strcat_demo.c
#include <stdio.h>
#include <string.h>

int main(void)
{
	char greeting[20] = "你好，";
	char name[] = "C 语言";

	strcat(greeting, name);
	printf("%s\n", greeting);
	printf("strlen(greeting) = %zu\n", strlen(greeting));

	return 0;
}
```

<!-- output: 3.4.6 -->
```text
你好，C 语言
strlen(greeting) = 17
```

算一笔账（UTF-8）：`"你好，"` 是 3 个汉字，各占 3 字节，共 9 字节；`"C 语言"` 是字母 `C`、空格和 2 个汉字，占 1 + 1 + 3 + 3 = 8 字节。拼接后内容 17 字节，加 `'\0'` 共 18 字节，`greeting` 的 20 字节装得下。

但只要数组再小一点，`strcat` 就会静默越界。它和 `strcpy` 一样，列入“工程上不用”的名单。

## 3.4.7 strncat：带上限的拼接

安全的替代是 `strncat(dst, src, n)`——它比 `strncpy` 贴心：**追加完 `src`（或 `n` 个字节）之后，一定会补上 `'\0'`**：

```c
// 3.4.7 strncat_demo.c
#include <stdio.h>
#include <string.h>

#define SIZE 20

int main(void)
{
	char greeting[SIZE] = "你好，";
	char name[] = "C 语言";
	size_t used = strlen(greeting);

	strncat(greeting, name, SIZE - used - 1);

	printf("%s\n", greeting);

	return 0;
}
```

<!-- output: 3.4.7 -->
```text
你好，C 语言
```

`SIZE − used − 1` 的意思是：总空间减去已用长度，再留 1 字节给 `'\0'`。这个公式适用于所有“追加”场景，记下来。

## 3.4.8 strcmp：比较字符串

两个字符串能不能用 `==` 比较？不能。`s1 == s2` 比较的是**地址**（数组名转换成的首元素地址，3.1.7 讲过），不是内容。比较内容必须用 `strcmp`：

用生活场景打个比方：两张内容一模一样的抄写作业，是“两张不同的纸”还是“同一张纸”？`==` 检查的是后者（是不是同一张纸），`strcmp` 检查的是前者（写的内容是否相同）。两张纸内容一样，但纸显然是两张——所以 `==` 返回“不是同一张”，即使内容完全相同。

```c
// 3.4.8 strcmp_demo.c
#include <stdio.h>
#include <string.h>

int main(void)
{
	char a[] = "apple";
	char b[] = "apple";
	char c[] = "banana";

	if (strcmp(a, b) == 0) {
		printf("a 和 b 内容相同\n");
	}
	if (strcmp(a, c) < 0) {
		printf("a 排在 c 前面\n");
	}
	if (strcmp(c, a) > 0) {
		printf("c 排在 a 后面\n");
	}

	return 0;
}
```

<!-- output: 3.4.8 -->
```text
a 和 b 内容相同
a 排在 c 前面
c 排在 a 后面
```

`strcmp` 按**字典序**逐字符比较（实际比较的是字符编码值），返回值只有三种含义：

比较过程就像老师在点名册上找名字：从第一个字母开始逐个比，比到第一个不同的字母立刻分出先后（"apple" 和 "banana" 第一个字母就分出胜负）；一路全同才算“同名同姓”，返回 0。这和查词典排单词的顺序一模一样。

| 返回值 | 含义 |
|--------|------|
| 负数（`< 0`） | 第一个字符串排在前面 |
| `0` | 内容完全相同 |
| 正数（`> 0`） | 第一个字符串排在后面 |

**不要假设具体是 −1 或 1**。不同实现可能返回任意负数、任意正数，判断只写 `== 0`、`< 0`、`> 0`，不要写 `== -1`。

比较中文同样适用（按 UTF-8 字节序比较），但“字典序”对汉字没有英语那么直观，初学阶段知道能比、结果非 0 即不同就够了。

## 3.4.9 strstr：查找子串

`strstr(s, sub)` 在 `s` 里找 `sub` 第一次出现的位置。返回的是**地址**：找到返回指向那个位置的指针，找不到返回 `NULL`。

```c
// 3.4.9 strstr_demo.c
#include <stdio.h>
#include <string.h>

int main(void)
{
	char text[] = "I love C programming";
	char word[] = "C";

	char *pos = strstr(text, word);

	if (pos != NULL) {
		printf("找到了，从第 %d 个字符开始\n", (int)(pos - text));
		printf("剩下的内容：%s\n", pos);
	} else {
		printf("没找到\n");
	}

	return 0;
}
```

<!-- output: 3.4.9 -->
```text
找到了，从第 7 个字符开始
剩下的内容：C programming
```

两个新东西：

1. `char *pos` 是一个指向 `char` 的指针变量，用来接住 `strstr` 返回的地址。指针的完整话题在第 4 章，这里只需要会用“和 `NULL` 比较”以及“两个地址相减”这两个动作。
2. `pos − text` 是“这个地址离字符串开头多少个字符”，得到出现位置的下标。

## 3.4.10 动手实现 my_strlen

这些库函数并不神秘。自己写一遍，既理解了 `'\0'` 的作用，也为 3.5 的“数组与函数”和第 6 章的函数设计做铺垫。

`my_strlen`：从开头走，数到 `'\0'` 为止：

```c
// 3.4.10 my_strlen.c
#include <stdio.h>
#include <string.h>

size_t my_strlen(const char s[])
{
	size_t count = 0;

	while (s[count] != '\0') {
		count++;
	}

	return count;
}

int main(void)
{
	char s[] = "hello";

	printf("my_strlen = %zu\n", my_strlen(s));
	printf("strlen    = %zu\n", strlen(s));

	return 0;
}
```

<!-- output: 3.4.10 -->
```text
my_strlen = 5
strlen    = 5
```

参数写成 `const char s[]`：`const` 表示函数承诺不修改字符串内容（呼应 2.6 的规范）。`[]` 写法读起来像“传进来一个字符序列”，它的真实含义下一节就揭晓。

## 3.4.11 动手实现 my_strcmp

`my_strcmp`：逐字符比较，出现不同立刻分出大小；一路相同则比谁先到 `'\0'`：

```c
// 3.4.11 my_strcmp.c
#include <stdio.h>

int my_strcmp(const char a[], const char b[])
{
	int i = 0;

	while (a[i] != '\0' && a[i] == b[i]) {
		i++;
	}

	return (unsigned char)a[i] - (unsigned char)b[i];
}

int main(void)
{
	printf("my_strcmp(\"apple\", \"apple\") = %d\n",
	       my_strcmp("apple", "apple"));
	printf("my_strcmp(\"apple\", \"banana\") = %d\n",
	       my_strcmp("apple", "banana"));
	printf("my_strcmp(\"banana\", \"apple\") = %d\n",
	       my_strcmp("banana", "apple"));

	return 0;
}
```

<!-- output: 3.4.11 -->
```text
my_strcmp("apple", "apple") = 0
my_strcmp("apple", "banana") = -1
my_strcmp("banana", "apple") = 1
```

几个细节：

1. 返回的是两个字符的差，语义是“负数 / 0 / 正数”。上面输出恰好是 −1 和 1（因为 `a` 和 `b` 的编码差恰好是 1），但标准只保证符号，判断时用 `== 0`、`< 0`、`> 0`。
2. `(unsigned char)` 是为了把 `char` 可能带符号的问题排除掉（第 4 章再细讲），照抄这个习惯即可。
3. 循环条件 `a[i] != '\0' && a[i] == b[i]` 利用了 `&&` 的短路（2.1.6）：一旦 `a` 走到结尾，就不再比较，直接用 `a[i] - b[i]` 分出胜负——`'\0'` 是 0，比任何字符都小。

## 3.4.12 常见错误

| 错误写法 | 问题 | 正确写法 |
|----------|------|----------|
| `if (s1 == s2)` | 比较的是地址，不是内容 | `if (strcmp(s1, s2) == 0)` |
| `strcpy(dst, src);`，`dst` 可能不够大 | 缓冲区溢出 | `snprintf(dst, sizeof(dst), "%s", src);` |
| `strncpy(dst, src, n);` 之后就当字符串用 | `src` 长度 ≥ `n` 时 `dst` 没有 `'\0'` | 自己补 `dst[n - 1] = '\0';` 或改用 `snprintf` |
| `if (strcmp(a, b) == -1)` | 返回值只保证符号 | `if (strcmp(a, b) < 0)` |
| `strcat` 前不确认剩余空间 | 同样是溢出 | `strncat(dst, src, 总长 - 已用 - 1);` |

## 3.4.13 小结

- `string.h` 提供 `strlen`、`strcpy`、`strncpy`、`strcat`、`strcmp`、`strstr` 等函数。
- `strcpy` 和 `strcat` 不检查目标空间，工程上不用；复制优先 `snprintf`，追加用 `strncat` 并算好长度。
- `strncpy` 的坑：源串太长时不会补 `'\0'`，必须自己补。
- `strcmp` 返回负数 / 0 / 正数，判断只写 `== 0`、`< 0`、`> 0`；比较字符串内容不要用 `==`。
- `strstr` 找不到子串返回 `NULL`。
- `my_strlen` 和 `my_strcmp` 说明了这些函数的原理：一切围绕 `'\0'`。

#### 一、选择题

1. **B**。`==` 比较的是地址，几乎总不相等；`strcmp` 返回 0 才表示内容相同。D 只比长度，长度一样内容可以不同。

3. **C**。`strcmp` 按字符编码逐字符比较，`'a'`（97）大于 `'A'`（65），第一个字符就分出了大小，返回正数。（B 选项的表述自相矛盾，是干扰项。）
4. `size_t`；`%zu`。
5. `strcat`；`'\0'`。

#### 三、改错题

三处错误：

1. `if (a == b)`：比较的是两个数组的地址，永远不相等，判断形同虚设。应写成 `if (strcmp(a, b) == 0)`，并包含 `<string.h>`。
2. `strcat` 没有检查空间：`a` 只有 20 字节，装着 `"hello"`（6 字节），再拼上 `"hello"` 需要 11 字节——这里刚好装得下，但这是巧合而非设计。更稳妥的写法是 `snprintf(a, sizeof(a), "%s%s", a, b);`。本题把它算作隐患型错误：拼接前应确认目标空间足够。
3. `%lu` 打印 `strlen` 的返回值：应使用 `%zu`（`size_t` 的正确格式符）。
