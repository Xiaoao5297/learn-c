# 3.3 字符串基础

从第 1 章起我们就在写字符串（string）：`printf("你好，世界！\n");`。但 C 语言里**没有字符串类型**。那这些文字存在哪里？答案就是上一章的主角：数组。

这一节讲清楚字符串的本质，以及怎么安全地读入一个字符串。

## 3.3.1 字符数组与字符串的区别

字符数组（char array）就是元素类型为 `char` 的数组：

```c
char letters[5] = {'H', 'e', 'l', 'l', 'o'};
```

C 语言的字符串在此基础上加了一条约定：**用空字符（null terminator）`'\0'` 标记结尾**。也就是说：

- 字符数组：只是装字符的数组，长度由声明决定。
- 字符串：以 `'\0'` 结尾的字符序列。所有处理字符串的函数（`printf` 的 `%s`、`strlen` 等）都靠找 `'\0'` 来确定字符串到哪里结束。

`"Hello"` 这个字符串字面量在内存里是这样的：

| 下标 | 0 | 1 | 2 | 3 | 4 | 5 |
|------|---|---|---|---|---|---|
| 字符 | `H` | `e` | `l` | `l` | `o` | `'\0'` |

5 个可见字符，却要占 6 个字节。每个字符串字面量都自动带一个结尾的 `'\0'`，编译器替你加上，不用手写。

`'\0'` 的值是数字 0。注意区分三个长得像的东西：

| 写法 | 含义 | 值 |
|------|------|-----|
| `'\0'` | 空字符，字符串结束标志 | 0 |
| `'0'` | 字符“零” | 48 |
| `0` | 整数零 | 0 |

## 3.3.2 初始化字符串的几种写法

```c
// 3.3.2 string_init.c
#include <stdio.h>

int main(void)
{
	char s1[6] = {'H', 'e', 'l', 'l', 'o', '\0'};
	char s2[6] = "Hello";
	char s3[] = "Hello";

	printf("s1 = %s\n", s1);
	printf("s2 = %s\n", s2);
	printf("s3 = %s\n", s3);

	printf("sizeof(s2) = %zu\n", sizeof(s2));
	printf("sizeof(s3) = %zu\n", sizeof(s3));

	return 0;
}
```

<!-- output: 3.3.2 -->
```text
s1 = Hello
s2 = Hello
s3 = Hello
sizeof(s2) = 6
sizeof(s3) = 6
```

三种写法结果相同：

1. 逐个字符写，末尾手动放 `'\0'`。麻烦，容易漏写结束符，不推荐。
2. 用字符串字面量初始化，并留够长度。**字符数 ≥ 可见字符数 + 1**。
3. 省略长度，让编译器数。最省事，长度自动是“可见字符数 + 1”。

一个常被忽略的写法是给“更长的数组”赋短字符串：

```c
char buffer[20] = "Hi";
```

`buffer` 有 20 个字节，前 3 个是 `H`、`i`、`'\0'`，其余自动补 0。这样写完全合法，剩余空间正好留给以后追加或覆盖，3.3.5 读入字符串时就会用到。

## 3.3.3 sizeof vs strlen

`sizeof` 数的是**数组占多少字节**，`strlen` 数的是**字符串里有多少个字符**（不算 `'\0'`）。两者差一个结束符：

```c
// 3.3.3 sizeof_strlen.c
#include <stdio.h>
#include <string.h>

int main(void)
{
	char s[10] = "Hi";

	printf("sizeof(s) = %zu\n", sizeof(s));
	printf("strlen(s) = %zu\n", strlen(s));

	char t[] = "Hello";
	printf("sizeof(t) = %zu\n", sizeof(t));
	printf("strlen(t) = %zu\n", strlen(t));

	return 0;
}
```

<!-- output: 3.3.3 -->
```text
sizeof(s) = 10
strlen(s) = 2
sizeof(t) = 6
strlen(t) = 5
```

| 对比项 | `sizeof` | `strlen` |
|--------|----------|----------|
| 是什么 | 运算符，编译期算出 | `string.h` 里的函数，运行时数到 `'\0'` |
| 返回 | 占用的总字节数 | 字符个数，**不含** `'\0'` |
| 对 `char s[10] = "Hi"` | `10`（数组总大小） | `2` |
| 需要 `%zu` 打印 | 是 | 是 |

记住口诀：**sizeof 看盒子，strlen 看内容**。两者打印都用 `%zu`，不要用 `%lu` 或 `%d`。

## 3.3.4 scanf 读字符串：必须限宽

从键盘读一个单词（不含空格），`scanf` 配 `%s` 可以做到。但 `%s` 有个致命问题：**它不知道目标数组有多大，输入太长就会溢出**。

错误示范，不要照抄：

```c
char name[20];

/* 错误示范：%s 不限宽，写入超过 19 个字符就会溢出 */
scanf("%s", name);
```

如果用户输入 50 个字符，`scanf` 会老老实实写满 `name` 的 20 个字节再继续写下去，把数组外面的内存也改掉——这就是缓冲区溢出（buffer overflow），和 3.1.4 的越界是同一类灾难，而且 `scanf` 自己帮不了你。

正确的写法是在 `%` 和 `s` 之间写上**最大字符数**（比数组长度小 1，给 `'\0'` 留位置）：

```c
// 3.3.4 scanf_width.c
#include <stdio.h>

int main(void)
{
	char name[20];

	printf("请输入你的名字（一个单词）：\n");
	if (scanf("%19s", name) != 1) {
		printf("读取失败\n");
		return 1;
	}

	printf("你好，%s！\n", name);
	printf("长度是 %zu\n", strlen(name));

	return 0;
}
```

<!-- output: 3.3.4 -->
```text
请输入你的名字（一个单词）：
你好，张三！
长度是 6
```

上面假设输入了“张三”（终端里还能看到输入的回显，上面省去）。`%19s` 的含义：最多读 19 个字符，第 20 个字节留给 `'\0'`。配 `char name[20]`，宽度就是 20 − 1 = 19。

> **Windows 提示**：在 Windows 的旧版控制台里，源文件若不是 UTF-8 编码，中文提示可能显示乱码。建议源文件统一用 UTF-8 保存；如果终端还是乱码，可在程序开头执行一次 `system("chcp 65001");`（需要 `stdlib.h`），把控制台切到 UTF-8。

注意输出里的“长度是 6”：“张三”是 2 个汉字，为什么是 6？这正好引出 3.3.6 的编码问题。

另外两点说明：

1. `scanf("%19s", name)` 里 `name` 前面**不加 `&`**。数组名在传参时会自动转换为首元素的地址（3.1.7 讲过转换，这里先记住写法）。
2. `%s` 遇到空格就停，读不了“王小明 20”这种带空格的整行。读整行用 3.3.5 的 `fgets`。

## 3.3.5 fgets：推荐的读入方式

读一整行文本，标准做法是 `fgets`：

```c
fgets(数组名, 数组长度, stdin);
```

- `stdin` 是标准输入，即键盘输入。本教程第 1 章的 `scanf` 也从它读，这里只是显式写出。
- 它最多读 `长度 − 1` 个字符，第 `长度` 个字节自动放 `'\0'`——**永远不会溢出**，不需要手工算宽度。
- 它会连着行尾的 `'\n'` 一起存进数组（如果放得下），这是和 `scanf` 最大的行为差异。

```c
// 3.3.5 fgets_demo.c
#include <stdio.h>
#include <string.h>

int main(void)
{
	char line[32];

	printf("请输入一行文字：\n");
	if (fgets(line, sizeof(line), stdin) == NULL) {
		printf("读取失败\n");
		return 1;
	}

	printf("读到的内容：%s", line);
	printf("strlen 是 %zu\n", strlen(line));

	if (line[strlen(line) - 1] == '\n') {
		printf("末尾是换行符，去掉它\n");
		line[strlen(line) - 1] = '\0';
	}

	printf("处理后：[%s]，长度是 %zu\n", line, strlen(line));

	return 0;
}
```

<!-- output: 3.3.5 -->
```text
请输入一行文字：
读到的内容：hello world
strlen 是 12
末尾是换行符，去掉它
处理后：[hello world]，长度是 11
```

上面假设输入了“hello world”（终端里还能看到输入的回显，上面省去）。逐点解释：

1. `hello world` 是 11 个字符，`strlen` 却是 12，因为 `fgets` 把你按下的回车（`'\n'`）也存了进去。第 12 个字节是 `'\0'`。
2. 去掉换行的标准写法：检查末尾字符是不是 `'\n'`，是就把它改写成 `'\0'`。这个“截短一格”的动作以后会反复用，值得记住。
3. `sizeof(line)` 直接当 `fgets` 的长度参数，数组改大小后这行代码不用动。
4. 如果输入超过 31 个字符，`fgets` 只读前 31 个，不溢出；剩下的字符会留在输入缓冲区里，等下次读取时被读到。

本教程后续章节读字符串一律优先 `fgets`；`%19s` 这种限宽 `scanf` 只在读单个单词时用。

## 3.3.6 中文字符串与编码

第 0 章提过：现代系统普遍用 UTF-8 编码，**一个英文字符占 1 字节，一个常用汉字占 3 字节**。`strlen` 数的是字节，不是“字的个数”：

```c
// 3.3.6 strlen_utf8.c
#include <stdio.h>
#include <string.h>

int main(void)
{
	char en[] = "abc";
	char zh[] = "中文";

	printf("sizeof(en) = %zu\n", sizeof(en));
	printf("strlen(en) = %zu\n", strlen(en));
	printf("sizeof(zh) = %zu\n", sizeof(zh));
	printf("strlen(zh) = %zu\n", strlen(zh));

	return 0;
}
```

<!-- output: 3.3.6 -->
```text
sizeof(en) = 4
strlen(en) = 3
sizeof(zh) = 7
strlen(zh) = 6
```

对照着看：

| 字符串 | 可见字符 | 字节数（UTF-8） | `sizeof` | `strlen` |
|--------|----------|------------------|----------|----------|
| `"abc"` | 3 个英文字母 | 3 + 1 结束符 | 4 | 3 |
| `"中文"` | 2 个汉字 | 2 × 3 + 1 结束符 | 7 | 6 |

3.3.4 里“张三”的 `strlen` 是 6，就是同样的道理。所以：

1. `strlen("中文") == 6` 不是 bug，是 UTF-8 的字节数。
2. 想给中文留空间的字符数组，按“汉字个数 × 3 + 1”估算。
3. C 标准库没有内置的“按字处理”函数，初学阶段用 `strlen` 数字节即可，知道差在哪就行。

## 3.3.7 常见错误

| 错误写法 | 问题 | 正确写法 |
|----------|------|----------|
| `char s[5] = "Hello";` | 5 个可见字符 + `'\0'` 需要 6 个字节，越界 | `char s[6] = "Hello";` 或 `char s[] = "Hello";` |
| `char s[5] = {'H', 'i'};` 后用 `printf("%s", s)` | 没有 `'\0'`，`%s` 会一直读下去 | 手动补 `s[2] = '\0';` 或改用字面量初始化 |
| `scanf` 的 `%s` 不限宽 | 可能缓冲区溢出 | `scanf("%19s", name);` |
| 把 `strlen(s)` 的结果当“汉字个数” | UTF-8 下一个汉字 3 字节 | `strlen` 数的是字节 |
| 忘了处理 `fgets` 留下的 `'\n'` | 字符串末尾多个换行，比较、拼接都会出问题 | 末尾是 `'\n'` 就改写成 `'\0'` |
| `printf("%d", strlen(s))` | 格式符不匹配 | `printf("%zu", strlen(s))` |

## 3.3.8 小结

- C 没有字符串类型，字符串就是以 `'\0'` 结尾的字符数组。
- 字符串字面量自动带 `'\0'`：`"Hello"` 占 6 字节。
- `sizeof` 看盒子（总字节数），`strlen` 看内容（不含 `'\0'` 的字符数），都用 `%zu` 打印。
- `scanf` 的 `%s` 必须限宽（如 `%19s` 配 `char name[20]`），否则可能缓冲区溢出。
- 读整行优先 `fgets`，记得把末尾的 `'\n'` 改写成 `'\0'`。
- UTF-8 下一个常用汉字占 3 字节，`strlen` 数的是字节不是汉字个数。
