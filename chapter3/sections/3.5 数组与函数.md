# 3.5 数组与函数

第 2.5 节学了函数，但有一个重要类型还没交给函数处理过：数组。这一节讲数组怎么传进函数、传进去之后发生了什么，并完成本章的综合实战。

## 3.5.1 数组作参数：退化为指针

先看结论：**把数组传给函数时，传过去的不是整个数组的副本，而是数组首元素的地址**。也可以说，数组参数退化为指针（pointer decay）。

可以想象成把整个储物柜搬去函数太费事，于是只递过去一张写着“7 号柜组从这儿开始”的纸条。函数拿着纸条按编号找到每一个柜子，取放东西改的都是**原来那排柜子**——这就解释了为什么函数内改元素，函数外看得见。但纸条上只有“从哪开始”，没有“一共有几个柜子”，所以长度必须另附一张纸条（单独传 `count`）。

这带来两条直接后果：

1. 函数内修改数组元素，**函数外能看到**——因为操作的是同一块内存。这和普通变量按值传递（2.5 讲过）正好相反。
2. 函数**不知道数组有多长**，必须把长度作为单独的参数传进去。

```c
// 3.5.1 array_param.c
#include <stdio.h>

void double_all(int nums[], int count)
{
	for (int i = 0; i < count; i++) {
		nums[i] *= 2;
	}
}

int main(void)
{
	int nums[5] = {1, 2, 3, 4, 5};

	double_all(nums, 5);

	for (int i = 0; i < 5; i++) {
		printf("%d", nums[i]);
		if (i < 4) {
			printf(" ");
		}
	}
	printf("\n");

	return 0;
}
```

<!-- output: 3.5.1 -->
```text
2 4 6 8 10
```

`main` 里的 `nums` 没有返回值接收，却真的被翻倍了。原因：`double_all` 收到的是 `main` 里那个数组的地址，`nums[i] *= 2` 改的就是原数组。

对比一下：普通变量传参是“寄复印件”（2.5 讲过），改复印件原稿没事；数组传参是“递一张写着储物柜位置的字条”，函数顺着字条找到的正是你原来那排柜子，改动当然留在原地。

## 3.5.2 大坑：函数内 sizeof 数组参数

3.1.6 说 `sizeof(数组) / sizeof(数组[0])` 能算元素个数。把数组传进函数后，这个技巧**失效**。

先看错误示范，不要照抄：

```c
void print_size(int nums[])
{
	/* 错误示范：这里想得到数组大小 */
	printf("%zu\n", sizeof(nums));
}
```

`main` 里的 `nums` 若是 `int nums[5]`，`sizeof(nums)` 是 20；但参数 `nums[]` 一进函数就退化为指针，`sizeof(nums)` 得到的是**一个指针的大小**——64 位系统上是 8 字节。结果对照：

| 位置 | `sizeof(nums)` 的值 | 原因 |
|------|---------------------|------|
| `main` 里（`int nums[5]`） | `20` | `nums` 还是数组类型 |
| 函数参数里（`int nums[]`） | `8` | `nums` 已经是指针 |

这个坑的恐怖之处有两层：

1. 结果不是编译错误，只是一个“错得很稳定”的数字，程序照样跑。
2. 在 32 位系统上指针是 4 字节，恰好等于一个 `int` 的大小，错误更隐蔽。

有的编译器对这种写法直接给出警告（clang 会报 `-Wsizeof-array-argument`），开了 `-Werror` 就编不过——算是帮了大忙。规矩要记死：

> **函数里永远不要对数组参数做 `sizeof`。长度必须作为单独的参数传入。**

所以处理数组的函数都长这样（长度是独立参数）：

| 函数签名 | 说明 |
|----------|------|
| `double average(const int scores[], int count)` | 一维数组：传数组名 + 长度 |
| `void print_matrix(int m[][COLS], int rows)` | 二维数组：列数写死，行数传参（见 3.5.4） |

## 3.5.3 一维数组传参示例

有了“数组 + 长度”的固定搭配，统计类代码就能搬进函数了。注意参数里的 `const`：函数承诺只读不改。

```c
// 3.5.3 array_average.c
#include <stdio.h>

double average(const int scores[], int count)
{
	int sum = 0;

	for (int i = 0; i < count; i++) {
		sum += scores[i];
	}

	return (double)sum / count;
}

int max_of(const int scores[], int count)
{
	int max = scores[0];

	for (int i = 1; i < count; i++) {
		if (scores[i] > max) {
			max = scores[i];
		}
	}

	return max;
}

int main(void)
{
	int scores[6] = {85, 92, 78, 65, 100, 54};

	printf("平均分：%.1f\n", average(scores, 6));
	printf("最高分：%d\n", max_of(scores, 6));

	return 0;
}
```

<!-- output: 3.5.3 -->
```text
平均分：79.0
最高分：100
```

`const int scores[]` 的含义（呼应 2.6 的规范）：`average` 承诺不修改 `scores` 的任何元素。只读的数组参数一律加 `const`，读代码的人一看就知道这个函数是“查”不是“改”，写错时编译器还会替你拦住：

```c
double average(const int scores[], int count)
{
	scores[0] = 0;    /* 编译错误：不能修改 const 数组 */
	...
}
```

这是错误示范，编译不会通过。而 3.5.1 的 `double_all` 要修改数组，参数就不能加 `const`。

## 3.5.4 二维数组传参：列数必须写死

3.2.3 说过，编译器靠列数计算 `m[i][j]` 的位置。数组参数退化后行数丢了，但**列数必须跟着类型一起传进去**，所以二维数组参数要写明列数：

```c
void print_matrix(int m[][COLS], int rows);
```

`m[][COLS]` 的意思是“每行都是 `COLS` 个 int 的数组，行数由参数 `rows` 决定”。只写 `m[][]` 是编译错误。

```c
// 3.5.4 matrix_param.c
#include <stdio.h>

#define ROWS 2
#define COLS 3

void print_matrix(int m[][COLS], int rows)
{
	for (int row = 0; row < rows; row++) {
		for (int col = 0; col < COLS; col++) {
			printf("%4d", m[row][col]);
		}
		printf("\n");
	}
}

int main(void)
{
	int matrix[ROWS][COLS] = {
		{1, 2, 3},
		{4, 5, 6}
	};

	print_matrix(matrix, ROWS);

	return 0;
}
```

<!-- output: 3.5.4 -->
```text
   1   2   3
   4   5   6
```

函数里的循环直接复用宏 `COLS`，行数则用参数 `rows`——这就是“列数写死、行数传参”的标准形态。这也解释了 3.2.2 的“列数不能省略”：省了列数，函数内算不出 `m[i][j]` 在哪里。

## 3.5.5 冒泡排序

排序是数组 + 函数的经典应用。冒泡排序（bubble sort）的思路：从头开始两两比较相邻元素，顺序不对就交换；每一轮都把当前最大的“冒泡”到末尾。

想象体育课按身高排队：老师从队头开始，让相邻两个人比身高，矮的站前面、高的站后面，一路比到队尾。走完一趟，最高的那个人一定已经被“顶”到了队尾——像水里的气泡一样浮到了最上面。再来一趟，第二高的也归位了。几趟下来，整支队伍就排好了。

```c
// 3.5.5 bubble_sort.c
#include <stdio.h>

void bubble_sort(int nums[], int count)
{
	for (int i = 0; i < count - 1; i++) {
		for (int j = 0; j < count - 1 - i; j++) {
			if (nums[j] > nums[j + 1]) {
				int temp = nums[j];
				nums[j] = nums[j + 1];
				nums[j + 1] = temp;
			}
		}
	}
}

int main(void)
{
	int nums[6] = {64, 25, 90, 12, 88, 33};

	bubble_sort(nums, 6);

	for (int i = 0; i < 6; i++) {
		printf("%d", nums[i]);
		if (i < 5) {
			printf(" ");
		}
	}
	printf("\n");

	return 0;
}
```

<!-- output: 3.5.5 -->
```text
12 25 33 64 88 90
```

三个要点：

1. 外层跑 `count − 1` 轮；每轮结束后，末尾 `i` 个元素已经排好，所以内层边界是 `count − 1 − i`。
2. 交换两个变量要借助临时变量 `temp`，三行顺序不能乱。
3. 比较 `>` 得到升序；改成 `<` 就是降序。

## 3.5.6 冒泡排序的优化：提前退出

如果某一轮一次交换都没发生，说明数组已经有序，后面的轮次全是白跑。用一个标志变量检测这一点：

```c
// 3.5.6 bubble_sort_opt.c
#include <stdio.h>
#include <stdbool.h>

void bubble_sort(int nums[], int count)
{
	for (int i = 0; i < count - 1; i++) {
		bool swapped = false;

		for (int j = 0; j < count - 1 - i; j++) {
			if (nums[j] > nums[j + 1]) {
				int temp = nums[j];
				nums[j] = nums[j + 1];
				nums[j + 1] = temp;
				swapped = true;
			}
		}

		if (!swapped) {
			break;
		}
	}
}

int main(void)
{
	int nums[6] = {1, 2, 3, 4, 5, 6};

	bubble_sort(nums, 6);

	for (int i = 0; i < 6; i++) {
		printf("%d", nums[i]);
		if (i < 5) {
			printf(" ");
		}
	}
	printf("\n");

	return 0;
}
```

<!-- output: 3.5.6 -->
```text
1 2 3 4 5 6
```

这个例子里数组本来就有序：第一轮一次交换都没发生，`swapped` 保持 `false`，`break` 直接退出，只跑了一轮。对已经有序（或接近有序）的数据，优化版从 `count − 1` 轮降到 1 轮；对完全乱序的数据，最坏情况轮数不变。这是用 `bool` 表达判断结果的典型场景（呼应 2.6）。

## 3.5.7 综合示例：成绩统计程序

把本章的东西串起来：读入人数和成绩，输出平均分、最高分和排序结果。

```c
// 3.5.7 score_stats.c
#include <stdio.h>
#include <stdbool.h>

#define MAX_STUDENTS 50

void bubble_sort(int nums[], int count)
{
	for (int i = 0; i < count - 1; i++) {
		bool swapped = false;

		for (int j = 0; j < count - 1 - i; j++) {
			if (nums[j] > nums[j + 1]) {
				int temp = nums[j];
				nums[j] = nums[j + 1];
				nums[j + 1] = temp;
				swapped = true;
			}
		}

		if (!swapped) {
			break;
		}
	}
}

double average(const int scores[], int count)
{
	int sum = 0;

	for (int i = 0; i < count; i++) {
		sum += scores[i];
	}

	return (double)sum / count;
}

int max_of(const int scores[], int count)
{
	int max = scores[0];

	for (int i = 1; i < count; i++) {
		if (scores[i] > max) {
			max = scores[i];
		}
	}

	return max;
}

int main(void)
{
	int scores[MAX_STUDENTS];
	int count = 0;

	printf("请输入人数（1 到 %d）：\n", MAX_STUDENTS);
	if (scanf("%d", &count) != 1 || count < 1 || count > MAX_STUDENTS) {
		printf("人数不合法\n");
		return 1;
	}

	printf("请输入 %d 个成绩（0 到 100）：\n", count);
	for (int i = 0; i < count; i++) {
		if (scanf("%d", &scores[i]) != 1) {
			printf("成绩读取失败\n");
			return 1;
		}
	}

	printf("平均分：%.1f\n", average(scores, count));
	printf("最高分：%d\n", max_of(scores, count));

	bubble_sort(scores, count);
	printf("从低到高：");
	for (int i = 0; i < count; i++) {
		printf("%d", scores[i]);
		if (i < count - 1) {
			printf(" ");
		}
	}
	printf("\n");

	return 0;
}
```

<!-- output: 3.5.7 -->
```text
请输入人数（1 到 50）：
请输入 5 个成绩（0 到 100）：
平均分：84.0
最高分：100
从低到高：65 78 85 92 100
```

上面假设输入了人数 `5` 和成绩 `85 92 78 65 100`（终端里还能看到输入的回显，上面省去）。

这个程序值得多看两眼：

1. 数组按**最大可能长度**声明（`MAX_STUDENTS`），实际用多少个由 `count` 决定。C 的数组长度不能是运行期才确定的变量，所以“先定上限、再记实际个数”是标准做法。
2. 读入人数后先检查范围（1 到 50），不合法就退出。这防住了两件事：`count` 为 0 或负数导致后面循环不正常，`count` 超过 50 导致写数组越界。防御式写法从现在开始养成（第 5 章会系统讲错误处理）。
3. 三个函数各管一件事：排序、平均、最值。`main` 只负责输入输出和组装。参数里的 `const` 精确区分了“改数组”的 `bubble_sort` 和“只读”的 `average`、`max_of`。

> **Windows 提示**：中文提示乱码时，确认源文件以 UTF-8 保存，或在 `main` 开头执行 `system("chcp 65001");`（需要 `#include <stdlib.h>`）。

## 3.5.8 常见错误

| 错误写法 | 问题 | 正确写法 |
|----------|------|----------|
| 在函数内对数组参数用 `sizeof` 求长度 | 得到的是指针大小（如 8），不是数组大小 | 长度作为独立参数传入 |
| `void f(int m[][])` | 二维数组参数缺列数，编译错误 | `void f(int m[][COLS], int rows)` |
| `void f(int a[])`，函数内修改，却不希望修改 | 数组传参改的是原数组 | 只读参数加 `const`：`void f(const int a[], int n)` |
| 交换两个元素忘了临时变量，或顺序写错 | 数据被覆盖丢失 | 借助 `temp`，三行顺序不能乱 |
| `count` 不检查范围就当循环上限用 | 可能越界写数组 | 先检查 `1 <= count <= MAX` |

## 3.5.9 小结

- 数组作参数退化为指针：函数内修改元素会影响原数组，但函数不知道长度。
- 长度必须作为独立参数传入；函数内 `sizeof(数组参数)` 是指针大小，这是初学者大坑。
- 只读的数组参数加 `const`，如 `double average(const int scores[], int count)`。
- 二维数组作参数必须写明列数：`void print_matrix(int m[][COLS], int rows)`。
- 冒泡排序：相邻两两比较交换，外层 `count − 1` 轮，内层边界 `count − 1 − i`；用 `swapped` 标志可提前退出。
- 综合程序的模式：数组按最大长度声明，实际个数记在变量里并检查范围。

<summary>参考答案</summary>

1. 会变。数组传参传的是首元素地址，函数内的 `nums[i]` 和函数外是同一块内存，和普通变量按值传递不同。
