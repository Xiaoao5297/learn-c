# 3.1 数组

第 1、2 章的程序有一个共同点：数据都不多。一个变量存一个成绩，两个变量做一次比较。一旦数据变成 50 个、100 个，再一个个起名字就不现实了。

这一节介绍数组（array）：用一个名字，管住一串同类型的数据。

## 3.1.1 为什么需要数组

假设要保存一个班 5 个学生的成绩。用变量可以写成：

```c
int score1 = 85;
int score2 = 92;
int score3 = 78;
int score4 = 65;
int score5 = 100;
```

5 个还能忍。如果是 100 个呢？你要写 100 行声明，求平均分要写 100 个名字相加，改个需求（比如变成 200 人）要改遍全文。

数组把“一串同类型的数据”放进一个名字里：

| 对比项 | 单独变量 | 数组 |
|--------|----------|------|
| 声明 100 个数据 | 100 行声明 | 1 行声明 |
| 访问第 i 个数据 | 写死变量名 | `scores[i]`，下标可以是变量 |
| 配合循环 | 做不到 | 天然搭档 |
| 改数据规模 | 到处改 | 通常只改一个数字 |

**数组（array）** 是把多个相同类型的数据按顺序连续存放、用一个名字加下标（index）访问的构造类型。

| 术语 | 英文 | 含义 |
|------|------|------|
| 数组名 | array name | 这串数据的总名字，如 `scores` |
| 元素 | element | 数组里的每一个数据 |
| 下标 | index | 元素的编号，从 0 开始 |
| 长度 | length | 元素个数 |

## 3.1.2 声明和初始化数组

声明数组的语法：

```c
类型 数组名[长度];
```

| 写法 | 含义 |
|------|------|
| `int scores[5];` | 5 个 `int`，值未初始化（是垃圾值） |
| `int scores[5] = {95, 88, 72, 100, 60};` | 完全初始化，逐个对应 |
| `int scores[5] = {1, 2};` | 部分初始化，只给前 2 个，其余自动为 0 |
| `int scores[5] = {0};` | 全部初始化为 0，最常用 |
| `int scores[] = {10, 20, 30};` | 省略长度，编译器数出来是 3 |

```c
// 3.1.2 array_init.c
#include <stdio.h>

int main(void)
{
	int scores[5] = {95, 88, 72, 100, 60};
	int partial[5] = {1, 2};
	int zeros[5] = {0};
	int auto_size[] = {10, 20, 30};

	printf("scores[0] = %d\n", scores[0]);
	printf("partial[2] = %d\n", partial[2]);
	printf("zeros[4] = %d\n", zeros[4]);
	printf("auto_size 有 %zu 个元素\n",
	       sizeof(auto_size) / sizeof(auto_size[0]));

	return 0;
}
```

<!-- output: 3.1.2 -->
```text
scores[0] = 95
partial[2] = 0
zeros[4] = 0
auto_size 有 3 个元素
```

两点说明：

1. 部分初始化时，没给值的元素自动为 0。这条规则只对初始化成立，先声明后赋值没有这种好事。
2. `%zu` 是打印 `sizeof` 结果（`size_t` 类型）的正确格式符。`sizeof` 的结果不是 `int`，用 `%d` 或 `%lu` 都不合适，固定用 `%zu`。

## 3.1.3 下标：从 0 开始

用 `数组名[下标]` 访问元素，下标从 0 开始。长度为 5 的数组，下标是 0、1、2、3、4。

| 下标 | 0 | 1 | 2 | 3 | 4 |
|------|---|---|---|---|---|
| 元素 | 95 | 88 | 72 | 100 | 60 |

```c
// 3.1.3 array_access.c
#include <stdio.h>

int main(void)
{
	int scores[5] = {95, 88, 72, 100, 60};

	scores[1] = 90;

	printf("第一个元素：%d\n", scores[0]);
	printf("第二个元素：%d\n", scores[1]);
	printf("最后一个元素：%d\n", scores[4]);

	return 0;
}
```

<!-- output: 3.1.3 -->
```text
第一个元素：95
第二个元素：90
最后一个元素：60
```

`scores[1] = 90;` 说明下标位置既可以读，也可以写。最后一个元素的下标永远是“长度 − 1”。

## 3.1.4 越界：未定义行为

下标超出了 `0` 到 `长度 − 1` 的范围，就是越界（out of bounds）。看一个错误示范，不要照抄：

```c
int scores[5] = {95, 88, 72, 100, 60};

printf("%d\n", scores[5]);
scores[100] = 1;
```

`scores[5]` 和 `scores[100]` 都不存在。这两行访问的是数组后面的内存，可能读出垃圾值，也可能把别的变量改坏，严重时程序直接崩溃。

关键在于：**C 语言不做下标检查，越界是未定义行为（undefined behavior）**。编译器不一定报错，甚至可能一声不吭地编译通过。程序可能“看起来正常”，然后在某个随机时刻出问题——这是初学者最难排查的一类 bug。

好的习惯是：每写一个数组循环，都核对一次边界。`for (int i = 0; i < 长度; i++)` 是安全模板，条件用 `<` 而不是 `<=`。

## 3.1.5 遍历数组

“逐个处理每个元素”叫遍历（traverse）。数组和 `for` 循环是固定搭档：

```c
// 3.1.5 array_traverse.c
#include <stdio.h>

int main(void)
{
	int scores[5] = {95, 88, 72, 100, 60};

	for (int i = 0; i < 5; i++) {
		printf("scores[%d] = %d\n", i, scores[i]);
	}

	return 0;
}
```

<!-- output: 3.1.5 -->
```text
scores[0] = 95
scores[1] = 88
scores[2] = 72
scores[3] = 100
scores[4] = 60
```

遍历模板值得记住：

```c
for (int i = 0; i < 长度; i++) {
	/* 用 数组名[i] 处理每个元素 */
}
```

`i` 从 0 开始、条件用 `<`，这两个细节凑在一起，刚好覆盖全部下标且不越界。

## 3.1.6 用 sizeof 计算元素个数

数组元素个数往往由别人维护，写死 `5` 容易在数组变长后忘了改。用 `sizeof` 可以让编译器替你算：

```c
// 3.1.6 array_sizeof.c
#include <stdio.h>

int main(void)
{
	int scores[] = {95, 88, 72, 100, 60};

	printf("整个数组占 %zu 字节\n", sizeof(scores));
	printf("一个元素占 %zu 字节\n", sizeof(scores[0]));
	printf("元素个数是 %zu\n", sizeof(scores) / sizeof(scores[0]));

	return 0;
}
```

<!-- output: 3.1.6 -->
```text
整个数组占 20 字节
一个元素占 4 字节
元素个数是 5
```

`sizeof(数组)` 返回整个数组占用的字节数，除以单个元素的字节数，就是元素个数。

注意两个限制：

1. 这个技巧**只在定义数组的同一个函数里有效**。把数组传给函数后，`sizeof` 得到的就不是数组大小了，3.5.2 会专门讲这个坑。
2. 打印 `sizeof` 的结果用 `%zu`，不要用 `%lu` 或 `%d`。

## 3.1.7 数组名不是指针

网上流传一种说法：“数组名就是指针”。这句话是错的，不要记。

准确的说法是：**在大多数表达式中，数组名会自动转换（decay）为指向首元素的指针；但数组本身不是指针，它的类型是“长度为 N 的数组”**。

证据就在 3.1.6 的输出里：

| 表达式 | 结果 | 说明 |
|--------|------|------|
| `sizeof(scores)` | `20` | 整个数组的大小（5 × 4 字节） |
| `sizeof(scores[0])` | `4` | 一个 `int` 的大小 |
| 一个指针的大小（64 位系统） | `8` | 如果数组名真是指针，`sizeof(scores)` 就该是 8 |

如果 `scores` 真是指针，`sizeof(scores)` 应该得到 8，而不是 20。`sizeof` 是为数数不多的“能看见数组本来面目”的场合。

自动转换带来一个方便：`scores[i]` 之所以能用下标访问，正是因为编译器把 `scores` 当成首元素地址来算偏移。也正因为有转换，把数组传给函数时传的其实是地址——这是 3.5 的主题，现在只需要记住结论：

1. 数组本身不是指针。
2. 表达式里的数组名会转换为首元素的地址。
3. 想知道数组大小，要在数组定义所在的函数里用 `sizeof`。

## 3.1.8 统计：求和、平均分、最值

把遍历和第 2 章的分支组合起来，就能处理一大类问题：统计。下面一个循环同时完成求和、找最高分、找最低分、数及格人数：

```c
// 3.1.8 array_stats.c
#include <stdio.h>

int main(void)
{
	int scores[8] = {85, 92, 78, 65, 100, 54, 88, 76};
	int count = 8;

	int sum = 0;
	int max = scores[0];
	int min = scores[0];
	int pass = 0;

	for (int i = 0; i < count; i++) {
		sum += scores[i];
		if (scores[i] > max) {
			max = scores[i];
		}
		if (scores[i] < min) {
			min = scores[i];
		}
		if (scores[i] >= 60) {
			pass++;
		}
	}

	printf("总分：%d\n", sum);
	printf("平均分：%.1f\n", (double)sum / count);
	printf("最高分：%d\n", max);
	printf("最低分：%d\n", min);
	printf("及格人数：%d\n", pass);

	return 0;
}
```

<!-- output: 3.1.8 -->
```text
总分：638
平均分：79.8
最高分：100
最低分：54
及格人数：7
```

两个套路值得记住：

1. **求最值**：先把 `max` 设成第一个元素 `scores[0]`，再从第二个开始逐个比较更新。不要设成 0 或 100 这类想当然的数——如果全是负数，初始值 0 就错了。
2. **平均分**：`(double)sum / count` 先把整数和转成浮点数再做除法，否则整数除法会丢掉小数（2.1.2 讲过）。

## 3.1.9 逆序输出

把数组从后往前打印一遍，循环变量倒着走就行：

```c
// 3.1.9 array_reverse.c
#include <stdio.h>

int main(void)
{
	int nums[5] = {1, 2, 3, 4, 5};

	for (int i = 4; i >= 0; i--) {
		printf("%d\n", nums[i]);
	}

	return 0;
}
```

<!-- output: 3.1.9 -->
```text
5
4
3
2
1
```

起始值是 `长度 − 1`，条件是 `i >= 0`。这两个边界一个都不能错，否则要么漏掉首元素，要么越界。

## 3.1.10 判断回文

回文（palindrome）指正着读和倒着读都一样的序列，比如 `{1, 2, 3, 2, 1}`。思路：比较第 `i` 个和倒数第 `i + 1` 个，只要比到中间就行。

```c
// 3.1.10 array_palindrome.c
#include <stdio.h>
#include <stdbool.h>

int main(void)
{
	int nums[5] = {1, 2, 3, 2, 1};
	bool is_palindrome = true;

	for (int i = 0; i < 5 / 2; i++) {
		if (nums[i] != nums[5 - 1 - i]) {
			is_palindrome = false;
			break;
		}
	}

	if (is_palindrome) {
		printf("是回文\n");
	} else {
		printf("不是回文\n");
	}

	return 0;
}
```

<!-- output: 3.1.10 -->
```text
是回文
```

三个细节：

1. 只需要比 `长度 / 2` 次。长度是 5 时比 2 次，中间那个元素不用和自己比。
2. 倒数第 `i + 1` 个元素的下标是 `长度 − 1 − i`。
3. 一旦发现不相等，用 `break` 提前退出，后面不用再比。

可以把 `nums` 改成 `{1, 2, 3, 4, 5}` 再运行一次，验证输出变成“不是回文”。

## 3.1.11 常见错误

| 错误写法 | 问题 | 正确写法 |
|----------|------|----------|
| `int a[5]; a[5] = 1;` | 越界，未定义行为 | 下标最大是 `4` |
| `for (int i = 0; i <= 5; i++)` | 多跑一次，越界 | `i < 5` |
| `printf("%lu", sizeof(a))` | 格式符不匹配 | `printf("%zu", sizeof(a))` |
| `int a[3]; a[0] = 1;` 之后直接用 `a[1]` | 未初始化，值不确定 | 声明时 `{0}` 全部清零 |
| 认为“数组名就是指针” | 类型错误的理解 | 数组不是指针，表达式中会转换为首元素地址（见 3.1.7） |
| `int a[3] = {1, 2, 3}; int b[3]; b = a;` | 数组不能整体赋值 | 逐元素复制，或用循环 |

## 3.1.12 小结

- 数组用一个名字管理一串同类型的数据，元素按下标从 0 开始编号。
- 长度为 n 的数组，下标范围是 `0` 到 `n − 1`，越界是未定义行为，编译器不一定报错。
- 初始化：完全初始化、部分初始化（其余补 0）、`{0}` 全清零、省略长度。
- 遍历模板：`for (int i = 0; i < 长度; i++)`。
- `sizeof(数组) / sizeof(数组[0])` 算元素个数，打印用 `%zu`。
- 数组名在表达式中会转换为首元素的地址，但数组本身不是指针。
- 求最值先把结果设为第一个元素；平均分记得转成浮点除法。
