# 第3章：数组与字符串 —— 给数据安个"家" 🏠

## 📖 本章导读

还记得第1章结尾的问题吗？

> "如果想存100个学生的成绩，难道要写100个变量吗？"

写 100 个 `score1`、`score2`... 显然不现实。从这一章开始，我们终于要给数据安一个"家"了！

这个"家"就是**数组**——它像一个**超级大柜子**，能一次性装下很多同类型的"小盒子"（变量）。

而C语言里有个特别的东西：**字符串**（文字）在C中其实也是用数组实现的——是一个装着字符的数组！

在本章中，我们将一起：

- 📦 **认识数组** —— 用"一个名字"装"一堆数据"
- 🗺️ **学习二维数组** —— 像课表、棋盘一样，按"行×列"存数据
- 🔤 **认识字符串** —— 理解C语言中"文字"是怎么存放的
- 🧩 **数组与函数** —— 把一柜子数据交给函数去处理

## 🎯 学习目标

完成本章后，你将能够：

1. ✅ 声明、初始化并遍历一维数组和二维数组
2. ✅ 用数组 + 循环解决"一堆数据"的统计问题
3. ✅ 理解C字符串的本质（字符数组 + 结束符 `\0`）
4. ✅ 把数组作为参数传给函数，写出更强大的程序

## 💡 学习建议

> 📌 **这一章开始接触"批量数据"！**
>
> 数组是后面所有数据结构（字符串、结构体、链表）的基石。
> 
> - 🔢 **下标从0开始**：这是程序员的老规矩，别记成从1开始
> - 🔁 **数组离不开循环**：99%的数组操作都要配合循环
> - 🧪 **亲手试一试**：改改下标、改改长度，观察会发生什么
