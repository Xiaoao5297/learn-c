# 第 3 章：数组与字符串

前两章的程序有一个共同限制：一个变量只能装一个数据。要存 50 个学生的成绩，难道声明 50 个变量？从这一章开始，这个问题有了答案：数组。

而 C 语言里的“文字”——字符串——本质上也是数组。学完数组，字符串就顺理成章。

本章会学到：

- 用数组把“一串数据”放进一个名字里，配合循环处理。
- 用二维数组处理“行 × 列”的表格数据。
- 理解字符串的本质：以 `'\0'` 结尾的字符数组。
- 使用 `string.h` 的常用函数，并知道哪些函数有安全风险。
- 把数组交给函数处理，完成排序、统计等综合程序。

## 前置知识

- 第 1 章：变量、数据类型、`printf`、`scanf`。
- 第 2 章：运算符、条件、循环、函数基础。

## 学完这一章，你应该能

1. 声明、初始化、遍历一维数组和二维数组，并说清楚下标为什么从 0 开始。
2. 判断代码有没有越界，理解越界是未定义行为。
3. 说清楚 `sizeof` 和 `strlen` 的区别。
4. 用限宽 `scanf` 或 `fgets` 安全地读入字符串。
5. 使用 `strlen`、`strcmp`、`strstr` 等函数，并避开 `strcpy`、`strcat` 的安全坑。
6. 把数组传给函数，写出求平均、找最值、冒泡排序这样的通用函数。

## 本章工程支线

第 2 章的工程支线是“怎么写代码”，本章的工程支线是“怎么写出不崩的代码”，它直接通向第 4 章的多文件工程和第 6 章的函数设计：

- **3.3 的安全读入**：限宽 `scanf` 与 `fgets`。缓冲区溢出是真实软件中最常见的安全漏洞之一，从第一个字符串程序起就按安全写法来。
- **3.4 的安全字符串处理**：不用 `strcpy`、`strcat`，用 `snprintf`、`strncat` 代替。第 5 章讲错误处理时会回看这些选择。
- **3.5 的参数传递**：数组传参退化为指针、长度必须显式传、只读参数加 `const`。这套签名习惯是第 6 章函数设计和第 4 章指针内容的地基。

## 预计时间

- 只读一遍：4 到 6 小时。
- 做完每节练习和章末测试：8 到 12 小时。
- 建议分 3 到 4 次学习，3.1 和 3.3 概念最重，值得多留时间。

## 学习建议

- 每节的示例先自己运行，再改几个数字看输出。
- 3.1.7（数组名不是指针）和 3.5.2（函数内 sizeof 是指针大小）是本章最容易理解错的地方，读慢一点。
- 练习题先写，再展开答案。
- 字符串示例涉及中文时注意编码，第 0 章的 UTF-8 说明在这里用上了。
