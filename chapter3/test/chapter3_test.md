**12. 写出下面程序的输出，并说明 `sum` 为什么是这个值。**

```c
#include <stdio.h>

int main(void)
{
	int a[2][3] = {
		{1, 2, 3},
		{4, 5, 6}
	};
	int sum = 0;

	for (int i = 0; i < 2; i++) {
		for (int j = 0; j < 3; j++) {
			if ((i + j) % 2 == 0) {
				sum += a[i][j];
			}
		}
	}

	printf("%d\n", sum);
	return 0;
}
```

## 四、编程题（每题 10 分，共 20 分）

**13. 安全的字符串读入**

编写程序，读入一行文字（用 `fgets`），去掉末尾换行后输出它的长度。运行效果：

```text
请输入一行文字：
hello C
长度是 8
```

要求：

- 使用 `fgets(line, sizeof(line), stdin)`。
- 处理 `fgets` 留下的 `'\n'`。
- `strlen` 的结果用 `%zu` 打印。
- 使用 `int main(void)`。

---

**14. 冒泡排序函数**

编写函数 `void sort_desc(int nums[], int count);`，把数组按**从大到小**排序，并在 `main` 里验证。运行效果：

```text
90 64 33 25 12
```

要求：

- 用冒泡排序实现，内层比较条件注意方向。
- 函数外打印结果。
- 使用 `int main(void)`。

### 一、选择题

1. **C**。下标从 0 开始，最大是 `长度 − 1`，即 `0` 到 `4`。
2. **A**。`sizeof(a)` 是 12 字节，除以一个元素 4 字节，得到元素个数 3。
3. **B**。`strlen` 数内容不含 `'\0'`，是 2；`sizeof` 数盒子，`"Hi"` 是 2 个字符加 `'\0'`，是 3。
4. **C**。宽度要比数组长度小 1，给 `'\0'` 留位置。不限宽会溢出；`%20s` 最多写 20 个字符，`'\0'` 会落到 `name[20]` 之外；数组名传参不需要 `&`。
5. **B**。数组传参传的是首元素地址，函数内 `a[0] = 100` 改的就是原数组。

### 二、填空题

6. `n − 1`；未定义。
7. `%zu`。
8. `'\0'`（空字符）；`0`。
9. 数组首元素的地址；数组长度（元素个数）。
10. 指针（64 位系统上是 8 字节）。

### 三、阅读程序

11. 输出：

```text
10 3
```

`sizeof(s)` 是数组总大小 10 字节；`strlen(s)` 是内容 `"abc"` 的长度 3，不含 `'\0'`。

12. 输出：

```text
12
```

`(i + j) % 2 == 0` 选中的是 `a[0][0]`（1）、`a[0][2]`（3）、`a[1][1]`（5），其余三个元素被 `if` 跳过。所以和是 1 + 3 + 5 = **9**。

### 四、编程题

13. 参考代码：

```c
#include <stdio.h>
#include <string.h>

int main(void)
{
	char line[64];

	printf("请输入一行文字：\n");
	if (fgets(line, sizeof(line), stdin) == NULL) {
		return 1;
	}

	if (line[strlen(line) - 1] == '\n') {
		line[strlen(line) - 1] = '\0';
	}

	printf("长度是 %zu\n", strlen(line));

	return 0;
}
```

14. 参考代码：

```c
#include <stdio.h>

void sort_desc(int nums[], int count)
{
	for (int i = 0; i < count - 1; i++) {
		for (int j = 0; j < count - 1 - i; j++) {
			if (nums[j] < nums[j + 1]) {
				int temp = nums[j];
				nums[j] = nums[j + 1];
				nums[j + 1] = temp;
			}
		}
	}
}

int main(void)
{
	int nums[5] = {64, 25, 90, 12, 33};

	sort_desc(nums, 5);

	for (int i = 0; i < 5; i++) {
		printf("%d", nums[i]);
		if (i < 4) {
			printf(" ");
		}
	}
	printf("\n");

	return 0;
}
```
