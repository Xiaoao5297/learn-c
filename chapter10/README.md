# 第10章：C语言收官篇 —— 宏、位运算、函数指针与毕业项目 🎓

## 📖 本章导读

从第1章的 `Hello World` 一路走到第9章的二叉树，你已经掌握了 C 语言的"主干"：变量、流程控制、函数、数组、指针、结构体、内存管理、递归、算法与数据结构。

但 C 语言还有几样"**隐藏技能**"，平时不显山露水，一旦用上却能让人拍案叫绝：

- 🏷️ **预处理与宏** —— `#define`、条件编译：写给"编译器动手之前"看的指令
- 🔣 **位运算** —— `& | ^ ~ << >>`：直接在二进制位上一次处理几十个开关
- 🎯 **函数指针** —— 把"函数本身"当数据传来传去，写出优雅的"回调"

学会了它们，再亲手做一个**把前面九章全串起来的收官大项目**，你就能底气十足地说："我会 C 语言了！"

在本章中，我们将一起：

- 🏷️ **认识预处理与宏** —— 常量宏、带参宏、条件编译与头文件卫士
- 🔣 **玩转位运算** —— 判断奇偶、乘除 2、做"权限开关"
- 🎯 **掌握函数指针** —— 声明/调用、函数指针数组，把"函数"当数据
- 🧰 **qsort 实战** —— 一个比较器，int/结构体随便排，算法与规则分离
- 🎓 **毕业大项目** —— 一个"通讯录"，把结构体、字符串、排序、查找、文件读写全装进去

## 🎯 学习目标

完成本章后，你将能够：

1. ✅ 用 `#define` 定义常量和带参宏，用条件编译控制代码是否参与编译
2. ✅ 用位运算处理"开关"（权限、状态），看懂 `<<` `>>` `&` `|` `^` `~`
3. ✅ 声明、赋值、调用函数指针；用它给 `qsort` 写比较器
4. ✅ 独立完成一个"结构体 + 菜单 + 文件"的综合小项目，给整个 C 学习画上句号

## 💡 学习建议

> 📌 **这一章是"锦上添花 + 融会贯通"。**
>
> 前九章是"必须会"，本章是"会了更专业"。
> 
> - 🔍 **先看现象再记语法**：宏是"替换"，位运算是"二进制"，函数指针是"函数的门牌号"——都从"为什么"入手
> - 🧪 **亲手编译试试**：宏展开可以看 `gcc -E`，位运算可以打印二进制，函数指针错了编译器会骂你，都是好老师
> - 🎓 **毕业项目一定要动手敲**：把功能一个个加进去，跑通的那一刻，就是你 C 语言的"毕业典礼"
