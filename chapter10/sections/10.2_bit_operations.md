# 10.2 位运算：直接在"二进制位"上做文章

> 💬 **节前语：**
>
> 上一节结尾我们问：能不能一次操作数据里的每一个"二进制位"？
>
> 能！C 语言专门准备了一组**位运算符（bitwise operators）**：`&`、`|`、`^`、`~`、`<<`、`>>`。
>
> 它们不是用来算 3+5 的，而是**直接盯着一个数的"二进制位"做逻辑**：
>
> - 判断一个数是奇是偶，其实只要看**最后一位**
> - 一个 `int` 有 32 个位，能当 **32 个开关**打包用（这就是操作系统里"权限"的底层玩法）
> - 左移一位 = 乘 2，右移一位 = 除 2
>
> 位运算是 C 的"祖传手艺"——毕竟 C 当年就是用来写操作系统的，而操作系统整天在和"位"打交道。准备好了吗？开始吧！

---

## 10.2.1 先会数"二进制"

计算机里一切数据归根结底是 0/1。一个数在内存里就是一串 bit（位），比如 `6` 是 `110`，我们用 8 位写整齐是 `00000110`：

```
二进制位：  1   1   0   1   1   0   0   1   （这是 217）
对应权值：128  64  32  16   8   4   2   1
```

> 📌 **最右边那一位叫"最低位"，权重是 1**——所以一个数是奇是偶，看最低位是 1 还是 0 就行。

下面我们写个小帮手 `printBits`，把数用 8 位二进制打印出来（只看低 8 位，够用）：

```c
void printBits(unsigned int x) {
    for (int i = 7; i >= 0; i--) {
        printf("%d", (x >> i) & 1);   // 一位一位"抠"出来
    }
}
```

## 10.2.2 六大位运算符

| 运算符 | 名字 | 规则（按位操作） | 生活比喻 |
|--------|------|-----------------|---------|
| `&` | 按位与 | **全1才1**，否则 0 | 两个都要同意才通过 |
| `\|` | 按位或 | **有1就1** | 只要有一个同意就行 |
| `^` | 按位异或 | **不同才1**（相同为0） | 意见不一致才响铃 |
| `~` | 按位取反 | 0变1、1变0 | 把灯全反转 |
| `<<` | 左移 | 所有位往左挪，右边补0 | 二进制后补 0 = ×2 |
| `>>` | 右移 | 所有位往右挪 | 去掉最低位 = ÷2 |

用 6（`00000110`）和 3（`00000011`）演示：

```c
#include <stdio.h>

void printBits(unsigned int x) {
    for (int i = 7; i >= 0; i--) {
        printf("%d", (x >> i) & 1);
    }
}

int main() {
    unsigned int a = 6;   // 0000 0110
    unsigned int b = 3;   // 0000 0011
    printf("a    = 6  →  "); printBits(a); printf("（二进制）\n");
    printf("b    = 3  →  "); printBits(b); printf("（二进制）\n");
    printf("a & b =    →  "); printBits(a & b); printf(" = %u\n", a & b);
    printf("a | b =    →  "); printBits(a | b); printf(" = %u\n", a | b);
    printf("a ^ b =    →  "); printBits(a ^ b); printf(" = %u\n", a ^ b);
    printf("~a   =    →  "); printBits(~a); printf("（~ 是取反）\n");
    return 0;
}
```

输出：
```
a    = 6  →  00000110（二进制）
b    = 3  →  00000011（二进制）
a & b =    →  00000010 = 2
a | b =    →  00000111 = 7
a ^ b =    →  00000101 = 5
~a   =    →  11111001（~ 是取反）
```

**对照着算一遍 `a & b`：**

```
  00000110  （6）
& 00000011  （3）
  --------
  00000010  （2）
```

按位对齐逐位做"全1才1"：只有**权重 2 那一位**两个数都是 1，其余位置至少有一个是 0 → 结果 `00000010` = 2。

> 💡 `~a` 在 32 位 int 里其实是把 32 位全取反（`1111...1001`），我们打印时只截了低 8 位，所以看到 `11111001`。

## 10.2.3 实用招数 ①：判断奇偶、乘2除2

```c
#include <stdio.h>

int main() {
    int n = 7;
    if (n & 1) printf("%d 是奇数\n", n);      // 最低位是1 → 奇数
    else printf("%d 是偶数\n", n);

    int x = 6;
    printf("%d << 1 = %d\n", x, x << 1);      // 左移1位 = ×2
    printf("%d >> 1 = %d\n", x, x >> 1);      // 右移1位 = ÷2
    printf("%d << 2 = %d\n", x, x << 2);      // 左移2位 = ×4
    return 0;
}
```

输出：
```
7 是奇数
6 << 1 = 12
6 >> 1 = 3
6 << 2 = 24
```

> 📌 **原理一句话：** 二进制里往左挪一位，等于每位权重翻倍 → 整体 ×2；往右挪一位 → ÷2。`x << 2` 就是连续左移两次 = ×4。**移位比乘除更快**，编译器自己也会偷偷这么优化。

## 10.2.4 实用招数 ②：用一个 int 当"32 个开关"（权限系统）

真实系统里，"能不能读/能不能写/能不能执行"经常用一个整数打包。我们把每一位当成一个开关：

```c
#define READ  1   // 001：能读
#define WRITE 2   // 010：能写
#define EXEC  4   // 100：能执行
```

于是权限可以拼成一个数（比如"可读可写" = 011 = 3）：

| 操作 | 写法 | 含义 |
|------|------|------|
| 打开某权限 | `perm = perm | READ;` | 按位或，把对应位变 1 |
| 关闭某权限 | `perm = perm & ~READ;` | 先 `~` 把 READ 位以外的变1、READ 位变0，再 `&` |
| 检查某权限 | `if (perm & READ)` | 结果不为 0 → 该位是 1 |
| 切换某权限 | `perm = perm ^ READ;` | 异或：1↔0 来回翻 |

```c
#include <stdio.h>

#define READ  1   // 001：能读
#define WRITE 2   // 010：能写
#define EXEC  4   // 100：能执行

int main() {
    int perm = READ | WRITE;              // 011：读 + 写
    printf("perm 初始值：%d\n", perm);

    if (perm & READ)  printf("可以读\n");
    if (perm & WRITE) printf("可以写\n");
    if (perm & EXEC)  printf("可以执行\n");

    perm = perm | EXEC;                   // 打开 EXEC
    if (perm & EXEC) printf("加上 EXEC 后：可以执行了\n");

    perm = perm & ~WRITE;                 // 关闭 WRITE
    if (perm & WRITE) printf("还能写\n");
    else printf("去掉 WRITE 后：不能写了\n");

    perm = perm ^ READ;                   // 切换 READ（1 → 0）
    printf("切换 READ 后 perm 值：%d\n", perm);
    return 0;
}
```

输出：
```
perm 初始值：3
可以读
可以写
加上 EXEC 后：可以执行了
去掉 WRITE 后：不能写了
切换 READ 后 perm 值：4
```

> 🎉 看到了吗？几十个"开关"挤在**一个 int 里**，一次就能开/关/查——这就是 Unix/Linux 文件权限 `rwx` 的底层玩法（`chmod 755` 的 755 就是这么来的）！

> ⚠️ **提醒：`&` 和 `|` 是"按位"运算，和 `&&`/`||`（逻辑运算，用于 if 判断）不是一回事！** `3 & 2` 是数值运算得 2；`a && b` 只关心"真假"得 1 或 0。别混！

## 10.2.5 还有个小彩蛋：异或加密

`x ^ y` 有个神奇性质：**一个数连续异或同一个数两次，会变回它自己**：

```
(a ^ k) ^ k == a
```

用它就能做最简单的"密钥加密"：用 k 异或原文得到密文，再用同样的 k 异或密文，就能还原原文（可用来加密文件或隐藏字符串）。练一练试试看！

## 10.2.6 本节小结

这一节我们学了：

✅ **六大位运算符：** `&`（全1才1）、`|`（有1就1）、`^`（不同才1）、`~`（取反）、`<<`（左移×2）、`>>`（右移÷2）

✅ **实用招数：** `n & 1` 判奇偶；`x << 1` 乘2；移位比乘除更快

✅ **权限开关：** 一个 int 打包多个标志，`|` 打开、`& ~` 关闭、`&` 检查、`^` 切换

✅ **别混淆：** `& |` 是按位运算，`&& ||` 是逻辑运算

> 💡 **记住：位运算是 C 与硬件"对话"的语言。想写出高效的开关、标志、状态机，它都是主角。**

### 三、改错题

**8. 以下代码有 3 处概念错误：**

```c
#include <stdio.h>

int main() {
    int a = 6, b = 3;
    int c = a && b;        // 错误区①：想求"按位与"，这里用的是逻辑与！
    printf("按位与结果：%d\n", c);

    int n = 8;
    if (n << 1 == 4) {     // 错误区②：<< 的优先级和 == 谁高？会怎样？
        printf("8 左移1位是 4？\n");
    }

    int perm = 5;          // 101
    perm = perm ^ 4;       // 错误区③：这里是想"关闭"还是"切换"EXEC 位？
    printf("perm = %d\n", perm);
    return 0;
}
```

> 提示：①`&&`/`||` 是逻辑运算，`&`/`|` 才是按位；②位运算符优先级比 `==` 低，要先加括号 `(n << 1) == 4`；③异或 `^` 是"切换"而不是"清零"。
