# 10.4 qsort 与比较器

第 8 章我们手写过三种 O(n²) 排序和快速排序；8.5.5 还预告过标准库里有一个"任何类型都能排"的 `qsort`，当时只看了比较函数的样子，细节说好留给第 10 章。现在兑现。

`qsort` 住在 `<stdlib.h>` 里，本质是 10.3"回调"思想的工业化产品：**排序算法它包了，"谁该排前面"这条规则留给你**。学完这一节，你会同时收获一个实用工具和一条设计原则。

## 10.4.1 qsort 的四个参数

`qsort` 的原型：

```c
void qsort(void *base, size_t nmemb, size_t size,
           int (*compar)(const void *, const void *));
```

拆成四个参数看，每个都不难：

| 参数 | 意思 | 你要传什么 |
|------|------|-----------|
| `base` | 数组首地址 | 数组名（自动退化成指针） |
| `nmemb` | 元素**个数** | `count` 这类变量 |
| `size` | 单个元素的**字节数** | `sizeof(int)`、`sizeof(struct contact)` |
| `compar` | 比较器：返回负/零/正的函数指针 | 你自己写的比较函数名 |

两个参数类型上的讲究：

1. **`void *` 是"不知道类型的指针"**（4.6.2）。`qsort` 想给任何类型排序，就不能在参数里写死 `int *` 或 `struct student *`，只能用 `void *` 把"具体类型"这一层暂时藏起来，等你的比较器把它转换回去。
2. **`size_t` 是 `sizeof` 的结果类型**（3.1 用 `%zu` 打印过它）。元素个数和元素大小都用 `size_t`，平时传 `int` 变量也没问题，隐式转换会完成。

`qsort` 为什么需要 `size`？因为它要亲手搬动元素做交换，却不认识元素的内容——只告诉它首地址，它连"一个元素占几个字节"都不知道，根本没法把第 0 个和第 1 个换位置。`base` 告诉它"从哪开始"，`nmemb` 告诉它"有多少个"，`size` 告诉它"每个多大"——三个数一凑，任何数组在它眼里都是一排等宽的格子。

## 10.4.2 比较器：三条约定

比较器是你在排序中唯一拥有"话语权"的地方，三条约定：

**约定一：参数是 `const void *`，先转换回具体类型再取值。**

```c
int compare_int(const void *a, const void *b)
{
	int x = *(const int *)a;
	int y = *(const int *)b;

	return (x > y) - (x < y);
}
```

`(const int *)a` 把"不知道类型的指针"转回 `int *`，再解引用取值。参数带 `const` 是因为 `qsort` 承诺不让你通过这个指针改元素——比较只是"看"，不是"动"。

**约定二：返回负数、0、正数，表示 a 应排前、无所谓、b 应排前。**

`qsort` 只看返回值的**符号**，不看大小。返回 `-5` 和返回 `-1` 对它来说一模一样。所以比较器的正确写法是把结果"规约"成符号：

```c
return (x > y) - (x < y);
```

逐项翻译：`x > y` 时得 `1 - 0 = 1`（正，b 在前），`x < y` 时得 `0 - 1 = -1`（负，a 在前），相等得 `0`。一个表达式，永远只会产生 -1、0、1。

**约定三：不要写 `return x - y;`。**

旧代码里常见 `x - y`，数据小时它能工作，为什么不行？**溢出**。1.4.6 讲过 int 的范围约 ±21 亿：`x = 2147483647`、`y = -2147483648` 时，`x - y` 的真值约 43 亿，装不进 int——有符号溢出又是未定义行为，返回值的符号完全不可信，排序结果随之错乱。`(x > y) - (x < y)` 两个比较各得 0 或 1，相减最多差 1，永远不会溢出。8.5.5 埋的伏笔在这里正式兑现：**从第一个比较器开始就写规约形式，别给 `x - y` 任何机会。**

眼见为实，看看"直接相减"能离谱到什么程度：

```c
// 10.4.2 qsort_overflow.c
#include <stdio.h>
#include <limits.h>

int main(void)
{
	int big = INT_MAX;
	int small = INT_MIN;

	printf("INT_MAX = %d，INT_MIN = %d\n", big, small);
	printf("直接相减会溢出：%d - %d 的结果用 long long 算是 %lld\n",
	       big, small, (long long)big - (long long)small);
	printf("真正的差远超 int 范围，返回值符号可能错乱\n");
	printf("(big > small) - (big < small) = %d\n",
	       (big > small) - (big < small));

	return 0;
}
```

<!-- output: 10.4.2 -->
```text
INT_MAX = 2147483647，INT_MIN = -2147483648
直接相减会溢出：2147483647 - -2147483648 的结果用 long long 算是 4294967295
真正的差远超 int 范围，返回值符号可能错乱
(big > small) - (big < small) = 1
```

用 `long long` 一算就清楚：真差值约 43 亿，而 `int` 装不下 21 亿以上的数。规约写法则给出干净的 `1`——big 大于 small，符号正确。

## 10.4.3 第一个实战：int 数组排序

```c
// 10.4.1 qsort_int.c
#include <stdio.h>
#include <stdlib.h>

int compare_int(const void *a, const void *b)
{
	int x = *(const int *)a;
	int y = *(const int *)b;

	return (x > y) - (x < y);
}

int main(void)
{
	int nums[6] = {7, 2, 9, 4, 5, 2};

	qsort(nums, 6, sizeof(int), compare_int);

	printf("升序：");
	for (int i = 0; i < 6; i++) {
		printf("%d", nums[i]);
		if (i < 5) {
			printf(" ");
		}
	}
	printf("\n");

	return 0;
}
```

<!-- output: 10.4.1 -->
```text
升序：2 2 4 5 7 9
```

`qsort` 一行完成第 8 章几十行的工作。注意两个 2 的顺序没有保证——比较器返回 0 时 `qsort` 按它自己的方式摆放相等元素，这是标准明确允许的（`qsort` 不保证"稳定"，想保持相等元素的原始相对顺序得靠别的办法，初学阶段知道即可）。

降序只要把比较器反过来：

```c
// 10.4.3 qsort_desc_double.c
#include <stdio.h>
#include <stdlib.h>

int compare_int_desc(const void *a, const void *b)
{
	int x = *(const int *)a;
	int y = *(const int *)b;

	return (x < y) - (x > y);
}

int compare_double(const void *a, const void *b)
{
	double x = *(const double *)a;
	double y = *(const double *)b;

	if (x < y) {
		return -1;
	}
	if (x > y) {
		return 1;
	}
	return 0;
}

void print_ints(const int nums[], int count)
{
	for (int i = 0; i < count; i++) {
		printf("%d", nums[i]);
		if (i < count - 1) {
			printf(" ");
		}
	}
	printf("\n");
}

int main(void)
{
	int scores[5] = {73, 91, 66, 85, 78};

	qsort(scores, 5, sizeof(int), compare_int_desc);
	printf("分数降序：");
	print_ints(scores, 5);

	double heights[4] = {1.75, 1.62, 1.80, 1.68};

	qsort(heights, 4, sizeof(double), compare_double);
	printf("身高升序：");
	for (int i = 0; i < 4; i++) {
		printf("%.2f", heights[i]);
		if (i < 3) {
			printf(" ");
		}
	}
	printf("\n");

	return 0;
}
```

<!-- output: 10.4.3 -->
```text
分数降序：91 85 78 73 66
身高升序：1.62 1.68 1.75 1.80
```

两个新看点：

1. **降序 = 升序比较器的方向反过来**。`(x < y) - (x > y)`：x 小时得 -1，x 排前，大的自然挤到前面。升序降序是同一个算法换一副"眼镜"。
2. **double 比较器不能照抄整数那招**。`(x > y) - (x < y)` 对 double 其实也能用（两个比较结果是 int），但 `x - y` 绝对不行——浮点相减不溢出也可能差出一个极小的非零值，被 `qsort` 当成"不相等"。规范写法是 `if (x < y) return -1; if (x > y) return 1; return 0;`，把三种情况写明白。

## 10.4.4 给结构体排序

`qsort` 不认识你的结构体，但它也不需要认识：你给它的 `size` 告诉它每个格子多宽，你的比较器告诉它谁在前。

```c
// 10.4.4 qsort_struct.c
#include <stdio.h>
#include <stdlib.h>
#include <string.h>

struct student {
	char name[32];
	int score;
};

int compare_by_name(const void *a, const void *b)
{
	const struct student *sa = (const struct student *)a;
	const struct student *sb = (const struct student *)b;

	return strcmp(sa->name, sb->name);
}

int compare_by_score_desc(const void *a, const void *b)
{
	const struct student *sa = (const struct student *)a;
	const struct student *sb = (const struct student *)b;

	return (sa->score < sb->score) - (sa->score > sb->score);
}

void print_students(const struct student list[], int count)
{
	for (int i = 0; i < count; i++) {
		printf("%s(%d)", list[i].name, list[i].score);
		if (i < count - 1) {
			printf(" ");
		}
	}
	printf("\n");
}

int main(void)
{
	struct student list[4] = {
		{"Bob", 72},
		{"Alice", 88},
		{"Dave", 88},
		{"Carol", 95},
	};

	qsort(list, 4, sizeof(struct student), compare_by_name);
	printf("按姓名：");
	print_students(list, 4);

	qsort(list, 4, sizeof(struct student), compare_by_score_desc);
	printf("按分数降序：");
	print_students(list, 4);

	return 0;
}
```

<!-- output: 10.4.4 -->
```text
按姓名：Alice(88) Bob(72) Carol(95) Dave(88)
按分数降序：Carol(95) Alice(88) Dave(88) Bob(72)
```

比较器内部固定三步：`void *` 转回 `const struct student *`、取字段比较、规约返回值。姓名比较直接用 `strcmp` 的返回值——3.4 讲过它恰好返回负/零/正，天然满足比较器约定，连规约都省了。

按分数排序时，Alice 和 Dave 同为 88 分，谁先谁后由 `qsort` 内部决定，两次运行之间没有保证。**想给"同分"再定一个次序，就是多关键字排序**——8.4 留的那道伏笔在这里兑现。

## 10.4.5 多关键字比较：总分相同比语文

多关键字的套路：先比第一关键字，不相等直接返回；相等再比第二关键字。就像点名册先按班级排，同班的再按学号排：

```c
// 10.4.5 qsort_two_keys.c
#include <stdio.h>
#include <stdlib.h>
#include <string.h>

struct record {
	char name[32];
	int chinese;
	int math;
};

/* 先比总分（降序），总分相同再按语文分（降序） */
int compare_total_then_chinese(const void *a, const void *b)
{
	const struct record *ra = (const struct record *)a;
	const struct record *rb = (const struct record *)b;

	int total_a = ra->chinese + ra->math;
	int total_b = rb->chinese + rb->math;

	if (total_a != total_b) {
		return (total_a < total_b) - (total_a > total_b);
	}

	return (ra->chinese < rb->chinese) - (ra->chinese > rb->chinese);
}

int main(void)
{
	struct record list[4] = {
		{"xiaoming", 85, 90},
		{"xiaohong", 90, 85},
		{"xiaogang", 88, 84},
		{"xiaomei", 85, 95},
	};

	qsort(list, 4, sizeof(struct record),
	      compare_total_then_chinese);

	for (int i = 0; i < 4; i++) {
		printf("%s 总分 %d（语文 %d 数学 %d）\n",
		       list[i].name,
		       list[i].chinese + list[i].math,
		       list[i].chinese, list[i].math);
	}

	return 0;
}
```

<!-- output: 10.4.5 -->
```text
xiaomei 总分 180（语文 85 数学 95）
xiaohong 总分 175（语文 90 数学 85）
xiaoming 总分 175（语文 85 数学 90）
xiaogang 总分 172（语文 88 数学 84）
```

xiaohong 和 xiaoming 总分同为 175，第二关键字语文分分出先后：90 在 85 前。**每一级关键字都要单独规约**，别把"总分 × 100 + 语文"这类合并写法当成比较值——那不过是把溢出请回来。想要第三关键字，就在第二关键字相等时继续往下比，套一层 `if` 的事。

## 10.4.6 算法与规则分离

把本章的 `qsort` 和第 8 章手写的快排放一起看：

| | 手写 quick_sort（8.5） | qsort + 比较器 |
|---|------------------------|----------------|
| 排序算法 | 写死在函数里 | 标准库提供，你不用管 |
| 比较规则 | `nums[j] <= pivot` 写死 | 比较器函数，随调用而换 |
| 能排的类型 | int 数组 | 任何类型 |
| 换排序规则的成本 | 改算法内部代码 | 换一个函数参数 |

`qsort` 把**"怎么排"（算法骨架）和"谁在前"（比较规则）彻底分开**：算法只用一套，规则随便换。这就是回调思想（10.3）的价值——变化的和不变化的各归其位，加一种排序需求只需加一个函数，不碰算法一行代码。

这种"骨架固定、规则可插拔"的分离，是工程代码最重要的设计习惯之一：菜单分发把"菜单骨架"和"各选项的行为"分开，`apply` 把"遍历"和"变换"分开，`qsort` 把"排序"和"比较"分开。往后写任何稍大的程序，先问一句"哪部分是骨架，哪部分是规则"，代码自然就有了层次。

## 10.4.7 常见错误

| 错误写法 | 问题 | 正确写法 |
|----------|------|----------|
| `return x - y;` | int 相减可能溢出，符号错乱 | `return (x > y) - (x < y);` |
| `qsort(arr, n, sizeof(int *), cmp);` | 元素大小传错，qsort 按错误的宽度搬动数据 | `sizeof(int)`，与数组元素类型一致 |
| `return strcmp(...) == 0;` | 只返回 0 或 1，丢了"小于"的负值 | `return strcmp(sa->name, sb->name);` |
| 比较器参数不写 `const` | 与函数指针类型不匹配，编译警告或错误 | `const void *a` 原样照抄原型 |
| 依赖"同值元素保持原顺序" | `qsort` 不保证稳定 | 需要稳定顺序时加第二关键字 |

## 10.4.8 小结

- `qsort(base, nmemb, size, compar)`：数组首地址、元素个数、元素字节数、比较器函数指针，四样缺一不可。
- 比较器收两个 `const void *`，先转换回具体类型；返回负/零/正表示 a 前/相等/b 前，`qsort` 只看符号。
- int 比较器规约写法 `(x > y) - (x < y)`，防溢出；`x - y` 是必须戒掉的老写法。
- 降序把比较方向反过来；double 用显式 `if` 分三种情况；结构体比较器取字段；多关键字层层 `if`，每级都单独规约。
- `qsort` 的本质是算法与规则分离：骨架由标准库承担，规则由比较器注入——回调思想最著名的产品。

#### 一、选择题

1. B。`qsort(base, nmemb, size, compar)`——数组、个数、元素大小、比较器，顺序不能乱。
2. C。正数表示"b 应排在 a 前面"；负数才是 a 在前，0 表示无所谓。
3. B。`INT_MAX - (-1)` 或 `INT_MAX - INT_MIN` 都会超出 int 范围，有符号溢出是未定义行为，符号可能错乱。

#### 二、填空题

4. `void`；字节数（`sizeof(元素类型)`）。
5. `(x < y)`；`strcmp`。

#### 三、改错题

6. 三处错误：

- 第一处：`return a - b;` 错。`a`、`b` 是 `const void *` 指针，直接相减做的是指针运算，结果毫无意义；就算先取值再相减（`x - y`），也有溢出风险，而且是升序。应取值后写 `return (x < y) - (x > y);`。
- 第二处：`qsort` 第三个参数传了 `sizeof(int *)`。元素是 `int`，应传 `sizeof(int)`；传指针大小会让 `qsort` 按 8 字节（常见平台）一组搬动数据，把数组搅乱。
- 第三处：`cmp_desc` 里没有把 `void *` 转换回 `const int *` 就使用，取不到元素值（编译都过不了）。应先 `int x = *(const int *)a;`。

修正后的完整程序：

```c
#include <stdio.h>
#include <stdlib.h>

int cmp_desc(const void *a, const void *b)
{
	int x = *(const int *)a;
	int y = *(const int *)b;

	return (x < y) - (x > y);
}

int main(void)
{
	int arr[5] = {7, 2, 9, 4, 5};

	qsort(arr, 5, sizeof(int), cmp_desc);

	for (int i = 0; i < 5; i++) {
		printf("%d ", arr[i]);
	}
	printf("\n");

	return 0;
}
```

#### 四、编程题

7. 参考代码：

```c
#include <stdio.h>
#include <stdlib.h>

int compare_double(const void *a, const void *b)
{
	double x = *(const double *)a;
	double y = *(const double *)b;

	if (x < y) {
		return -1;
	}
	if (x > y) {
		return 1;
	}
	return 0;
}

int main(void)
{
	double vals[4] = {3.2, 1.5, 2.8, 1.5};

	qsort(vals, 4, sizeof(double), compare_double);

	for (int i = 0; i < 4; i++) {
		printf("%.2f", vals[i]);
		if (i < 3) {
			printf(" ");
		}
	}
	printf("\n");

	return 0;
}
```

输出：

```text
1.50 1.50 2.80 3.20
```

两个 1.50 谁在前没有保证，`qsort` 不保证稳定。

8. 参考代码：

```c
#include <stdio.h>
#include <stdlib.h>
#include <string.h>

struct book {
	char title[32];
	double price;
};

int compare_by_price_desc(const void *a, const void *b)
{
	const struct book *ba = (const struct book *)a;
	const struct book *bb = (const struct book *)b;

	if (ba->price > bb->price) {
		return -1;
	}
	if (ba->price < bb->price) {
		return 1;
	}
	return 0;
}

int main(void)
{
	struct book list[3] = {
		{"aa", 25.0},
		{"bb", 18.5},
		{"cc", 30.0},
	};

	qsort(list, 3, sizeof(struct book), compare_by_price_desc);

	for (int i = 0; i < 3; i++) {
		printf("%s %.2f\n", list[i].title, list[i].price);
	}

	return 0;
}
```

输出：

```text
cc 30.00
aa 25.00
bb 18.50
```

价格是 `double`，比较器用显式 `if` 分三种情况；降序所以"大于"返回 -1。
