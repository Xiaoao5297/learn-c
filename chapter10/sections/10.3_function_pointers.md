# 10.3 函数指针：把"函数"也当成数据

> 💬 **节前语：**
>
> 第4章我们说过：**指针存的是"门牌号"**。变量的门牌号是它的地址，数组的门牌号是首元素地址。
>
> 那……**函数有没有门牌号？** 当然有！函数编译后也住在内存里，也有自己的地址。把函数的地址存进一个指针，就得到了**函数指针（Function Pointer）**。
>
> 有了它，就能玩出第4章做不到的花样：
>
> - 🎮 **把函数当数据存**：把一串函数放进数组，按编号直接调用（做菜单神器）
> - 🧩 **把函数当参数传**：让"算法"和"规则"分离，写出优雅的回调
> - 📦 **下一节的 `qsort`**：C 标准库能"什么类型都能排"，就是靠接收你传进去的"比较器"函数
>
> 这一节先学会函数指针的"地基"：怎么声明、怎么调用、怎么存进数组。准备好了吗？开始吧！

---

## 10.3.1 函数指针怎么声明和调用？

先看最朴素的三步：声明一个"能装下 `int f(int,int)` 这类函数"的指针，赋值，然后通过它调用。

```c
#include <stdio.h>

int add(int a, int b) { return a + b; }
int sub(int a, int b) { return a - b; }
int mul(int a, int b) { return a * b; }

int main() {
    int (*op)(int, int);       // 声明函数指针：能指向"返回 int、收两个 int"的函数
    op = add;                  // 让 op 指向 add（函数名就是它的地址！）
    printf("op=add：%d\n", op(10, 3));

    op = sub;
    printf("op=sub：%d\n", op(10, 3));

    op = mul;
    printf("op=mul：%d\n", op(10, 3));
    return 0;
}
```

输出：
```
op=add：13
op=sub：7
op=mul：30
```

### 🔍 语法解剖：`int (*op)(int, int)`

| 部分 | 意思 |
|------|------|
| `int` | 这个指针指向的**函数返回 int** |
| `(*op)` | op 是**指针**（括号不能省！）|
| `(int, int)` | 指向的函数**接收两个 int 参数** |

> 🚨 **`(*op)` 的括号是命根子！** 写 `int *op(int, int)` 就变成"一个返回 `int*` 的普通函数 op"了——完全不同的东西。口诀：**看到 `(*名字)` 才是指针**。

### 💡 两种调用方式都可以

```c
op(10, 3);      // 直接像函数一样用（推荐，好读）
(*op)(10, 3);   // 显式"解引用"再用（更强调它是指针）
```

函数名（如 `add`）就代表函数地址，所以 `op = add` 就行，不用写 `&add`（写了也对）。

## 10.3.2 函数指针数组：把一串函数"排队"

函数指针也能进数组——这样就能用**下标**选函数了：

```c
#include <stdio.h>

int add(int a, int b) { return a + b; }
int sub(int a, int b) { return a - b; }
int mul(int a, int b) { return a * b; }
int divide(int a, int b) { return b ? a / b : 0; }

int main() {
    int (*ops[])(int, int) = {add, sub, mul, divide};  // 函数指针数组
    char *names[] = {"加法", "减法", "乘法", "除法"};

    int a = 20, b = 5;
    for (int i = 0; i < 4; i++) {
        printf("%s：%d\n", names[i], ops[i](a, b));
    }
    return 0;
}
```

输出：
```
加法：25
减法：15
乘法：100
除法：4
```

> 💡 这种"数组 + 下标"选函数的方式，特别适合做**菜单系统**：选项 1 调 `ops[0]`、选项 2 调 `ops[1]`……10.5 的毕业项目我们也能这样给菜单"排兵布阵"。

## 10.3.3 小贴士：用 `typedef` 给函数指针起别名

函数指针的声明有点绕，可以用 `typedef` 起个短名：

```c
typedef int (*BinOp)(int, int);   // 以后 BinOp 就代表"这种函数指针类型"

BinOp op;        // 相当于 int (*op)(int, int);
BinOp ops[4];    // 函数指针数组
```

> 💡 起别名后，函数指针用起来跟普通类型一样自然。工程里大量使用这种写法。

---

## 10.3.4 什么叫"回调"？—— 函数指针的大用处预告

函数指针真正的威力，是**把函数当作参数传给另一个函数**——那个函数在合适的时机再"回过头来"调用它，这就是 **回调（callback）**。

```c
// 例子：让 sort 接收"怎么比"的回调
void sort(int a[], int n, int (*how)(int, int));   // how 就是回调
```

> 🎯 **"算法"和"规则"分离**：排序函数只管排，至于"谁该在前"，由调用者按需传入。下一节的 `qsort` 就是这么干的！

## 10.3.5 本节小结

这一节我们学了：

✅ **函数指针：** 存函数地址的指针，`int (*op)(int,int)`，括号是命根子

✅ **函数名即地址：** `op = add`，调用 `op(a,b)` 或 `(*op)(a,b)`

✅ **函数指针数组：** 下标选函数，菜单系统的利器

✅ **typedef 起别名：** `typedef int (*BinOp)(int,int);`

✅ **回调预告：** 把"怎么比"作为参数传进去，算法与规则分离

> 💡 **记住：函数指针让"函数"第一次可以当"数据"用。下一节，我们就用它去驾驭标准库的 `qsort`！**

### 三、改错题

**8. 以下使用函数指针的代码有 2 个错误：**

```c
#include <stdio.h>

int add(int a, int b) { return a + b; }
int square(int x) { return x * x; }

int main() {
    int *op(int, int);        // 错误区①：这是函数指针声明吗？
    op = add;
    printf("%d\n", op(3, 4)); // 期望 7

    op = square;              // 错误区②：square 的类型和 op 匹配吗？
    printf("%d\n", op(3, 4));
    return 0;
}
```

> 提示：①应写 `int (*op)(int,int);`；②`square` 只收一个参数，类型对不上，不能塞进 op。
