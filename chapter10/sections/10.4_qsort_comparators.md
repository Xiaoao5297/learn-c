## 10.4.1 认识 qsort：四个参数

`qsort` 的原型：

```c
void qsort(void *base, size_t nmemb, size_t size,
           int (*compar)(const void *, const void *));
```

看不懂没关系，拆开看四个参数：

| 参数 | 意思 |
|------|------|
| `base` | 要排序的数组（首地址）|
| `nmemb` | 元素个数 |
| `size` | 每个元素多大（`sizeof(元素)`）|
| `compar` | **你提供的"比较规则"函数**（函数指针！）|

> 📌 **为什么有 `void *`？** 因为 qsort 要"什么类型都能排"，所以它把数组当"一串不知道内容的字节"看待——你不告诉它每个元素多大、怎么比，它就只能靠你的比较器决定顺序。

---

## 10.4.2 比较器怎么写？三条铁律

比较器是个返回 `int` 的函数，收到两个元素 `a`、`b`：

```
返回负数 → a 应该排在 b 前面
返回 0   → a、b 相等（谁在前都行）
返回正数 → b 应该排在 a 前面
```

写的时候有两步套路：

```c
int cmpAsc(const void *a, const void *b) {
    int x = *(const int *)a;   // ① void* 先转回 int*，再 * 取值
    int y = *(const int *)b;
    return x - y;              // ② 升序：小的返回负数 → 排前面
}
```

> 🚨 **`const void *` 是 qsort 的规定**（"我不关心你是什么类型"）。用的时候：① 强转回 `const 你的类型 *`；② `*` 解引用拿值。类型不同，强转的目标类型就不同——这就是它"万能"的秘密。

---

## 10.4.3 第一个实战：int 数组升序 + 降序

同一个数组，想升序升序、想降序降序——**只换一个比较器**：

```c
#include <stdio.h>
#include <stdlib.h>

int cmpAsc(const void *a, const void *b) {
    int x = *(const int *)a;
    int y = *(const int *)b;
    return x - y;                 // 升序
}

int cmpDesc(const void *a, const void *b) {
    int x = *(const int *)a;
    int y = *(const int *)b;
    return y - x;                 // 降序：大的返回负数 → 排前面
}

int main() {
    int arr[] = {7, 2, 9, 4, 5};
    int n = 5;

    qsort(arr, n, sizeof(int), cmpAsc);
    printf("升序：");
    for (int i = 0; i < n; i++) printf("%d ", arr[i]);
    printf("\n");

    qsort(arr, n, sizeof(int), cmpDesc);
    printf("降序：");
    for (int i = 0; i < n; i++) printf("%d ", arr[i]);
    printf("\n");
    return 0;
}
```

输出：
```
升序：2 4 5 7 9
降序：9 7 5 4 2
```

> 🎉 **第8章辛辛苦苦手写的排序，这一行全包了**——而且比 O(n²) 的冒泡快得多。看，函数指针 + 比较器就是这么优雅。

## 10.4.4 高级实战：给"结构体数组"排序

`qsort` 不挑类型，所以给结构体排也轻轻松松——比较器里换成结构体字段即可：

```c
#include <stdio.h>
#include <stdlib.h>
#include <string.h>

typedef struct {
    char name[32];
    int score;
} Student;

// 按姓名字典序排（strcmp 正好返回 负/0/正）
int cmpByName(const void *a, const void *b) {
    const Student *sa = (const Student *)a;
    const Student *sb = (const Student *)b;
    return strcmp(sa->name, sb->name);
}

// 按分数升序排
int cmpByScore(const void *a, const void *b) {
    const Student *sa = (const Student *)a;
    const Student *sb = (const Student *)b;
    return sa->score - sb->score;
}

int main() {
    Student stu[] = {
        {"Alice", 88},
        {"Bob", 72},
        {"Carol", 95}
    };
    int n = 3;

    qsort(stu, n, sizeof(Student), cmpByName);
    printf("按姓名排：");
    for (int i = 0; i < n; i++) printf("%s(%d) ", stu[i].name, stu[i].score);
    printf("\n");

    qsort(stu, n, sizeof(Student), cmpByScore);
    printf("按分数排：");
    for (int i = 0; i < n; i++) printf("%s(%d) ", stu[i].name, stu[i].score);
    printf("\n");
    return 0;
}
```

输出：
```
按姓名排：Alice(88) Bob(72) Carol(95)
按分数排：Bob(72) Alice(88) Carol(95)
```

> 📌 注意比较器的通用写法：`const 你的类型 *p = (const 你的类型 *)a;`，然后比较 `p->字段` 或 `*p`。**想加一种新的排序方式，就多写一个比较器，仅此而已。**

## 10.4.5 为什么 qsort 这么"万能"？—— 算法与规则分离

回顾一下我们做的事：

| 变化的东西 | 不变的东西 |
|-----------|-----------|
| 比较规则（升序/降序、按名字/按分数）| qsort 的排序算法 |
| 数据类型（int/结构体/字符串…）| qsort 的"排序骨架" |

**qsort 把"怎么排"（算法）和"谁在前"（规则）彻底分开**——算法只用一套，规则随便换。这正是上一节说的"回调"思想的威力：**传入的 `compar` 就是回调函数**。

> 💡 这种"算法 + 回调"的套路你在真实项目里会反复见到：排序、查找、事件处理、定时器……都是"骨架固定、行为可插拔"。

## 10.4.6 本节小结

这一节我们学了：

✅ **qsort 四参数：** 数组、个数、元素大小、比较器函数指针

✅ **比较器铁律：** 返回 负/0/正 决定 a、b 谁在前

✅ **int 排序：** 升序 `x-y`，降序 `y-x`，只换比较器

✅ **结构体排序：** 比较器里取字段，`strcmp` 排名字、数值比较排分数

✅ **万能原因：** 算法与规则分离——骨架固定、行为可插拔（回调思想）

### 三、改错题

**8. 以下排序代码有 3 个错误：**

```c
#include <stdio.h>
#include <stdlib.h>

int cmpDesc(const void *a, const void *b) {
    int x = *(const int *)a;
    int y = *(const int *)b;
    return x - y;                 // 错误区①：main 里调用它想要"降序"，对吗？
}

int main() {
    int arr[] = {7, 2, 9, 4, 5};
    int n = 5;
    qsort(arr, n, sizeof(int *), cmpDesc);   // 错误区②：第三个参数该传多大？
    for (int i = 0; i < n; i++) printf("%d ", arr[i]);
    printf("\n");                            // 期望输出：9 7 5 4 2
    return 0;
}
```

> 提示：①升/降序看返回 `x-y` 还是 `y-x`；②第三个参数应传 `sizeof(int)`，传 `sizeof(int *)` 会让 qsort 把数据当"指针"搬，全乱套！
