**11. 写出下面程序的输出。**

```c
#include <stdio.h>

int main(void)
{

	a = a * 2;

	printf("a = %d\n", a);
	printf("大小是 %zu 字节\n", sizeof(a));

```

## 四、编程题（每题 10 分，共 20 分）

**13. 圆的面积**

编写程序，读入半径（`double`），计算并输出圆的面积，保留 2 位小数。要求：

- 用 `const` 定义圆周率。
- 检查 `scanf` 的返回值，输入不合法时打印 `输入格式不对` 并返回 1。
- 使用 `int main(void)`。

**14. 带校验的年龄输入**

编写程序，反复读入年龄，直到输入的是 0 到 120 之间的整数为止，然后输出 `明年你 N 岁`。要求：

- 输入不是整数时，清空缓冲区并提示重新输入。
- 输入的数超出范围时，提示重新输入。

### 一、选择题

1. **B**。编译器负责把源代码翻译成机器能执行的可执行文件；编辑器只负责写代码。
2. **C**。`(void)` 明确表示不接收参数，是本书采用的标准写法。
3. **C**。`%d` 是整数格式符，却传了一个 `double`。这类格式符与类型不匹配的问题通常不会导致编译错误，输出是混乱的数字，实际行为未定义。
4. **C**。`sizeof` 的返回类型是 `size_t`，对应的格式符是 `%zu`。
5. **B**。`%s` 不带宽度时，输入超过数组容量就会越界写入，造成缓冲区溢出。A 的宽度 31 比数组大小 32 小 1，是正确写法。

### 二、填空题

6. `main`。
7. 换行；制表符（用于对齐）。
8. `3.14`。`%.2f` 表示保留 2 位小数。
9. 65。
10. `%lf`；空格。

### 三、阅读程序

11. 输出：

```text
a = 20
大小是 4 字节
```

`a` 从 7 加 3 得 10，再乘 2 得 20。`int` 在常见平台上占 4 字节。

12. 输出：

```text
c 的编号是 10
```

`10` 是 `\n` 的 ASCII 编码。`%d` 读到 `25` 就停了，回车残留在缓冲区里，随后不带空格的 `%c` 把它读走。改正：写成 `scanf(" %c", &c);`，用空格跳过空白字符；或先用 `getchar` 循环清空一行。

### 四、编程题

13. 参考代码：

```c
#include <stdio.h>

int main(void)
{
	const double PI = 3.14159;
	double radius = 0.0;

	printf("请输入半径：");
	if (scanf("%lf", &radius) != 1) {
		printf("输入格式不对\n");
		return 1;
	}

	printf("面积是 %.2f\n", PI * radius * radius);

	return 0;
}
```

14. 参考代码：

```c
#include <stdio.h>

int main(void)
{
	int age = -1;

	while (age < 0 || age > 120) {
		printf("请输入年龄（0 到 120）：");

		if (scanf("%d", &age) != 1) {
			printf("输入的不是整数\n");

			int ch;
			while ((ch = getchar()) != '\n' && ch != EOF) {
			}

			age = -1;
		} else if (age < 0 || age > 120) {
			printf("范围不对\n");
		}
	}

	printf("明年你 %d 岁\n", age + 1);

	return 0;
}
```

关键点有三处：检查 `scanf` 返回值；非法输入后用 `getchar` 循环清空缓冲区，否则死循环；循环条件覆盖"不是整数"和"超出范围"两种情况。
