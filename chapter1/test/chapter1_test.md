## 三、改错题（共1题）

**11. 以下程序有4个错误，请逐一找出并改正，使程序能正确运行并输出：**

```
你好，C语言！
圆周率： 3.14159
```

**有错误的代码：**

```c
#include <stdio.h>

int main() {
    const double PI = 3.14159;
    PI = 3.14;
    
    char name[] = "你好，C语言！

}
```

### 改错题答案

**11. 四处错误：**

```c
#include <stdio.h>

int main() {
    // 错误1：PI = 3.14（常量不能被修改，删除此行）
    const double PI = 3.14159;
    
    // 错误2："你好，C语言！ → "你好，C语言！"（字符串缺少右引号）
    char name[] = "你好，C语言！";
    printf("%s\n", name);
    
    // 错误3：%d → %lf（PI 是 double 类型，要用 %lf）
    // 错误4：末尾加 \n（让"圆周率"单独一行）
    printf("圆周率：%lf\n", PI);
    return 0;
}
```

### 编程题参考答案

**12. 自我介绍卡片：**

```c
#include <stdio.h>

int main() {
    char name[] = "小明";
    int age = 20;
    double height = 175.5;
    
    printf("=== 自我介绍 ===\n");
    printf("姓名：%s\n", name);
    printf("年龄：%d\n", age);
    printf("身高：%.1f\n", height);
    return 0;
}
```

---

**13. 简单计算器：**

```c
#include <stdio.h>

int main() {
    int a = 15;
    int b = 4;
    
    printf("a = %d, b = %d\n", a, b);
    printf("a + b = %d\n", a + b);
    printf("a - b = %d\n", a - b);
    printf("a * b = %d\n", a * b);
    printf("a / b = %d\n", a / b);
    printf("a %% b = %d\n", a % b);
    return 0;
}
```

> 📌 **注意：** 在C语言中，如果要打印一个 `%` 字符，需要写 **两个** `%%`！

---

**14. 温度转换器：**

```c
#include <stdio.h>

int main() {
    // 摄氏转华氏
    double celsius = 25.0;
    double fahrenheit = celsius * 9 / 5 + 32;
    
    printf("=== 温度转换 ===\n");
    printf("摄氏度：%.1f\n", celsius);
    printf("华氏度：%.1f\n", fahrenheit);
    
    // 加分项：华氏转摄氏
    double f = 98.6;
    double c = (f - 32) * 5 / 9;
    printf("华氏度：%.1f → 摄氏度：%.1f\n", f, c);
    return 0;
}
```
