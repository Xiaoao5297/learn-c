# 1.5 scanf 与输入

前面的程序只会"自说自话"，数据写死在代码里。这一节让程序能读用户输入的东西——用 `scanf`。

先声明一点：`scanf` 是 C 标准库里出了名的"坑多"函数。这一节不仅教它怎么用，更教你怎么避开它的坑。最后的小节会把"输入校验"做完整，它也是本章的工程支线。

## 1.5.1 scanf 的基本用法

`scanf`（scan formatted，格式化扫描）从标准输入读取数据，按格式符解析后放进变量。基本形式：

```c
scanf("%d", &age);
```

对照 `printf` 看：格式符是同一套（`%d` 对应整数），但参数多了一个 `&`。

`&` 是取地址（address-of）运算符，`&age` 表示"变量 `age` 所在的内存地址"。`scanf` 需要地址，是因为它要把读到的值**写进**你的变量——只给值是改不了变量的，必须告诉它"写到哪去"。第 3 章讲指针时，你会对这个区别有更深的理解。

先给一个完整的例子：

```c
// 1.5.1 scan_two.c
#include <stdio.h>

int main(void)
{
	int a = 0;
	int b = 0;

	printf("请输入两个整数（用空格隔开）：");
	if (scanf("%d %d", &a, &b) != 2) {
		printf("输入格式不对\n");
		return 1;
	}

	printf("%d + %d = %d\n", a, b, a + b);

	return 0;
}
```

<!-- output: 1.5.1 -->
```text
请输入两个整数（用空格隔开）：3 + 5 = 8
```

实际交互时，你输入 `3 5` 再回车，程序打印 `3 + 5 = 8`。上面输出里提示文字后面直接跟结果，是因为本书用输入重定向喂的数据，回车不可见。

常用格式符与 `printf` 基本一致，但有一处重要差异：

| 格式符 | scanf 中对应的变量 | 说明 |
|--------|--------------------|------|
| `%d` | `int`，要加 `&` | 读整数 |
| `%lf` | `double`，要加 `&` | 读浮点数 |
| `%c` | `char`，要加 `&` | 读单个字符 |
| `%s` | 字符数组，不加 `&` | 读单词，**必须带宽度**，见 1.5.4 |

注意读 `double` 用的是 `%lf`，不是 `%f`。这一点和 `printf` 不同（`printf` 打印 `double` 用 `%f`），很容易记混。

## 1.5.2 必须检查 scanf 的返回值

`scanf` 的返回值是"成功读取的项目数"。这个值经常被忽略，但它是发现输入错误的关键线索：

- 输入 `3 5`，`scanf("%d %d", &a, &b)` 返回 `2`——两个都读到了。
- 输入 `abc`，它返回 `0`——连一个整数都没读到。
- 遇到输入结束（如按 Ctrl+D），返回 `EOF`。

不检查返回值时，输入不合法的后果是：变量保持原值或垃圾值，程序继续往下跑，产出错误结果。检查返回值，程序才有机会及时反应。1.5.1 的示例已经用了标准写法：

```c
if (scanf("%d", &x) != 1) {
	printf("输入格式不对\n");
	return 1;
}
```

**从今天起养成习惯：每写一个 `scanf`，就用 `if` 检查它的返回值。** 这是本书贯穿始终的要求，后面的章节和工程代码都按这个标准写。

一个只读一个数的完整例子：

```c
// 1.5.2 scan_check.c
#include <stdio.h>

int main(void)
{
	int age = 0;

	printf("请输入年龄：");
	if (scanf("%d", &age) != 1) {
		printf("这不是一个整数\n");
		return 1;
	}

	if (age < 0 || age > 150) {
		printf("年龄应该在 0 到 150 之间\n");
		return 1;
	}

	printf("明年你 %d 岁\n", age + 1);

	return 0;
}
```

<!-- output: 1.5.2 -->
```text
请输入年龄：明年你 21 岁
```

两次运行对照：输入 `20` 时输出 `明年你 21 岁`；输入 `abc` 时输出 `这不是一个整数`，程序以状态 1 退出。这就是"读到了"和"读对了"分开检查的思路：先检查返回值，再检查取值范围。

## 1.5.3 回车残留问题

读整数后再读单个字符，会遇到一个经典的坑。先看现象：

```c
// 1.5.3 scan_char_bad.c
#include <stdio.h>

int main(void)
{
	int age = 0;
	char choice = 0;

	printf("请输入年龄：");
	scanf("%d", &age);

	printf("请输入 y 或 n：");
	scanf("%c", &choice);

	printf("choice 的编号是 %d\n", choice);

	return 0;
}
```

<!-- output: 1.5.3 -->
```text
请输入年龄：请输入 y 或 n：choice 的编号是 10
```

交互时输入 `25` 回车、再输入 `y` 回车，结果 `choice` 的编号是 `10`——10 是 `\n` 的 ASCII 编码。**第二个 `scanf` 读到的是残留的回车，不是你输入的 y。**

原因：`%d` 读到 `25` 就停了，用户按下的回车符 `\n` 还留在输入缓冲区里。接着的 `%c` 不跳过任何字符，上来就把这个 `\n` 读走了。

### 解法一：在 `%c` 前加一个空格

```c
scanf(" %c", &choice);
```

格式串里的空格表示"跳过所有连续的空白字符（空格、制表符、换行符）"，直到读到真正的内容。这是最常用的解法。

### 解法二：手动读掉残留的回车

```c
int ch;

while ((ch = getchar()) != '\n' && ch != EOF) {
}
```

`getchar()` 每次从输入读一个字符。这个循环把缓冲区里残留的字符一直读到行尾，把它们全部丢掉。需要"清空一行"的场合用它，比解法一更彻底。

修正后的完整程序：

```c
// 1.5.4 scan_char.c
#include <stdio.h>

int main(void)
{
	int age = 0;
	char choice = 0;

	printf("请输入年龄：");
	scanf("%d", &age);

	printf("请输入 y 或 n：");
	scanf(" %c", &choice);

	printf("age = %d, choice = %c\n", age, choice);

	return 0;
}
```

<!-- output: 1.5.4 -->
```text
请输入年龄：请输入 y 或 n：age = 25, choice = y
```

记住规则：**`%c` 前面习惯性加一个空格**，除非你确实想读空白字符本身。

## 1.5.5 读字符串：%s 必须带宽度

读字符串用 `%s` 配一个字符数组（array，第 3 章详讲）：

```c
char name[32];
scanf("%31s", name);
```

这里有两件事必须讲清楚。

### 为什么要带宽度

`%31s` 中的 `31` 是宽度上限：最多读 31 个字符。最后 1 个位置留给字符串结束符 `\0`。

如果不带宽度，格式串里只写一个孤零零的 `%s`，用户输入一旦超过 31 个字符，`scanf` 就会写出数组的边界，把内存里别的数据踩掉。这种错误叫缓冲区溢出（buffer overflow），轻则输出混乱，重则程序崩溃，也是许多安全漏洞的根源。编译器不会替你拦住它，所以必须在格式符里写死宽度。

**规则：本书所有 `%s` 一律写成 `%宽度s` 的形式，且宽度比数组大小小 1。**

数组大小 32，宽度就是 31。记住这个配套关系。

### 完整示例

```c
// 1.5.5 scan_name.c
#include <stdio.h>

int main(void)
{
	char name[32];

	printf("请输入名字：");
	if (scanf("%31s", name) != 1) {
		printf("输入格式不对\n");
		return 1;
	}

	printf("你好，%s\n", name);

	return 0;
}
```

<!-- output: 1.5.5 -->
```text
请输入名字：你好，小明
```

两点说明：

1. `%s` 读取时遇到空白（空格、回车）就停，所以只能读一个"单词"。读整行文字要用 `fgets`，第 3 章讲。
2. 数组名 `name` 本身就代表地址，所以 `%s` 后面**不加** `&`。这和 `%d`、`%lf` 形成对比，原因在第 3 章讲数组时解释。

## 1.5.6 读浮点数

读 `double` 用 `%lf`：

```c
// 1.5.6 scan_double.c
#include <stdio.h>

int main(void)
{
	double height = 0.0;

	printf("请输入身高（米）：");
	if (scanf("%lf", &height) != 1) {
		printf("输入格式不对\n");
		return 1;
	}

	printf("身高是 %.2f 米\n", height);

	return 0;
}
```

<!-- output: 1.5.6 -->
```text
请输入身高（米）：身高是 1.75 米
```

再强调一次：`scanf` 读 `double` 用 `%lf`，`printf` 打印 `double` 用 `%f`。用错的话输出会混乱。

## 1.5.7 输入校验：不合法就重来

1.5.2 的程序遇到非法输入时直接退出了。更好的体验是让用户重新输入，直到输入合法为止。把"检查返回值"和"检查取值范围"放进循环：

```c
// 1.5.7 scan_loop.c
#include <stdio.h>

int main(void)
{
	int score = -1;

	while (score < 0 || score > 100) {
		printf("请输入 0 到 100 之间的整数：");

		if (scanf("%d", &score) != 1) {
			printf("输入的不是整数，请重新输入\n");

			int ch;
			while ((ch = getchar()) != '\n' && ch != EOF) {
			}

			score = -1;
		} else if (score < 0 || score > 100) {
			printf("范围不对，请重新输入\n");
		}
	}

	printf("成绩是 %d\n", score);

	return 0;
}
```

<!-- output: 1.5.7 -->
```text
请输入 0 到 100 之间的整数：输入的不是整数，请重新输入
请输入 0 到 100 之间的整数：成绩是 59
```

实际交互是：先输入 `abc`，程序提示"输入的不是整数"，再输入 `59`，程序输出 `成绩是 59`。

这个循环的要点：

1. **返回值检查**：输入不是整数时，`scanf` 返回 0，而且那个非法内容会一直留在缓冲区。不清掉它，下一次 `scanf("%d", ...)` 还会读到同一个 `abc`，陷入死循环。所以必须用 `getchar` 循环把这一行清空。
2. **范围检查**：读到了整数还要看范围，不合法就继续循环。
3. **循环条件**：`score` 不在 0 到 100 之间就一直循环，合法时自然退出。

这就是"输入校验"（input validation）的雏形。**凡是读用户输入，都默认用户可能输入任何东西**——这是工程开发的基本假设，也是本章工程支线的核心：

> 本章的输入校验会在后续章节反复扩展：第 2 章学到循环和函数后，会把它封装成可复用的"安全读整数"函数；第 5 章讲错误处理时，会升级成统一的错误报告风格。现在先把"检查返回值 + 检查范围 + 清空缓冲区"三件事做熟。

## 1.5.8 小结

- `scanf` 从标准输入读取数据，格式符与 `printf` 同源，但参数要传地址（`&`）。
- `scanf` 读 `double` 用 `%lf`；`printf` 打印 `double` 用 `%f`。
- **必须检查 `scanf` 的返回值**：`if (scanf("%d", &x) != 1) { ... }`。
- `%d` 读整数后回车会残留在缓冲区，再读 `%c` 会读到 `\n`；解法是在 `%c` 前加空格，或用 `getchar` 循环清行。
- **`%s` 必须带宽度**：`%31s` 配 `char name[32]`，防止缓冲区溢出；数组名不加 `&`。
- 输入校验三件套：检查返回值、检查取值范围、非法输入后清空缓冲区。
- 凡读用户输入，默认它可能不合法。
