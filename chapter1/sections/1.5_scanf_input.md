# 1.5 让程序"听懂"你的话：scanf 输入

> 💬 **节前语：**
>
> 到现在为止，我们的程序只会"说话"（用 `printf` 打印），还不会"听话"。
>
> 想想看：一个程序如果只能打印写死的文字，那它永远只是"复读机"。真正有用的程序，都得**能接收用户输入**——比如：
>
> - 输入你的名字，程序向你问好
> - 输入半径，程序算出圆的面积
> - 输入两个数，程序帮你求和
>
> C 语言里负责"听"的就是 `scanf`（scan + format，扫描并格式化）。它和 `printf` 是"亲兄弟"：`printf` 按格式**输出**，`scanf` 按格式**输入**。
>
> 这一节我们就学会它，顺便躲过初学者最容易踩的"回车残留"大坑。准备好了吗？开始吧！

---

## 1.5.1 scanf 长什么样？先认识 `&`

`printf` 输出时把变量的**值**交给它；`scanf` 要输入时，得告诉它把读到的值**放到哪**——也就是"变量在内存里的地址"。

```c
#include <stdio.h>

int main() {
    int age;
    printf("请输入你的年龄：");
    scanf("%d", &age);          // 把读到的整数，放进变量 age
    printf("你 %d 岁了！\n", age);
    return 0;
}
```

运行示例（`15` 是你输入的）：
```
请输入你的年龄：15
你 15 岁了！
```

### 📌 那个神奇的 `&` 是什么？

```c
scanf("%d", &age);    // 注意 age 前面有个 &！
```

- `printf("%d", age)`：把 **age 的值**打印出来
- `scanf("%d", &age)`：把读到的数**放进 age 所在的内存**，所以需要 age 的**地址**

> 📌 **先记住这条规矩：`scanf` 里除了"字符数组/字符串"之外，普通变量前都要加 `&`。** 至于 `&` 到底怎么"取地址"、地址是什么，第 4 章《指针》会揭晓——现在先把它当成"交给 scanf 的魔法符号"。

---

## 1.5.2 常见格式符：`scanf` 版 vs `printf` 版不一样！

| 格式符 | `scanf` 怎么用 | `printf` 怎么用 | 变量类型 |
|--------|----------------|----------------|----------|
| `%d` | `scanf("%d", &n)` | `printf("%d", n)` | `int` |
| `%f` | `scanf("%f", &f)` | `printf("%f", f)` | `float` |
| `%lf` | `scanf("%lf", &d)` | `printf("%.2f", d)` | `double` |
| `%c` | `scanf("%c", &ch)` | `printf("%c", ch)` | `char` |
| `%s` | `scanf("%s", name)` | `printf("%s", name)` | `char` 数组（第3章细讲）|

> 🚨 **最容易踩的坑：`double` 在 `scanf` 里必须写 `%lf`，但在 `printf` 里写 `%f` 就够了（写 `%lf` 也行）。** 千万别把 `printf` 的 `%f` 直接搬进 `scanf`——那样读进去的数字会是一团乱码！

> 📌 一个 `scanf` 可以同时读多个数，中间用空格/回车隔开都行：
> ```c
> scanf("%d %d", &a, &b);    // 输入 "3 5" 或分行输入都可以
> ```

---

## 1.5.3 动手试：读两个整数求和

```c
#include <stdio.h>

int main() {
    int a, b;
    printf("请输入两个整数（用空格或回车隔开）：");
    scanf("%d %d", &a, &b);
    printf("和 = %d\n", a + b);
    return 0;
}
```

运行示例：
```
请输入两个整数（用空格或回车隔开）：3 5
和 = 8
```

> 💡 `scanf` 很"宽容"：输入 `3 5`、`3   5`、或者两行分别输入，它都能正确读走两个数——因为它会自动跳过数字之间的**空白**（空格、换行、Tab）。

---

## 1.5.4 读小数：`%lf`（double）

```c
#include <stdio.h>

int main() {
    double r;
    printf("请输入圆的半径：");
    scanf("%lf", &r);                 // double 输入：必须 %lf
    printf("面积 = %.2f\n", 3.14159 * r * r);   // double 输出：用 %f（%.2f 保留两位）
    return 0;
}
```

运行示例：
```
请输入圆的半径：2.5
面积 = 19.63
```

> 📌 记住口诀：**输入 `double` 用 `%lf`，输出 `double` 用 `%f`。**

## 1.5.5 大坑预警：读 `%c` 会吃到"回车残留" 🕳️

`scanf` 自动跳过**数字之间**的空白，但对 `%c` 却不跳——它会**原样读走下一个字符**，包括你按下的回车 `\n`！

看这个"翻车"程序：先读整数年龄，再读一个字符等级：

```c
#include <stdio.h>

int main() {
    int age;
    char grade;
    printf("请输入年龄：");
    scanf("%d", &age);
    printf("请输入等级（A/B/C）：");
    scanf("%c", &grade);              // ❌ 这里会出问题！
    printf("年龄=%d，等级='%c'\n", age, grade);
    return 0;
}
```

运行示例：
```
请输入年龄：15
请输入等级（A/B/C）：        ← 程序根本没等我们输入 B，就直接往下跑了！
年龄=15，等级='
'
```

### 🔍 发生了什么？

```
你输入： 15↵ B↵
            ↑
第一次 scanf("%d")  读走了数字 15，但把"↵"（回车）留在了输入缓冲区里
第二次 scanf("%c")  一上来就读到了这个残留的"↵"→ grade 变成了换行符！
```

> 📌 **为什么 `%d` 会跳过回车、`%c` 不跳？** 因为 `%d` 这类"数字格式"会自动跳过前导空白，而 `%c` 是"一个字符都不能少"地读——回车也算一个字符。

### ✅ 解法 1：在 `%c` 前加一个空格，让它跳过空白

```c
scanf(" %c", &grade);     // ✅ 空格会先跳过回车/空格，再读真正想要的字符
```

### ✅ 解法 2：手动把残留的回车"读掉"

```c
scanf("%d", &age);
while (getchar() != '\n');   // 把这一行剩下的字符（含回车）全部读掉
scanf("%c", &grade);
```

**修复后的完整程序（用解法 1）：**

```c
#include <stdio.h>

int main() {
    int age;
    char grade;
    printf("请输入年龄：");
    scanf("%d", &age);
    printf("请输入等级（A/B/C）：");
    scanf(" %c", &grade);            // ✅ 空格跳过上次留下的回车
    printf("年龄=%d，等级='%c'\n", age, grade);
    return 0;
}
```

运行示例：
```
请输入年龄：15
请输入等级（A/B/C）：B
年龄=15，等级='B'
```

> 💡 **记规律：只要前面用 `scanf` 读过"数字/字符串"，后面想用 `%c` 读字符，就给 `%c` 前加个空格，基本不会错。**

## 1.5.6 输入错了怎么办？检查 scanf 的返回值

用户手滑输入了字母，可你的程序却等着数字——会发生什么？`scanf` 读不到想要的类型，就直接"放弃治疗"了，变量保持原样（甚至可能是垃圾值）。

好在 `scanf` 有**返回值**：它返回"**成功读到了几个**"。想读 1 个，就检查是不是等于 1：

```c
#include <stdio.h>

int main() {
    int n;
    printf("请输入一个整数：");
    if (scanf("%d", &n) != 1) {     // 没成功读到 1 个数？
        printf("输入的不是数字，程序结束。\n");
        return 1;                   // 提前结束程序
    }
    printf("你输入的是 %d\n", n);
    return 0;
}
```

运行示例（输入的是字母）：
```
请输入一个整数：abc
输入的不是数字，程序结束。
```

> 📌 **养成好习惯：读几个数就检查返回值是不是几。** 这样程序不会在错误的输入上继续乱跑。想一次读 2 个数就读完检查 `scanf(...) == 2`。

> 💡 还有一种更"整行"的读法：先用 `fgets` 把整行读进来再解析，适合读"带空格的一句话"。它需要字符串知识，第 3 章《字符串》和复习篇都会再见面。

## 1.5.7 本节小结

这一节我们学了：

✅ **scanf 基本用法：** `scanf("格式", &变量)`，按格式读取用户输入

✅ **`&` 的意义：** 取变量的地址，"先记住"，第4章详解

✅ **格式符对照：** `%d` int、`%lf` double（输入）、`%c` char、`%s` 字符串

✅ **`printf` vs `scanf` 的差异：** double 输入要 `%lf`，输出用 `%f` 就够

✅ **回车残留坑：** `%c` 不跳过空白会吃到回车 → 前面加空格或先读掉回车

✅ **输入校验：** 检查 `scanf` 返回值（读到几个），防止垃圾输入继续乱跑

> 💡 **记住：程序会"说"（printf）还不行，还要会"听"（scanf）。会听 + 会说 + 会算，程序才算真正活起来！**
