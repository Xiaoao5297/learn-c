## 1.4.1 什么是"变量"？

### 🎯 核心比喻：变量就是一个"盒子"

想象一下你在家里的储物柜：

```
┌─────────────────┐
│                 │
│     储物柜       │
│                 │
│   ┌─────────┐   │
│   │  物品    │   │
│   └─────────┘   │
│                 │
│   标签：鞋子     │
└─────────────────┘
```

| 储物柜 | 变量 |
|--------|------|
| 柜子里的物品 | 存在变量里的**值** |
| 柜子上的标签 | 变量的**名字** |
| 柜子的类型（鞋柜/衣柜） | 变量的**类型** |
| 换掉柜子里的东西 | 给变量**赋新值** |

### 📌 变量的定义

> **变量（Variable）** = 一个有名字的"存储位置"，用来存放数据。

**为什么要用变量？** 因为没有变量的程序，就像——

- 一台只会唱一首歌的音乐播放器
- 一本每页内容都一样的书
- 一个只会说同一句话的机器人

**有了变量，程序就能：**

- ✅ 记住用户输入的信息
- ✅ 做数学运算
- ✅ 根据不同的情况做不同的事
- ✅ 处理不确定的数据

## 1.4.2 声明和使用变量

### 📝 第一种方式：先声明，再赋值

```c
#include <stdio.h>

int main() {
    int age;              // 声明一个整数变量，名叫 age
    age = 20;             // 给 age 赋值
    
    printf("年龄：%d\n", age);
    return 0;
}
```

### 🔍 逐行解析

```c
int age;
```

| 部分 | 含义 |
|------|------|
| `int` | 变量的类型，表示里面存的是整数 |
| `age` | 变量的名字（你可以自己取） |
| `;` | 语句结束的分号 |

**翻译成人话：** "给我准备一个名字叫 `age` 的盒子，专门用来装整数"

---

```c
age = 20;
```

| 部分 | 含义 |
|------|------|
| `age` | 变量名 |
| `=` | 赋值运算符（不是数学的等于！） |
| `20` | 要存进去的值 |

**翻译成人话：** "把数字 20 放进 age 这个盒子里"

> ⚠️ **重要：** 编程里的 `=` 不是数学上的"等于"，而是**赋值**！
> 
> 它的意思是：**把右边的值，存到左边的变量里**。

---

### 📝 第二种方式：声明并立即赋值（最常用！）⭐

```c
#include <stdio.h>

int main() {
    int age = 20;         // 声明 + 赋值，一步搞定
    printf("年龄：%d\n", age);
    return 0;
}
```

这相当于把两步合并成一步：

| 之前 | 现在 |
|------|------|
| `int age;`<br>`age = 20;` | `int age = 20;` |

> 💡 **实际开发中，`int age = 20;` 是最常用的！** 声明并赋值一步到位，写起来最快。

## 1.4.3 变量的"变"——修改变量的值

"变量"之所以叫"变量"，就是因为它的值**可以改变**。

```c
#include <stdio.h>

int main() {
    int age = 20;             // age 现在是 20
    printf("年龄：%d\n", age);
    
    age = 21;                 // age 变成 21
    printf("一年后，年龄：%d\n", age);
    
    age = age + 1;            // age 再加 1
    printf("又一年后，年龄：%d\n", age);
    return 0;
}
```

输出：
```
年龄： 20
一年后，年龄： 21
又一年后，年龄： 22
```

### 🤔 理解 `age = age + 1`

在数学里，`x = x + 1` 是一个矛盾的等式（一个数怎么可能等于自己加1呢？）。

但在编程里，这完全合理！因为它的意思是：

```
1. 先计算右边：age + 1 = 20 + 1 = 21
2. 再把结果存回左边：age = 21
3. age 的值从 20 变成了 21
```

**比喻：** 就像你往存钱罐里加钱：
- 存钱罐原来有 20 元
- 你往里面加了 1 元
- 现在存钱罐里有 21 元
- `存钱罐 = 存钱罐 + 1` ✅

### ⚡ 偷懒写法

编程中，`age = age + 1` 太常用了，C语言提供了偷懒写法：

| 完整写法 | 偷懒写法 | 意思 |
|----------|----------|------|
| `age = age + 1;` | `age++;` 或 `++age;` | 加1 |
| `age = age - 1;` | `age--;` 或 `--age;` | 减1 |
| `sum = sum + i;` | `sum += i;` | 加上i |
| `total = total * 2;` | `total *= 2;` | 乘以2 |

> 💡 `++` 叫**自增**，`--` 叫**自减**，`+=` 叫**复合赋值**。以后写循环会经常用到！

## 1.4.4 数据类型

### 🎯 比喻：不同类型的盒子

不同类型的物品需要不同的容器来装：

| 物品 | 容器 | 比喻 |
|------|------|------|
| 水 | 杯子/瓶子 | 液体需要能密封的容器 |
| 衣服 | 衣柜 | 衣物需要挂起来的空间 |
| 书 | 书架 | 书本需要分层的架子 |

C语言也是如此，不同类型的数据需要不同类型的"盒子"。

### 📊 C的基本数据类型

| 类型 | 存什么 | 例子 | printf格式符 |
|------|--------|------|--------------|
| `int` | 整数 | `10`, `-5`, `100` | `%d` |
| `float` | 小数（单精度） | `3.14`, `-0.5` | `%f` |
| `double` | 小数（双精度，更精确） | `3.14159265` | `%lf` |
| `char` | 单个字符 | `'A'`, `'a'`, `'1'` | `%c` |

> 📌 **C语言没有专门的"字符串"类型！** 字符串是用 `char` 的数组实现的，我们会在后面的章节学习。先混个脸熟：
> ```c
> char name[] = "小明";
> printf("姓名：%s\n", name);   // %s 打印字符串
> ```

---

### 1️⃣ 整数类型 `int`

```c
int age = 25;
int score = 100;
int temperature = -10;
```

> 📌 `int` 是 **integer**（整数）的缩写。
> 
> 能存多大的数？大约 ±21亿，日常完全够用！

**可以做什么运算：**

```c
int a = 10;
int b = 3;

printf("%d\n", a + b);   // 加：13
printf("%d\n", a - b);   // 减：7
printf("%d\n", a * b);   // 乘：30
printf("%d\n", a / b);   // 除：3（整数除法，舍去小数！）
printf("%d\n", a % b);   // 取余：1（10 ÷ 3 = 3 余 1）
```

> ⚠️ **重点！** 在C语言中，**两个整数相除，结果还是整数**！
> 
> `10 / 3` 的结果是 `3`，不是 `3.33...`，小数部分被直接**丢掉**了。
> 
> （这和数学不一样，数学里 10÷3=3.333...，但C里整数除整数只取整数部分。）

---

### 2️⃣ 小数类型 `float` 和 `double`

```c
float pi = 3.14159;        // 单精度小数
double price = 19.99;      // 双精度小数（更精确）
```

| 类型 | 精度 | 建议 |
|------|------|------|
| `float` | 约6~7位有效数字 | 简单场景够用 |
| `double` | 约15~16位有效数字 | **推荐**，更精确 |

> 📌 `double` 名字的意思是 **double precision**（双精度），是 `float` 的"加强版"。
> 
> 日常编程中，**小数优先用 `double`**！

**整数和小数的区别：**

```c
int a = 10;        // int（整数）
double b = 10.0;   // double（小数）
```

看起来一样，但在C眼里：`10` 和 `10.0` 是**不同类型**的！

**打印小数时的格式控制：**

```c
double pi = 3.14159;

printf("%f\n", pi);    // 输出：3.141590（默认6位小数）
printf("%.2f\n", pi);  // 输出：3.14（保留2位小数）
printf("%.4f\n", pi);  // 输出：3.1416（保留4位小数，会四舍五入）
```

> 💡 `%.nf` 表示保留 n 位小数。这个技能以后打印价格、成绩时会非常有用！

---

### 3️⃣ 字符类型 `char`

```c
char grade = 'A';
char op = '+';
```

> 📌 字符必须用**单引号** `''` 包裹（字符串才用双引号 `""`）。
> 
> `char` 是 **character**（字符）的缩写。

**打印字符：**

```c
#include <stdio.h>

int main() {
    char grade = 'A';
    printf("你的等级是：%c\n", grade);
    return 0;
}
```

输出：
```
你的等级是：A
```

---

### 4️⃣ 布尔类型 `bool`（需要引入头文件）

C语言原本没有布尔类型，但在 **C99标准**之后，引入了 `bool`：

```c
#include <stdbool.h>    // 需要引入这个头文件！

int main() {
    bool isAdult = true;
    bool isStudent = false;
    
    printf("是否成年：%d\n", isAdult);    // 输出：1（true 打印为 1）
    printf("是否学生：%d\n", isStudent);  // 输出：0（false 打印为 0）
    return 0;
}
```

> 📌 **小知识：** 布尔值只有两个——`true`（真）和 `false`（假）。
> 
> 打印时，`true` 显示为 `1`，`false` 显示为 `0`。
> 
> 其实在C里，**0 代表假，任何非0的数都代表真**。

**布尔值通常用于判断：**

```c
int age = 20;
bool isAdult = (age >= 18);    // age 大于等于 18 吗？是的，所以 isAdult = true

printf("%d\n", isAdult);       // 输出：1（代表 true）
```

## 1.4.5 printf 格式符总结

printf 需要知道每个变量"是什么类型"，才能正确打印。所以要用**格式符**告诉它：

| 格式符 | 对应类型 | 例子 | 输出 |
|--------|----------|------|------|
| `%d` | 整数 `int` | `printf("%d", 20)` | `20` |
| `%f` | 小数 `float` | `printf("%.1f", 3.14)` | `3.1` |
| `%lf` | 小数 `double` | `printf("%.2lf", 3.14159)` | `3.14` |
| `%c` | 字符 `char` | `printf("%c", 'A')` | `A` |
| `%s` | 字符串 `char[]` | `printf("%s", "你好")` | `你好` |
| `\n` | 换行 | `printf("\n")` | 换一行 |
| `\t` | 制表符 | `printf("\t")` | 空几个格 |

**一个printf打印多个值：**

```c
#include <stdio.h>

int main() {
    int age = 20;
    double score = 95.5;
    char grade = 'A';
    
    printf("年龄 %d 岁，成绩 %.1f 分，等级 %c\n", age, score, grade);
    return 0;
}
```

输出：
```
年龄 20 岁，成绩 95.5 分，等级 A
```

> 💡 **记住公式：** 格式符按顺序和后面的变量一一对应，第一个 `%d` 对应第一个变量，以此类推。

## 1.4.6 常量：永远不会变的值

有时候，你想定义一个**永远不变**的值。这时要用**常量**。

C语言有两种方式定义常量：

### 方式一：`const` 关键字（推荐）

```c
const double PI = 3.14159;   // 圆周率，永远不变
const int DAYS_IN_WEEK = 7;  // 一周7天，不会变
```

### 方式二：`#define` 宏定义

```c
#define PI 3.14159   // 注意：没有类型、没有分号！
```

**两种方式的对比：**

| | `const double PI = 3.14;` | `#define PI 3.14` |
|---|---|---|
| 有类型吗 | 有（double） | 没有 |
| 要分号吗 | 要 | 不要 |
| 推荐程度 | ⭐ 推荐 | 传统写法 |

> 📌 初学者用 **`const`** 就够了，简单直观。

**完整示例：**

```c
#include <stdio.h>

int main() {
    const double PI = 3.14159;
    
    printf("圆周率：%lf\n", PI);
    return 0;
}
```

| 变量 | 常量 |
|------|------|
| 值可以随时修改 | 定义后不能修改 |
| 比喻：储物柜 | 比喻：保险箱（锁上了就不能改） |

**尝试修改常量会报错：**

```c
const double PI = 3.14159;
PI = 3.14;    // ❌ 错误！常量不能被赋值
```

## 1.4.7 综合示例：学生信息卡片

让我们用一个综合的例子，把今天学的串起来：

```c
#include <stdio.h>

int main() {
    // === 学生信息卡片 ===
    
    // 整数：年龄
    int age = 18;
    
    // 小数：成绩
    double score = 95.5;
    
    // 字符：等级
    char grade = 'A';

    printf("=== 学生信息 ===\n");

    printf("成绩：%.1f 分\n", score);
    printf("等级：%c\n", grade);
    
    // 修改变量
    age = age + 1;
    printf("一年后，年龄变成：%d 岁\n", age);
    
    return 0;
}
```

输出：
```
=== 学生信息 ===
年龄：18 岁
成绩：95.5 分
等级：A
一年后，年龄变成：19 岁
```

## 1.4.8 命名规则

### 📝 变量名的规则

| 规则 | 正确 ✅ | 错误 ❌ |
|------|---------|---------|
| 只能用字母、数字、下划线 | `myName`, `age1` | `my-name`, `1age` |
| 不能以数字开头 | `name1` | `1name` |
| 不能用C的关键字 | 不能用 `int`, `return` 等做变量名 | `int = 10;` ❌ |
| 区分大小写 | `Age` 和 `age` 是两个变量 |  |

### 💡 命名建议

C语言社区的习惯是使用 **下划线命名法**（snake_case）：

| 风格 | 例子 | C推荐？ |
|------|------|----------|
| 下划线 | `my_name`, `student_age` | ✅ 是 |
| 驼峰 | `myName`, `studentAge` | ⚠️ 也可以 |
| 全大写 | `MYNAME` | ❌ 不推荐（常量除外） |

> 📌 **小贴士：** C语言里常量通常用**全大写**：`PI`、`DAYS_IN_WEEK`。
