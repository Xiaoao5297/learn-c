# 1.4 变量与数据类型

程序的本质之一是处理数据。这一节讲数据放在哪里、怎么标记它、有哪些类型，以及 `printf` 怎样把它们打印出来。

## 1.4.1 什么是变量

变量（variable）是内存里一块有名字的存储空间。程序运行时，数据就放在这些空间里；通过名字，我们可以存入或取出数据。

把变量想成一个带标签的盒子：盒子里放数据，标签是变量名。写程序时做两件事：

1. 声明一个盒子，决定它放什么类型的数据。
2. 用名字往盒子里放值、取值。

变量名是我们给内存空间起的名字。起名有规则：

| 规则 | 例子 |
|------|------|
| 只能由字母、数字、下划线组成 | `score`、`max_value` |
| 不能以数字开头 | `2day` 不合法，`day2` 合法 |
| 不能用 C 的关键字 | `int`、`return` 不能作变量名 |
| 区分大小写 | `age` 和 `Age` 是两个不同的变量 |

本书统一采用小写加下划线的命名风格（snake_case），如 `total_price`、`max_count`，与第 2 章的代码规范一致。

> **常见错误：变量名没有意义**
>
> - 错误写法：`int a = 95; int b = 3;`
> - 正确写法：`int score = 95; int level = 3;`
>
> 两种写法机器都能执行，但一个月后回看代码，`a` 和 `b` 是什么意思只有天知道。变量名是写给人看的。

## 1.4.2 声明、赋值和初始化

使用变量前必须先声明（declare）：告诉编译器变量叫什么、是什么类型。

声明之后可以赋值（assign）：用 `=` 把一个值放进去。声明的同时就赋值，叫初始化（initialize）：

```c
// 1.4.2 variables.c
#include <stdio.h>

int main(void)
{
	int score;
	int age = 20;
	double pi = 3.14159;
	char grade = 'A';

	score = 95;
	age = age + 1;

	printf("score = %d\n", score);
	printf("age = %d\n", age);
	printf("pi = %f\n", pi);
	printf("grade = %c\n", grade);

	return 0;
}
```

<!-- output: 1.4.2 -->
```text
score = 95
age = 21
pi = 3.141590
grade = A
```

几个要点：

1. `int score;` 只是声明，盒子里的值是不确定的。使用前必须赋值，否则读到的是垃圾值。
2. `=` 是赋值，不是数学上的"相等"。`age = age + 1` 的意思是：取出 `age` 的值，加 1，再放回 `age`。执行后 `age` 从 20 变成 21。
3. 赋值可以随时进行，变量的值因此可以"变"——这就是"变量"名字的由来。

> **常见错误：使用未初始化的变量**
>
> - 错误写法：`int score; printf("%d\n", score);`
> - 正确写法：`int score = 0; printf("%d\n", score);`
>
> 未初始化的局部变量里是随机垃圾值，打印结果不可预测。现代编译器开启警告（`-Wall`）时会提醒你，但不是所有环境都会提醒。建议：声明变量的同时就初始化。

> **常见错误：混淆 `=` 和 `==`**
>
> - 错误写法：`if (age = 18) { ... }`（把 18 赋给 age，条件永远为真）
> - 正确写法：`if (age == 18) { ... }`
>
> `=` 是赋值，`==` 是比较。这个坑第 2 章讲条件判断时还会强调，现在先记住。

## 1.4.3 基本数据类型

数据有不同种类：整数、小数、字符。C 用类型（type）来区分它们，不同类型占用不同大小的内存、支持不同的运算。

本节先掌握三个最基本的类型：

| 类型 | 用于 | 示例 |
|------|------|------|
| `int` | 整数 | `42`、`-7`、`0` |
| `double` | 小数（浮点数） | `3.14`、`-0.5`、`2.0` |
| `char` | 单个字符 | `'A'`、`'9'`、`'\n'` |

字符类型的字面量用单引号，且只能放一个字符：`'A'` 是合法的，`'AB'` 不是。注意 `'9'` 是字符 9，不是数字 9，两者的区别在 1.4.6 讲。

为什么有了 `int` 还需要其他类型？因为它们占用内存不同、表示范围不同。用 `sizeof` 可以查看任何类型或变量占用的字节数（byte）：

```c
// 1.4.3 sizeof_types.c
#include <stdio.h>

int main(void)
{
	printf("int 的大小：%zu 字节\n", sizeof(int));
	printf("double 的大小：%zu 字节\n", sizeof(double));
	printf("char 的大小：%zu 字节\n", sizeof(char));

	int x = 10;
	double y = 3.14;

	printf("变量 x 的大小：%zu 字节\n", sizeof(x));
	printf("变量 y 的大小：%zu 字节\n", sizeof(y));

	return 0;
}
```

<!-- output: 1.4.3 -->
```text
int 的大小：4 字节
double 的大小：8 字节
char 的大小：1 字节
变量 x 的大小：4 字节
变量 y 的大小：8 字节
```

说明两点：

1. `sizeof` 是 C 的一个运算符，返回变量或类型占用的字节数。
2. 打印 `sizeof` 的结果用 `%zu`。这是专门对应 `size_t` 类型的占位符；误用整数或长整型格式符打印它，在某些平台上会产生错误结果，务必使用 `%zu`。

C 标准只保证 `sizeof(char)` 是 1，其他类型的大小随平台变化。上表是 64 位 Linux/Windows 的典型值。

## 1.4.4 printf 格式符表

1.3 节见过几个占位符，这里给出完整的常用表。占位符也叫格式符（format specifier），必须与要打印的值类型匹配：

| 格式符 | 匹配的类型 | 用途 | 示例输出 |
|--------|------------|------|----------|
| `%d` | `int` | 打印整数 | `42` |
| `%f` | `double` | 打印浮点数，默认 6 位小数 | `3.141590` |
| `%.2f` | `double` | 打印浮点数，保留 2 位小数 | `3.14` |
| `%c` | `char` | 打印单个字符 | `A` |
| `%s` | 字符串 | 打印一串字符 | `hello` |
| `%zu` | `size_t` | 打印 `sizeof` 的结果 | `4` |
| `%p` | 指针 | 打印地址 | `0x7ffd4a2b3c` |

关于 `%f` 和 `%zu` 的补充说明：

- `%.nf` 中的 n 是保留的小数位数，写 `%.0f` 就是四舍五入到整数。
- `%zu` 对应 `size_t`（sizeof 的返回类型），不要误写成整型或长整型的格式符。

```c
// 1.4.4 printf_formats.c
#include <stdio.h>

int main(void)
{
	int age = 20;
	double price = 12.5;
	char initial = 'L';
	char name[] = "Lin";

	printf("%d\n", age);
	printf("%f\n", price);
	printf("%.2f\n", price);
	printf("%c\n", initial);
	printf("%s\n", name);
	printf("%zu\n", sizeof(int));

	return 0;
}
```

<!-- output: 1.4.4 -->
```text
20
12.500000
12.50
L
Lin
4
```

`%p` 打印变量的内存地址。取地址用 `&` 运算符，打印时需要转换成 `void *` 类型：

```c
int age = 20;
printf("%p\n", (void *)&age);
```

输出类似 `0x7fdfe98508`。地址的具体数值每次运行、每台机器都不同，无法在文档里给出固定结果，看懂格式即可：`0x` 开头说明是十六进制数，表示内存中的一个位置。指针是第 3 章的主题，现在只需要知道"变量有地址"。

> **常见错误：格式符与类型不匹配**
>
> - 错误写法：`printf("%d\n", 3.14);`（用整数格式符打印浮点数）
> - 正确写法：`printf("%f\n", 3.14);`
>
> 类型不匹配时，输出会是混乱的数字，甚至程序崩溃。这是初学者最常见的"程序不报错但输出不对"的原因之一。编译器的 `-Wall` 警告通常能抓到，请重视每一条警告。

## 1.4.5 常量

有些值在程序运行过程中不应该变，比如圆周率、最大分数。C 用常量（constant）表示它们：

```c
// 1.4.5 constants.c
#include <stdio.h>

int main(void)
{
	const double PI = 3.14159;
	const int MAX_SCORE = 100;

	printf("圆周率约等于 %.5f\n", PI);
	printf("满分是 %d\n", MAX_SCORE);

	return 0;
}
```

<!-- output: 1.4.5 -->
```text
圆周率约等于 3.14159
满分是 100
```

`const` 写在类型前面，表示"这个变量的值不许改"。如果你试图给 `PI` 赋新值，编译器会直接报错：

```c
const double PI = 3.14159;
PI = 3.14;
```

编译器报错：

```text
error: cannot assign to variable 'PI' with const-qualified type 'const double'
```

### const 还是 #define？

C 还有一种定义常量的老写法——宏定义（macro definition）：

```c
#define PI 3.14159
```

`#define` 是预处理指令，在编译前做简单的文本替换。它和 `const` 的关键区别：

| 对比项 | `const double PI = 3.14159;` | `#define PI 3.14159` |
|--------|------------------------------|----------------------|
| 类型 | 有明确类型（double） | 无类型，只是文本替换 |
| 检查时机 | 编译器做类型检查 | 预处理器不检查，错误发现得晚 |
| 作用范围 | 遵循正常的作用域规则 | 从定义处到文件结尾 |

**本书建议：优先用 `const`。** 它有类型、有作用域、能被调试器查看，出错时编译器能给出更有用的信息。`#define` 的适用场景（如条件编译）在第 10 章预处理与宏里细讲。

> **常见错误：`#define` 写成分号结尾**
>
> - 错误写法：`#define PI 3.14159;`
> - 正确写法：`#define PI 3.14159`
>
> 预处理是纯文本替换，多出来的分号会被一起替换进代码，导致编译错误。预处理指令不以分号结尾。

## 1.4.6 类型溢出与 char 和 ASCII

### int 的范围与溢出

`int` 通常占 4 字节，即 32 位。它能表示的范围大约是 -21 亿到 21 亿（精确值是 -2147483648 到 2147483647）。超过范围会发生什么？

最直观的例子是"无符号整数溢出"，它有明确定义的行为：像汽车里程表一样从最大值绕回最小值：

```c
// 1.4.6 overflow.c
#include <stdio.h>

int main(void)
{
	unsigned int count = 0;

	count = count - 1;

	printf("count = %u\n", count);

	return 0;
}
```

<!-- output: 1.4.6 -->
```text
count = 4294967295
```

`0 - 1` 得到的不是 -1，而是 4294967295，即无符号 32 位整数的最大值。这就是溢出（overflow）：数据超出了类型能表示的范围。

有符号 `int` 的溢出在 C 标准里是未定义行为，编译器可以做任何事，所以不能依赖"绕回来"。实际写程序时要注意两点：

1. 涉及可能很大的数时，考虑用范围更大的类型（如 `long long`）。
2. 累加、累乘前先想清楚：最大会到多少？

更多整数类型的用法，遇到时会顺带说明；溢出的更多例子在第 10 章位运算和数据边界处还会出现。

### char 的真面目：数字

`char` 存的其实是一个整数。每个字符都对应一个编号，这套编号表叫 ASCII 码（American Standard Code for Information Interchange）。常用的：`'A'` 是 65，`'B'` 是 66，……`'a'` 是 97，数字字符 `'0'` 到 `'9'` 是 48 到 57。

因此 `'A'` 和 65 在 C 里关系密切，可以互相转换：

```c
// 1.4.7 char_ascii.c
#include <stdio.h>

int main(void)
{
	char letter = 'A';
	int code = letter;

	printf("字母：%c\n", letter);
	printf("编码：%d\n", code);

	code = 66;
	printf("编码 66 对应的字母：%c\n", code);

	char next = letter + 1;
	printf("%c 后面一个字母是 %c\n", letter, next);

	return 0;
}
```

<!-- output: 1.4.7 -->
```text
字母：A
编码：65
编码 66 对应的字母：B
A 后面一个字母是 B
```

同一个值，用 `%c` 打印就是字符，用 `%d` 打印就是数字。理解这一点对后面处理用户输入、字符判断很有用。

注意：中文字符不在 ASCII 表里。汉字在 UTF-8 编码下占多个字节，不能用单个 `char` 存放，这也是第 0 章讲编码问题的原因之一。

## 1.4.8 小结

- 变量是有名字的内存空间，用名字存取数据；命名用 snake_case 风格。
- 声明决定类型，赋值放值，声明同时赋值叫初始化；使用前必须初始化。
- 三个基本类型：`int`（整数）、`double`（小数）、`char`（单字符）。
- `sizeof` 查看占用字节数，打印它用 `%zu`。
- 格式符必须与值类型匹配：`%d`、`%f`、`%.2f`、`%c`、`%s`、`%zu`、`%p`。
- `%p` 打印地址，取地址用 `&`，打印时写成 `(void *)&x`。
- 不变的值用 `const` 定义，优先于 `#define`。
- `int` 表示范围有限，超出范围是溢出；有符号整数溢出是未定义行为。
- `char` 本质是整数，`'A'` 是 65；`%c` 打印字符，`%d` 打印编号。

```c
printf("页数是 %d\n", 298.5);
```

5. 编程题：定义 `const int DAYS_IN_WEEK = 7`，打印 `3 周有 21 天`（天数用变量计算，不要写死 21）。
6. 编程题：打印 `'A'` 到 `'E'` 五个字符及其 ASCII 编码，一行一个。
