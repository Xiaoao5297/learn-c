# 4.3 结构体

> 💬 **节前语：**
>
> 学了数组，我们能把"很多个 int"装在一起；学了字符串，我们能把"很多个 char"装在一起。
>
> 但问题来了——一个**学生**的信息，既有文字（姓名），又有数字（年龄、成绩），还有字符（性别）：
>
> ```c
> char name[20];     // 姓名（字符串）
> int age;           // 年龄（int）
> double score;      // 成绩（double）
> char gender;       // 性别（char）
> ```
>
> 这些是**不同类型**的数据，数组装不了。如果班里 50 个学生，就得写 200 个变量，太崩溃了！
>
> 这时就需要**结构体**——它能把不同类型的数据**打包成一份"个人档案"**！
>
> 这一节，我们来学它。准备好了吗？开始吧！

---

## 4.3.1 为什么需要结构体？

### 🤔 没有结构体的痛苦

要描述一个学生，得写 4 个互不相关的变量：

```c
char name1[20] = "小明";
int age1 = 18;
double score1 = 95.5;
char gender1 = 'M';

char name2[20] = "小红";   // 第二个学生，又来4个！
int age2 = 19;
double score2 = 88.0;
char gender2 = 'F';
// ... 写到第50个学生？疯了！
```

**问题：**
1. 变量太多、太散，看不出"这是一份档案"
2. 想整体传给函数？做不到，只能一个个传
3. 想用数组装？类型都不一样，装不了

### ✅ 结构体的思路

把这些字段**打包**成一个整体：

```
┌──────────────────────────┐
│        struct Student     │
│  ┌────────────────────┐  │
│  │ 姓名：小明          │  │
│  │ 年龄：18            │  │
│  │ 成绩：95.5          │  │
│  │ 性别：M             │  │
│  └────────────────────┘  │
└──────────────────────────┘
   一份完整的"学生档案"
```

> 📌 **结构体（struct）** = 把**多个不同类型的变量**打包成一个新的"复合类型"。就像一个能装各种物品的"文件袋"。

---

## 4.3.2 定义和使用结构体

### 📝 第一步：定义结构体"模板"

```c
struct Student {
    char name[20];    // 姓名
    int age;          // 年龄
    double score;     // 成绩
    char gender;      // 性别
};
```

> ⚠️ **注意：** 这里只是定义了一个"模板/图纸"，还没有真正创建学生！
> 
> **别忘了结尾的分号 `;`！**

### 📝 第二步：用模板创建变量

```c
struct Student stu1;    // 创建一份学生档案 stu1
```

### 📝 第三步：用 `.` 访问成员

```c
#include <stdio.h>
#include <string.h>

struct Student {
    char name[20];
    int age;
    double score;
    char gender;
};

int main() {
    struct Student stu1;
    
    // 给各个"格子"填内容
    strcpy(stu1.name, "小明");   // 字符串要复制！(回忆3.3节)
    stu1.age = 18;
    stu1.score = 95.5;
    stu1.gender = 'M';
    
    // 访问成员
    printf("姓名：%s\n", stu1.name);
    printf("年龄：%d\n", stu1.age);
    printf("成绩：%.1f\n", stu1.score);
    printf("性别：%c\n", stu1.gender);
    
    return 0;
}
```

输出：
```
姓名：小明
年龄：18
成绩：95.5
性别：M
```

> 📌 **`.`（点运算符）：** 用 `变量名.成员名` 来读写结构体里的某个字段，比如 `stu1.age`。
> 
> 记忆：**"stu1 的 age"** → `stu1.age`

## 4.3.3 初始化结构体

### 方式一：声明时用大括号（顺序要对应）

```c
struct Student stu2 = {"小红", 19, 88.0, 'F'};
```

对应关系：
```
{"小红", 19, 88.0, 'F'}
   │     │    │     │
  name  age score gender
```

### 方式二：先声明再逐个赋值

```c
struct Student stu3;
strcpy(stu3.name, "小刚");
stu3.age = 20;
stu3.score = 76.5;
stu3.gender = 'M';
```

### 📝 完整例子

```c
#include <stdio.h>
#include <string.h>

struct Student {
    char name[20];
    int age;
    double score;
};

int main() {
    struct Student stu1 = {"小明", 18, 95.5};
    struct Student stu2;
    
    strcpy(stu2.name, "小红");
    stu2.age = 19;
    stu2.score = 88.0;
    
    printf("%s：%d岁，成绩%.1f\n", stu1.name, stu1.age, stu1.score);
    printf("%s：%d岁，成绩%.1f\n", stu2.name, stu2.age, stu2.score);
    return 0;
}
```

输出：
```
小明：18岁，成绩95.5
小红：19岁，成绩88.0
```

## 4.3.4 结构体数组：一班的学生

一个学生是一个 `struct Student`，**很多学生**就是"结构体数组"！

```c
#include <stdio.h>
#include <string.h>

struct Student {
    char name[20];
    int age;
    double score;
};

int main() {
    // 一个班3个学生 → 结构体数组
    struct Student class[3] = {
        {"小明", 18, 95.5},
        {"小红", 19, 88.0},
        {"小刚", 20, 76.5}
    };
    
    // 遍历打印每个学生
    for (int i = 0; i < 3; i++) {
        printf("第%d个：%s，%d岁，成绩%.1f\n",
               i, class[i].name, class[i].age, class[i].score);
    }
    
    return 0;
}
```

输出：
```
第0个：小明，18岁，成绩95.5
第1个：小红，19岁，成绩88.0
第2个：小刚，20岁，成绩76.5
```

> 📌 **访问：** `class[i]` 是第 i 个学生，`class[i].name` 是它的姓名。和"二维数组"的 `arr[i][j]` 有点神似，但这里是"数组 + 成员"。

**遍历结构体数组做统计：**

```c
double total = 0;
for (int i = 0; i < 3; i++) {
    total += class[i].score;   // 累加每个学生的成绩
}
printf("班级平均分：%.1f\n", total / 3);
```

输出：
```
班级平均分：86.7
```

## 4.3.5 结构体可以整体赋值和复制

结构体是**值类型**——和 int、double 一样，可以整体赋值！

```c
struct Student stu1 = {"小明", 18, 95.5};
struct Student stu2;

stu2 = stu1;    // ✅ 结构体整体复制（数组可不行！）
```

```c
#include <stdio.h>
#include <string.h>

struct Student {
    char name[20];
    int age;
    double score;
};

int main() {
    struct Student stu1 = {"小明", 18, 95.5};
    struct Student stu2 = stu1;   // 声明时也能整体复制
    
    stu2.age = 20;                // 改 stu2 不影响 stu1
    
    printf("stu1：%s %d\n", stu1.name, stu1.age);
    printf("stu2：%s %d\n", stu2.name, stu2.age);
    return 0;
}
```

输出：
```
stu1：小明 18
stu2：小明 20
```

> 📌 **结构体复制 = 复制一份"档案副本"**，改副本不影响原件。（回忆第2章：这就像"值传递"！）

## 4.3.6 typedef：给结构体起个"外号"

每次写 `struct Student` 有点长，能不能直接写 `Student`？

用 **`typedef`**（type define）起别名：

```c
// 定义结构体并起别名 Student
typedef struct Student {
    char name[20];
    int age;
    double score;
} Student;

// 以后就能直接用了！
Student stu1;          // 不用再写 struct 关键字了
```

> 📌 **这是C语言最常见的写法！** 大型项目里几乎都用 typedef 简化。学了它，读别人代码再也不晕。

**对比：**

| 写法 | 声明变量 |
|------|----------|
| 没用 typedef | `struct Student stu1;` |
| 用了 typedef | `Student stu1;`（更简洁） |

### 📝 完整例子

```c
#include <stdio.h>
#include <string.h>

typedef struct Student {
    char name[20];
    int age;
    double score;
} Student;

int main() {
    Student stu1 = {"小明", 18, 95.5};
    
    printf("姓名：%s\n", stu1.name);
    printf("年龄：%d\n", stu1.age);
    printf("成绩：%.1f\n", stu1.score);
    return 0;
}
```

> 💡 **进阶小贴士：** 也可以连结构体名都不写，直接匿名：
> ```c
> typedef struct {
>     char name[20];
>     int age;
> } Student;   // 没有 struct 名字，只留别名
> ```

## 4.3.7 本节小结

这一节我们学了：

✅ **结构体是什么：** 把不同类型的数据打包成一个"复合类型"的档案

✅ **定义：** `struct Student { ... };` 别忘了分号

✅ **创建变量：** `struct Student stu1;`

✅ **访问成员：** `stu1.age`（点运算符）

✅ **初始化：** `struct Student s = {"小明", 18, 95.5};`

✅ **结构体数组：** `Student class[3] = {...}` 表示很多学生

✅ **整体赋值：** 结构体能像 int 一样整体复制（数组不行！）

✅ **typedef：** 给结构体起别名，写起来更简洁

> 💡 **记住：数组装"同类"，结构体装"异类"，结构体数组 = 一叠档案！**

### 三、改错题

**6. 以下程序有4个错误，请找出并改正：**

```c
#include <stdio.h>

struct Book {
    char title[50];
    int pages;
    double price;
}                                // 错误区①：结构体定义少了分号

int main() {
    Book book1;                  // 错误区②：没 typedef，不能省 struct
    book1.title = "C语言入门";    // 错误区③：字符串不能直接赋值
    book1.pages = 320;
    book1.price = 49.9;

    printf("《%s》 共%d页\n", book1.titl, book1.pages);   // 错误区④：拼写错误
    return 0;
}
```

> 提示：4个错误分别涉及：
> 1. 结构体定义结尾缺分号
> 2. 没有 typedef 却把 `struct` 省略了（应为 `struct Book book1;`）
> 3. 字符串不能整体赋值（需用 `strcpy`，记得包含 `<string.h>`）
> 4. 成员名拼写错误（`titl` → `title`）

### 四、编程练习

**7. 定义一个 `Point` 结构体（含 x、y 两个 int），创建两个点并计算它们之间的距离：**

> 点1 `(0, 0)`，点2 `(3, 4)`。
> 
> 距离公式：`√((x2-x1)² + (y2-y1)²)`。开方用 `<math.h>` 里的 `sqrt`，编译时加 `-lm`。

> 📖 **术语卡：`#include <math.h>` 为什么还要加 `-lm`？**
> 
> 你可能奇怪：`printf` 不用额外加什么，为什么 `sqrt` 就要加 `-lm`？
> 
> 这得从"链接"说起。编译程序其实分两步：**编译**（每个 .c → .o）和**链接**（把 .o 和现成的"库"拼成可执行文件）。
> 
> | 头文件 | 提供什么 | 要不要链接库 |
> |--------|----------|--------------|
> | `stdio.h` | printf、fopen 等**声明** | 需要，但编译器**默认自动**链上标准IO库 |
> | `string.h` | strlen 等**声明** | 同上，默认自动链 |
> | `math.h` | sqrt、pow 等**声明** | 数学库**不会默认链**，要手动加 `-lm` |
> 
> 头文件里只是"声明"（告诉编译器有这个函数），函数真正"实现"在库文件里。`-l` 是"链接某个库"，`m` 是数学库（math）的名字。所以 `gcc main.c -o main -lm` 就是告诉编译器："记得把数学库也链接进来"！
> 
> > 小知识：Windows 的 gcc（MinGW）常常不加 `-lm` 也能用，Linux/macOS 则通常必须加。遇到 `sqrt` 报"undefined reference to 'sqrt'"，十有八九就是忘了 `-lm`。
> 
> 预期输出：
> ```
> 两点间距离：5.00
> ```
