# 4.1 指针基础

> 💬 **节前语：**
>
> 还记得3.4节留下的那个伏笔吗？

> 我们把数组传给函数时，传的是"地址"。函数拿到"地址"就能修改外面的数组。
> 
> 那——"地址"到底是什么？它能不能被保存下来、能不能被我们操作？

> 
> 它是C语言最著名、也最让初学者头疼的概念。但别怕，我们用一个简单的比喻，把它彻底讲明白。准备好了吗？开始吧！

## 4.1.1 内存与"门牌号"

### 🏠 生动的比喻：宿舍楼的房间

想象一栋宿舍楼，每个房间都住着数据。每个房间都有**门牌号**（地址）。

```c
int age = 20;
```

这一行代码做了什么？——在内存里找了一间"房间"，门上写着 `age`，房间里的值存着 `20`。

```
内存（简化示意图）：

地址：0x7ffe0000    0x7ffe0004    0x7ffe0008   ...
      ┌──────────┐  ┌──────────┐  ┌─────────┐
      │   20     │  │  .....   │  │  .....  │
      └──────────┘  └──────────┘  └─────────┘
        ↑
     这间房的门牌号是 0x7ffe0000（举例）
       变量名叫 age，里面放着 20
```

> 📌 **地址（Address）**：每个变量在内存里都有一个"门牌号"。程序通过地址找到变量。
> 
> 地址通常写成十六进制，像 `0x7ffe0000`。你**不用记**它长什么样，只要知道它存在、能用就行。

> 📖 **术语卡：十六进制（hexadecimal）**
> 
> 我们平时数数用**十进制**（0~9，逢10进1）。地址为什么长那样？
> 
> - **十六进制**用 0~9 加 A~F 共 16 个符号，逢16进1
> - C语言里以 **`0x`** 开头就表示十六进制，比如 `0x10` 其实是十进制的 16
> - 内存地址、颜色值（如网页的 `#FF0000` 红色）都喜欢用十六进制，因为它和"字节"（8位二进制）对得很整齐，写起来短
> 
> 地址值不重要，你只需要知道：**`0x` 开头 = 十六进制数 = 电脑内存的"门牌号"写法**。

### 📍 用 `&` 取地址

C语言用 **`&`（取地址符）** 拿到变量的"门牌号"：

```c
#include <stdio.h>

int main() {
    int age = 20;
    
    printf("age 的值：%d\n", age);      // 20（房间里的东西）
    printf("age 的地址：%p\n", &age);   // 0x7ff...（门牌号）
    
    return 0;
}
```

输出（地址每次运行可能不同）：
```
age 的值：20
age 的地址：0x7ffe0000
```

> 📌 **`%p`** 是专门用来打印"地址"的格式符。

## 4.1.2 指针：存放"门牌号"的变量

### 🤔 地址能不能存起来？

当然能！存地址的变量，就叫**指针变量**（简称指针）。

### 📝 声明指针

```c
int *p;    // p 是一个指针，它能存放"int变量的地址"
```

`int *` 表示："这是一个指针，它指向 int 类型的数据"。

### 📝 让指针指向变量

```c
int age = 20;
int *p = &age;    // 把 age 的"门牌号"（地址）存进 p
```

```
p（一张纸条）──────────→ age（房间）
   写着 0x7ffe0000             里面：20
```

> 📌 指针 p 自己也是一个变量，只不过它里面存的不是"值 20"，而是"地址 0x7ffe0000"。

### 📝 用 `*` 解引用：通过纸条找到房间

想通过指针 p 访问它指向的变量，用 **`*`（解引用符）**：

```c
#include <stdio.h>

int main() {
    int age = 20;
    int *p = &age;      // p 指向 age
    
    printf("%d\n", *p);   // *p 就是 p 指向的那个变量（age）→ 20
    
    *p = 30;              // 修改 *p，就等于修改 age！
    printf("%d\n", age);  // 30
    
    return 0;
}
```

输出：
```
20
30
```

> 🎯 **核心理解：`*p` 就是 p 指向的那个变量。**
> 
> p 指向 age，所以 `*p` 和 `age` 是**同一个东西**。
> - `*p = 30;` 相当于 `age = 30;`
> - 修改 `*p`，age 也会变

**一张图看懂 `&` 和 `*`：**

```
int age = 20;
int *p = &age;

  p（存地址）          *p（找房子，等价于 age）
   │                        │
   │ &age 把地址放进来       │  *p = 30 → age = 30
   ▼                        ▼
┌─────────┐            ┌─────────┐
│0x7ff... │ ──────────→ │   20    │
└─────────┘   指向       └─────────┘
   p                       age
```

> 📌 **`&` 和 `*` 是一对相反的操作：**
> - `&变量` → 取变量的"门牌号"
> - `*指针` → 通过"门牌号"找到那个变量
> 
> 记住口诀：**`&` 是"问地址"，`*` 是"找房子"**。

---

## 4.1.3 三种指针相关的写法别搞混

```c
int age = 20;
int *p = &age;    // 声明指针并初始化，让它指向 age

p     // 就是那个"门牌号"（地址），例如 0x7ffe0000
*p    // 是"房子里的人"（age 的值），也就是 20
&age  // 也是那个"门牌号"，和 p 一样
```

| 写法 | 含义 |
|------|------|
| `p` | 地址（门牌号） |
| `&age` | age 的地址，等于 p |
| `*p` | p 指向的变量 = age |
| `*&age` | 对 age 先取地址再解引用 = age |

> 📌 **记忆窍门：** `*p` 读作"p 指向的那个东西"。只要 p 指向 age，`*p` 和 `age` 就永远是一回事。

## 4.1.4 指针变量的类型很重要

### 🤔 为什么要写 `int *p`，而不是 `*p`？

因为指针要知道它指向的"房间"是装 int 还是 double，才能正确处理。

```c
int a = 10;
double b = 3.14;

int *pa = &a;       // ✅ 指向 int 的指针
double *pb = &b;    // ✅ 指向 double 的指针
// int *pa2 = &b;   // ❌ 类型不匹配！&b 是 double*，不能放进 int*
```

```c
#include <stdio.h>

int main() {
    int a = 10;
    double b = 3.14;
    
    int *pa = &a;
    double *pb = &b;
    
    printf("%d\n", *pa);     // 10
    printf("%.2lf\n", *pb);  // 3.14
    return 0;
}
```

> 📌 **指针的类型 = 它指向的数据的类型。** `int *` 指向 int，`double *` 指向 double，`char *` 指向 char。

## 4.1.5 指针为什么重要：swap 函数！

### 🤔 经典问题：交换两个变量的值

第2章我们学过"普通变量传值是复制一份"，所以**用普通参数交换是行不通的**：

```c
#include <stdio.h>

void swapBad(int a, int b) {
    int temp = a;   // 换的只是"复印件"
    a = b;
    b = temp;
}

int main() {
    int x = 10, y = 20;
    
    swapBad(x, y);      // 把 x、y 的值复制过去
    
    printf("x = %d, y = %d\n", x, y);   // 还是 10 20，没换过来！
    return 0;
}
```

输出：
```
x = 10, y = 20
```

**问题出在哪？** swapBad 里交换的是**副本**，外面的 x、y 根本没被碰。

### ✅ 用指针就能真的交换！

把"门牌号"传给函数，函数就能直接改房子里的东西：

```c
#include <stdio.h>

void swap(int *a, int *b) {
    int temp = *a;   // *a 就是外面的 x
    *a = *b;         // 把 y 的值放进 x 的房间
    *b = temp;       // 把原来的 x 放进 y 的房间
}

int main() {
    int x = 10, y = 20;
    
    printf("交换前：x = %d, y = %d\n", x, y);
    
    swap(&x, &y);    // 注意！要传地址
    
    printf("交换后：x = %d, y = %d\n", x, y);
    return 0;
}
```

输出：
```
交换前：x = 10, y = 20
交换后：x = 20, y = 10
```

**图解：**

```
main:  x(房间)   y(房间)
         │10       │20
         │          │
swap(&x, &y) 传入门牌号
         │          │
swap 里 a→x 的房间, b→y 的房间
    temp = *a  →  temp = 10
    *a = *b    →  往 x 房间写入 20
    *b = temp  →  往 y 房间写入 10
```

> 🎯 **规律总结：**
> - 想让函数**修改外面的普通变量** → 必须传它的地址 `&变量`，函数参数写成指针
> - 在函数里通过 `*指针` 来读写那个变量

## 4.1.6 指针的经典套路：让函数"返回"多个结果

还记得"C函数只能返回一个值"吗？用指针就能"带出"多个结果！

### 📝 同时求最大值和最小值

```c
#include <stdio.h>

// 找出数组的最大值和最小值，分别存进 *maxPtr 和 *minPtr
void findMaxMin(int arr[], int n, int *maxPtr, int *minPtr) {
    *maxPtr = arr[0];
    *minPtr = arr[0];
    for (int i = 1; i < n; i++) {
        if (arr[i] > *maxPtr) *maxPtr = arr[i];
        if (arr[i] < *minPtr) *minPtr = arr[i];
    }
}

int main() {
    int scores[] = {85, 92, 54, 100, 76};
    int max, min;
    
    findMaxMin(scores, 5, &max, &min);
    
    printf("最大值：%d\n", max);
    printf("最小值：%d\n", min);
    return 0;
}
```

输出：
```
最大值：100
最小值：54
```

> 💡 **套路：** 想从函数里"带回"多个值，就在参数里加几个指针（`int *maxPtr`），调用时传变量的地址（`&max`）。函数内部用 `*指针 = ...` 把结果写出去。

## 4.1.7 空指针 NULL 与常见错误

### 📌 NULL：哪都不指向

指针有时候"还没有目标"，可以赋成 `NULL`：

```c
int *p = NULL;   // NULL 表示"这个指针现在不指向任何地方"
```

> 📌 `NULL` 的值其实是 0。使用指针前，先判断它是不是 NULL 是个好习惯。

> 📖 **术语卡：崩溃 / 段错误（Segmentation Fault）**
> 
> 上面总说"可能崩溃"，那"崩溃"到底长什么样？运行程序时如果访问了**不属于你的内存**（比如解引用 NULL、越界、乱改地址），操作系统会直接**杀掉程序**，并在屏幕上提示 `Segmentation fault`（段错误，常简写为 `Segfault`）。
> 
> 它不是一个"错误信息"，而是——程序被强制终止，什么结果都没有。遇到它别慌，多半是：指针没初始化就用了 / 数组越界 / 解引用 NULL。回头检查这几处就好。

### 🚨 常见错误1：用了没初始化/没指向的指针

```c
int *p;      // p 里是垃圾值，不知道指向哪！
*p = 100;    // 🚨 危险！往"不知道哪里"的内存写数据 → 可能崩溃！
```

**解决：** 先让 p 指向一个真实变量，再使用：

```c
int x = 5;
int *p = &x;    // ✅ 先指向
*p = 100;       // ✅ 现在安全，改的是 x
```

### 🚨 常见错误2：解引用 NULL

```c
int *p = NULL;
printf("%d", *p);    // 🚨 崩溃！NULL 没有可解引用的房子
```

**解决：** 用之前先检查：

```c
if (p != NULL) {
    printf("%d", *p);
}
```

> 💡 **安全习惯：** 拿到一个"可能是别人的"指针时，先判断 `if (p != NULL)` 再使用。

## 4.1.8 本节小结

这一节我们学了：

✅ **内存与地址：** 每个变量都有"门牌号"（地址）

✅ **取地址 `&`：** `&age` 得到 age 的地址

✅ **指针：** 存放地址的变量，`int *p = &age;`

✅ **解引用 `*`：** `*p` 就是 p 指向的那个变量

✅ **类型匹配：** `int *` 指向 int，不能混用

✅ **swap 与多个返回值：** 传地址给函数，函数能修改外面变量

✅ **NULL 与安全：** 用之前判断是否为 NULL

> 💡 **记住口诀：`&` 问地址，`*` 找房子！**
