## 4.4.1 结构体传给函数：是"复制副本"

### 🤔 试试直接改，行不行？

```c
#include <stdio.h>

typedef struct {
    char name[20];
    int age;
    double score;
} Student;

// 想在这里把成绩改成满分
void setFullScore(Student s) {
    s.score = 100.0;    // 改的是副本！
}

int main() {
    Student stu = {"小明", 18, 95.5};
    
    setFullScore(stu);   // 传值
    
    printf("成绩：%.1f\n", stu.score);   // 还是 95.5！
    return 0;
}
```

输出：
```
成绩：95.5
```

**又是老问题！** 结构体作为参数是**值传递**——函数拿到的是"档案复印件"，改了也不影响原件。

### ⚠️ 还有个隐藏问题：浪费！

如果结构体字段特别多（100个字段的大档案），每次传参都复制一整套，**又慢又费内存**。

> 📌 怎么解决？——**传指针！** 只传"档案的存放地址"，又快又能改原件。

## 4.4.2 结构体指针与 `->`

### 📝 指向结构体的指针

```c
Student stu = {"小明", 18, 95.5};
Student *p = &stu;    // p 指向 stu
```

现在：
- `(*p).age` 就是 `stu.age`（通过指针访问成员）
- 太啰嗦了！C语言提供了更帅的写法：**`p->age`**

### 📝 `->` 运算符（箭头）

```c
p->age     // 完全等价于 (*p).age，也等价于 stu.age
p->name
p->score
```

| 写法 | 含义 |
|------|------|
| `stu.age` | 用变量直接访问 |
| `(*p).age` | 先解引用再访问（啰嗦） |
| `p->age` | 箭头语法（推荐！）⭐ |

> 📌 **记忆：** `->` 读作"指向"，`p->age` 就是"p 指向的那个结构体的 age 字段"。
> 
> **什么时候用 `.`，什么时候用 `->`？**
> - 手里是**结构体变量** → 用 `.`：`stu.age`
> - 手里是**结构体指针** → 用 `->`：`p->age`

### 📝 完整例子

```c
#include <stdio.h>

typedef struct {
    char name[20];
    int age;
    double score;
} Student;

int main() {
    Student stu = {"小明", 18, 95.5};
    Student *p = &stu;
    
    printf("用 . ：%s\n", stu.name);
    printf("用 ->：%s\n", p->name);    // 效果一样！
    
    p->score = 100.0;      // 通过指针修改，一样影响 stu
    printf("新成绩：%.1f\n", stu.score);
    
    return 0;
}
```

输出：
```
用 . ：小明
用 ->：小明
新成绩：100.0
```

## 4.4.3 把结构体指针传给函数

### 📝 修改成绩（这次真的能改了！）

```c
#include <stdio.h>

typedef struct {
    char name[20];
    int age;
    double score;
} Student;

// 参数用指针！通过 -> 修改
void setFullScore(Student *s) {
    s->score = 100.0;    // 等价于 (*s).score = 100.0;
}

int main() {
    Student stu = {"小明", 18, 95.5};
    
    printf("修改前：%.1f\n", stu.score);
    
    setFullScore(&stu);   // 传地址！
    
    printf("修改后：%.1f\n", stu.score);
    return 0;
}
```

输出：
```
修改前：95.5
修改后：100.0
```

> 🎯 **规律和普通变量一模一样：**
> 
> | 想让函数修改外面变量 | 函数参数 | 调用 |
> |----------------------|----------|------|
> | 普通 int | `int *x` | `f(&x)` |
> | 结构体 Student | `Student *s` | `f(&stu)` |
> 
> 区别只是：改结构体成员用 `->`，而不是 `*x`。

### 📝 还能交换两个学生的档案

```c
#include <stdio.h>
#include <string.h>

typedef struct {
    char name[20];
    int age;
    double score;
} Student;

void swapStudent(Student *a, Student *b) {
    Student temp = *a;   // 整个结构体复制到 temp
    *a = *b;
    *b = temp;
}

int main() {
    Student stu1 = {"小明", 18, 95.5};
    Student stu2 = {"小红", 19, 88.0};
    
    printf("交换前：%s vs %s\n", stu1.name, stu2.name);
    
    swapStudent(&stu1, &stu2);
    
    printf("交换后：%s vs %s\n", stu1.name, stu2.name);
    return 0;
}
```

输出：
```
交换前：小明 vs 小红
交换后：小红 vs 小明
```

> 💡 **结构体的整体赋值 `temp = *a;`** 是不是很爽？这比数组方便多了（数组不能整体赋值）！

## 4.4.4 综合实战：班级成绩管理系统

让我们把结构体、数组、函数、指针**全部串起来**，写一个班级管理系统！

### 📝 需求
- 有一个班 5 个学生（姓名、成绩）
- 能打印全部学生
- 能算平均分
- 能找最高分的学生
- 能把某个学生的成绩改成满分（用指针参数）

```c
#include <stdio.h>

typedef struct {
    char name[20];
    double score;
} Student;

// 函数声明
void printAll(Student arr[], int n);
double averageScore(Student arr[], int n);
int topIndex(Student arr[], int n);
void setFullScore(Student *s);

int main() {
    Student class[5] = {
        {"小明", 85.0},
        {"小红", 92.0},
        {"小刚", 76.5},
        {"小丽", 98.0},
        {"小华", 60.0}
    };
    int n = 5;
    
    printf("=== 班级成绩单 ===\n");
    printAll(class, n);
    
    printf("\n平均分：%.1f\n", averageScore(class, n));
    
    int top = topIndex(class, n);
    printf("最高分：%s（%.1f分）\n", class[top].name, class[top].score);
    
    // 让小华（下标4）的成绩变成满分
    setFullScore(&class[4]);
    printf("\n给小华开个小灶后：\n");
    printAll(class, n);
    
    return 0;
}

// 打印所有学生
void printAll(Student arr[], int n) {
    for (int i = 0; i < n; i++) {
        printf("%s：%.1f分\n", arr[i].name, arr[i].score);
    }
}

// 算平均分
double averageScore(Student arr[], int n) {
    double sum = 0;
    for (int i = 0; i < n; i++) {
        sum += arr[i].score;
    }
    return sum / n;
}

// 返回最高分学生的下标
int topIndex(Student arr[], int n) {
    int top = 0;
    for (int i = 1; i < n; i++) {
        if (arr[i].score > arr[top].score) {
            top = i;
        }
    }
    return top;
}

// 通过指针把某个学生的成绩改成满分
void setFullScore(Student *s) {
    s->score = 100.0;
}
```

输出：
```
=== 班级成绩单 ===
小明：85.0分
小红：92.0分
小刚：76.5分
小丽：98.0分
小华：60.0分

平均分：82.3
最高分：小丽（98.0分）

给小华开个小灶后：
小明：85.0分
小红：92.0分
小刚：76.5分
小丽：98.0分
小华：100.0分
```

> 🧠 **这段代码用到了我们学的所有东西：**
> - ✅ 结构体 + typedef：定义"学生档案"
> - ✅ 结构体数组：一个班的 5 份档案
> - ✅ 数组传函数：`Student arr[]`（其实传的是地址）
> - ✅ 结构体指针：`Student *s` + `->` 修改原档案
> - ✅ 遍历 + 统计套路：找最大、求平均

## 4.4.5 让系统更好用：结构体数组也能排序

排序是结构体最经典的应用！比如按成绩从高到低排。用到 `swapStudent`（4.4.3学过）：

```c
#include <stdio.h>

typedef struct {
    char name[20];
    double score;
} Student;

void swapStudent(Student *a, Student *b) {
    Student temp = *a;
    *a = *b;
    *b = temp;
}

// 冒泡排序：按成绩从高到低
void sortByScore(Student arr[], int n) {
    for (int i = 0; i < n - 1; i++) {
        for (int j = 0; j < n - 1 - i; j++) {
            if (arr[j].score < arr[j + 1].score) {
                swapStudent(&arr[j], &arr[j + 1]);
            }
        }
    }
}

int main() {
    Student class[4] = {
        {"小明", 85.0},
        {"小红", 92.0},
        {"小刚", 76.5},
        {"小丽", 98.0}
    };
    
    sortByScore(class, 4);
    
    printf("按成绩从高到低：\n");
    for (int i = 0; i < 4; i++) {
        printf("第%d名：%s（%.1f分）\n", i + 1, class[i].name, class[i].score);
    }
    
    return 0;
}
```

输出：
```
按成绩从高到低：
第1名：小丽（98.0分）
第2名：小红（92.0分）
第3名：小明（85.0分）
第4名：小刚（76.5分）
```

> 💡 **冒泡排序的思路：** 两两比较相邻的学生，成绩低的往"下沉"。一轮下来，最高的浮到最前面；多轮后全部排好。**交换两个结构体 = `swapStudent`**，这就是指针在排序里的威力！

## 4.4.6 本节小结

这一节我们学了：

✅ **结构体传函数是值传递：** 复制副本，函数里改了不影响外面

✅ **结构体指针：** `Student *p = &stu;`

✅ **`->` 运算符：** `p->age` 等价于 `(*p).age`、`stu.age`

✅ **让函数改结构体：** 参数用指针 `Student *s`，调用传 `&stu`

✅ **结构体整体赋值/交换：** `temp = *a;`（比数组方便多了！）

✅ **综合应用：** 结构体数组 + 函数 + 指针，能做管理系统、排序

> 💡 **记住口诀：结构体变量用 `.`，结构体指针用 `->`，想让函数修改就传地址！**

**6. 以下程序想把学生成绩改成满分，有4个错误，请找出并改正：**

```c

    char name[20];
```
