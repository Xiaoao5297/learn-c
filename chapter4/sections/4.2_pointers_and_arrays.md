## 4.2.1 数组名就是一个"地址"

### 🤔 数组在内存里长什么样？

```c
int arr[5] = {10, 20, 30, 40, 50};
```

这 5 个 int 在内存里是**紧挨着**存放的：

```
地址： base     base+4   base+8   base+12  base+16
      ┌───────┬───────┬───────┬───────┬───────┐
      │  10   │  20   │  30   │  40   │  50   │
      └───────┴───────┴───────┴───────┴───────┘
        ↑
       arr[0]  arr[1]  arr[2]  arr[3]  arr[4]
```

> 📌 **数组名 `arr` 的本质：它就是数组第一个元素的地址！**
> 
> 也就是 `arr` == `&arr[0]`。

### 📝 验证一下

```c
#include <stdio.h>

int main() {
    int arr[5] = {10, 20, 30, 40, 50};
    
    printf("arr 的值：   %p\n", arr);      // 第一个元素的地址
    printf("&arr[0] 的值：%p\n", &arr[0]);  // 和上面一样！
    printf("arr[0] 的值： %d\n", arr[0]);   // 10（房间里的东西）
    
    return 0;
}
```

输出（地址可能不同）：
```
arr 的值：   0x7ffe0000
&arr[0] 的值：0x7ffe0000
arr[0] 的值： 10
```

**两个地址完全一样！** 这证明了：数组名就是一个指向第一个元素的指针（常量）。

## 4.2.2 用指针访问数组

既然数组名是地址，那就可以把它放进指针：

```c
int arr[5] = {10, 20, 30, 40, 50};
int *p = arr;      // 等价于 int *p = &arr[0];
```

现在：
- `p` 指向 `arr[0]`
- `*p` == `arr[0]` == `10`
- `*(p + 1)` == `arr[1]` == `20`

### 📝 两种访问方式完全等价！

```c
#include <stdio.h>

int main() {
    int arr[5] = {10, 20, 30, 40, 50};
    int *p = arr;
    
    // 方式一：用下标 arr[i]
    printf("%d ", arr[2]);    // 30
    
    // 方式二：用指针 *(p + i)
    printf("%d\n", *(p + 2)); // 30
    
    // 也可以混着写！
    printf("%d %d\n", p[3], *(arr + 4));   // 40 50
    
    return 0;
}
```

输出：
```
30 30
40 50
```

> 🎯 **重要等价关系（背下来！）：**
> 
> | 写法 | 等价于 | 说明 |
> |------|--------|------|
> | `arr[i]` | `*(arr + i)` | 下标就是解引用 |
> | `&arr[i]` | `arr + i` | 第i个元素的地址 |
> 
> **`arr[i]` 其实就是 `*(arr + i)` 的"语法糖"！**

## 4.2.3 指针加减：在数组中"走动"

### 🤔 p + 1 到底加了多少？

指针 `p + 1` 并不是"地址 +1字节"，而是**"移到下一个元素"**！

```c
int *p = arr;    // 指向 arr[0]
p + 1            // 指向 arr[1]
p + 2            // 指向 arr[2]
```

对 `int` 数组，每个元素占 4 字节，所以 `p + 1` 的地址其实**加了4**——因为要跳过整个 int，才能到下一个 int。

> 📌 **指针加减的规则：`p + 1` 移动"一个元素"的距离**，至于实际加几个字节，由指针指向的类型决定。编译器会帮你算好！

### 📝 用指针遍历数组

```c
#include <stdio.h>

int main() {
    int arr[5] = {10, 20, 30, 40, 50};
    
    // 让指针从头走到尾
    for (int *p = arr; p < arr + 5; p++) {
        printf("%d ", *p);
    }
    printf("\n");
    
    return 0;
}
```

输出：
```
10 20 30 40 50 
```

**理解这段代码：**
- `int *p = arr`：p 从头开始（指向 arr[0]）
- `p < arr + 5`：p 还没走过最后一个元素
- `p++`：p 向后移动一个元素
- `*p`：取出 p 当前指向的元素

> 📌 注意：`arr` 本身是**常量地址**，不能写 `arr++`（数组名不能移动）。但指针变量 `p` 可以 `p++`。

## 4.2.4 解开谜团：函数里为什么数不出长度？

现在终于可以彻底解释 3.4 节的谜团了！

```c
void printArray(int arr[], int n) { ... }
```

**其实函数参数 `int arr[]` 和 `int *arr` 是完全一样的写法！** 编译器都把它当作一个指针：

```c
void printArray(int arr[], int n)   // 等价 ↓
void printArray(int *arr, int n)    // 传入的是一个指针！
```

所以在函数里 `sizeof(arr)` 得到的是**指针的大小**（8字节），而不是整个数组的大小。

**图解：**

```
main 里：
    arr  →  整个数组（20字节）   sizeof(arr) = 20 ✅

调用 printArray(arr, 5) 后：
    函数收到的 arr → 只是一个地址（8字节）
    它只"知道"数组从哪开始，不知道有多大！
    sizeof(arr) = 8 ❌（数不出元素个数）
```

> 🎯 **为什么必须传长度 n？** 因为函数拿到的只是一个"起点地址"，没有结束标记。它不知道前面有多少个元素，只能靠你告诉它！
> 
> （对比字符串：字符串自带 `'\0'` 结束符，所以传字符串不用带长度。）

## 4.2.5 通过指针参数修改数组（回顾）

上一章我们用 `arr[]` 形式修改数组，这一节我们用指针形式写——其实完全一样：

```c
#include <stdio.h>

// 把所有元素翻倍（写法一：下标）
void doubleAllIndex(int arr[], int n) {
    for (int i = 0; i < n; i++) {
        arr[i] *= 2;
    }
}

// 把所有元素翻倍（写法二：指针）
void doubleAllPointer(int *arr, int n) {
    for (int i = 0; i < n; i++) {
        *(arr + i) *= 2;
    }
}

int main() {
    int nums[3] = {1, 2, 3};
    
    doubleAllIndex(nums, 3);
    printf("下标版：");
    for (int i = 0; i < 3; i++) printf("%d ", nums[i]);
    printf("\n");
    
    doubleAllPointer(nums, 3);
    printf("指针版：");
    for (int i = 0; i < 3; i++) printf("%d ", nums[i]);
    printf("\n");
    
    return 0;
}
```

输出：
```
下标版：2 4 6 
指针版：4 8 12 
```

> 💡 **两种写法效果完全一样！** 下标写法更直观，指针写法更接近本质。你爱用哪种都行，但都要理解它们是等价的。

## 4.2.6 字符指针：字符串的另一种打开方式

### 📝 两种表示字符串的方式

```c
char s1[] = "hello";      // 方式一：字符数组
char *s2 = "hello";       // 方式二：字符指针
```

都可以用 `%s` 打印、用 `s[0]` 访问，看起来一样。但它们有一个**重要区别**！

### ⚠️ 区别：能不能修改

```c
char s1[] = "hello";
s1[0] = 'H';      // ✅ 可以改！s1 是自己的数组

char *s2 = "hello";
s2[0] = 'H';      // 🚨 危险！"hello"是只读的字符串字面量，改它可能崩溃！
```

> 📌 **记忆：**
> - `char s[] = "..."` → 数组，数据拷贝到自己家里，**可以改**
> - `char *s = "..."` → 指针，指向一个只读的"字面量"，**别改**（只读）！
> 
> 需要修改字符串时，用数组方式最安全。

> 📖 **术语卡：字面量（Literal）**
> 
> "字面量"就是**直接写在代码里的值**，即"字面上的值"，没有经过计算、也没有变量名：
> 
> ```c
> int x = 42;            // 42 是整数 字面量
> double y = 3.14;       // 3.14 是小数 字面量
> char c = 'A';          // 'A' 是字符 字面量
> char *s = "hello";     // "hello" 是字符串字面量（数组/指针两种写法都引用它）
> ```
> 
> 字符串字面量 `"hello"` 在内存里是一段**只读**的数据（存在只读区），所以 `char *s = "hello"` 只是让指针指向它，改它会出问题；而 `char s[] = "hello"` 是**复制了一份**到自己可改的数组里。

### 📝 用字符指针遍历字符串

```c
#include <stdio.h>

int main() {
    char *s = "hello";
    
    // 用指针从前往后走，遇到 '\0' 停下
    for (char *p = s; *p != '\0'; p++) {
        printf("%c", *p);
    }
    printf("\n");
    
    return 0;
}
```

输出：
```
hello
```

> 💡 这里 `p++` 让指针在字符串里"走"，`*p` 取出当前字符——和遍历 int 数组是一个道理！

## 4.2.7 一个容易混的点：指针的指针？（选读）

学了"数组名是地址"后，你可能会想：**数组名（地址）的地址又是什么？**

```c
int arr[3] = {1, 2, 3};
int *p = arr;        // p 指向数组
int **pp = &p;       // pp 指向"p 这个指针"（指针的指针）
```

这就是传说中的 **二级指针**。现阶段**不用深究**，知道有这回事就行：

- `*p` → arr[0]
- `**pp` → *p → arr[0]

> 📌 别被吓到！你现在只需要牢牢掌握 `*p` 和 `&` 就够了。二级指针在以后处理"指针数组"时自然会见到的。

## 4.2.8 综合示例：用指针实现数组求和

来一个指针版本的经典求和：

```c
#include <stdio.h>

// 用指针从头走到尾求和
int sumWithPointer(int *arr, int n) {
    int sum = 0;
    for (int *p = arr; p < arr + n; p++) {
        sum += *p;
    }
    return sum;
}

int main() {
    int scores[] = {85, 92, 78, 100, 60};
    int n = sizeof(scores) / sizeof(scores[0]);
    
    printf("总和：%d\n", sumWithPointer(scores, n));
    return 0;
}
```

输出：
```
总和：415
```

> 💡 **什么时候用下标，什么时候用指针？**
> - 简单访问 → 下标 `arr[i]` 更清晰
> - 从头到尾遍历 → 指针 `p++` 很优雅
> - 需要移动位置、配合复杂逻辑 → 指针更灵活
> 
> 两者等价，按场景选顺手的！

## 4.2.9 本节小结

这一节我们学了：

✅ **数组名 = 首地址：** `arr` 就是 `&arr[0]`

✅ **等价关系：** `arr[i]` 就是 `*(arr + i)`

✅ **指针加减：** `p + 1` 移动到下一个元素（字节数由类型决定）

✅ **函数参数 `int arr[]` 就是 `int *arr`：** 所以函数里 sizeof 数不出长度

✅ **两种字符串：** `char s[]`（可改） vs `char *s`（字面量，只读）

✅ **指针遍历数组：** `for (p = arr; p < arr+n; p++)`

> 💡 **记住：`arr[i]` = `*(arr + i)`，数组和指针是孪生兄弟！**

### 三、改错题

**6. 以下程序想用指针遍历数组并求和，有4个错误，请找出并改正：**

```c
#include <stdio.h>

int sumArray(int arr[], int n) {
    int sum = 0;
    int *p = arr;
    
    while (p <= arr + n) {      // 错误区①：多走了一步，越界
        sum += *p;
        p++;                    // 错误区②：?（这行其实没错，请检查其他行）
    }
    return sum;
}

int main() {
    int nums[] = {1, 2, 3, 4};
    int *q;                     // 错误区③：未初始化的指针
    
    *q = 100;                   // 错误区④：危险写入
    
    int total = sumArray(nums, 4);
    printf("总和：%d\n", total);
    return 0;
}
```

> 提示：除了未初始化指针，注意 while 的结束条件：最后一个有效指针应该是 `arr + n - 1`，所以条件是 `p < arr + n`。
