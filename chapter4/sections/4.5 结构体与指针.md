# 4.5 结构体与指针

4.4 末尾留了个悬念：大结构体传参“建议传指针”。这一节把结构体和指针结合起来，这也是真实 C 项目里最常见的搭配。

## 4.5.1 箭头运算符 `->`

结构体指针的声明方式和其他指针一样，类型写成 `struct student *`：

```c
struct student s = {"小明", 18, 92.5};
struct student *p = &s;    /* p 指向 s */
```

通过指针访问成员有两种写法，完全等价：

| 写法 | 读法 | 说明 |
|------|------|------|
| `(*p).age` | 先解引用，再取成员 | 括号必须写：`.` 优先级高于 `*` |
| `p->age` | p 所指结构的 age 成员 | 箭头运算符，等价的简写 |

因为 `(*p).age` 写起来又绕又容易漏括号，C 语言专门提供了 `->`（箭头运算符）。实际代码里几乎总是用箭头：

箭头可以读成“顺着纸条去查那一栏”：`p` 是写着某张登记表存放位置的纸条，`p->age` 就是“按纸条找到那张表，翻开年龄栏”。一查一个准，还不用操心括号的事。

```c
// 4.5.1 arrow_operator.c
#include <stdio.h>

struct student {
	char name[20];
	int age;
	double score;
};

int main(void)
{
	struct student s = {"小明", 18, 92.5};
	struct student *p = &s;

	printf("(*p).age = %d\n", (*p).age);
	printf("p->age   = %d\n", p->age);
	printf("p->name  = %s\n", p->name);

	p->age = 19;
	printf("修改后 s.age = %d\n", s.age);

	return 0;
}
```

<!-- output: 4.5.1 -->
```text
(*p).age = 18
p->age   = 18
p->name  = 小明
修改后 s.age = 19
```

`p->age = 19` 改的是 p 指向的结构体，也就是 `main` 里的 `s`——和 4.1 的 `*p = 100` 是同一个道理，只是从“一个变量”升级成了“一整包成员”。

漏括号的后果值得看一眼。`*p.age` 会被解析成 `*(p.age)`，相当于对数字 18 解引用，直接编译错误。**用箭头写法可以从根上避免这个坑。**

## 4.5.2 函数传结构体：传值还是传指针

结构体作为参数默认按值传递，整个结构体被复制一份——函数内改的是副本（4.4.4 的整包复制在参数上的体现）。对比实验：

`raise_by_value` 相当于把登记表**复印一份**寄给函数，函数在复印件上加 5 分，寄回来的路上复印件还弄丢了，你的原表分毫未动。`raise_by_pointer` 则是把“原表放在几号档案柜”的地址递过去，函数直接在原表上改——这次是真的加上了。

```c
// 4.5.2 struct_param.c
#include <stdio.h>

struct student {
	char name[20];
	double score;
};

void raise_by_value(struct student s)
{
	s.score += 5.0;
}

void raise_by_pointer(struct student *s, double bonus)
{
	s->score += bonus;
}

int main(void)
{
	struct student stu = {"小明", 92.5};

	printf("修改前：%.1f\n", stu.score);

	raise_by_value(stu);
	printf("按值传递后：%.1f\n", stu.score);

	raise_by_pointer(&stu, 5.0);
	printf("按指针传递后：%.1f\n", stu.score);

	return 0;
}
```

<!-- output: 4.5.2 -->
```text
修改前：92.5
按值传递后：92.5
按指针传递后：97.5
```

`raise_by_value` 白忙一场：`s.score += 5.0` 加在副本上。`raise_by_pointer` 顺着地址找到原结构体，修改真实生效。

什么时候传值、什么时候传指针？两条实用规则：

1. **想修改原结构体，必须传指针。**
2. **只读不改的结构体，也建议传指针**，并加 `const`：`void print_student(const struct student *s)`。好处有二：避免整包复制的开销；和 4.7 学生管理模块的写法保持一致。

只读函数的标准形态（4.7 已经出现过，现在你能看懂它了）：

```c
void print_student(const struct student *s)
{
	printf("%s，%.1f 分\n", s->name, s->score);
}

print_student(&stu);    /* 调用时取地址 */
```

`const struct student *` 表示“函数承诺不修改这个结构体的任何成员”，写错了编译器会拦（4.6 展开）。

## 4.5.3 用指针遍历结构体数组

结构体数组名同样会退化为指向首元素的指针，类型是 `struct student *`。用指针遍历：

```c
// 4.5.3 struct_array_ptr.c
#include <stdio.h>

struct student {
	char name[20];
	int age;
};

int main(void)
{
	struct student students[3] = {
		{"小明", 18},
		{"小红", 17},
		{"小刚", 18}
	};

	for (struct student *p = students; p < students + 3; p++) {
		printf("%s %d 岁\n", p->name, p->age);
	}

	return 0;
}
```

<!-- output: 4.5.3 -->
```text
小明 18 岁
小红 17 岁
小刚 18 岁
```

`p++` 一次前进多远？步长是一个结构体的大小（这里是 `sizeof(struct student)`，至少 24 字节），正好从一个学生跳到下一个学生——指针算术的步长由类型决定（4.1.3），对结构体同样成立。

下标写法 `students[i].name` 和指针写法 `p->name` 完全等价。指针遍历在“函数里收到的只是指针、不知道长度”的场景下更自然；日常代码两种都要能读懂。

用“翻登记表”来记指针的步长：结构体数组像一叠等高的表，`p++` 就是“翻到下一张”——不管每张表多厚，一次正好翻一张，绝不会翻到某张表的中间。

## 4.5.4 综合示例：找出最高分学生

把本章的东西串起来：写一个函数，接收结构体数组和长度，返回**指向最高分学生的指针**。

```c
// 4.5.4 top_student.c
#include <stdio.h>

struct student {
	char name[20];
	double score;
};

struct student *top_student(struct student arr[], int count)
{
	struct student *best = &arr[0];

	for (int i = 1; i < count; i++) {
		if (arr[i].score > best->score) {
			best = &arr[i];
		}
	}

	return best;
}

int main(void)
{
	struct student students[5] = {
		{"小明", 85.0},
		{"小红", 92.0},
		{"小刚", 76.0},
		{"小丽", 98.0},
		{"小华", 60.0}
	};

	struct student *best = top_student(students, 5);

	printf("最高分：%s（%.1f 分）\n", best->name, best->score);
	printf("地址没有变，students[3].score = %.1f\n", students[3].score);

	return 0;
}
```

<!-- output: 4.5.4 -->
```text
最高分：小丽（98.0 分）
地址没有变，students[3].score = 98.0
```

读这个函数注意三点：

1. 返回类型是 `struct student *`——返回的是**地址**，不是整包复制的结构体副本。
2. `best` 是个“当前最优指针”，初始指向 `arr[0]`，谁分高就指向谁。这和 3.1.8 的“先设第一个元素再比较”是同一个套路，只是存的从值变成了地址。
3. 返回的指针指向 `main` 里的数组，`best->name` 直接读原数组，没有任何复制发生。`students[3].score` 验证了这一点。

返回指针要遵守一条底线：**指向的内存必须在函数返回后依然有效**。指向调用方的数组没问题；但如果让指针指向函数内部定义的局部变量，函数一返回那块内存就失效了——这是第 6 章动态内存之前要先立好的规矩，练习里会再见到它。

## 4.5.5 常见错误

| 错误写法 | 问题 | 正确写法 |
|----------|------|----------|
| `*p.age` | 解析成 `*(p.age)`，编译错误 | `(*p).age` 或直接 `p->age` |
| 函数参数 `struct student s`，内部赋值想改到外面 | 按值传递改的是副本 | `struct student *s`，调用时传 `&stu` |
| 忘记取地址：`raise(stu)`（参数是指针时） | 类型不匹配 | `raise(&stu)` |
| `struct student *p = &s; s->age = 1;` | s 是结构体不是指针，没有 `->` | `p->age = 1;` 或 `s.age = 1;` |
| 函数返回指向自己局部变量的指针 | 返回后内存失效，野指针 | 返回指向调用方数据的指针，或用参数带回 |
| 只读结构体参数不加 `const` | 调用方无法确认函数会不会改 | `const struct student *s` |

## 4.5.6 小结

- 结构体指针访问成员用箭头：`p->age` 等价于 `(*p).age`，且不用担心括号。
- 结构体参数默认按值传递（整包复制）；想修改原结构体必须传指针。
- 只读的结构体参数建议 `const struct student *s`，省复制也表明意图。
- 结构体数组名同样退化为首元素地址，`p++` 一次前进一个结构体的大小。
- 函数可以返回指向结构体的指针；指向的内存必须在返回后依然有效。

#### 一、选择题

1. **B**。`p` 是指针，用箭头 `->` 访问成员；`.` 只能用于结构体变量。
2. **C**。`p->age` 就是 `(*p).age` 的简写——先解引用拿到结构体，再用点号访问。

4. `sizeof(struct student)`（整个结构体的大小）；`struct student *`。
5. `s->score += bonus;`；`&stu`。

#### 三、改错题

三处错误：

1. `void add_bonus(struct student s, double bonus)`：按值传递，加分加在副本上，调用方看不到变化。参数应改为 `struct student *s`，函数体内写成 `s->score += bonus;`。
2. `add_bonus(stu, 5.0);` 调用时传的是结构体值。参数改成指针后，这里应传地址：`add_bonus(&stu, 5.0);`。
3. `printf("%s %.1f\n", p->name, p.score);`：`p` 是指针，`p.score` 不合法。应统一用箭头：`p->score`。

	double score;

void add_bonus(struct student *s, double bonus)
{
	s->score += bonus;
}

int main(void)
{

	struct student *p = &stu;
