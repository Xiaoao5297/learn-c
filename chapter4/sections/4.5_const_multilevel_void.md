# 4.5 指针进阶（上）：const 指针、void* 与多级指针

> 💬 **节前语：**
>
> 第 4.1 节我们学了指针的"地基"：`&` 取地址、`*` 解引用、swap 让函数改外面的变量。
>
> 但真实的 C 代码里，指针还有几副"更讲究的面孔"：
>
> - 🔒 **只读指针**：有些数据只想让别人"看"，不想让别人"改"（const）
> - 📦 **通用指针 `void *`**：一个能"装任何类型地址"的万能盒子
> - 🪜 **指针的指针 `int **`**：想改"指针本身"，就得传指针的地址
> - ↩️ **函数返回指针**：注意别返回"局部变量"的地址
>
> 学会了它们，很多开源代码和标准库（比如第10章的 `qsort`）你就能看懂了。准备好了吗？开始吧！

## 4.5.1 给指针上"锁"：const 家族

有时你只是想把数据的地址"借"给别人，但**不希望对方改掉里面的值**。C 用 `const`（constant，常量）来表态：**修饰谁，谁就只读**。

```c
int a = 5, b = 9;

const int *p1 = &a;     // ① 指向"只读 int" 的指针：*p1 不能改
int *const p2 = &a;     // ② "const 指针"：p2 自己不能再指向别人
const int *const p3 = &a;   // ③ 两个都不能改
```

| 写法 | `*p`（指向的值）| `p`（指针自己）| 形象记忆 |
|------|----------------|---------------|----------|
| `const int *p` | 只读 | 可改 | const 在 `*` **左边** → 说的是"内容" |
| `int *const p` | 可改 | 只读 | const 在 `*` **右边** → 说的是"指针自己" |
| `const int *const p` | 只读 | 只读 | 两边都有 → 都只读 |

> 📌 **口诀：`const` 在 `*` 的哪一边，哪一边就"只读"。** `const int *p` 和 `int const *p` 是同一回事，都表示"指向的内容只读"。

### 🚨 亲手试试"锁"的效果

下面这段**故意写错**，用于演示哪些操作不被允许（注释标注，无法编译）：

```c
#include <stdio.h>

int main() {
    int a = 5, b = 9;
    const int *p1 = &a;     // *p1 只读
    int *const p2 = &a;     // p2 只读（不能再指向别处）

    *p1 = 7;                // ❌ 错误！不能通过 p1 修改 a
    p1 = &b;                // ✅ 允许：p1 自己可以改指向
    p2 = &b;                // ❌ 错误！p2 不能指向别处
    *p2 = 8;                // ✅ 允许：p2 指向的 int 可改

    printf("%d %d\n", *p1, a);
    return 0;
}
```

**正确、能编译的写法：**

```c
#include <stdio.h>

int main() {
    int a = 5, b = 9;
    const int *p1 = &a;     // *p1 只读
    int *const p2 = &a;     // p2 不能再指向别人

    p1 = &b;                // 允许：只读"内容"，指针本身能换
    *p2 = 8;                // 允许：p2 只锁"指向"，内容能改

    printf("p1 现在指向 b：%d\n", *p1);   // 9
    printf("通过 p2 把 a 改成了：%d\n", a); // 8
    return 0;
}
```

输出：
```
p1 现在指向 b：9
通过 p2 把 a 改成了：8
```

> 💡 **为什么要有 `const` 指针？** 很多函数只"读"数据不"改"数据（比如第10章的 `qsort` 比较器参数是 `const void *`）。写 `const` 相当于给调用者吃定心丸："我保证不改你的数据"；万一你想改，编译器会立刻报错拦住你。

## 4.5.2 万能盒子：void *

指针都有类型（`int *`、`double *`…），因为解引用时要按类型解释内存。但有一种指针**不挑类型**——`void *`，它只负责"记住地址"，不管里面是什么。

```c
#include <stdio.h>

int main() {
    int    n = 42;
    double x = 3.14;
    void *vp;                  // 万能指针：能装任何地址

    vp = &n;                   // 装 int 的地址
    int *pi = (int *)vp;       // 用之前要"转回"原来的类型
    printf("int: %d\n", *pi);

    vp = &x;                   // 换成装 double 的地址
    double *pd = (double *)vp;
    printf("double: %.2f\n", *pd);
    return 0;
}
```

输出：
```
int: 42
double: 3.14
```

> 📌 **`void *` 的使用规则：**
> 1. 可以接收任意类型的指针（`vp = &n`）
> 2. **不能直接解引用** `*vp`（编译器不知道是什么类型）——必须先强转回原类型
> 3. 常用于"通用的函数参数"，例如 `qsort(数组, 个数, 大小, 比较器)` 里那前几个 `void *`

> 🚨 **强转要"转得对"**：存进去时是什么类型，取出来就要转回什么类型。转错了（把 `int *` 当 `double *` 用），就是未定义行为，数据全乱。

## 4.5.3 多级指针：想改"指针本身"用 int **

第 4.1 节讲过 swap：**想改函数外面的变量，就传它的地址**。那如果外面那个"变量"本身是一个指针，想改它该传什么？——传**指针的地址**，也就是"指针的指针"：

```c
#include <stdio.h>

// 把外面的指针 pp 重新指向 newp
void redirect(int **pp, int *newp) {
    *pp = newp;                // *pp 就是"外面那个指针 p"
}

int main() {
    int a = 10, b = 99;
    int *p = &a;
    printf("最初 *p = %d\n", *p);

    redirect(&p, &b);          // 传入 p 的地址，让 p 指向 b
    printf("改后 *p = %d\n", *p);
    return 0;
}
```

输出：
```
最初 *p = 10
改后 *p = 99
```

> 📌 **对照着想：**
> - 改普通变量 `a` → 传 `&a`，形参写 `int *`
> - 改指针变量 `p` → 传 `&p`，形参写 `int **`
> - 改指针的指针 → 传 `&&p`，形参写 `int ***`……以此类推（不过三层以上就很少见了）
>
> 这也是第 6 章链表里 `push_front(Node **head, ...)` 的原因——头插要改 main 里那个 `head` 指针本身！

## 4.5.4 函数返回指针：小心"悬空" 🕳️

函数可以 `return` 一个指针，但有个大坑：**别返回局部变量的地址**。因为局部变量在函数结束时就被回收了，返回的地址指向一块"已失效"的内存（悬垂指针，第 6.2 节细讲）。

那怎么才能安全地"从函数带出一个指针"？两种合法姿势：

### 姿势 1：返回 `static` 变量的地址

```c
#include <stdio.h>

int *counter() {
    static int v = 0;   // static：只初始化一次，函数结束也不消失
    v++;
    return &v;          // 返回 static 变量地址 → 安全
}

int main() {
    printf("%d %d %d\n", *counter(), *counter(), *counter());
    return 0;
}
```

输出：
```
1 2 3
```

### 姿势 2：返回 `malloc` 出来的内存地址（第 6 章主角）

```c
int *makeInt(int value) {
    int *p = (int *)malloc(sizeof(int));   // 在"堆"上申请
    *p = value;
    return p;                               // 堆内存不会自动回收，安全！
}
// 用完之后要 free(p)；malloc 在第6章细讲
```

> 🚨 **绝对别这样写：**
> ```c
> int *bad() {
>     int x = 3;      // 局部变量
>     return &x;      // ❌ x 在函数结束时就没了！返回的是悬垂地址
> }
> ```

> 💡 **一句话：局部变量"出门即失效"，要带回指针就靠 `static` 或"堆"（malloc）。**

## 4.5.5 本节小结

这一节我们学了：

✅ **const 指针：** `const` 在 `*` 哪边，哪边就只读——内容只读 vs 指针自己只读

✅ **void *：** 万能地址盒，能装任意指针，用前必须**强转回原类型**（`qsort` 的伏笔）

✅ **int **：** 想改"指针本身"就传"指针的地址"（链表 `Node **head` 的真相）

✅ **函数返回指针：** 别返回局部变量地址；用 `static` 变量或 `malloc`（第6章）

> 💡 **记住：const 是"锁"，void* 是"万能盒"，int** 是"改指针的钥匙"，返回指针要"留得住"。**
