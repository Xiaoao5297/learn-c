# 4.3 指针与字符串

3.3 学过用 `char` 数组存字符串。这一节从指针的角度再看字符串，你会突然明白很多以前“死记”的规则。

## 4.3.1 `char *` 与字符串字面量

字符串常量（如 `"hello"`）在 C 语言里是什么？答案是：**一段以 `'\0'` 结尾的字符序列，表达式 `"hello"` 的值就是它首字符的地址**。也就是说，字符串字面量天然是 `char *` 类型：

```c
char *s = "hello";    /* s 指向字面量的首字符 h */
```

```c
// 4.3.1 char_star_string.c
#include <stdio.h>
#include <string.h>

int main(void)
{
	char arr[] = "hello";
	char *s = "hello";

	printf("arr = %s\n", arr);
	printf("s   = %s\n", s);
	printf("*s 的首字符：%c\n", *s);
	printf("sizeof(arr) = %zu\n", sizeof(arr));
	printf("strlen(s)   = %zu\n", strlen(s));

	return 0;
}
```

<!-- output: 4.3.1 -->
```text
arr = hello
s   = hello
*s 的首字符：h
sizeof(arr) = 6
strlen(s)   = 5
```

`char arr[] = "hello"` 和 `char *s = "hello"` 打印出来一样，但机制不同：

用快递柜来分清这两种写法：`char arr[]` 是“把包裹拆开，里面的东西**复制一份**放进自己的柜子”——柜子里的东西随便你拆改；`char *s` 是“只在纸条上抄下公共储藏室的柜号”——东西还在人家那儿，只许看不许动，硬撬开改（`s[0] = 'H'`）就是在动公共财产，程序多半当场崩溃。

| 对比项 | `char arr[] = "hello"` | `char *s = "hello"` |
|--------|------------------------|---------------------|
| 内存 | 把 6 个字节（含 `'\0'`）**复制**进自己的数组 | s 只存字面量的**地址**，不复制内容 |
| `sizeof` | `6`（整个数组） | 一个指针的大小（常见 64 位系统上是 8） |
| 能否修改内容 | 能：`arr[0] = 'H'` 合法 | **不能**：字面量通常放在只读存储区，`s[0] = 'H'` 是未定义行为 |
| 能否重指向 | 数组名不能变（4.2） | 能：`s = "world";` 让 s 改指别处 |

```c
/* 错误示范，不要照抄 */
char *s = "hello";
s[0] = 'H';    /* 试图修改字符串字面量：未定义行为，多半崩溃 */
```

建议：**需要修改的字符串用 `char arr[]` 存；只读的字符串才用 `char *` 接字面量**。指向字面量、不打算修改的指针，最好声明成 `const char *s = "hello";`，编译器会替你拦住误改（4.6 展开 `const`）。

## 4.3.2 遍历字符串：以 `'\0'` 为终点

字符串的结束标志是 `'\0'`（空字符，值为 0）。遍历字符串不需要知道长度，遇到 `'\0'` 停下即可。用指针写一遍 3.4 自己实现过的 `strlen`：

还是 3.3 那支“队尾站着哨兵”的队伍：指针像阅兵时从队头走过来的检阅官，每走一步看一眼当前的人（`*s`），数一个人前进一步（`s++`），看到队尾哨兵就停止阅兵。检阅官不需要提前知道队伍多长——哨兵就是他的终点线。

```c
// 4.3.2 my_strlen.c
#include <stdio.h>

size_t my_strlen(const char *s)
{
	size_t count = 0;

	while (*s != '\0') {
		count++;
		s++;
	}

	return count;
}

int main(void)
{
	printf("hello 有 %zu 个字符\n", my_strlen("hello"));
	printf("hi 有 %zu 个字符\n", my_strlen("hi"));

	return 0;
}
```

<!-- output: 4.3.2 -->
```text
hello 有 5 个字符
hi 有 2 个字符
```

指针版 `strlen` 的逻辑值得细读：

1. `*s != '\0'`：当前字符没到结尾就继续。
2. `s++`：指针前进一个字符（`char` 步长是 1 字节）。
3. 参数写成 `const char *s`：承诺不修改字符串内容。

以 `"hi"` 为例：`s` 从 `h` 出发，数完 `h`、`i` 后，第三个字符是 `'\0'`，循环停止，返回 2。

也可以用 `while (*s)` 代替 `while (*s != '\0')`——`'\0'` 的值是 0，为假。两种写法都常见，前一种意图更明显，推荐先写前一种。

## 4.3.3 能修改的字符串和只读的字符串

用 `char` 数组存字符串，内容可以随便改——改的只是自己那份副本：

```c
// 4.3.3 string_modify.c
#include <stdio.h>

int main(void)
{
	char word[] = "hello";

	word[0] = 'H';
	printf("word 变成：%s\n", word);

	char *p = word;
	p[1] = 'E';
	printf("通过指针改：%s\n", word);

	return 0;
}
```

<!-- output: 4.3.3 -->
```text
word 变成：Hello
通过指针改：HEllo
```

`word[0] = 'H'` 和 `p[1] = 'E'` 做的是同一件事：下标是指针算术的缩写（4.2.3），数组名和指向它的指针访问同一块内存。

对比 4.3.1 的表格：把 `char word[]` 换成 `char *s = "hello"`，上面两行赋值都会变成未定义行为。判断标准只有一个——**这段字符串存在“我自己的数组”里，还是存在只读的字面量区**。

## 4.3.4 综合示例：统计元音字母

把遍历和统计结合起来：读入一行英文，数一数元音字母（a、e、i、o、u，不分大小写）出现了几次。

```c
// 4.3.4 vowel_count.c
#include <stdio.h>
#include <string.h>

int count_vowels(const char *s)
{
	int count = 0;

	while (*s != '\0') {
		char lower = *s;
		if (lower >= 'A' && lower <= 'Z') {
			lower = (char)(lower + ('a' - 'A'));
		}
		if (lower == 'a' || lower == 'e' || lower == 'i'
		    || lower == 'o' || lower == 'u') {
			count++;
		}
		s++;
	}

	return count;
}

int main(void)
{
	char line[64];

	printf("请输入一行英文：\n");
	if (fgets(line, sizeof(line), stdin) == NULL) {
		printf("读取失败\n");
		return 1;
	}
	line[strcspn(line, "\n")] = '\0';

	printf("%s 中有 %d 个元音字母\n", line, count_vowels(line));

	return 0;
}
```

<!-- output: 4.3.4 -->
```text
请输入一行英文：
Hello World 中有 3 个元音字母
```

输入是 `Hello World`（回显省去）。其中的元音是 e、o、o，共 3 个。

用到的两个老朋友：

1. `fgets` 读一行并保留行尾的 `'\n'`（3.3 讲过），`line[strcspn(line, "\n")] = '\0';` 把它去掉，否则行尾的换行符也会被打印出来。
2. `count_vowels` 里的指针遍历和 4.3.2 相同：`*s` 看一个字符，`s++` 前进一步，`'\0'` 收工。大小写归一用区间比较加固定差值 `'a' - 'A'`（1.4.7 讲过字符就是整数）。

## 4.3.5 常见错误

| 错误写法 | 问题 | 正确写法 |
|----------|------|----------|
| `char *s = "hello"; s[0] = 'H';` | 修改字面量，未定义行为 | `char arr[] = "hello";` 再改 |
| `char *s; scanf("%s", s);` | s 是野指针，而且 `%s` 不限宽 | 用 `char arr[N]; fgets(arr, N, stdin);` |
| 遍历时 `for (i = 0; i < strlen(s); i++)` 每轮重算长度 | 能用但效率低 | 先存长度，或用 `'\0'` 终止的指针遍历 |
| `char *s = "hello"; s = "world";` 以为改了原字符串 | 只是让 s 改指别处，字面量没变 | 明确“改指针”和“改内容”是两回事 |
| 用 `==` 比较两个字符串内容 | 比较的是地址 | 用 `strcmp`（3.4 讲过） |

## 4.3.6 小结

- 字符串字面量是 `char *`：表达式 `"hello"` 的值是首字符的地址，末尾自动带 `'\0'`。
- `char arr[] = "hello"` 复制内容进自己的数组、可修改；`char *s = "hello"` 只存地址、内容只读。
- 遍历字符串以 `'\0'` 为终点：`while (*s != '\0') { ...; s++; }`。
- 修改字符串前先问：它存在可写的数组里吗？字面量不可修改。
- 读字符串用 `fgets`，禁止不限宽的 `scanf("%s")`。

## 练习

### 一、选择题

**1. `char a[] = "hi";` 和 `char *b = "hi";` 的区别是：**

A. 完全一样\
B. `a` 是可以修改字符内容的数组，`b` 指向字符串字面量，字面量不可修改\
C. `b` 不能遍历\
D. `a` 的内容不可修改

**2. 下面代码的最大问题是：**

```c
char *s = "abc";

s[0] = 'A';
```

A. 编译必定失败，无法运行\
B. `s` 指向字符串字面量，字面量存放在只读存储区，修改它是未定义行为\
C. `s[0]` 的下标超范围\
D. 缺少 `<string.h>`

**3. `while (*s != '\0')` 可以简写成 `while (*s)`，原因是：**

A. 两种写法编译结果不同\
B. `'\0'` 的值是 0，在条件里为假；其他字符值非 0，为真，语义相同\
C. C 语言规定循环条件只能是 `*s`\
D. 没有区别也没有道理，只是习惯

#### 一、选择题

1. **B**。数组 `a` 的 3 个字节在栈上，随便改；`b` 指向的字面量在只读存储区，只能读不能写。
2. **B**。未定义行为，可能运行看起来“正常”，也可能崩溃，这正是它危险的地方。想修改应声明 `char arr[] = "abc";`。
3. **B**。条件本质就是“值非零”，`*s` 非 0 等价于 `*s != '\0'`。
4. `3`；`2`；`8`（一个指针的大小，与字符串无关）。
5. `'\0'`；`s++`（或 `s = s + 1`，让指针前进）。

#### 三、改错题

三处错误：

1. `if (*s = target)`：赋值误作比较。这句会把 `target` 写进当前字符、把原内容破坏掉，且条件恒为真。应写成 `*s == target`。
2. 循环体里忘了推进指针：`s` 永远停在第一个字符上，条件永远为真，死循环。循环末尾应加 `s++;`。
3. 函数只读字符串，参数应加 `const`：`int count_char(const char *s, char target)`。

修正后的完整程序（输出 `l 的个数：2`）：

```c
#include <stdio.h>

int count_char(const char *s, char target)
{
	int count = 0;

	while (*s != '\0') {
		if (*s == target) {
			count++;
		}
		s++;
	}

	return count;
}

int main(void)
{
	char line[] = "hello";

	printf("l 的个数：%d\n", count_char(line, 'l'));

	return 0;
}
```
