# 4.4 结构体

一个学生的信息有姓名、年龄、成绩——类型不同、缺一不可。用三个散落的变量存，传参要传三个，复制要复制三份，改个需求就得满代码找。这一节介绍结构体（struct）：把相关的数据打包成一个整体。

## 4.4.1 定义和使用结构体

**结构体（structure）** 是把若干个不同类型的成员（member）组合成一个类型的构造类型。定义和使用：

可以把结构体想成一张学生登记表：姓名、年龄、成绩印在一张表上，各栏格式不同（字符串、整数、小数），但它们属于同一个人，登记时要填在同一张纸上。用的时候报“这张表的姓名栏”（`s1.name`）就能取到对应信息——信息捆在一起，不会散落。

```c
// 4.4.1 struct_basic.c
#include <stdio.h>

struct student {
	char name[20];
	int age;
	double score;
};

int main(void)
{
	struct student s1 = {"小明", 18, 92.5};

	printf("%s %d 岁，成绩 %.1f\n", s1.name, s1.age, s1.score);

	s1.score = 95.0;
	printf("更新后的成绩：%.1f\n", s1.score);

	printf("s1 占 %zu 字节\n", sizeof(s1));

	return 0;
}
```

<!-- output: 4.4.1 -->
```text
小明 18 岁，成绩 92.5
更新后的成绩：95.0
s1 占 32 字节
```

几个关键点：

1. `struct student` 一起构成类型名，声明变量时 `struct` 不能省。
2. 初始化用花括号，按成员顺序一一对应，和数组初始化的规则一样（3.1.2）。
3. 访问成员用点运算符 `.`：`s1.age`、`s1.score`，既能读也能赋值。
4. `sizeof(s1)` 是所有成员的大小之和再**加上填充字节**。三个成员 20 + 4 + 8 = 32 字节，这个例子正好没有多余填充；但“结构体大小 = 成员大小之和”并不总成立——编译器为了对齐会在成员之间插空隙，具体布局随平台变化，用 `sizeof` 验证即可，不要心算。

本教程的规范（呼应第 0 章）：默认不写 `typedef struct { ... } Student;`，直接用 `struct student`。多写两个单词，换来一眼看清“这是个结构体”。

## 4.4.2 结构体数组

一个学生的信息打包成了 `struct student`，一个班的学生就是结构体数组：

结构体数组就像班主任手里的一叠登记表：每张表是一个学生，整叠按顺序排好，报“第 i 张表的成绩栏”（`students[i].score`）就能翻到对应信息。

```c
// 4.4.2 struct_array.c
#include <stdio.h>

struct student {
	char name[20];
	int age;
	double score;
};

int main(void)
{
	struct student students[3] = {
		{"小明", 18, 85.0},
		{"小红", 17, 92.0},
		{"小刚", 18, 76.0}
	};

	double sum = 0.0;

	for (int i = 0; i < 3; i++) {
		printf("%s %d 岁 %.1f 分\n",
		       students[i].name, students[i].age, students[i].score);
		sum += students[i].score;
	}

	printf("平均分：%.1f\n", sum / 3);

	return 0;
}
```

<!-- output: 4.4.2 -->
```text
小明 18 岁 85.0 分
小红 17 岁 92.0 分
小刚 18 岁 76.0 分
平均分：84.3
```

访问结构体数组的成员：`students[i].score`。运算顺序是先下标后点号——`students[i]` 得到一个结构体，再取它的 `score` 成员。

对比一下组织方式的差别：第 3 章的 `int scores[3]` 只能存 3 个成绩，谁是这份成绩的主人要靠下标位置去猜。`struct student students[3]` 把姓名、年龄、成绩绑在一起，一个下标就是一个完整的人。**结构体解决“数据有关联”的问题，数组解决“数据有多个”的问题，两者组合是 C 语言里组织数据的基本盘。**

## 4.4.3 嵌套结构体

结构体的成员也可以是另一个结构体。比如给每个学生加一个生日：

```c
// 4.4.3 struct_nested.c
#include <stdio.h>

struct date {
	int year;
	int month;
	int day;
};

struct student {
	char name[20];
	struct date birthday;    /* 嵌套：成员是另一个结构体 */
	double score;
};

int main(void)
{
	struct student s = {"小红", {2007, 3, 15}, 92.0};

	printf("%s 的生日：%d 年 %d 月 %d 日\n",
	       s.name, s.birthday.year, s.birthday.month, s.birthday.day);

	s.birthday.year = 2008;
	printf("更正后的出生年份：%d\n", s.birthday.year);

	return 0;
}
```

<!-- output: 4.4.3 -->
```text
小红 的生日：2007 年 3 月 15 日
更正后的出生年份：2008
```

嵌套成员的访问就是点号连点号：`s.birthday.year`。初始化时，内层结构体用一对内层花括号：`{"小红", {2007, 3, 15}, 92.0}`。

注意定义顺序：`struct student` 用到了 `struct date`，所以 `struct date` 必须定义在前面。编译器从上往下读，用之前先见到定义。

## 4.4.4 结构体赋值：整包复制

数组不能整体赋值（3.1 的常见错误表），结构体可以。`s2 = s1` 把**所有成员逐个复制**一份：

这像给全班复印登记表：复印机把每一栏（姓名、年龄、成绩）都原样印到新纸上，得到一张完全独立的副本。之后你在副本上怎么涂改，原表都不受影响。

```c
// 4.4.4 struct_assign.c
#include <stdio.h>

struct student {
	char name[20];
	int age;
	double score;
};

int main(void)
{
	struct student a = {"小明", 18, 90.0};
	struct student b = a;    /* 整包复制 */

	b.age = 19;
	b.score = 88.0;

	printf("a：%s %d 岁 %.1f 分\n", a.name, a.age, a.score);
	printf("b：%s %d 岁 %.1f 分\n", b.name, b.age, b.score);

	return 0;
}
```

<!-- output: 4.4.4 -->
```text
a：小明 18 岁 90.0 分
b：小明 19 岁 88.0 分
```

`b` 是一份完全独立的副本：改 `b` 的任何成员都影响不到 `a`，连 `name` 数组都是复制过去的一份。

两个限制要记住：

1. 结构体之间**不能用 `==` 比较**。即使想比较“所有成员都相同”，`a == b` 也是编译错误。需要比较就逐成员比较（或用第 3 章的 `strcmp` 比较字符串成员）。
2. 整包复制对大结构体代价不小。成员多时，传参建议传指针（4.5 的主题）。

## 4.4.5 常见错误

| 错误写法 | 问题 | 正确写法 |
|----------|------|----------|
| `student s1;` | 少了 `struct`（没有 typedef 时） | `struct student s1;` |
| `struct student s; s.name = "小明";` | 数组不能整体赋值 | 初始化 `{"小明", ...}` 或 `snprintf(s.name, sizeof(s.name), "%s", "小明")` |
| `struct student s = {18, "小明", 90.0};` | 顺序错了，类型不匹配 | 按成员定义顺序初始化 |
| `if (a == b)`（结构体变量） | 结构体不能用 `==` 比较 | 逐成员比较 |
| `}` 后面忘写分号 | 编译错误，报错位置还常常在别处 | `struct student { ... };` 记住结尾的分号 |
| 先用 `struct student` 后定义 | 编译器还没见到这个类型 | 先定义类型，再声明变量 |

## 4.4.6 小结

- 结构体把不同类型的成员打包成一个类型；定义以 `};` 结尾，`struct` 关键字不能省。
- 初始化用花括号按成员顺序对应；访问成员用 `.`，读和写都可以。
- 结构体数组 + `for` 循环管理批量数据：`students[i].score`。
- 嵌套结构体点号连缀：`s.birthday.year`；被嵌套的类型要先定义。
- 结构体赋值是整包复制，副本和原件互相独立；结构体之间不能用 `==` 比较。

#### 一、选择题

1. **A**。`struct student { ... };` 结尾的分号常被漏掉，而且报错位置往往在别处，非常迷惑。

5. `students[4].age`；定义。

#### 三、改错题

三处错误：

1. `char name[20]`：成员声明行尾漏了分号。应写成 `char name[20];`。
2. `if (a == b)`：结构体不能用 `==` 比较，编译失败。要判断“数据相同”需逐成员比较，例如 `if (a.age == b.age && a.score == b.score && strcmp(a.name, b.name) == 0)`（需要 `<string.h>`）；本题其实不需要这个判断，可直接删除。
3. 交换逻辑本身没错（`temp` 整包复制三行是对的），但交换后只输出 `a`——按题意应把两名学生的信息都输出验证。这是功能缺失型错误：补上 `printf` 输出 `b`。

修正后的完整程序（交换后输出 `小红 14 88.0` 和 `小明 15 92.5`）：

```c
#include <stdio.h>

struct student {
	char name[20];
	int age;
	double score;
};

int main(void)
{
	struct student a = {"小明", 15, 92.5};
	struct student b = {"小红", 14, 88.0};

	struct student temp = a;
	a = b;
	b = temp;

	printf("%s %d %.1f\n", a.name, a.age, a.score);
	printf("%s %d %.1f\n", b.name, b.age, b.score);

	return 0;
}
```
