# 4.2 指针与数组

上一节学会了取地址和解引用。这一节把指针和数组放到一起——它们关系密切，也是初学者误解最多的地方。

## 4.2.1 数组名的自动转换

先说结论，再说证据。

**在大多数表达式中，数组名会自动转换为指向首元素的指针（这个过程叫 decay，退化）。但数组本身不是指针。**

```c
int arr[5] = {10, 20, 30, 40, 50};
int *p = arr;    /* arr 在这里转换成了 &arr[0] */
```

`int *p = arr;` 能编译通过，是因为 arr “退化”成了首元素的地址。但它不等于说“数组名就是一个指针”。看实验：

```c
// 4.2.1 array_decay.c
#include <stdio.h>

int main(void)
{
	int arr[5] = {10, 20, 30, 40, 50};
	int *p = arr;

	printf("sizeof(arr) = %zu 字节\n", sizeof(arr));
	printf("sizeof(p)   = %zu 字节\n", sizeof(p));
	printf("*p = %d\n", *p);
	printf("*arr = %d\n", *arr);

	return 0;
}
```

<!-- output: 4.2.1 -->
```text
sizeof(arr) = 20 字节
sizeof(p)   = 8 字节
*p = 10
*arr = 10
```

注意区别：

| 表达式 | 结果 | 说明 |
|--------|------|------|
| `sizeof(arr)` | `20` | 整个数组的大小：5 × 4 字节。**如果数组名是指针，这里该是 8** |
| `sizeof(p)` | `8` | p 是货真价实的指针（常见 64 位系统上指针占 8 字节，见 4.1.3） |
| `*arr` | `10` | 表达式里 arr 已退化为 `&arr[0]`，解引用得到首元素 |

还有一个不容易察觉的区别在 `&` 上：

| 写法 | 类型 | 含义 |
|------|------|------|
| `&arr[0]` | `int *` | 首元素的地址 |
| `&arr` | `int (*)[5]` | **整个数组**的地址，数值上和首元素地址相同，但类型不同 |

`int (*)[5]` 读作“指向长度为 5 的 int 数组的指针”。对它做 `+1`，会跳过整个数组（20 字节），而不是一个元素。初学阶段只需要记住结论：**`&arr` 和 `&arr[0]` 数值一样，类型不一样**。

数组的三个身份可以总结成一句话：

1. 数组本身不是指针，它是“一串连续存放的元素”。
2. 在大多数表达式中，数组名自动转换为首元素的地址。
3. 两个例外：`sizeof(arr)` 得到整个数组的大小；`&arr` 得到整个数组的地址。

## 4.2.2 指针算术

指针可以加减整数，但含义和普通数字不同：

```c
p + 1    /* 不是地址加 1 个字节，而是加 1 个“元素”的宽度 */
```

对 `int *` 来说，`p + 1` 把地址加 4 字节（一个 int 的宽度），正好指向下一个元素。编译器知道指针的类型，会自动乘上步长：

```c
// 4.2.2 pointer_arith.c
#include <stdio.h>

int main(void)
{
	int arr[5] = {10, 20, 30, 40, 50};
	int *p = arr;

	printf("p 指向：%d\n", *p);

	p++;
	printf("p++ 后指向：%d\n", *p);
	printf("*(p + 2)：%d\n", *(p + 2));
	printf("p + 2 == &arr[3] 吗：%d\n", p + 2 == &arr[3]);

	return 0;
}
```

<!-- output: 4.2.2 -->
```text
p 指向：10
p++ 后指向：20
*(p + 2)：40
p + 2 == &arr[3] 吗：1
```

解读：

1. `p` 从首元素出发，`*p` 是 10。
2. `p++` 让指针前进一步，指向 `arr[1]`，`*p` 变成 20。
3. `*(p + 2)` 从 `arr[1]` 再前进 2 个元素，指向 `arr[3]`，解引用得到 40。注意 `p + 2` **不修改 p**，表达式算出的临时地址只在解引用时用一次。
4. `p + 2 == &arr[3]` 成立，输出 1（呼应 2.1.5：比较结果 1 表示真）。

指针算术最容易错的就是“现在到底指向第几个元素”。养成习惯：每做一个 `p++` 或 `p + n`，都在纸上把箭头挪一格、数清楚下标，再写代码。

另外，两个指向**同一个数组**的指针可以比较和相减：

```c
int *q = &arr[4];
printf("%d\n", q - p);        /* 相隔几个元素 */
printf("%d\n", p < q);        /* 1，p 在前 */
```

相减得到的是元素个数（不是字节数），结果是 `ptrdiff_t` 类型，打印用 `%td`。指向不同数组的指针做比较、相减是没有意义的行为，不要写。

## 4.2.3 `arr[i]` 就是 `*(arr + i)`

C 语言有个漂亮的设计：下标运算符只是指针算术的缩写。

```text
arr[i]  完全等价于  *(arr + i)
```

`arr[2]` 的真实过程：arr 转换为首元素地址，加上 2 个元素的偏移，再解引用。验证：

```c
// 4.2.3 index_equivalence.c
#include <stdio.h>

int main(void)
{
	int arr[5] = {10, 20, 30, 40, 50};

	printf("arr[2]      = %d\n", arr[2]);
	printf("*(arr + 2)  = %d\n", *(arr + 2));
	printf("2[arr]      = %d\n", 2[arr]);

	return 0;
}
```

<!-- output: 4.2.3 -->
```text
arr[2]      = 30
*(arr + 2)  = 30
2[arr]      = 30
```

三个输出一样，因为加法可交换：`arr + 2` 和 `2 + arr` 相同。`2[arr]` 能编译能运行，但**可读性极差，禁止在正式代码里这样写**——这里展示它只为证明“下标就是指针算术”这件事。

这也解释了 3.1.7 留下的那句话：`scores[i]` 之所以能用下标访问，正是因为编译器把数组名当成首元素地址来算偏移。

## 4.2.4 数组作为函数参数

3.5 已经用过“数组 + 长度”的传参写法，现在能说清原理了：

**函数参数里的 `int a[]` 就是指针。**编译器把它改写成 `int *a`，传进来的是首元素地址。所以：

1. 函数内修改 `a[i]`，改的是原数组（顺着地址找到了原数据）。
2. 函数内 `sizeof(a)` 得到的是一个指针的大小（常见 64 位系统上是 8 字节），**不是数组大小**——长度必须单独传参。

```c
/* 错误示范，不要照抄 */
void print_size(int nums[])
{
	printf("%zu\n", sizeof(nums));    /* 打印的是指针大小，不是数组大小 */
}
```

```c
// 4.2.4 array_param.c
#include <stdio.h>

int sum(const int nums[], int count)
{
	int total = 0;

	for (int i = 0; i < count; i++) {
		total += nums[i];
	}

	return total;
}

void add_bonus(int nums[], int count)
{
	for (int i = 0; i < count; i++) {
		nums[i] += 5;
	}
}

int main(void)
{
	int scores[5] = {80, 90, 70, 60, 100};

	printf("加分前总分：%d\n", sum(scores, 5));

	add_bonus(scores, 5);

	printf("加分后总分：%d\n", sum(scores, 5));
	printf("第一个人的成绩变成了 %d\n", scores[0]);

	return 0;
}
```

<!-- output: 4.2.4 -->
```text
加分前总分：400
加分后总分：425
第一个人的成绩变成了 85
```

三个要点：

1. `sum` 只读不改，参数写 `const int nums[]`，和 `const int *nums` 含义相同：不能通过这个指针修改元素（呼应 3.5.3）。
2. `add_bonus` 要修改原数组，参数不能加 `const`。
3. 两个函数都不知道数组多长，长度 `count` 由调用方传入。

也可以用指针写法写遍历，和下标写法完全等价（4.2.3 的结论）：

```c
void add_bonus(int nums[], int count)
{
	for (int *p = nums; p < nums + count; p++) {
		*p += 5;
	}
}
```

初学阶段建议优先用下标写法，直观且不容易错；指针写法在阅读别人的代码时要认识。

## 4.2.5 常见错误

| 错误写法 | 问题 | 正确写法 |
|----------|------|----------|
| 认为“数组名就是一个指针” | 数组不是指针，表达式中才转换（见 4.2.1） | 记住 `sizeof(arr)` 是整个数组大小 |
| 函数内对数组参数 `sizeof` 求长度 | 得到指针大小（如 8），不是数组大小 | 长度作为独立参数传入 |
| `int *p = arr; *p = 5;` 以为改了 p | 改的是 `arr[0]`，p 没变 | 区分“修改指针本身”和“修改指向的数据” |
| `p = arr; p[2]` 之后认为 arr 也移动了 | 数组名不会变，移动的只是 p | 数组名是“地址常量”，不能 `arr++` |
| `arr++` 或 `arr = arr + 1` | 数组名不是可修改的左值 | 用一个指针变量接住：`int *p = arr; p++;` |
| 对两个不同数组的指针比较或相减 | 无意义，未定义行为 | 只比较指向同一数组的指针 |

## 4.2.6 小结

- 数组名在大多数表达式中自动转换为指向首元素的指针，但数组本身不是指针：`sizeof(arr)` 是整个数组的大小，`&arr` 的类型是 `int (*)[N]`。
- 指针加减整数按元素移动，`p + 1` 前进一个元素，不是 1 个字节。
- `arr[i]` 与 `*(arr + i)` 完全等价，下标是指针算术的缩写。
- 函数参数里的 `int a[]` 就是指针：函数能修改原数组，但函数内 `sizeof(a)` 是指针大小，长度必须单独传参。
- 只读的数组参数加 `const`；指针遍历用 `for (int *p = nums; p < nums + count; p++)`。

## 练习

1. `int a[6];` 在 64 位系统上，`sizeof(a)`、`sizeof(a + 0)`、`sizeof(&a[0])` 各是多少？逐一说明原因。
2. `int a[4] = {1, 2, 3, 4}; int *p = a + 1;`，`*(p + 2)` 和 `p[-1]` 分别是多少？
3. 用指针算术（不用 `[]`）重写下面循环，输出所有元素：

```c
for (int i = 0; i < 5; i++) {
	printf("%d\n", nums[i]);
}
```

4. 函数参数 `void f(int nums[])` 和 `void f(int *nums)` 有区别吗？
5. 下面代码错在哪？

```c
int a[3] = {1, 2, 3};
a++;
printf("%d\n", *a);
```

6. 编程题：写函数 `void reverse_array(int nums[], int count);` 用两个指针（一个从头出发、一个从尾出发）相向移动并交换元素，把数组原地逆序。在 `main` 里用 `{1, 2, 3, 4, 5}` 验证，输出：

```text
5 4 3 2 1
```

for (int *p = nums; p < nums + 5; p++) {

5. `a++` 编译失败（或警告）：数组名不是可修改的左值，它不能自增。应改为 `int *p = a; p++;` 再用 `*p`。
6. 参考代码：

```c
#include <stdio.h>

void reverse_array(int nums[], int count)
{
	int *front = nums;
	int *back = nums + count - 1;

	while (front < back) {
		int temp = *front;
		*front = *back;
		*back = temp;
		front++;
		back--;
	}
}

int main(void)
{
	int nums[5] = {1, 2, 3, 4, 5};

	reverse_array(nums, 5);

	for (int i = 0; i < 5; i++) {
		printf("%d", nums[i]);
		if (i < 4) {
			printf(" ");
		}
	}
	printf("\n");

	return 0;
}
```
