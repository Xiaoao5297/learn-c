# 4.6 const 与多级指针

这是第 4 章进阶部分的最后一节，三个主题都有同一个特征：**单个知识点不难，组合起来信息量大**。第一遍读不懂可以先跳过，等用到了再回来查。

## 4.6.1 `const` 与指针的四种组合

`const` 表示“不能修改”。它和指针组合时，关键看 `const` 修饰的是**指针指向的数据**还是**指针本身**：

| 声明 | 指向的数据可改？ | 指针可改指向？ | 读法 |
|------|------------------|----------------|------|
| `int *p;` | 能 | 能 | 普通指针 |
| `const int *p;` | 不能 | 能 | 指向 const 的指针 |
| `int *const p;` | 能 | 不能 | const 指针 |
| `const int *const p;` | 不能 | 不能 | 指向 const 的 const 指针 |

记忆技巧：**从左往右读声明，`const` 出现在谁前面就管住谁**。`const int *p` 里 const 贴着 `int`，管住“指向的数据”；`int *const p` 里 const 贴着 `p`，管住指针本身。

可以用教室的规矩来记：`const int *p` 是“贴在**储物柜**上的封条”——柜里的东西不许动，但你可以换一个柜子去看（改指向）；`int *const p` 是“贴在**你本人**身上的封条”——你只能盯这一个柜子，柜门没封，里面的东西照样能动。封条贴在谁身上，谁就不能动。

```c
// 4.6.1 const_pointer.c
#include <stdio.h>

int main(void)
{
	int x = 10;
	int y = 20;

	/* 指向 const 的指针：数据不能改，指针可以改指向 */
	const int *p1 = &x;
	p1 = &y;
	printf("*p1 = %d\n", *p1);

	/* const 指针：指针不能改指向，数据可以改 */
	int *const p2 = &x;
	*p2 = 30;
	printf("x = %d\n", x);

	/* 都不能改 */
	const int *const p3 = &x;
	printf("*p3 = %d\n", *p3);

	return 0;
}
```

<!-- output: 4.6.1 -->
```text
*p1 = 20
x = 30
*p3 = 30
```

合法的部分都验证了。非法的部分编译器会拦住，写成错误示范对比：

```c
/* 错误示范：两类编译错误，不要照抄 */
const int *p = &x;

*p = 5;    /* 编译错误：指向的数据不能改 */
p = &y;    /* 合法：指针本身可以改指向 */

int *const q = &x;

q = &y;    /* 编译错误：const 指针不能改指向 */
*q = 5;    /* 合法：数据可以改 */
```

什么时候用哪种？两条实用建议：

1. **函数参数表示“只读一块数据”时用 `const int *p`**——4.2 的 `sum(const int nums[], int count)`、4.5 的 `print_student(const struct student *s)` 都是这一类，这也是初学者最该掌握的一种。
2. `int *const p` 用得少，常见于“这个指针一辈子只指一个地方”的场景（比如指向某个固定的缓冲区）。

## 4.6.2 `void *`：万能指针

`void *` 是“不指定类型的指针”，任何类型的地址都能存进它：

```c
int i = 42;
double d = 3.14;

void *v = &i;    /* 合法 */
v = &d;          /* 合法：类型不同也行 */
```

```c
// 4.6.2 void_pointer.c
#include <stdio.h>

int main(void)
{
	int i = 42;
	double d = 3.14;

	void *v = &i;
	printf("v 指向的整数：%d\n", *(int *)v);

	v = &d;
	printf("v 指向的小数：%.2f\n", *(double *)v);

	printf("v 占 %zu 字节\n", sizeof(v));

	return 0;
}
```

<!-- output: 4.6.2 -->
```text
v 指向的整数：42
v 指向的小数：3.14
v 占 8 字节
```

三个要点：

1. **解引用前必须转换成具体类型**：`*(int *)v` 先把 `void *` 转成 `int *`，再解引用。`*v` 是编译错误——编译器不知道该读几个字节、怎么解释（4.1.3：类型决定解引用的行为，`void` 恰恰表示“不知道类型”）。
2. 存进去是什么类型，就要按什么类型取出来。`v = &d;` 之后按 `int *` 解引用是未定义行为。
3. `sizeof(v)` 还是一个指针的大小（常见 64 位系统上是 8 字节），和其他指针无异。`void *` 不是“没有指针”，是“不知道类型的指针”。

`void *` 的价值在于写**通用接口**：`memcpy`、`malloc` 等标准库函数的参数和返回值都是 `void *`，这样同一套函数才能处理任意类型的数据。初学阶段知道“见转换、别乱用”即可：

- 读别人的代码，看到 `(int *)v` 明白是在恢复类型。
- 自己的代码里，能写具体类型就不写 `void *`，等第 5、6 章遇到标准库接口时它自然会出现在你面前。

## 4.6.3 二级指针

指针本身也是变量，也有地址。**存“指针的地址”的指针，叫二级指针（pointer to pointer）**：

一级指针已经是“写着柜号的纸条”，二级指针就是“记着这张纸条夹在哪一页笔记本里的记录”。翻到那一页（第一次 `*`），找到纸条；照着纸条去开柜（第二次 `*`），才拿到包裹。两层记录，两次翻找。

```c
int x = 5;
int *p = &x;      /* p 存 x 的地址 */
int **pp = &p;    /* pp 存 p 的地址 */
```

层层解引用：`*pp` 是 `p`，`**pp` 是 `x`。

```c
// 4.6.3 double_pointer.c
#include <stdio.h>

int main(void)
{
	int x = 5;
	int *p = &x;
	int **pp = &p;

	printf("x     = %d\n", x);
	printf("*p    = %d\n", *p);
	printf("**pp  = %d\n", **pp);

	**pp = 8;
	printf("修改后 x = %d\n", x);

	return 0;
}
```

<!-- output: 4.6.3 -->
```text
x     = 5
*p    = 5
**pp  = 5
修改后 x = 8
```

三个打印都是 5，因为 `x`、`*p`、`**pp` 是同一块内存的三条访问路径。`**pp = 8` 沿着“地址的地址的地址”找到 `x`，把它改成 8。

它有什么用？最典型的场景：**让函数修改调用方的指针本身**。4.1 解决了“函数改外部变量”（传 `&变量`），现在指针也是变量，同理要传它的地址：

还是 2.5 的道理：函数拿到指针参数时只得到“复印件”，改复印件改不到你的原件。想让函数把你那张“柜号纸条”换成另一张，就得告诉它“纸条本身夹在笔记本哪一页”——也就是传纸条的地址（二级指针）。

```c
// 4.6.4 redirect_pointer.c
#include <stdio.h>

void redirect(int **pp, int *target)
{
	*pp = target;    /* 修改调用方指针的指向 */
}

int main(void)
{
	int a = 1;
	int b = 2;
	int *p = &a;

	printf("p 指向的值：%d\n", *p);

	redirect(&p, &b);
	printf("重定向后 p 指向的值：%d\n", *p);

	return 0;
}
```

<!-- output: 4.6.4 -->
```text
p 指向的值：1
重定向后 p 指向的值：2
```

对照 4.1.2 的 `swap` 一遍就通了：

| 想修改的东西 | 参数类型 | 调用时传 |
|--------------|----------|----------|
| `int` 变量 | `int *` | `&x` |
| `int *` 指针 | `int **` | `&p` |
| `struct student` | `struct student *` | `&stu` |

规律一致：**想改什么，就传“它的地址”，参数类型加一层 `*`。**二级指针更主要的舞台在第 6 章（动态内存：`malloc` 失败时要通过二级指针带回错误信息）和第 9 章（链表的插入删除），现在能读懂 `int **` 就够了。

## 4.6.4 常见错误

| 错误写法 | 问题 | 正确写法 |
|----------|------|----------|
| `const int *p = &x; *p = 5;` | 指向的数据不能修改 | 改数据用 `int *p`，或去掉 const |
| `int *const p = &x; p = &y;` | const 指针不能改指向 | 去掉 const，或换 `const int *p` |
| `void *v = &i; printf("%d", *v);` | `void *` 不能直接解引用 | `*(int *)v` |
| `v = &d;` 之后 `*(int *)v` | 类型不匹配，未定义行为 | 按存进去的类型取：`*(double *)v` |
| `int **pp = &x;` | 一级变量的地址不能给二级指针 | `int *p = &x; int **pp = &p;` |
| `*p = 5` 和 `p = &y` 写混 | 一个改数据、一个改指向 | 先想清楚要改哪个 |

## 4.6.5 小结

- `const` 管住紧跟其后的东西：`const int *p` 数据只读、指向可换；`int *const p` 指向固定、数据可改。
- 只读的指针参数写 `const T *p`，这是最常见的用法。
- `void *` 万能指针：任何类型的地址都能存，解引用前必须转换回具体类型，取出时类型要和存入时一致。
- 二级指针存指针的地址，`**pp` 两条路径解引用；它让函数能够修改调用方的指针本身。
- 通用规律：想通过函数修改 T 类型的东西，参数就用 `T *`，调用时传地址。

**1. `const int *p` 的含义是：**

A. 指针本身不能改指向，数据可以改\
B. 指向的数据不能通过 `*p` 修改，指针可以改指向\
C. 数据和指向都不能改\
D. `p` 必须初始化为 `NULL`

**2. `int *const p = &x;` 之后，下面哪一行会被编译器拒绝？**

A. `*p = 20;`\
B. `p = &y;`\
C. `printf("%d\n", *p);`\
D. `x = 30;`

**3. `void *v = &x;`（`x` 是 `int`），想打印 `x` 的值，正确写法是：**

A. `printf("%d\n", *v);`\
B. `printf("%d\n", *(int *)v);`\
C. `printf("%d\n", v);`\
D. `printf("%d\n", (int)v);`

#### 一、选择题

1. **B**。`const` 贴着 `int`，管住“指向的数据”；指针本身可以换指向。
2. **B**。`int *const p` 是 const 指针，指向固定：改指向会被拒绝，改 `*p` 的数据可以。
3. **B**。`void *` 不能直接解引用，必须先转换回存入时的类型 `int *`。
4. 指向的数据；指针本身。
5. `2`（`p` 被改指向 `b`）；`1`（`a` 根本没被碰）。

#### 三、改错题

三处错误：

1. `void swap_pointers(int *pa, int *pb)`：参数只有一层指针，交换的是 `p1`、`p2` 的副本，调用方的指针纹丝不动。想改指针变量本身，参数应为 `int **pa, int **pb`。
2. 函数体内的交换逻辑也要跟着改：应通过二级指针交换“指针的值”，即 `int *temp = *pa; *pa = *pb; *pb = temp;`。
3. `swap_pointers(p1, p2);` 传的是指针的值。参数改成二级指针后，应传指针变量的地址：`swap_pointers(&p1, &p2);`。

修正后的完整程序：

```c
#include <stdio.h>

void swap_pointers(int **pa, int **pb)
{
	int *temp = *pa;
	*pa = *pb;
	*pb = temp;
}

int main(void)
{
	int a = 1;
	int b = 2;
	int *p1 = &a;
	int *p2 = &b;

	printf("交换前：%d %d\n", *p1, *p2);

	swap_pointers(&p1, &p2);

	printf("交换后：%d %d\n", *p1, *p2);

	return 0;
}
```
