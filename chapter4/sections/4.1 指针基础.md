# 4.1 指针基础

从第 1 章到现在，我们用变量存数据，一切都很自然。但有一个问题一直没问过：**变量到底存在哪里？**

程序运行时，变量放在内存里。内存像一排编了号的小格子，每个格子有一个编号，这个编号就是**地址（address）**。指针（pointer）就是存地址的变量——它不存数据本身，而是存“数据放在哪个格子”。

用快递柜来想最直观：柜子里装的是包裹（数据），柜子上的编号是地址。你手机短信里收到的“取件码 8-3021”不是包裹本身，只是“包裹在哪”的信息——它就是指针：一张写着柜号的小纸条。凭这张纸条就能取到包裹，而纸条可以塞进你的口袋（指针变量）里保存。

| 术语 | 英文 | 含义 |
|------|------|------|
| 地址 | address | 内存格子的编号 |
| 指针 | pointer | 存放地址的变量 |
| 取地址 | address-of | 用 `&` 拿到变量的地址 |
| 解引用 | dereference | 用 `*` 访问地址上的数据 |

## 4.1.1 取地址和解引用

先认识两个运算符：

| 运算符 | 读法 | 作用 | 例子 |
|--------|------|------|------|
| `&` | 取地址 | 得到变量的地址 | `&a` 是 a 的地址 |
| `*` | 解引用 | 访问地址上的数据 | `*p` 是 p 指向的那个变量 |

继续用快递柜类比：`&` 是问“这个包裹放在几号柜”（查柜号），`*` 是“凭这个柜号去把包裹取出来”（开柜取件）。一个问地址，一个用地址，方向正好相反。

声明一个指针的类型写法：在类型名和变量名之间加 `*`。指针 `*` 靠近变量名（呼应 2.6 的规范）：

```c
int a = 42;
int *p = &a;    /* p 里存的是 a 的地址，我们说“p 指向 a” */
```

```c
// 4.1.1 first_pointer.c
#include <stdio.h>

int main(void)
{
	int a = 42;
	int *p = &a;

	printf("a 的值：%d\n", a);
	printf("p 指向的值：*p = %d\n", *p);

	*p = 100;    /* 通过指针修改 a */
	printf("通过 *p 修改后，a = %d\n", a);

	return 0;
}
```

<!-- output: 4.1.1 -->
```text
a 的值：42
p 指向的值：*p = 42
通过 *p 修改后，a = 100
```

关键现象是最后一行：`*p = 100` 改的**不是 p**，而是 p 指向的变量 `a`。`*p` 和 `a` 是同一块内存的两个名字。

想看地址本身，用 `%p` 打印。打印时把地址转换成 `void *`（这是 `%p` 要求的标准写法）：

```c
printf("a 的地址：%p\n", (void *)&a);
printf("p 的值：  %p\n", (void *)p);
```

这两行会打印出形如 `0x7ffd3a2b4c5c` 的十六进制数。**每次运行、每台机器上的地址都不同**，所以教程不给它写固定输出，你自己在机器上运行看一眼即可。但两行打印的值一定相同：`p` 里存的正是 `a` 的地址。

## 4.1.2 用指针交换两个变量

指针最经典的应用：让函数修改调用方的变量。第 2 章讲过，普通参数按值传递，函数拿到的是副本，改不到外面（2.5）。把变量的**地址**传进去，函数就能顺着地址找到原变量：

打个比方：想让保洁员“处理你的桌子”，寄一张桌子的照片过去没有用——他只能对着照片干瞪眼；把“3 号楼 205 室靠窗那张桌子”的门牌号给他，他才能真的擦到那张桌子。传值是寄照片，传指针是给门牌号。

```c
// 4.1.2 swap.c
#include <stdio.h>

void swap(int *a, int *b)
{
	int temp = *a;
	*a = *b;
	*b = temp;
}

int main(void)
{
	int x = 3;
	int y = 7;

	printf("交换前：x = %d, y = %d\n", x, y);
	swap(&x, &y);
	printf("交换后：x = %d, y = %d\n", x, y);

	return 0;
}
```

<!-- output: 4.1.2 -->
```text
交换前：x = 3, y = 7
交换后：x = 7, y = 3
```

拆开看调用过程：

1. `swap(&x, &y)` 把 x 和 y 的**地址**传给函数。
2. 在 `swap` 里，`a` 存着 x 的地址，`b` 存着 y 的地址。
3. `temp = *a` 把 x 的值暂存；`*a = *b` 把 y 的值写进 x；`*b = temp` 把暂存的值写进 y。
4. 函数返回后，x 和 y 真的交换了。

对比：如果参数写成 `int a, int b`，交换只发生在副本上，`main` 里毫无变化。**想通过函数修改外部变量，就必须传指针**。3.5 的数组之所以能被函数修改，正是因为数组传参传的是地址——学完本节，那个现象的原因就清楚了。

## 4.1.3 指针的大小和类型

指针存的是地址，那么一个指针变量占几个字节？用 `sizeof` 验证：

```c
// 4.1.3 pointer_size.c
#include <stdio.h>

int main(void)
{
	int a = 1;
	double d = 2.0;
	char c = 'x';

	int *p1 = &a;
	double *p2 = &d;
	char *p3 = &c;

	printf("int * 占 %zu 字节\n", sizeof(p1));
	printf("double * 占 %zu 字节\n", sizeof(p2));
	printf("char * 占 %zu 字节\n", sizeof(p3));

	return 0;
}
```

<!-- output: 4.1.3 -->
```text
int * 占 8 字节
double * 占 8 字节
char * 占 8 字节
```

在常见 64 位系统上，指针都是 8 字节（32 位系统上是 4 字节）。指针的大小和它指向什么类型**无关**——地址的宽度是统一的。

那指针为什么还要区分类型？因为类型决定了两件事：

| 类型 | 告诉编译器什么 |
|------|----------------|
| 指向的类型 | 解引用 `*p` 时读几个字节、怎么解释：`int *` 读 4 字节当整数，`double *` 读 8 字节当小数 |
| 算术的步长 | `p + 1` 跳过几个字节：`int *` 跳 4 字节，`double *` 跳 8 字节（4.2 展开） |

所以不能拿 `int *` 去“随便指”一个 `double` 变量再解引用，编译器会拦住你。类型是保护，不是负担。

## 4.1.4 NULL：空指针

指针声明后如果不初始化，它的值是**不确定的**，指向一个随机的地址——这种指针叫**野指针（wild pointer）**。解引用野指针是未定义行为，可能崩溃，也可能悄悄改坏别的数据，比数组越界更难排查。

```c
/* 错误示范，不要照抄 */
int *p;
*p = 10;    /* p 没初始化，指向哪里？写了谁的内存？ */
```

规矩：**指针要么立刻指向一个有效的地址，要么先设为 `NULL`**。`NULL` 是标准库定义的常量，表示“不指向任何地方”：

```c
// 4.1.4 null_pointer.c
#include <stdio.h>

int main(void)
{
	int *p = NULL;

	if (p == NULL) {
		printf("p 还没有指向任何地方\n");
	}

	int x = 5;
	p = &x;

	if (p != NULL) {
		printf("现在可以放心使用 *p：%d\n", *p);
	}

	return 0;
}
```

<!-- output: 4.1.4 -->
```text
p 还没有指向任何地方
现在可以放心使用 *p：5
```

使用指针前先检查 `p != NULL`，是 C 语言最重要的防御习惯之一。函数拿到指针参数时，第一件事也常常是判断它是不是 `NULL`。

`NULL` 可以想成快递柜上一个明确的“此柜空闲”标识：它不是垃圾数据，而是一个看得懂的信号——“这张纸条上没有有效柜号，别去取件”。没有标识的纸条才是最危险的：上面可能是一串毫无意义的数字，照着去找柜子，开出来的就是别人家的柜门。

## 4.1.5 常见错误

| 错误写法 | 问题 | 正确写法 |
|----------|------|----------|
| `int *p; *p = 10;` | 野指针，未定义行为 | `int *p = NULL;` 或立刻指向有效地址 |
| `int *p = NULL; *p = 10;` | 解引用空指针 | 先判断 `p != NULL` |
| `swap(int a, int b)` 想交换外部变量 | 按值传递改不到外面 | `swap(int *a, int *b)`，调用时传 `&x, &y` |
| `printf("%p", p)` | `%p` 要求 `void *` | `printf("%p", (void *)p)` |
| 把 `*` 当成指针名的一部分：`int* a, b;` | b 不是指针，是普通 int | 一行只声明一个变量，或 `int *a, *b;` |
| 解引用后赋值写反：`*p == 100;` | `==` 是比较，不是赋值 | `*p = 100;` |

## 4.1.6 小结

- 内存按地址编址；指针是存地址的变量。
- `&变量` 取地址，`*指针` 访问地址上的数据；通过 `*p` 赋值改的是被指向的变量。
- 想让函数修改外部变量，传地址：`swap(&x, &y)`。
- 常见 64 位系统上指针占 8 字节，可用 `sizeof` 验证；指针的大小与指向类型无关，但类型决定解引用怎么解释和算术的步长。
- 指针声明后必须初始化，暂不使用就设为 `NULL`；解引用前检查 `!= NULL`。

三处错误：

1. `swap(int a, int b)` 按值传参：函数交换的是副本，调用方的 `x`、`y` 纹丝不动。参数应改为 `int *a, int *b`。
