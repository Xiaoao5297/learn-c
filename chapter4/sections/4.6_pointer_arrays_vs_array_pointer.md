# 4.6 指针进阶（下）：指针数组与数组指针

> 💬 **节前语：**
>
> 上一节我们给指针上了 const、学会 void* 和 int**。这一节，轮到指针和数组这对"亲戚"最绕的一题：
>
> ```c
> int *p[3];      // 这是啥？
> int (*p)[3];    // 这又是啥？
> ```
>
> 两者只差一个括号，意思却天差地别：
>
> - **指针数组** `int *p[3]`：`p` 是**数组**，数组里装了 **3 个 `int *` 指针**
> - **数组指针** `int (*p)[3]`：`p` 是**一个指针**，它指向"**含 3 个 int 的一维数组**"
>
> 它们是很多初学者的"鬼打墙"，也是读懂二维数组、字符串表的关键。别怕，跟着口诀一步步拆，两分钟就分清了。准备好了吗？开始吧！

---

## 4.6.1 先背口诀：怎么一眼分清？

C 里有一个优先级规则：**`[]`（下标）的优先级比 `*`（解引用）高**。

- 想让 `p` 先当数组 → 不用管优先级，`p` 自然先跟 `[]` 结合 → **指针数组**
- 想让 `p` 先当指针 → 必须用 `()` 把它和 `*` 绑在一起 → **数组指针**

```c
int *p[3];        // 先读 p[3]：p 是个"能装3个东西"的数组；每个元素类型是 int*
                  //  → p 是数组，元素是指针  →  指针数组

int (*p)[3];      // 先读 (*p)：p 是指针；它指向的类型是 int[3]
                  //  → p 是指针，指向"含3个int的数组"  →  数组指针
```

> 📌 **口诀：`*` 被括号保住的是"数组指针"（是个指针）；没括号、先跟 `[]` 的是"指针数组"（是个数组）。**

画个图感受一下：

```
int *p[3];             int (*p)[3];
┌──┬──┬──┐           p ──► ┌───┬───┬───┐
│p0│p1│p2│ (三个指针)        │int│int│int│ (一整行3个int)
└─┴─┴─┘                └───┴───┴───┘
    ↓ ↓ ↓
 各指向一块数据           p 每次 +1 会跳过"一整行"
```

## 4.6.2 指针数组实战：装一堆字符串

最常用的指针数组就是**字符串数组**：每个元素是一个 `char *`，指向一个字符串字面量。

```c
#include <stdio.h>

int main() {
    char *names[] = {"周一", "周二", "周三"};   // 数组里有 3 个 char* 指针

    for (int i = 0; i < 3; i++) {
        printf("%s ", names[i]);
    }
    printf("\n");
    return 0;
}
```

输出：
```
周一 周二 周三 
```

**对比：`char *names[]` 和 第3章的 `char names[3][10]` 有啥区别？**

| | `char names[3][10]` | `char *names[]` |
|---|---------------------|-----------------|
| 本质 | 二维字符数组 | **指针数组**（元素是指针）|
| 存法 | 每个字符串"复制"进固定格子里 | 指针"指向"字符串字面量 |
| 每个长度 | 必须一样（最长那个+1）| 可以长短不一 |
| 能否修改内容 | 可以改 | 指向的是"只读字面量"，别去改 ⚠️ |

> 🚨 **注意：`char *s = "Hi";` 里的字符串是"只读字面量"，不要写 `s[0] = 'h';`**（可能崩溃）。想改内容就用字符数组 `char s[] = "Hi";`。

> 💡 装"一组文字（菜单项、星期、月份…）"，用 `char *xxx[]` 最省心——数组里只存地址，不复制整段文字。

## 4.6.3 数组指针实战：指向"一行"

二维数组 `a[2][3]` 的本质是"**2 个一维数组**，每个一维数组含 3 个 int"。`a` 作为数组名，指向的是第一个"一维数组"（第一行）——也就是"指向含 3 个 int 的数组的指针"。

```c
#include <stdio.h>

int main() {
    int a[2][3] = {{1, 2, 3}, {4, 5, 6}};

    int (*p)[3] = a;        // p 指向"a 的第一行"（一个含 3 个 int 的数组）

    printf("a[1][2] = %d\n", p[1][2]);   // 用 p 也能当二维数组访问：第2行第3列
    printf("a[0][1] = %d\n", p[0][1]);
    return 0;
}
```

输出：
```
a[1][2] = 6
a[0][1] = 2
```

> 📌 **关键是理解 `p + 1` 会跳过"一整行"（3 个 int），而不是 1 个 int。** 因为 `p` 指向的类型是 `int[3]`——回想 4.2 节：指针加 1 移动"一个所指向的类型"的距离。
>
> ```c
> p     == &a[0]     // 指向第 0 行
> p + 1 == &a[1]     // 指向第 1 行（跳过了一整行）
> *(p + 1) 就是 a[1]，所以 (*(p+1))[2] == a[1][2]
> ```

> 🔎 **顺带解答一个"历史之谜"：** 第 3 章我们说过"二维数组传给函数，形参要写 `int a[][3]`"。为什么第二维 `3` 不能省？——因为函数收到的其实是一个**数组指针 `int (*)[3]`**，第二维 `3` 正是"一行有多长"，丢了它函数就不知道 `p+1` 该跳过多少！

---

## 4.6.4 总结小抄：一眼区分四兄弟

| 写法 | 先读谁 | 它是什么 | 每走 `+1` 跳过多大 |
|------|--------|----------|-------------------|
| `int *p[3]` | `p[3]` | 数组，元素是 `int*` | 数组整体（一堆指针）|
| `int (*p)[3]` | `(*p)` | 指针，指向 `int[3]` | 一整行 3 个 int |
| `int *p` | `*p` | 指针，指向一个 int | 1 个 int |
| `int **p` | `*p` | 指针的指针 | 1 个 int* |

> 📌 **记忆：先问"`p` 是数组还是指针"——被 `[]` 抢走的就是数组，被 `(*...)` 保住的才是指针。** 再问"里面/指向的是啥"，就能写出类型了。

---

## 4.6.5 本节小结

这一节我们学了：

✅ **优先级：** `[]` 比 `*` 高；`int *p[3]` 是**指针数组**，`int (*p)[3]` 是**数组指针**

✅ **指针数组实战：** `char *names[]` 装一堆字符串（长短随意、指向字面量）

✅ **数组指针实战：** 二维数组名其实是"指向一行的指针"，`p+1` 跳过一整行

✅ **为什么 `int a[][3]` 不能省第二维：** 函数收到的是 `int (*)[3]`，必须知道一行多长

✅ **小抄：** 先分"数组还是指针"，再分"里面装啥/指向啥"

> 💡 **记住：差别就在括号。括号里的 `*` = 指针；括号外的 `[]` = 数组。**

### 三、改错题

**8. 以下代码有 2 处概念错误：**

```c
#include <stdio.h>

int main() {
    int a[2][3] = {{1,2,3},{4,5,6}};

    int *p[3] = a;          // 错误区①：a 应该赋给哪种指针？
    printf("%d\n", p[1][2]);  // 期望 6

    char *s = "Hello";
    s[0] = 'h';             // 错误区②：指向的字面量能改吗？

    printf("%s\n", s);
    return 0;
}
```

> 提示：①应写 `int (*p)[3] = a;`（数组指针）；②`"Hello"` 是只读字面量，改用 `char s[] = "Hello";` 才能改内容。
