# 第4章：指针与结构体 —— 掌握数据的"门牌号" 🏰

## 📖 本章导读

如果问C程序员："C语言最难的是什么？" 十有八九会回答——**指针**。

如果问C程序员："C语言最强的是什么？" 答案还是——**指针**！

指针是什么？简单说，它就像一个**门牌号**：

> 普通变量 = 房子里的东西
> 地址 = 房子的门牌号
> 指针 = 一张写着门牌号的小纸条

有了这张"小纸条"，你就能找到那间房子，随意取放里面的东西——甚至隔着很远的函数都能修改它！

在本章中，我们将一起：

- 📍 **认识指针** —— 学会用 `&` 取地址、用 `*` 访问
- 🔗 **指针与数组** —— 揭开"数组传参传的是地址"的真相
- 🏷️ **结构体** —— 把相关的数据打包成一个"小档案"
- 🎓 **综合实战** —— 用结构体+指针写出像样的管理系统
- 🔒 **指针进阶（上）** —— const 指针、void*、多级指针、返回指针
- 🔍 **指针进阶（下）** —— 分清"指针数组"和"数组指针"

## 🎯 学习目标

完成本章后，你将能够：

1. ✅ 说出指针是什么，会使用 `&` 和 `*`
2. ✅ 理解数组与指针的关系，看懂"地址"相关代码
3. ✅ 定义结构体，用 `.` 访问成员
4. ✅ 综合使用结构体、数组、函数、指针，写出一个小管理系统
5. ✅ 使用 const 指针、`void*`、多级指针，安全地从函数返回指针
6. ✅ 分清"指针数组"和"数组指针"，理解二维数组传参的本质
