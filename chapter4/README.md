# 第 4 章：指针与结构体

指针是 C 语言里最容易被神化、也最容易被讲糊涂的部分。它没有那么神秘：变量存放在内存里，指针保存的就是一个地址。

这一章从地址讲起，先学会用 `&` 取地址、用 `*` 访问地址上的数据，再处理指针和数组、函数之间的关系。后半部分用结构体把相关数据打包，最后把代码拆成多个文件，用 Makefile 构建。

## 学完这一章，你应该能

1. 解释变量、地址和指针之间的关系。
2. 用 `&` 和 `*` 读写变量，用指针作为函数参数修改调用方的数据。
3. 说清楚数组名在表达式中如何转换为指向首元素的指针，以及它为什么不是指针本身。
4. 定义结构体，用 `.` 和 `->` 访问成员。
5. 使用 `const`、`void *` 和多级指针，并知道什么时候不该用。
6. 把一个小程序拆成多个 `.c` 和 `.h` 文件，用 Makefile 编译。

## 阅读建议

- 4.1 和 4.2 要慢。每看到一个指针，先在纸上画出变量、地址和箭头。
- 4.3 到 4.4 是数据组织，重点是把现实问题拆成结构体。
- 4.5 和 4.6 是进阶内容，第一遍读不懂可以先跳过，等写完第 5、6 章再回来。
- 4.7 是工程内容。不要只看 Makefile，跟着敲一遍，故意制造一次链接错误，再看报错信息。

## 学习目标

这一章不要求背语法。真正要掌握的是三件事：

1. 看到一个指针时，知道它指向什么类型。
2. 看到一个 `*` 时，知道它是在声明指针、解引用，还是乘法。
3. 看到一段操作内存的代码时，能判断它有没有越界、有没有使用未初始化的值。
