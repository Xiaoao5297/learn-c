# 第 2 章：运算符、条件、循环与函数

第 1 章让程序能说话、能记住数据。这一章让程序开始“思考”：

- 用运算符做计算和比较。
- 用条件判断选择不同的路。
- 用循环重复做一件事。
- 用函数把代码组织成可复用的块。
- 用规范让代码更容易读、更容易改。

## 前置知识

- 第 1 章：变量、数据类型、`printf`、`scanf`。
- 能使用编辑器创建 `.c` 文件，并用编译器生成可执行文件。

## 学完这一章，你应该能

1. 写出包含算术、比较和逻辑运算的表达式。
2. 用 `if` 和 `switch` 处理不同情况。
3. 用 `while`、`for`、`do-while` 完成重复任务。
4. 用 `break` 和 `continue` 控制循环。
5. 定义和调用自己的函数。
6. 按统一规范排版和命名代码。

## 本章工程支线

2.6 不是“可看可不看”的附录，而是本章的一部分。后面第 4 章的多文件工程、第 5 章的错误处理、第 6 章的内存清理都会继续使用这里的规则：

- Tab 缩进，宽度 4。
- 函数大括号另起一行。
- 小写加下划线命名。
- 函数短小，嵌套不超过 4 层。
- 用 `bool` 表达判断结果。
- 用 `clang-format` 保持格式一致。

## 预计时间

- 只读一遍：4 到 6 小时。
- 做完每节练习和章末测试：8 到 12 小时。
- 建议分 3 到 4 次学习，不要一次读完。

## 学习建议

- 每节的示例先自己运行，再改几个数字看输出。
- 练习题先写，再展开答案。
- 遇到编译错误，先看文件名、行号和第一条错误，不要从最后一条开始看。
- 不要抄代码。照着思路自己写一遍，效果更好。
