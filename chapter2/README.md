# 第2章：C语言基础运算 —— 让程序会"思考" 🧠

## 📖 本章导读

在第1章中，我们学会了让程序"说话"（打印文字）和"记住"（变量）。

但这还不够——一个真正有用的程序，需要能够**做决策**和**重复工作**。

想象一下：

- 🤖 **没有条件判断的程序**：像一个不会看路的人，无论红灯绿灯都往前走
- 🔁 **没有循环的程序**：像一个不会偷懒的人，每件事都要重复写一遍指令

在本章中，我们将学习让程序变"聪明"的三大技能：

| 技能 | 作用 | 比喻 |
|------|------|------|
| 🔢 **运算符** | 做各种运算 | 工具箱里的各种工具 |
| 🔀 **条件判断** | 根据不同情况做不同事 | 遇到岔路口选择方向 |
| 🔄 **循环** | 自动重复做一件事 | 流水线上的机械臂 |

最后，我们还会学习**函数**——把代码打包成可重复使用的"魔法盒子"。

> 💡 **小预告：** 学完这一章，程序就能自己"算"、"判断"、"重复干活"了。到了第3章，我们再给程序加一个"超级大柜子"（数组），让它能一次性装下很多数据！

## 🎯 学习目标

完成本章后，你将能够：

1. ✅ 熟练使用各种运算符进行计算和判断
2. ✅ 使用条件语句让程序根据不同情况做出决策
3. ✅ 使用循环语句让程序自动重复执行
4. ✅ 定义和调用自己的函数

## 💡 学习建议

> 条件判断和循环是所有程序逻辑的基石。
