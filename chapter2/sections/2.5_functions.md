## 2.5.1 什么是函数？

### 🎯 生动的比喻：函数就像一个"魔法盒子"

```
┌─────────────────────────────┐
│        魔法盒子              │
│                             │
│   输入 ──→  [ 函数 ]  ──→ 输出 │
│   (参数)         │        (返回值) │
│                 │              │
└─────────────────────────────┘
```

你给它一些东西（**参数**），它处理完后，吐给你一个结果（**返回值**）。

### 💻 程序中的函数

其实你早就用过函数了！

| 函数 | 你放进去 | 它返回给你 |
|------|----------|-----------|
| `printf("你好")` | 一段文字 | 在屏幕上显示 |
| `scanf(...)` | 输入内容 | 把内容存进变量 |

而这一节，我们要**自己制造**这样的魔法盒子！

## 2.5.2 为什么需要函数？

### 原因一：避免重复代码

假设要计算三次两个数的和，**没有函数**：

```c
int a = 3, b = 5;
int r1 = a + b;
printf("%d\n", r1);

int c = 10, d = 20;
int r2 = c + d;
printf("%d\n", r2);

int e = 7, f = 8;
int r3 = e + f;
printf("%d\n", r3);
```

**有函数：**

```c
int add(int x, int y) {     // 写一次
    return x + y;
}

printf("%d\n", add(3, 5));      // 用三次
printf("%d\n", add(10, 20));
printf("%d\n", add(7, 8));
```

**比喻：** 就像写作文的"好词好句本"，好句子记下来，写的时候直接引用，不用每次重写！

### 原因二：让代码更清晰

```
int main() {
    处理用户输入...
    计算成绩...
    打印报告...
    保存文件...
}
```

用函数把不同功能分开，main 就像一张**目录**，一眼看懂程序在干嘛。

### 原因三：方便修改

如果计算成绩的规则变了，只需要**改一个函数**，所有用到它的地方都跟着变。不用到处找代码改。

## 2.5.3 定义和调用函数

### 📝 基本语法

```c
返回类型 函数名(参数1, 参数2, ...) {
    // 函数体
    return 返回值;
}
```

### 📝 第一个函数：两数相加

```c
#include <stdio.h>

// 定义一个加法函数
int add(int a, int b) {
    int sum = a + b;
    return sum;
}

int main() {
    int result = add(3, 5);     // 调用函数
    printf("3 + 5 = %d\n", result);
    
    printf("10 + 20 = %d\n", add(10, 20));   // 也可以直接用在printf里
    
    return 0;
}
```

输出：
```
3 + 5 = 8
10 + 20 = 30
```

### 🧩 拆解来看

**定义部分：**

| 代码 | 作用 | 比喻 |
|------|------|------|
| `int` | 返回类型：这个盒子会吐出 int | 承诺吐出的东西类型 |
| `add` | 函数名 | 盒子的名字 |
| `(int a, int b)` | 参数列表：收两个 int | 盒子的输入口 |
| `{ ... }` | 函数体 | 盒子的内部加工 |
| `return sum;` | 把 sum 作为结果吐出去 | 盒子的输出口 |

**调用部分：**

```c
add(3, 5)
```

意思是：调用名叫 `add` 的函数，把 `3` 给 `a`，把 `5` 给 `b`，最后得到返回值 `8`。

> 📌 **关键理解：参数是"传递值"。**
> 
> 调用 `add(3, 5)` 时，`3` 和 `5` 会"复制"给函数里的 `a` 和 `b`。函数内部对 `a`、`b` 怎么改，都不会影响外面的变量。这种传值方式叫**值传递**（第4章学指针时我们会再见到它）。

> 📖 **术语卡：形参 vs 实参**
> 
> 这两个词常把新手绕晕，其实很简单：
> 
> | 术语 | 英文 | 是什么 | 例子 |
> |------|------|--------|------|
> | **形参** | parameter | 定义函数时写在括号里的"占位符" | `int add(int a, int b)` 里的 `a`、`b` |
> | **实参** | argument | 调用函数时真正传进去的"值" | `add(3, 5)` 里的 `3`、`5` |
> 
> **一句话：形参是"空位"，实参是"填进去的真东西"。** 调用时，实参的值被复制给形参（值传递）。

## 2.5.4 函数的各种写法

### 1️⃣ 没有参数的函数

```c
void printWelcome() {
    printf("欢迎使用本程序！\n");
}

int main() {
    printWelcome();    // 直接调用，不用给参数
    printWelcome();
    return 0;
}
```

### 2️⃣ 没有返回值的函数（void）

如果函数只需要"干活"，不需要"吐结果"，返回类型写 `void`：

```c
void printInfo(char name[], int age) {
    printf("姓名：%s\n", name);
    printf("年龄：%d\n", age);
}

int main() {
    printInfo("小明", 20);
    return 0;
}
```

> 📌 `void` 表示"什么都没有"。`void` 函数里可以不写 `return`，也可以写 `return;`（后面不带值）提前结束。

### 3️⃣ 带参数的函数，返回值用 return

```c
int max(int a, int b) {
    if (a > b) {
        return a;      // 提前返回 a
    }
    return b;          // 否则返回 b
}

int main() {
    printf("较大的数是：%d\n", max(7, 3));   // 7
    printf("较大的数是：%d\n", max(3, 9));   // 9
    return 0;
}
```

> 💡 **`return` 有两个作用：**
> 1. 把结果"吐"出去
> 2. **立即结束函数**——`return` 后面的代码不会再执行！

```c
void check(int score) {
    if (score < 0) {
        printf("输入错误！\n");
        return;          // 提前结束函数，下面的代码不执行了
    }
    printf("你的分数是：%d\n", score);
}
```

### 4️⃣ 只能返回一个值！

> ⚠️ **C语言的特点：一个函数只能返回一个值！**
> 
> ```c
> return a, b;   // ❌ 这样是不对的！
> ```
> 
> 那如果想一次返回多个结果（比如同时算加法和乘法）怎么办？
> 
> 有两个办法：
> - 用"指针参数"传出去（第4章学！）
> - 用"结构体"打包（第4章学！）
> 
> 现在先记住：**一个函数只能 `return` 一个值**。

## 2.5.5 函数定义的顺序：别忘了"声明"

### 🤔 一个奇怪的问题

在C语言中，**调用函数之前，编译器必须先"见过"这个函数**。

如果函数定义在 main 的**后面**，直接调用会报错：

```c
#include <stdio.h>

int main() {
    int r = add(3, 5);    // ❌ 错误！编译器还没见过 add
    return 0;
}

// 定义在 main 后面
int add(int a, int b) {
    return a + b;
}
```

**错误信息：**
```
main.c:4:12: error: implicit declaration of function 'add'
```

**翻译：** "你调用 add，但我根本没听说过它！"

### ✅ 解决办法一：把函数定义放在 main 前面

```c
int add(int a, int b) {
    return a + b;
}

int main() {
    int r = add(3, 5);    // ✅ 编译器已经见过 add 了
    return 0;
}
```

**优点：** 简单直观。  
**缺点：** main 被挤到了最下面，看程序"主流程"不方便。

### ✅ 解决办法二：函数声明（原型 prototype）⭐

在 main 前面先"打个招呼"，告诉编译器函数的"长相"，定义可以放后面：

```c
#include <stdio.h>

// 函数声明（原型）：只写签名，不写函数体，结尾有分号
int add(int a, int b);

int main() {
    int r = add(3, 5);    // ✅ 已经"见过"声明了
    printf("%d\n", r);
    return 0;
}

// 函数定义：真正的实现放这里
int add(int a, int b) {
    return a + b;
}
```

> 📌 **函数声明 = 函数的"身份证"**：告诉编译器"我长这样，先认识一下，具体实现在后面"。
> 
> 这种"先声明、后定义"的写法让 main 能放在文件最上面，**看程序主流程非常方便**，大型项目里特别常用！

> 📌 其实我们早就用过"原型"了——`#include <stdio.h>` 引入的 `stdio.h` 里面，就写着 `printf`、`scanf` 等函数的**声明**。这就是为什么 `printf` 定义在别处，我们也能直接调用！

## 2.5.6 实战：常用的函数

### 📝 判断奇偶

```c
int isEven(int n) {
    return n % 2 == 0;    // 是偶数返回1，否则返回0
}

int main() {
    printf("%d\n", isEven(4));   // 1
    printf("%d\n", isEven(7));   // 0
    return 0;
}
```

### 📝 求最大值

```c
int max(int a, int b) {
    return a > b ? a : b;    // 三目运算符：a>b 就返回 a，否则返回 b
}

int main() {
    printf("%d\n", max(10, 20));   // 20
    return 0;
}
```

> 💡 **三目运算符** `条件 ? 结果1 : 结果2` 是 if-else 的"一句话版"：
> - 条件成立 → 结果是结果1
> - 条件不成立 → 结果是结果2

### 📝 判断素数（用循环）

```c
int isPrime(int n) {
    if (n < 2) {
        return 0;
    }
    for (int d = 2; d * d <= n; d++) {
        if (n % d == 0) {
            return 0;    // 有约数，不是素数
        }
    }
    return 1;    // 是素数
}

int main() {
    for (int i = 2; i <= 20; i++) {
        if (isPrime(i)) {
            printf("%d ", i);
        }
    }
    printf("\n");
    return 0;
}
```

输出：
```
2 3 5 7 11 13 17 19
```

> 💡 看！上一节那个"找素数"的复杂逻辑，现在被**装进函数**了。以后只要调用 `isPrime(97)` 就能判断，多方便！

### 📝 计算阶乘

```c
long long factorial(int n) {
    long long result = 1;
    for (int i = 2; i <= n; i++) {
        result *= i;
    }
    return result;
}

int main() {
    printf("10! = %lld\n", factorial(10));   // 10! = 3628800
    return 0;
}
```

> 📌 阶乘增长非常快，10! = 3628800，20! 已经超出普通 int 的范围了，所以这里用 `long long`（更大的整数类型，格式符是 `%lld`）。

## 2.5.7 变量的作用域

### 📌 局部变量：函数里的变量

在**函数内部**定义的变量，叫**局部变量**。它只在这个函数里有效，函数一结束就"消失"了。

```c
int add(int a, int b) {
    int sum = a + b;   // sum 是局部变量
    return sum;
}                      // 到这里 sum 就"消失"了

int main() {
    // printf("%d", sum);   ❌ sum 不在这里！
    int sum = 100;         // main 里的 sum 和 add 里的 sum 没关系
    return 0;
}
```

> 📌 **注意：** `main` 里的 `sum` 和 `add` 里的 `sum` 虽然同名，但是**两个完全不同的变量**，各用各的，互不干扰。就像两个房间各有一把同款钥匙，互不相通。

### 📌 全局变量：函数外的变量

在所有函数**外面**定义的变量，叫**全局变量**。它从程序开始到结束都有效，**所有函数都能用**。

```c
#include <stdio.h>

int total = 0;    // 全局变量

void addToTotal(int n) {
    total += n;   // 函数里可以直接用全局变量
}

int main() {
    addToTotal(10);
    addToTotal(20);
    printf("total = %d\n", total);   // 30
    return 0;
}
```

### 📊 局部变量 vs 全局变量

| 对比 | 局部变量 | 全局变量 |
|------|----------|----------|
| 定义位置 | 函数内部 | 所有函数外面 |
| 有效范围 | 只在当前函数 | 整个程序 |
| 生命周期 | 函数结束就消失 | 程序结束才消失 |
| 常用程度 | ⭐ 最常用 | 少用 |

> ⚠️ **建议：** 尽量少用全局变量！因为任何函数都能改它，一旦多了，程序哪里出了问题很难排查。能用局部变量就用局部变量。

## 2.5.8 函数调用示例：温度转换器

把之前第1章练习里的温度转换，做成一个函数：

```c
#include <stdio.h>

// 摄氏度 → 华氏度
double celsiusToFahrenheit(double celsius) {
    return celsius * 9.0 / 5.0 + 32;
}

// 华氏度 → 摄氏度
double fahrenheitToCelsius(double fahrenheit) {
    return (fahrenheit - 32) * 5.0 / 9.0;
}

int main() {
    double c = 25.0;
    double f = celsiusToFahrenheit(c);
    printf("摄氏 %.1f 度 = 华氏 %.1f 度\n", c, f);
    
    f = 98.6;
    c = fahrenheitToCelsius(f);
    printf("华氏 %.1f 度 = 摄氏 %.1f 度\n", f, c);
    
    return 0;
}
```

输出：
```
摄氏 25.0 度 = 华氏 77.0 度
华氏 98.6 度 = 摄氏 37.0 度
```

> 💡 **发现了吗？** 转换的逻辑被封装成函数后，`main` 变得非常清爽。以后想要多少种转换，就再写几个函数就行！

## 2.5.9 main 函数的特殊性

### 🤔 main 函数是什么？

你天天写 `main`，但有没有想过它特殊在哪？

| main 的特点 | 说明 |
|------------|------|
| 🚪 **程序入口** | 程序运行时，操作系统从 `main` 开始执行 |
| 1️⃣ **唯一** | 一个程序**只能有一个** main（否则不知道该从哪开始） |
| ↩️ **返回值** | 约定 `return 0` 表示"正常结束" |

**标准写法：**

```c
int main() {     // int 表示它会返回一个整数
    // 你的代码...
    return 0;    // 0 = 程序正常结束
}
```

> ⚠️ **注意：** 有人会写 `void main()`，这在很多编译器上也能跑，但**不是标准写法**！请统一使用 `int main()` + `return 0;`。

### 📌 程序的执行流程

```
编写 main.c
    ↓
编译（gcc main.c -o main）
    ↓
运行（./main）
    ↓
操作系统找到 main 函数，开始执行
    ↓
main 从上到下执行，遇到函数调用就"跳进去"执行
    ↓
执行完 return 0
    ↓
程序结束，回到操作系统
```

**比喻：** main 就像**公司的老板**，老板负责"统筹全局"、安排工作，具体活儿交给各个"员工"（函数）去干。

## 2.5.10 综合示例：简易计算器

让我们把函数 + switch + 原型，全部串起来做一个"简易计算器"：

```c
#include <stdio.h>

// 函数声明（原型）
int add(int a, int b);
int subtract(int a, int b);
int multiply(int a, int b);
int divide(int a, int b);

int main() {
    int a = 15;
    int b = 4;
    char op = '*';    // 想换个运算，改这里的字符就行
    
    printf("a = %d, b = %d, op = %c\n", a, b, op);
    
    switch (op) {
        case '+':
            printf("结果：%d\n", add(a, b));
            break;
        case '-':
            printf("结果：%d\n", subtract(a, b));
            break;
        case '*':
            printf("结果：%d\n", multiply(a, b));
            break;
        case '/':
            printf("结果：%d\n", divide(a, b));
            break;
        default:
            printf("不支持的运算符！\n");
            break;
    }
    
    return 0;
}

// 函数定义
int add(int a, int b) {
    return a + b;
}

int subtract(int a, int b) {
    return a - b;
}

int multiply(int a, int b) {
    return a * b;
}

int divide(int a, int b) {
    if (b == 0) {
        printf("错误：不能除以0！\n");
        return 0;
    }
    return a / b;
}
```

输出：
```
a = 15, b = 4, op = *
结果：60
```

**这段程序同时用到了：**
- ✅ 函数声明（原型）和函数定义分开写
- ✅ 4个功能不同的函数
- ✅ switch 语句做菜单选择
- ✅ 在函数里做"除0检查"

## 2.5.11 本节小结

这一节我们学了：

✅ **函数是什么：** 一个"魔法盒子"，输入参数，吐出返回值

✅ **为什么要用函数：** 避免重复代码、让代码清晰、方便修改

✅ **定义和调用函数：** `返回类型 函数名(参数) { ... }`

✅ **函数的各种形式：** 无参数、无返回值（void）、提前 return

✅ **函数声明（原型）：** 先"打身份证"，定义放后面，main 放最上面

✅ **C函数只能返回一个值：** 多返回值需要指针/结构体（第4章学）

✅ **作用域：** 局部变量（函数内）、全局变量（函数外）

✅ **main 的特殊性：** 程序入口，用 `int main()` + `return 0`

> 💡 **记住：函数是组织代码最重要的工具！学会了函数，你就能写出结构清晰的大程序了！**

### 三、改错题

**6. 以下程序有4个错误，请找出并改正：**

```c
#include <stdio.h>

int main() {
    int r = sum(1, 2, 3);    // 想求 1+2+3
    printf("结果：%d\n", r);
    return 0;
}

int sum(a, b, c) {           // 错误区①：参数没写类型
    int total = a + b + c;

    return total;
}

int sum(int a, int b, int c) {   // 错误区③：重复定义！
    return a + b + c;
}
```

> 提示：错误包括缺少函数声明、参数类型缺失、重复定义、逻辑错误。
