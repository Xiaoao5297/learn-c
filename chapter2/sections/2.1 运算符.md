# 2.1 运算符

程序要会“算”。运算符就是让程序做运算的符号。

这一节覆盖 C 语言最常用的一批运算符：

- 算术运算符：`+`、`-`、`*`、`/`、`%`
- 比较运算符：`>`、`<`、`==`、`!=` 等
- 逻辑运算符：`&&`、`||`、`!`
- 赋值运算符：`=`、`+=`、`-=` 等

## 2.1.1 算术运算符

| 运算符 | 含义 | 例子 | 结果 |
|--------|------|------|------|
| `+` | 加 | `5 + 3` | `8` |
| `-` | 减 | `5 - 3` | `2` |
| `*` | 乘 | `5 * 3` | `15` |
| `/` | 除 | `7 / 2` | `3`（整数除法） |
| `%` | 取余 | `7 % 2` | `1` |

先看一个完整例子：

```c
// 2.1.1 arithmetic.c
#include <stdio.h>

int main(void)
{
	int a = 7;
	int b = 2;

	printf("%d + %d = %d\n", a, b, a + b);
	printf("%d - %d = %d\n", a, b, a - b);
	printf("%d * %d = %d\n", a, b, a * b);
	printf("%d / %d = %d\n", a, b, a / b);
	printf("%d %% %d = %d\n", a, b, a % b);

	return 0;
}
```

<!-- output: 2.1.1 -->
```text
7 + 2 = 9
7 - 2 = 5
7 * 2 = 14
7 / 2 = 3
7 % 2 = 1
```

注意两点：

1. `printf` 里的 `%%` 才会输出一个百分号。单独的 `%` 会被当成格式符的开头。
2. `7 / 2` 的结果是 `3`，不是 `3.5`，因为两个操作数都是整数。

## 2.1.2 整数除法和浮点数除法

如果两个操作数都是整数，C 会做整数除法，小数部分被丢掉。

想要得到小数结果，至少让一个操作数是浮点数：

```c
// 2.1.2 integer_division.c
#include <stdio.h>

int main(void)
{
	int a = 7;
	int b = 2;

	printf("整数除法：%d / %d = %d\n", a, b, a / b);
	printf("浮点除法：%.1f / %.1f = %.2f\n", (double)a, (double)b, (double)a / (double)b);

	return 0;
}
```

<!-- output: 2.1.2 -->
```text
整数除法：7 / 2 = 3
浮点除法：7.0 / 2.0 = 3.50
```

这里用了 `(double)a`，叫强制类型转换。它把整数临时当成浮点数来参与运算。后面讲类型时还会详细说。

## 2.1.3 取余的用途

`%` 计算余数，常见用途是判断整除和奇偶。

```c
// 2.1.3 modulo.c
#include <stdio.h>

int main(void)
{
	int number = 17;

	if (number % 2 == 0) {
		printf("%d 是偶数\n", number);
	} else {
		printf("%d 是奇数\n", number);
	}

	printf("17 除以 5 的余数是 %d\n", 17 % 5);

	return 0;
}
```

<!-- output: 2.1.3 -->
```text
17 是奇数
17 除以 5 的余数是 2
```

`%` 只能用于整数。对浮点数使用 `%` 是编译错误。

## 2.1.4 自增和自减

`++` 让变量加 1，`--` 让变量减 1。

```c
// 2.1.4 increment.c
#include <stdio.h>

int main(void)
{
	int x = 5;

	printf("x++ 的值：%d\n", x++);
	printf("自增后 x：%d\n", x);
	printf("++x 的值：%d\n", ++x);
	printf("自减后 x：%d\n", --x);

	return 0;
}
```

<!-- output: 2.1.4 -->
```text
x++ 的值：5
自增后 x：6
++x 的值：7
自减后 x：6
```

区别在于：

- `x++`：先使用 `x` 原来的值，再自增。
- `++x`：先自增，再使用新值。

初学阶段建议把自增单独写成一行，不要塞进复杂表达式里，避免自己绕晕。

## 2.1.5 比较运算符

比较运算符用来产生“真”或“假”的结果：

| 运算符 | 含义 | 例子 |
|--------|------|------|
| `>` | 大于 | `a > b` |
| `<` | 小于 | `a < b` |
| `>=` | 大于等于 | `a >= b` |
| `<=` | 小于等于 | `a <= b` |
| `==` | 等于 | `a == b` |
| `!=` | 不等于 | `a != b` |

在 C 语言里，比较表达式的结果是整数：

- `1` 表示真。
- `0` 表示假。

```c
// 2.1.5 compare.c
#include <stdio.h>
#include <stdbool.h>

int main(void)
{
	int a = 5;
	int b = 3;
	bool greater = a > b;
	bool equal = a == b;

	printf("a > b：%d\n", greater);
	printf("a == b：%d\n", equal);
	printf("a != b：%d\n", a != b);

	return 0;
}
```

<!-- output: 2.1.5 -->
```text
a > b：1
a == b：0
a != b：1
```

### 最常见的错误：把 `=` 写成 `==`

- `=` 是赋值：把右边的值放进左边变量。
- `==` 是比较：判断两边是否相等。

下面这段是错误示范，不要照抄：

```c
if (score = 60) {
	printf("及格\n");
}
```

它的意思不是“如果 score 等于 60”，而是“把 60 赋给 score，然后判断 60 是否为真”。60 非零，所以条件永远为真。编译器可能会给出警告，但有些环境下仍然能编译通过。

写条件时，如果你愿意，可以把常量写在左边：

```c
if (60 == score) {
	printf("及格\n");
}
```

这样误写成 `=` 时，`60 = score` 会直接编译失败，错误更早暴露。这种写法不是强制要求，但很有效。

## 2.1.6 逻辑运算符

| 运算符 | 含义 | 例子 |
|--------|------|------|
| `&&` | 逻辑与，两边都为真才为真 | `age >= 18 && has_ticket` |
| `\|\|` | 逻辑或，至少一边为真就为真 | `is_weekend \|\| is_holiday` |
| `!` | 逻辑非，真变假，假变真 | `!is_finished` |

真值表：

| `a` | `b` | `a && b` | `a \|\| b` | `!a` |
|-----|-----|----------|------------|------|
| 0 | 0 | 0 | 0 | 1 |
| 0 | 1 | 0 | 1 | 1 |
| 1 | 0 | 0 | 1 | 0 |
| 1 | 1 | 1 | 1 | 0 |

```c
// 2.1.6 logical.c
#include <stdio.h>
#include <stdbool.h>

int main(void)
{
	int age = 20;
	bool has_ticket = true;

	if (age >= 18 && has_ticket) {
		printf("可以入场\n");
	} else {
		printf("不能入场\n");
	}

	if (age < 12 || age >= 65) {
		printf("可以购买优惠票\n");
	} else {
		printf("需要购买普通票\n");
	}

	printf("!has_ticket = %d\n", !has_ticket);

	return 0;
}
```

<!-- output: 2.1.6 -->
```text
可以入场
需要购买普通票
!has_ticket = 0
```

### 短路求值

`&&` 和 `||` 有“短路”行为：

- `a && b`：如果 `a` 为假，就不再计算 `b`。
- `a || b`：如果 `a` 为真，就不再计算 `b`。

这很有用。例如：

```c
if (p != NULL && *p > 0) {
	printf("正数\n");
}
```

如果 `p` 是空指针，`p != NULL` 为假，右边的 `*p` 不会执行，从而避免解引用空指针。

## 2.1.7 赋值运算符

| 运算符 | 等价写法 | 含义 |
|--------|----------|------|
| `=` | `a = b` | 赋值 |
| `+=` | `a = a + b` | 加后赋值 |
| `-=` | `a = a - b` | 减后赋值 |
| `*=` | `a = a * b` | 乘后赋值 |
| `/=` | `a = a / b` | 除后赋值 |
| `%=` | `a = a % b` | 取余后赋值 |

```c
// 2.1.7 assignment.c
#include <stdio.h>

int main(void)
{
	int total = 100;

	total += 20;
	printf("加 20 后：%d\n", total);

	total -= 30;
	printf("减 30 后：%d\n", total);

	total *= 2;
	printf("乘 2 后：%d\n", total);

	total /= 3;
	printf("除 3 后：%d\n", total);

	return 0;
}
```

<!-- output: 2.1.7 -->
```text
加 20 后：120
减 30 后：90
乘 2 后：180
除 3 后：60
```

## 2.1.8 运算符优先级

当一个表达式里有多个运算符，C 会按优先级决定先算谁。

常见优先级从高到低：

1. 括号 `()`
2. 自增 `++`、自减 `--`、逻辑非 `!`
3. 乘 `*`、除 `/`、取余 `%`
4. 加 `+`、减 `-`
5. 比较 `>`、`<`、`>=`、`<=`
6. 相等 `==`、`!=`
7. 逻辑与 `&&`
8. 逻辑或 `||`
9. 赋值 `=`、`+=` 等

不需要背完整张表。记住两条：

1. 不确定就加括号。
2. 不要在一条表达式里塞太多副作用（例如多个 `++`）。

```c
// 2.1.8 precedence.c
#include <stdio.h>

int main(void)
{
	int a = 2 + 3 * 4;
	int b = (2 + 3) * 4;

	printf("2 + 3 * 4 = %d\n", a);
	printf("(2 + 3) * 4 = %d\n", b);

	return 0;
}
```

<!-- output: 2.1.8 -->
```text
2 + 3 * 4 = 14
(2 + 3) * 4 = 20
```

## 2.1.9 综合示例：秒数换算

把 3725 秒换算成“几小时几分几秒”，正好用上除法和取余。

```c
// 2.1.9 time_conversion.c
#include <stdio.h>

int main(void)
{
	int total_seconds = 3725;
	int hours = total_seconds / 3600;
	int minutes = (total_seconds % 3600) / 60;
	int seconds = total_seconds % 60;

	printf("%d 秒 = %d 小时 %d 分 %d 秒\n",
	       total_seconds, hours, minutes, seconds);

	return 0;
}
```

<!-- output: 2.1.9 -->
```text
3725 秒 = 1 小时 2 分 5 秒
```

计算过程：

- `3725 / 3600` 得到 `1` 小时。
- `3725 % 3600` 得到余下的 `125` 秒。
- `125 / 60` 得到 `2` 分钟。
- `125 % 60` 得到 `5` 秒。

## 2.1.10 小结

- `+`、`-`、`*`、`/`、`%` 是最常用的算术运算符。
- 两个整数相除，结果仍是整数。
- `%` 只能用于整数。
- `=` 是赋值，`==` 是比较。
- `&&`、`||` 有短路求值。
- 不确定优先级时，加括号。

## 练习

1. 计算 `17 / 5` 和 `17 % 5` 的结果。
2. 判断一个整数 `n` 是否为偶数，写出条件表达式。
3. `5 > 3 && 2 > 4` 的结果是什么？
4. 把 100 秒换算成“分和秒”。
5. 下面两行代码分别输出什么？

```c
int x = 10;
printf("%d\n", x++);
printf("%d\n", x);
```

<details>
<summary>参考答案</summary>

1. `17 / 5` 是 `3`，`17 % 5` 是 `2`。
2. `n % 2 == 0`。
3. `0`。`5 > 3` 为真，但 `2 > 4` 为假，逻辑与的结果为假。
4. `1` 分 `40` 秒：`100 / 60` 和 `100 % 60`。
5. 第一行输出 `10`，第二行输出 `11`。`x++` 先使用旧值，再自增。

</details>
