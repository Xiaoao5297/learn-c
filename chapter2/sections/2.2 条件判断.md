# 2.2 条件判断

程序不能只会从上往下执行。它还要会根据情况选择不同的路。

这一节讲：

- `if`
- `if-else`
- `else if`
- 嵌套条件
- `switch`

## 2.2.1 最基本的 if

语法：

```c
if (条件) {
	条件为真时执行的语句;
}
```

条件为真，就执行大括号里的内容；为假，就跳过。

不妨把 `if` 想成考试结束时的对答案：答案对，就把这道题抄进错题本的“正确”页；不对，就翻过去什么都不做，直接看下一题。`if` 里的条件就是“对不对”，大括号里就是“对的时候要做的事”。

```c
// 2.2.1 basic_if.c
#include <stdio.h>

int main(void)
{
	int score = 72;

	if (score >= 60) {
		printf("及格\n");
	}

	printf("程序结束\n");

	return 0;
}
```

<!-- output: 2.2.1 -->
```text
及格
程序结束
```

`score >= 60` 为真，所以打印“及格”。后面的“程序结束”不属于 `if`，无论条件真假都会执行。

## 2.2.2 if-else

如果条件为假时也要做点事，用 `else`：

```c
if (条件) {
	条件为真;
} else {
	条件为假;
}
```

```c
// 2.2.2 if_else.c
#include <stdio.h>

int main(void)
{
	int number = 17;

	if (number % 2 == 0) {
		printf("%d 是偶数\n", number);
	} else {
		printf("%d 是奇数\n", number);
	}

	return 0;
}
```

<!-- output: 2.2.2 -->
```text
17 是奇数
```

`if` 和 `else` 必定有一个分支会执行，不会两个都执行。

## 2.2.3 else if：多条件判断

如果情况多于两种，可以用 `else if`：

```c
if (条件1) {
	...
} else if (条件2) {
	...
} else {
	...
}
```

判断顺序是从上到下，遇到第一个为真的分支就执行，然后跳出整个结构。

这就像广播操集合时的报数分组：老师从第一个条件问起，“1 班的先出列”——一旦某个条件命中，就直接执行那个分支，后面的条件看都不看，绝不重复处理。

```c
// 2.2.3 grade.c
#include <stdio.h>

int main(void)
{
	int score = 85;

	if (score >= 90) {
		printf("优秀\n");
	} else if (score >= 80) {
		printf("良好\n");
	} else if (score >= 60) {
		printf("及格\n");
	} else {
		printf("不及格\n");
	}

	return 0;
}
```

<!-- output: 2.2.3 -->
```text
良好
```

注意顺序。如果把 `score >= 60` 放在最前面，85 会先命中“及格”，后面的“良好”永远轮不到。

写多条件判断时，通常按范围从大到小或从小到大排列，并确保条件之间不重叠。

## 2.2.4 嵌套 if

一个 `if` 里面还可以再写 `if`：

```c
// 2.2.4 nested_if.c
#include <stdio.h>
#include <stdbool.h>

int main(void)
{
	int age = 20;
	bool has_ticket = true;

	if (age >= 18) {
		if (has_ticket) {
			printf("可以入场\n");
		} else {
			printf("需要先买票\n");
		}
	} else {
		printf("未成年，不能入场\n");
	}

	return 0;
}
```

<!-- output: 2.2.4 -->
```text
可以入场
```

嵌套会增加阅读难度。能合并的条件尽量合并：

```c
if (age >= 18 && has_ticket) {
	printf("可以入场\n");
}
```

一般不建议嵌套超过三层。层数多了，应该拆成函数或提前返回。

## 2.2.5 大括号和变量作用域

大括号不仅用来“包住多条语句”，还划出了一个作用域。

```c
// 2.2.5 scope.c
#include <stdio.h>

int main(void)
{
	int x = 10;

	if (x > 0) {
		int y = 20;
		printf("x = %d, y = %d\n", x, y);
	}

	printf("x = %d\n", x);

	return 0;
}
```

<!-- output: 2.2.5 -->
```text
x = 10, y = 20
x = 10
```

变量 `y` 只在 `if` 的大括号内存在。出了大括号再使用 `y` 会编译失败。

> **建议**
>
> 即使 `if` 后面只有一条语句，也建议写大括号。以后临时加一行代码时，不容易忘记补括号。

## 2.2.6 常见陷阱

### 陷阱一：`=` 和 `==`

```c
if (score = 60) {
	printf("及格\n");
}
```

这是赋值，不是比较。`score` 被改成 60，条件结果为 60（非零，视为真）。正确写法是 `score == 60`。

### 陷阱二：if 后面多写分号

```c
if (score >= 60); {
	printf("及格\n");
}
```

`if` 后面多了一个分号，条件成立时执行的是空语句；大括号里的内容反而无条件执行。

### 陷阱三：else 悬空

```c
if (a > 0)
	if (b > 0)
		printf("a 和 b 都是正数\n");
else
	printf("a 不是正数\n");
```

`else` 会就近匹配第二个 `if`，而不是第一个。缩进看起来像匹配外层，实际不是。加了大括号就不会有歧义。

### 陷阱四：switch 忘记 break

下一小节会讲。

## 2.2.7 switch 语句

当一个变量要分别匹配多个固定值时，`switch` 比一长串 `else if` 更清楚。

你可以把 `switch` 想成食堂的取餐窗口：你手里的餐票号就是“表达式”，1 号窗口卖 1 号票的菜，2 号窗口卖 2 号票的菜。你直接走到对应窗口，不用从 1 号窗口开始一个个问“这是我吗”。`case` 就是窗口上的号牌。

```c
switch (表达式) {
case 常量1:
	语句;
	break;
case 常量2:
	语句;
	break;
default:
	语句;
	break;
}
```

```c
// 2.2.6 switch_menu.c
#include <stdio.h>

int main(void)
{
	int choice = 2;

	switch (choice) {
	case 1:
		printf("新建文件\n");
		break;
	case 2:
		printf("打开文件\n");
		break;
	case 3:
		printf("保存文件\n");
		break;
	default:
		printf("无效选项\n");
		break;
	}

	return 0;
}
```

<!-- output: 2.2.6 -->
```text
打开文件
```

`case` 后面必须是常量，不能是变量或范围。

### break 的作用

`break` 用来跳出 `switch`。如果忘记写，程序会继续执行下一个 `case`，这叫“贯穿”。

贯穿就像打饭时排队没有止步线：你在 1 号窗口打完饭，如果没人拦着你（没有 `break`），你会顺着一格一格往前滑，把 2 号窗口的菜也顺手拿了。`break` 就是那条“打完请离开”的止步线。

```c
// 2.2.7 switch_fallthrough.c
#include <stdio.h>

int main(void)
{
	int choice = 1;

	switch (choice) {
	case 1:
		printf("一\n");
	case 2:
		printf("二\n");
		break;
	default:
		printf("其他\n");
		break;
	}

	return 0;
}
```

<!-- output: 2.2.7 -->
```text
一
二
```

`choice` 为 1，执行完 `case 1` 后没有 `break`，继续执行 `case 2`。

有些场景会故意利用贯穿，例如多个 `case` 共享同一段代码：

```c
switch (grade) {
case 'A':
case 'B':
	printf("通过\n");
	break;
default:
	printf("未通过\n");
	break;
}
```

初学阶段建议每个 `case` 都写 `break`，除非你非常清楚自己在利用贯穿。

## 2.2.8 综合示例：简单菜单

```c
// 2.2.8 menu.c
#include <stdio.h>

int main(void)
{
	int choice = 3;

	printf("1. 开始游戏\n");
	printf("2. 读取存档\n");
	printf("3. 退出\n");
	printf("请选择：");

	switch (choice) {
	case 1:
		printf("开始新游戏\n");
		break;
	case 2:
		printf("读取存档\n");
		break;
	case 3:
		printf("再见\n");
		break;
	default:
		printf("无效选项\n");
		break;
	}

	return 0;
}
```

<!-- output: 2.2.8 -->
```text
1. 开始游戏
2. 读取存档
3. 退出
请选择：再见
```

这里把 `choice` 写死为 3，是为了让示例可以直接运行。等学了 `scanf` 的输入校验后，再让用户真正输入。

## 2.2.9 小结

- `if` 在条件为真时执行。
- `if-else` 二选一。
- `else if` 按顺序判断多个条件。
- 嵌套不要太深，能合并就合并。
- 大括号也决定变量作用域。
- `switch` 适合匹配固定值，别忘了 `break`。
- `=` 是赋值，`==` 是比较。

## 练习

1. 写一个条件：判断 `age` 是否在 18 到 60 之间（包含 18 和 60）。
2. `if (x = 0)` 和 `if (x == 0)` 有什么区别？
3. 成绩 90 以上为 A，80–89 为 B，60–79 为 C，其余为 D，写出判断顺序。
4. `switch` 中忘记 `break` 会发生什么？
5. 下面代码输出什么？

```c
int x = 5;
if (x > 3)
	printf("A\n");
	printf("B\n");
```

<details>
<summary>参考答案</summary>

1. `age >= 18 && age <= 60`。
2. `x = 0` 是赋值，把 0 赋给 x，条件结果为 0（假）；`x == 0` 是比较，判断 x 是否等于 0。
3. 先判断 `>= 90`，再判断 `>= 80`，再判断 `>= 60`，最后 `else`。顺序不能反。
4. 会继续执行下一个 `case` 的代码，直到遇到 `break` 或 `switch` 结束。
5. 输出 `A` 和 `B`。`if` 只控制紧随其后的一条语句，`B` 那条不受 `if` 控制，所以无条件执行。

</details>
