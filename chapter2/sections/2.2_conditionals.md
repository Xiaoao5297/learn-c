# 2.2 条件判断

> 💬 **节前语：**
>
> 上一节我们学会了运算符，程序终于会"算"了。
>
> 但是——如果一个程序只会从头到尾"一条路走到黑"地执行，那它依然很笨。
>
> 想象一下：
> - 一个红绿灯，不管有没有车都一个样子 ❌
> - 一个红绿灯，看到车就变绿，没车就变红 ✅
>
> 让程序能"看情况办事"的，就是**条件判断**。
>
> 这一节，我们将学习 `if-else` 和 `switch`，让程序学会"做决策"。准备好了吗？开始吧！

---

## 2.2.1 什么是条件判断？

### 🎯 生活中的条件判断

其实我们每天都在做条件判断：

| 场景 | 条件 | 行动 |
|------|------|------|
| 🌧️ 出门前 | 如果下雨 | 带伞 |
| 🚦 过马路 | 如果绿灯 | 走 |
| 🍚 饿了 | 如果饿了 | 吃饭 |
| 📝 考试 | 如果及格 | 高兴；否则，复习 |

**看到规律了吗？** 所有判断都是：**"如果……就……"** 的结构。

### 💻 程序中的条件判断

在程序中，"如果"就是 `if`：

```
if (条件成立) {
    做这件事
}
```

**举例：**

```
if (外面下雨) {
    带上雨伞
}
```

> 📌 **条件判断的本质：** 根据条件的真假（`1` 或 `0`），决定**执行不同的代码**。

---

## 2.2.2 if 语句

### 📝 最基本的 if 语句

```c
if (条件) {
    // 条件成立（为真）时执行的代码
}
```

### 📝 动手试试

```c
#include <stdio.h>

int main() {
    int age = 20;
    
    if (age >= 18) {
        printf("你已经成年了！\n");
    }
    
    printf("程序结束。\n");
    return 0;
}
```

输出：
```
你已经成年了！
程序结束。
```

### 🔍 分析执行流程

```
age = 20
    ↓
检查条件：20 >= 18 吗？
    ↓
是（真，结果为 1）→ 进入大括号，执行 printf
    ↓
跳过 if 语句，继续执行后面的代码
```

### 🤔 如果条件不成立呢？

把 age 改成 15：

```c
int age = 15;

if (age >= 18) {
    printf("你已经成年了！\n");
}

printf("程序结束。\n");
```

输出：
```
程序结束。
```

**看到了吗？** 条件不成立时，if 里面的代码**被完全跳过**了。

> 📌 **C语言的"真"和"假"：** 
> - 条件成立 = 结果**非0**（只要不是0就算真）
> - 条件不成立 = 结果是 **0**
> 
> 所以 `if (1)`、`if (100)`、`if (-5)` 都是"真"，只有 `if (0)` 是"假"！

## 2.2.3 if-else 语句

很多时候，我们要处理"非此即彼"的情况：条件成立做一件事，不成立做另一件事。

### 📝 语法

```c
if (条件) {
    // 条件成立时执行
} else {
    // 条件不成立时执行
}
```

**比喻：** 就像一个岔路口，只能走其中一条路。

```
         ┌── 成立 → 走这条路（if 分支）
条件 ────┤
         └── 不成立 → 走那条路（else 分支）
```

### 📝 动手试试

```c
#include <stdio.h>

int main() {
    int score = 75;
    
    if (score >= 60) {
        printf("恭喜！你及格了！🎉\n");
    } else {
        printf("加油！下次一定行！💪\n");
    }
    
    return 0;
}
```

输出：
```
恭喜！你及格了！🎉
```

如果 score = 45：
```
加油！下次一定行！💪
```

### 🎯 生动的比喻

`if-else` 就像**开关灯**：

- 天黑了 → 开灯
- 天没黑 → 不开灯

不可能又开灯又不开灯，只能二选一。

## 2.2.4 if-else if-else 语句（多条件判断）

当有**多个条件**需要依次判断时，可以用 `else if`。

### 📝 语法

```c
if (条件1) {
    // 条件1成立
} else if (条件2) {
    // 条件1不成立，但条件2成立
} else if (条件3) {
    // 条件1、2都不成立，但条件3成立
} else {
    // 以上条件都不成立
}
```

**比喻：** 像一条**排队的通道**，依次检查，谁符合谁走。

```
条件1？ → 是 → 执行1
  ↓ 否
条件2？ → 是 → 执行2
  ↓ 否
条件3？ → 是 → 执行3
  ↓ 否
        执行else
```

### 📝 动手试试：成绩等级评定

```c
#include <stdio.h>

int main() {
    int score = 85;
    
    if (score >= 90) {
        printf("等级：A（优秀）\n");
    } else if (score >= 80) {
        printf("等级：B（良好）\n");
    } else if (score >= 70) {
        printf("等级：C（中等）\n");
    } else if (score >= 60) {
        printf("等级：D（及格）\n");
    } else {
        printf("等级：E（不及格）\n");
    }
    
    return 0;
}
```

输出：
```
等级：B（良好）
```

### ⚠️ 重要规则

> 📌 **执行顺序很重要！** 程序会**从上到下**依次判断，**一旦某个条件成立，后面的条件就不会再检查了**。
> 
> 所以 `else if` 里的条件一定要按**范围从大到小**（或从小到大）写清楚，不能乱序。

比如成绩 85：
- 先检查 `>= 90`？否
- 再检查 `>= 80`？**是** → 输出 B，后面的都不看了 ✅

如果把顺序写反了：
```c
if (score >= 60) {          // ❌ 85 >= 60，先到这里就停了！
    printf("等级：D（及格）\n");
} else if (score >= 90) {
    ...
}
```
这样 85 分就会错误地输出"D"，因为 `>= 60` 最先被满足了。

## 2.2.5 嵌套 if 语句

if 里面还可以再套 if，这叫**嵌套 if**。

### 📝 动手试试：游乐园门票

> 规则：身高 ≥ 1.2米 才可以玩过山车；如果年龄 < 12 岁，还需要大人陪同。

```c
#include <stdio.h>

int main() {
    double height = 1.3;
    int age = 10;
    
    if (height >= 1.2) {
        printf("身高合格，可以玩过山车！\n");
        
        // 嵌套的 if：在里面再判断一次
        if (age < 12) {
            printf("但是你还不到12岁，需要大人陪同哦！\n");
        } else {
            printf("你可以自己玩！\n");
        }
    } else {
        printf("身高不够，不能玩过山车。\n");
    }
    
    return 0;
}
```

输出：
```
身高合格，可以玩过山车！
但是你还不到12岁，需要大人陪同哦！
```

### 💡 嵌套的比喻

嵌套 if 就像**多层安检**：

```
进大门安检（外层if）
    ↓ 通过
进入候机厅，还要再过一次安检（内层if）
    ↓ 通过
才能登机
```

> 📌 **小提示：** 嵌套层数太多会让代码变乱，一般建议嵌套**不要超过2~3层**。太深的时候，后面章节学的函数、switch 都能帮我们简化。

## 2.2.6 代码块与变量作用域

### 🤔 大括号 `{ }` 是什么？

你有没有想过，if 后面的 `{ }` 到底是干嘛的？

`{ }` 叫**代码块**（block），它把多行代码"打包"在一起。

```c
if (条件) {
    // 这一整个 { } 都是 if 的"势力范围"
    printf("第一行\n");
    printf("第二行\n");
}
```

### 📝 变量的"出生范围"：作用域

在C语言中，**在某个 `{ }` 里定义的变量，只在这个 `{ }` 里有效**。离开这个块，变量就"消失"了。

```c
#include <stdio.h>

int main() {
    int x = 10;    // 这个 x 在整个 main 里都能用
    
    if (x > 5) {
        int y = 20;    // y 只在这个 { } 里有效
        printf("x + y = %d\n", x + y);
    }
    
    // 这里已经不能再用 y 了！
    // printf("%d", y);   ❌ 编译错误：y 未定义
    
    printf("x = %d\n", x);   // ✅ x 还能用
    
    return 0;
}
```

**比喻：** 变量就像一个**临时工**，只在它"工作的地方"（所在的 `{ }`）有效，出了门就不认账了。

> 📌 **作用域（Scope）** = 变量"活着"并且"能被使用"的范围。
> - 在 `{ }` 内定义的变量 → 只在这个块内有效
> - 这个"块"可以是 if、else、while、for，甚至是一个独立的 `{ }`

### ⚠️ 一个特别提醒

```c
// ❌ 在 if 外面使用 if 里面的变量，编译报错
if (score > 60) {
    int isPassed = 1;
}
printf("%d", isPassed);   // 错误！isPassed 只在 if 的 { } 里有效
```

所以，**如果需要在 if 外面使用某个结果，要提前在 if 外面声明变量**：

```c
int isPassed = 0;          // 提前声明（0 = 假）
if (score >= 60) {
    isPassed = 1;          // 修改外面声明的变量
}
printf("是否及格：%d\n", isPassed);   // ✅ 能用
```

## 2.2.7 经典陷阱与良好习惯

### 🚨 陷阱一：把 `==` 写成 `=`

还记得 2.1 节说的吗？在C语言里：

```c
// ❌ 危险！这是"赋值"而不是"比较"！
if (score = 100) {     // 把 100 赋给 score，且条件永远为真！
    printf("满分！\n");
}

// ✅ 正确
if (score == 100) {
    printf("满分！\n");
}
```

> 💡 **小技巧：** 如果你担心写错，可以反过来写 `if (100 == score)`。这样万一少写一个等号写成 `if (100 = score)`，编译器会直接报错（因为不能给常量赋值），帮你提前发现 bug！

### 🚨 陷阱二：if 后面没有大括号

C语言允许 if 后面**不带大括号**只写一行：

```c
if (score >= 60)
    printf("及格了！\n");   // 只有这一行属于 if
printf("这句话永远会执行\n");
```

**这样很容易出 bug！** 比如下面这种：

```c
if (score >= 60)
    printf("及格了！\n");
    printf("给你发证书！\n");   // ❌ 这行不在 if 里！它总会执行
```

> 📌 **良好习惯：** **永远给 if/else 加大括号** `{ }`，哪怕只有一行。虽然多打两个字符，但能避免无数坑！

## 2.2.8 switch 语句

当我们有**很多个固定的取值**要判断时，用 `if-else if` 会写很长。这时可以用 **switch**。

### 📝 基本语法

```c
switch (表达式) {
    case 值1:
        // 表达式的值 == 值1 时执行
        break;
    case 值2:
        // 表达式的值 == 值2 时执行
        break;
    case 值3:
        // 表达式的值 == 值3 时执行
        break;
    default:
        // 都不匹配时执行
        break;
}
```

### 📝 动手试试：星期判断

```c
#include <stdio.h>

int main() {
    int day = 3;
    
    switch (day) {
        case 1:
            printf("星期一\n");
            break;
        case 2:
            printf("星期二\n");
            break;
        case 3:
            printf("星期三\n");
            break;
        case 4:
            printf("星期四\n");
            break;
        case 5:
            printf("星期五\n");
            break;
        case 6:
            printf("星期六\n");
            break;
        case 7:
            printf("星期日\n");
            break;
        default:
            printf("输入错误！请输入 1~7\n");
            break;
    }
    
    return 0;
}
```

输出：
```
星期三
```

### ⚠️ 超级重要：别忘了 `break;`！

> 🚨 **C语言 switch 最大的坑：没有 break 就会"穿透"！**
> 
> 如果某个 `case` 后面**没有写 `break;`**，程序不会停下来，而是**继续往下执行下一个 case 的内容**，直到遇到 `break` 或 switch 结束为止。

**穿透的例子：**

```c
int day = 3;

switch (day) {
    case 1:
        printf("星期一\n");    // 没有 break！
    case 2:
        printf("星期二\n");    // 没有 break！
    case 3:
        printf("星期三\n");    // 没有 break！
    default:
        printf("默认\n");
}
```

输出：
```
星期三
默认
```

因为 day=3 匹配 case 3，但没有 `break`，程序就"一路滑下去"，把 default 也执行了！

> 💡 **"穿透"其实也有用！** 当多个 case 想执行**相同的代码**时，可以利用穿透：
> 
> ```c
> switch (grade) {
>     case 'A':
>     case 'B':
>     case 'C':
>         printf("及格\n");
>         break;
>     case 'D':
>     case 'E':
>         printf("不及格\n");
>         break;
> }
> ```
> 
> 这样 A、B、C 都会打印"及格"。

### 🎯 switch vs if-else if

| 对比 | switch | if-else if |
|------|--------|-----------|
| 适合场景 | 判断一个值的**固定取值** | 判断**范围**（如 >= 60）或复杂条件 |
| 可读性 | 多个取值时更清晰 | 范围判断更自然 |
| break | **必须自己写！** | 不需要 |
| 条件类型 | 整数、字符等 | 任意表达式 |

**选择建议：**
- 判断"是哪个值"（星期、菜单、等级）→ 用 `switch`
- 判断"在哪个范围"（分数段、年龄）→ 用 `if-else if`

## 2.2.9 综合示例：我的智能助手

让我们把这一节学的东西串起来，做一个"智能助手"：

```c
#include <stdio.h>

int main() {
    int hour = 15;    // 模拟当前时间：15点
    int day = 5;      // 模拟今天是星期几：星期五
    
    // 1. 根据时间打招呼（if-else if 判断范围）
    if (hour >= 5 && hour < 12) {
        printf("早上好！☀️\n");
    } else if (hour >= 12 && hour < 14) {
        printf("中午好！🍚\n");
    } else if (hour >= 14 && hour < 18) {
        printf("下午好！🍵\n");
    } else {
        printf("晚上好！🌙\n");
    }
    
    // 2. 根据星期判断是否周末（switch 判断固定值）
    int isWeekend = 0;
    switch (day) {
        case 6:
        case 7:
            isWeekend = 1;
            break;
        default:
            isWeekend = 0;
            break;
    }
    
    if (isWeekend) {
        printf("今天是周末，好好休息吧！🎉\n");
    } else {
        printf("今天是工作日，加油学习！💪\n");
    }
    
    return 0;
}
```

输出：
```
下午好！🍵
今天是工作日，加油学习！💪
```

## 2.2.10 本节小结

这一节我们学了：

✅ **条件判断的本质：** 根据条件的真假（非0为真、0为假）执行不同的代码

✅ **if / else：** 二选一，条件成立走 if，否则走 else

✅ **else if：** 多条件依次判断，注意范围顺序

✅ **嵌套 if：** if 里套 if，注意别超过2~3层

✅ **代码块与作用域：** `{ }` 里定义的变量只在块内有效

✅ **switch：** 多个固定取值时更清晰，**千万别忘 break**

✅ **两个经典陷阱：** `=` vs `==`、if 忘记加大括号

> 💡 **记住：让程序学会"做决策"，是让它变聪明的第一步！**
