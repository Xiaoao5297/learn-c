# 2.3 循环入门：while、for、do-while

> 💬 **节前语：**
>
> 上一节我们学了条件判断，程序终于会"做决策"了。
>
> 但现在有个新问题：**如果想让程序重复做一件事，怎么办？**
>
> 比如：
> - 输出 "Hello" 100次
> - 计算 1+2+3+...+100 的和
> - 把100个学生的成绩逐个判断是否及格
>
> 如果不用循环，你得写100行重复的代码。这显然是不可能的。
>
> 这就是**循环**的作用——让程序**自动重复**！
>
> 这一节，我们将学习C语言的三种循环：`while`、`for` 和 `do-while`。准备好了吗？开始吧！

---
## 2.3.1 什么是循环？

### 🎯 生动的比喻

循环就像一个**自动流水线**：

```
┌─────────────────────────────┐
│         循环                 │
│                             │
│   拿起一个零件 → 加工 → 放下  │
│   拿起一个零件 → 加工 → 放下  │
│   拿起一个零件 → 加工 → 放下  │
│   ...                       │
│   （直到零件用完）             │
│                             │
└─────────────────────────────┘
```

**没有循环：** 你需要手动拿起每个零件，加工，放下。重复100次。

**有循环：** 你设置好规则，流水线自动完成。

### 📌 循环的本质

> **循环 = 让一段代码重复执行多次，直到满足某个条件为止。**

---

## 2.3.2 while 循环

### 📝 基本语法

```c
while (条件) {
    // 循环体：重复执行的代码
}
```

**执行过程：**

```
1. 检查条件
2. 条件为真（非0）→ 执行循环体
3. 执行完，再回到第1步检查条件
4. 条件为假（0）→ 退出循环
```

**比喻：** while 就像在问"要不要再来一次？"——只要答案是"要"，就一直重复。

### 📝 动手试试：输出1到5

```c
#include <stdio.h>

int main() {
    int i = 1;
    
    while (i <= 5) {
        printf("第 %d 次循环\n", i);
        i++;      // 别忘了让 i 变大！否则会死循环
    }
    
    return 0;
}
```

**输出：**
```
第 1 次循环
第 2 次循环
第 3 次循环
第 4 次循环
第 5 次循环
```

### ⚠️ 千万别忘：让条件"变假"

```c
// ❌ 危险！i 永远不变，i <= 5 永远成立 → 死循环！
int i = 1;
while (i <= 5) {
    printf("第 %d 次循环\n", i);
    // 忘了写 i++;
}
```

> 💡 while 循环里**必须有一行代码让条件逐渐不成立**（比如 `i++`），否则程序会永远转圈！

## 2.3.3 for 循环

`for` 循环把"初始化、条件、更新"三件事写在了一起，结构更清晰。

### 📝 基本语法

```c
for (初始化; 条件; 更新) {
    // 循环体：重复执行的代码
}
```

### 🧩 三个部分

| 部分 | 作用 | 执行时机 |
|------|------|----------|
| **初始化** | 设置循环的起点 | 循环开始前执行一次 |
| **条件** | 判断是否继续循环 | 每次循环前检查 |
| **更新** | 修改循环变量 | 每次循环结束后执行 |

### 🎯 生动的比喻：爬楼梯

```
爬5层楼梯

for (从1层开始; 没到5层; 爬一层) {
    继续爬
}
```

| 部分 | 对应 |
|------|------|
| 初始化：从1层开始 | `int i = 1` |
| 条件：没到5层 | `i <= 5` |
| 更新：爬一层 | `i++` |

### 📝 动手试试：输出1到5

```c
#include <stdio.h>

int main() {
    for (int i = 1; i <= 5; i++) {
        printf("第 %d 次循环\n", i);
    }
    return 0;
}
```

**输出：**
```
第 1 次循环
第 2 次循环
第 3 次循环
第 4 次循环
第 5 次循环
```

> 📌 **注意：** 在 `for (int i = 1; ...)` 里直接声明变量 `i`，需要 **C99 或更高标准**。现在的 gcc / clang 都默认支持，放心用！这个写法很常用。

### 🔄 循环执行过程

```
1. 初始化：i = 1
2. 检查条件：1 <= 5？✅ 成立 → 进入循环
3. 执行循环体：输出 "第 1 次循环"
4. 更新：i++ → i = 2
5. 检查条件：2 <= 5？✅ 成立 → 进入循环
6. 执行循环体：输出 "第 2 次循环"
7. 更新：i++ → i = 3
...
10. 更新：i++ → i = 6
11. 检查条件：6 <= 5？❌ 不成立 → 退出循环
```

## 2.3.4 do-while 循环

### 📝 基本语法

```c
do {
    // 循环体
} while (条件);   // ⚠️ 别忘了结尾的分号！
```

**和 while 的区别：**

| 循环 | 特点 | 比喻 |
|------|------|------|
| `while` | **先检查**条件，再决定是否执行 | 先问再吃 |
| `do-while` | **先执行一次**，再检查条件 | 先吃一口再问 |

> 🎯 **do-while 保证：** 无论条件是否成立，**循环体至少会执行一次**！

### 📝 动手试试：看看两者的区别

```c
#include <stdio.h>

int main() {
    int x = 10;   // 条件 x < 5 一开始就不成立
    
    printf("=== while ===\n");
    while (x < 5) {
        printf("while 里的代码（一次都不执行）\n");
    }
    
    printf("=== do-while ===\n");
    do {
        printf("do-while 里的代码（至少执行一次）\n");
    } while (x < 5);
    
    return 0;
}
```

输出：
```
=== while ===
=== do-while ===
do-while 里的代码（至少执行一次）
```

**看到了吗？** 条件从一开始就不成立，但 do-while 还是执行了一次！

### 📝 do-while 实战：模拟"至少运行一次的菜单"

想象一个游戏菜单：**至少要让玩家看一次选项**，然后根据选择决定是否退出：

```c
#include <stdio.h>

int main() {
    int choice = 3;   // 模拟玩家选择了 3（退出）
    int count = 0;
    
    do {
        count++;
        printf("第 %d 次显示菜单：1.开始 2.设置 3.退出\n", count);
        
        if (choice == 3) {
            printf("选择退出，再见！\n");
            break;
        }
    } while (choice != 3);
    
    return 0;
}
```

输出：
```
第 1 次显示菜单：1.开始 2.设置 3.退出
选择退出，再见！
```

> 💡 **do-while 适合什么场景？** 当你**至少要执行一次**的时候——比如显示菜单、读取用户输入。这种场景非常经典！

## 2.3.5 三种循环怎么选？

| 循环 | 语法特点 | 什么时候用 |
|------|----------|-----------|
| `for` | 初始化、条件、更新写一起 | **最常用！** 知道循环几次 |
| `while` | 只有一个条件 | 不知道循环几次，只看某个条件 |
| `do-while` | 先执行一次再判断 | 至少要执行一次 |

**三句话记忆：**

- 知道"要循环几次" → 用 `for`
- 只知道"什么时候停" → 用 `while`
- "至少要跑一次" → 用 `do-while`

> 💡 **其实它们都能互相转换！** 上面三种写法都能输出 1~5：
> 
> ```c
> // 三种写法效果一样
> for (int i = 1; i <= 5; i++) { ... }
> 
> int i = 1;
> while (i <= 5) { ...; i++; }
> 
> int j = 1;
> do { ...; j++; } while (j <= 5);
> ```
> 
> 选择最贴合问题的那一个就行！

## 2.3.6 本节小结

这一节我们学了：

✅ **三种循环：** `for`（知道次数）、`while`（知道停的条件）、`do-while`（至少执行一次）

✅ **循环的执行过程：** 检查条件 → 执行 → 更新 → 再检查

✅ **while：** 先检查再执行，循环体里**必须有让条件变假**的语句（如 `i++`）

✅ **for：** 把"初始化、条件、更新"写在一起，最常用

✅ **do-while：** 先执行一次再判断，适合"菜单、读输入"这类至少要跑一次的场景

✅ **怎么选：** 知道次数用 `for`，只知道停的条件用 `while`，至少跑一次用 `do-while`

> 💡 **记住：三种循环可以互相转换，选最贴合问题的那一个就行。下一节，我们学怎么在循环里"急刹车"和"跳步"。**

### 三、改错题

**6. 以下程序有 3 处错误：**

```c
#include <stdio.h>

int main() {
    for (int i = 1, i <= 5, i++) {     // 错误区①：for 的三部分用什么分隔？
        printf("%d ", i);
    }
    printf("\n");

    int j = 1;
    while (j <= 3) {
        printf("%d ", j);              // 错误区②：j 永远不变会怎样？
    }
    printf("\n");

    do {
        printf("执行一次\n");
    } while (0)                        // 错误区③：do-while 结尾缺什么？

    return 0;
}
```

> 提示：①for 用**分号**分隔；②要写 `j++`；③do-while 结尾要有**分号**。
