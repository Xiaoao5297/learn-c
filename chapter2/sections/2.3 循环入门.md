# 2.3 循环入门

循环让程序重复做一件事。

没有循环，打印 1 到 100 要写 100 行 `printf`；有了循环，只需要几行。

这一节讲三种循环：

- `while`
- `for`
- `do-while`

## 2.3.1 while 循环

语法：

```c
while (条件) {
	循环体;
}
```

执行顺序：

1. 判断条件。
2. 条件为真，执行循环体。
3. 回到第 1 步。
4. 条件为假，结束循环。

你可以把 `while` 循环想成绕操场跑圈：每跑完一圈都要“检查一下是否达到目标圈数”（判断条件），没达到就再跑一圈，达到了就停下来。条件就是圈数牌，忘了计数员抬牌（更新 `i`），你就只能永远跑下去。

```c
// 2.3.1 while_count.c
#include <stdio.h>

int main(void)
{
	int i = 1;

	while (i <= 5) {
		printf("%d\n", i);
		i++;
	}

	return 0;
}
```

<!-- output: 2.3.1 -->
```text
1
2
3
4
5
```

循环变量 `i` 必须朝着让条件变假的方向变化。这里每次 `i++`，最终会超过 5，循环结束。

如果忘记 `i++`，条件永远为真，程序会一直打印，变成死循环。

## 2.3.2 for 循环

`for` 把“初始化、条件、更新”三件事写在同一个地方：

```c
for (初始化; 条件; 更新) {
	循环体;
}
```

```c
// 2.3.2 for_count.c
#include <stdio.h>

int main(void)
{
	for (int i = 1; i <= 5; i++) {
		printf("%d\n", i);
	}

	return 0;
}
```

<!-- output: 2.3.2 -->
```text
1
2
3
4
5
```

执行顺序：

1. 初始化：`int i = 1`，只执行一次。
2. 判断条件：`i <= 5`。
3. 条件为真，执行循环体。
4. 更新：`i++`。
5. 回到第 2 步。

`for` 适合“次数明确”的循环。`while` 更适合“条件满足就一直做”的循环。

打个比方：`for` 像“跑 10 圈就停”的训练计划，圈数明确，出发前把起点（初始化）、终点（条件）、计圈（更新）一次写在计划表上；`while` 像“跑到下雨为止”，要不要继续只看条件，不预设次数。

### for 循环的常见变体

```c
// 从 0 到 4
for (int i = 0; i < 5; i++) { ... }

// 从 5 到 1
for (int i = 5; i >= 1; i--) { ... }

// 每次加 2
for (int i = 0; i <= 10; i += 2) { ... }
```

## 2.3.3 do-while 循环

`do-while` 先执行一次循环体，再判断条件：

```c
do {
	循环体;
} while (条件);
```

注意最后有分号。

```c
// 2.3.3 do_while.c
#include <stdio.h>

int main(void)
{
	int choice = 0;

	do {
		printf("执行一次，choice = %d\n", choice);
		choice++;
	} while (choice < 3);

	return 0;
}
```

<!-- output: 2.3.3 -->
```text
执行一次，choice = 0
执行一次，choice = 1
执行一次，choice = 2
```

即使一开始条件为假，`do-while` 也会执行一次。它适合“至少要做一次”的场景，例如显示菜单。

想成吃自助餐就好理解了：`do-while` 是“先夹一筷子尝尝，再决定要不要再来”；`while` 是“先看菜谱，决定不吃就一口都不碰”。菜单程序天然属于前者——总得先让用户看到一次菜单。

```c
int choice;

do {
	printf("1. 开始\n");
	printf("2. 退出\n");
	printf("请选择：");
	scanf("%d", &choice);
} while (choice != 2);
```

这段代码会先显示菜单，再根据输入决定是否继续。

## 2.3.4 用循环做累加

```c
// 2.3.4 sum.c
#include <stdio.h>

int main(void)
{
	int sum = 0;

	for (int i = 1; i <= 100; i++) {
		sum += i;
	}

	printf("1 到 100 的和是 %d\n", sum);

	return 0;
}
```

<!-- output: 2.3.4 -->
```text
1 到 100 的和是 5050
```

累加模式很常见：

1. 准备一个累加变量，初始值通常是 0。
2. 循环中把每个值加到累加变量上。
3. 循环结束后输出结果。

这个模式可以想成往存钱罐里投硬币：罐子（`sum`）一开始是空的（0），每绕一圈投一个硬币（`sum += i`），全部投完后摇一摇罐子才知道总共攒了多少。

## 2.3.5 循环中的常见错误

### 忘记更新循环变量

```c
int i = 1;
while (i <= 5) {
	printf("%d\n", i);
}
```

`i` 永远是 1，条件永远为真。

### 差一错误

```c
for (int i = 1; i < 5; i++) {
	printf("%d\n", i);
}
```

输出 1 到 4，不是 1 到 5。想包含 5，条件要写 `i <= 5`。

### 在 for 后面多写分号

```c
for (int i = 0; i < 5; i++); {
	printf("hello\n");
}
```

分号让循环体变成空语句，大括号里的内容只执行一次。

### do-while 忘记分号

```c
do {
	...
} while (condition)
```

最后少一个分号，编译会报错。

## 2.3.6 三种循环怎么选

| 场景 | 推荐 |
|------|------|
| 次数明确，例如 1 到 100 | `for` |
| 条件满足就一直做，次数不确定 | `while` |
| 至少执行一次，例如菜单 | `do-while` |

三种循环可以互相改写。选可读性最好的那个。

## 2.3.7 综合示例：倒计时

```c
// 2.3.5 countdown.c
#include <stdio.h>

int main(void)
{
	for (int i = 5; i >= 1; i--) {
		printf("%d\n", i);
	}

	printf("起飞\n");

	return 0;
}
```

<!-- output: 2.3.5 -->
```text
5
4
3
2
1
起飞
```

## 2.3.8 小结

- `while` 先判断再执行。
- `for` 把初始化、条件、更新写在一起，适合次数明确的循环。
- `do-while` 先执行一次再判断，适合菜单。
- 循环变量要更新，否则容易死循环。
- 注意边界，避免差一错误。
- `for` 和 `while` 后面不要随便多写分号。

#### 三、改错题

三处错误：

1. `i % 2 = 0`：`=` 是赋值，不能给 `i % 2` 这样的表达式赋值，编译直接报错。判断相等要写 `i % 2 == 0`。
2. 差一错误：条件 `i < 10` 漏掉了 10，而 10 是偶数，和会少加 10。应改为 `i <= 10`。
3. `printf("偶数和是 %d\n", sum)`：行尾漏了分号。

修正后的完整程序（输出 `偶数和是 30`）：

```c
#include <stdio.h>

int main(void)
{
	int sum = 0;
	int i = 1;

	while (i <= 10) {
		if (i % 2 == 0) {
			sum += i;
		}
		i++;
	}

	printf("偶数和是 %d\n", sum);

	return 0;
}
```
