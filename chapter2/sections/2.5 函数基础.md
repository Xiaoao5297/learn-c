# 2.5 函数基础

当一段代码开始重复，或者一个 `main` 越来越长，就该把代码拆成函数了。

函数的作用：

- 避免重复写同样的代码。
- 给一段逻辑起名字，让代码更容易读。
- 修改时只改一个地方。
- 方便测试和复用。

## 2.5.1 定义和调用

一个最简单的函数：

```c
int add(int a, int b)
{
	return a + b;
}
```

拆开看：

- `int`：返回类型，表示函数返回一个整数。
- `add`：函数名。
- `(int a, int b)`：参数列表，调用时要传两个整数。
- `return a + b;`：把结果返回给调用者。

调用它：

```c
// 2.5.1 add.c
#include <stdio.h>

int add(int a, int b)
{
	return a + b;
}

int main(void)
{
	int result = add(3, 4);

	printf("3 + 4 = %d\n", result);

	return 0;
}
```

<!-- output: 2.5.1 -->
```text
3 + 4 = 7
```

`main` 也是函数，只不过它是程序的入口。

不妨把函数想成一台自动售货机：投进硬币（传入参数），按下按钮（函数名），掉出饮料（返回值）。至于机器内部怎么把饮料推出来，你不用关心——用函数的人也只需要知道“给什么、按哪个、出什么”。

## 2.5.2 参数和返回值

函数可以有参数，也可以没有；可以返回值，也可以不返回。

| 形式 | 例子 | 说明 |
|------|------|------|
| 有参数、有返回值 | `int add(int a, int b)` | 最常见 |
| 有参数、无返回值 | `void print_line(int n)` | 只做事，不返回结果 |
| 无参数、有返回值 | `int read_number(void)` | 从某处取一个值 |
| 无参数、无返回值 | `void say_hello(void)` | 只执行动作 |

无返回值用 `void`：

```c
// 2.5.2 void_function.c
#include <stdio.h>

void print_line(int length)
{
	for (int i = 0; i < length; i++) {
		printf("-");
	}
	printf("\n");
}

int main(void)
{
	print_line(10);
	printf("分隔线上面\n");
	print_line(10);

	return 0;
}
```

<!-- output: 2.5.2 -->
```text
----------
分隔线上面
----------
```

`void` 函数可以写 `return;` 提前结束，但不能 `return 一个值;`。

## 2.5.3 返回布尔值

判断类的函数适合返回 `bool`：

```c
// 2.5.3 is_even.c
#include <stdio.h>
#include <stdbool.h>

bool is_even(int number)
{
	return number % 2 == 0;
}

int main(void)
{
	int number = 18;

	if (is_even(number)) {
		printf("%d 是偶数\n", number);
	} else {
		printf("%d 是奇数\n", number);
	}

	return 0;
}
```

<!-- output: 2.5.3 -->
```text
18 是偶数
```

函数名用 `is_` 开头，调用处读起来就像一句话：`if (is_even(number))`。

## 2.5.4 函数声明

如果函数定义写在 `main` 后面，编译器在 `main` 里看到调用时还不知道这个函数存在，会报错或警告。

解决办法是先声明：

```c
// 2.5.4 prototype.c
#include <stdio.h>

int square(int x);

int main(void)
{
	printf("5 的平方是 %d\n", square(5));

	return 0;
}

int square(int x)
{
	return x * x;
}
```

<!-- output: 2.5.4 -->
```text
5 的平方是 25
```

声明只写返回类型、函数名和参数类型，不写函数体。定义才写具体实现。

声明就像教室门口贴的课表：“周三第 3 节有数学课”——先告诉你有这么一节课、什么形式；老师是谁、具体讲什么（定义），到时候才知道。编译器看到声明就肯放行调用，定义晚点再补上没问题。

声明也叫函数原型。多文件项目会把声明放在头文件里，第 4 章会讲。

## 2.5.5 变量的作用域

在函数内部定义的变量是局部变量，只在这个函数里有效。

```c
// 2.5.5 scope.c
#include <stdio.h>

int add_one(int value)
{
	int result = value + 1;
	return result;
}

int main(void)
{
	int number = 10;
	int result = add_one(number);

	printf("number = %d\n", number);
	printf("result = %d\n", result);

	return 0;
}
```

<!-- output: 2.5.5 -->
```text
number = 10
result = 11
```

`add_one` 里的 `result` 和 `main` 里的 `result` 是两个不同的变量，只是名字碰巧一样。

这就像三班有个班长叫李明，五班也有个班长叫李明——名字相同，完全是两个人。每个函数内部都是一个独立的“班级”，局部变量出了自己班就不存在了。

参数也是局部变量。函数收到的是值的副本，修改参数不会影响调用者的变量：

打个比方：你把作业拍照发给同学抄，他改来改去，你的原稿一个字都不会变——函数收到的是“复印件”。以后想让函数直接改你的原稿，得把“原稿放在哪”告诉它。

```c
void change(int x)
{
	x = 100;
}
```

调用 `change(number)` 后，`number` 仍然是原来的值。想让函数修改调用者的变量，需要传指针，第 4 章会讲。

## 2.5.6 常用函数示例

### 求最大值

```c
// 2.5.6 max.c
#include <stdio.h>

int max_int(int a, int b)
{
	if (a > b) {
		return a;
	}
	return b;
}

int main(void)
{
	printf("%d\n", max_int(3, 8));
	printf("%d\n", max_int(12, 5));

	return 0;
}
```

<!-- output: 2.5.6 -->
```text
8
12
```

### 计算阶乘

```c
// 2.5.7 factorial.c
#include <stdio.h>

int factorial(int n)
{
	int result = 1;

	for (int i = 2; i <= n; i++) {
		result *= i;
	}

	return result;
}

int main(void)
{
	printf("5! = %d\n", factorial(5));

	return 0;
}
```

<!-- output: 2.5.7 -->
```text
5! = 120
```

阶乘增长很快，`int` 很快就会溢出。这里只演示循环和函数，不处理大数。

### 温度转换

```c
// 2.5.8 temperature.c
#include <stdio.h>

double celsius_to_fahrenheit(double celsius)
{
	return celsius * 9.0 / 5.0 + 32.0;
}

int main(void)
{
	double c = 25.0;

	printf("%.1f 摄氏度 = %.1f 华氏度\n",
	       c, celsius_to_fahrenheit(c));

	return 0;
}
```

<!-- output: 2.5.8 -->
```text
25.0 摄氏度 = 77.0 华氏度
```

## 2.5.7 main 函数

`main` 的特殊之处：

- 它是程序入口。
- 操作系统调用它。
- 返回 0 通常表示程序正常结束。
- 标准写法是 `int main(void)` 或 `int main(int argc, char *argv[])`。

本书统一使用：

```c
int main(void)
{
	...
	return 0;
}
```

`void` 表示这个程序不接收任何参数。带参数的 `main` 和命令行参数是进阶话题，本书不展开；知道 `int main(void)` 是标准写法就够了。

## 2.5.8 综合示例：简易计算器

```c
// 2.5.9 calculator.c
#include <stdio.h>

int calculate(int left, int right, char op)
{
	switch (op) {
	case '+':
		return left + right;
	case '-':
		return left - right;
	case '*':
		return left * right;
	case '/':
		if (right == 0) {
			return 0;
		}
		return left / right;
	default:
		return 0;
	}
}

int main(void)
{
	printf("8 + 3 = %d\n", calculate(8, 3, '+'));
	printf("8 - 3 = %d\n", calculate(8, 3, '-'));
	printf("8 * 3 = %d\n", calculate(8, 3, '*'));
	printf("8 / 3 = %d\n", calculate(8, 3, '/'));
	printf("8 / 0 = %d\n", calculate(8, 0, '/'));

	return 0;
}
```

<!-- output: 2.5.9 -->
```text
8 + 3 = 11
8 - 3 = 5
8 * 3 = 24
8 / 3 = 2
8 / 0 = 0
```

这个例子把判断和计算放进函数，`main` 只负责调用和输出。除数为 0 时返回 0 并不是一个很好的错误处理方式，后面会改成更明确的错误码。

## 2.5.9 常见错误

### 忘记 return

```c
int add(int a, int b)
{
	int sum = a + b;
}
```

有返回值的函数必须返回一个值。编译器通常会警告，但不要依赖警告。

### 返回类型和实际值不一致

```c
int get_average(int a, int b)
{
	return (a + b) / 2.0;
}
```

这里会丢掉小数部分。想返回小数，返回类型应该用 `double`。

### 参数类型不匹配

```c
int add(int a, int b);

add(1.5, 2.5);
```

浮点数会被转换成整数，可能不是你想要的结果。设计函数时要明确参数类型。

### 在函数里修改局部变量，以为能影响外面

```c
void change(int x)
{
	x = 100;
}
```

C 默认按值传递，函数拿到的是副本。想让函数修改外部变量，就得把变量的“地址”交给函数——这要用到指针，第 4 章会专门讲。

## 2.5.10 小结

- 函数把一段逻辑打包起来，方便复用和阅读。
- 函数由返回类型、函数名、参数列表和函数体组成。
- `void` 表示不返回值。
- 有返回值的函数必须 `return`。
- 函数定义在调用之后时，要先声明。
- 局部变量只在函数或代码块内有效。
- C 默认按值传递，修改参数不会影响调用者。

void print_rule(void)
{
	printf("----------\n");
