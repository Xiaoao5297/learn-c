## 三、阅读程序（每题 5 分，共 10 分）

**11. 写出下面程序的输出。**

```c
#include <stdio.h>

int main(void)
{
	int sum = 0;

	for (int i = 1; i <= 5; i++) {
		if (i == 3) {
			continue;
		}
		sum += i;
	}

	printf("%d\n", sum);
	return 0;
}
```

## 四、编程题（每题 10 分，共 20 分）

**13. 温度转换函数**

编写函数 `celsius_to_fahrenheit`，把摄氏度转换为华氏度。公式是：

```text
F = C * 9 / 5 + 32
```

在 `main` 中分别转换 0 摄氏度和 100 摄氏度，输出：

```text
0.0 C = 32.0 F
100.0 C = 212.0 F
```

要求：

- 函数接收 `double`，返回 `double`。
- 输出保留一位小数。
- 使用 `int main(void)`。

---

**14. 奇数统计**

编写程序，统计 1 到 100 之间所有奇数的和与个数，输出：

```text
奇数和：2500
奇数个数：50
```

要求：

- 用循环完成，不要直接写死结果。
- 循环变量从 1 开始。

### 一、选择题

1. **A**。`17 / 5` 的商是 3，余数是 2。
2. **A**。两个整数相除，结果仍是整数，小数部分被丢掉。
3. **B**。`=` 是赋值，`==` 才是比较。
4. **B**。`&&` 从左向右计算，`x != 0` 已经是假，右边的 `10 / x` 不会执行，因此不会除以 0。
5. **B**。`case 2` 没有 `break`，会继续执行 `case 3`，先输出 `2`，再输出 `3`。

### 二、填空题

6. `55`。1 加到 10 的和是 55。
7. 一。条件一开始就是假，循环体也会先执行一次。
8. 当前；`continue` 之后。`break` 只结束最内层循环。
9. 声明（或函数原型、prototype）。
10. 局部。

### 三、阅读程序

11. 输出：

```text
12
```

`i` 等于 3 时执行 `continue`，跳过本次的 `sum += i`，其余几项相加：1 + 2 + 4 + 5 = 12。

12. 输出：

```text
1
```

C 语言默认按值传递。`change` 得到的是 `x` 的副本，在函数里把副本改成 100，不会影响 `main` 里的 `x`。

### 四、编程题

13. 参考代码：

```c
#include <stdio.h>

double celsius_to_fahrenheit(double celsius)
{
	return celsius * 9.0 / 5.0 + 32.0;
}

int main(void)
{
	printf("%.1f C = %.1f F\n", 0.0, celsius_to_fahrenheit(0.0));
	printf("%.1f C = %.1f F\n", 100.0, celsius_to_fahrenheit(100.0));

	return 0;
}
```

14. 参考代码：

```c
#include <stdio.h>

int main(void)
{
	int sum = 0;
	int count = 0;

	for (int i = 1; i <= 100; i += 2) {
		sum += i;
		count++;
	}

	printf("奇数和：%d\n", sum);
	printf("奇数个数：%d\n", count);

	return 0;
}
```
