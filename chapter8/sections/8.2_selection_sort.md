# 8.2 选择排序：一趟挑一个最小的

> 💬 **节前语：**
>
> 上一节的冒泡排序有个"小毛病"：一趟里可能交换好多次——明明一次就能把最小的数送到位，它却一路"邻居换邻居"地挪。
>
> 这一节我们换一种**更"讲究"**的思路，它来自生活里的挑选动作：
>
> - 🍎 **挑水果**：一筐苹果里，你总是先挑出**最大/最小**的那个拿走，再从剩下的里挑……
>
> 这种"**每趟都从没排好的部分里挑出最小的，放到前面**"的排法，就叫**选择排序（Selection Sort）**。它最大的优点：**一趟最多只交换一次**，比冒泡"省手"多了。
>
> 准备好了吗？开始吧！

---

## 8.2.1 思路：两段式 + 每趟挑最小

把数组想象成"两段"：左边是**已排好区**（逐渐变长），右边是**未排区**（逐渐变短）。每一趟只做两件事：

```
① 在"未排区"里找出最小的数，记住它的位置 minIdx
② 把它和"未排区"的第一个数交换 → 这个最小的数就归位了
```

看 `5, 2, 9, 1, 7` 的完整过程：

```
初始：5  2  9  1  7
      └─────未排区─────┘

第1趟：未排区 {5,2,9,1,7} 最小是 1 → 和第一个 5 交换
       → 1 | 2  9  5  7          （1 归位）
第2趟：未排区 {2,9,5,7}  最小是 2 → 它已在最前，不用换
       → 1  2 | 9  5  7          （2 归位）
第3趟：未排区 {9,5,7}   最小是 5 → 和 9 交换
       → 1  2  5 | 9  7          （5 归位）
第4趟：未排区 {9,7}     最小是 7 → 和 9 交换
       → 1  2  5  7 | 9          （7 归位，完成）
```

> 📌 **和冒泡最大的区别：** 冒泡是"相邻交换、大数慢慢冒"，一趟可能换好几次；选择是"先找最小、一步到位"，**一趟最多只交换一次**（只在归位那一刻换）。

## 8.2.2 上代码

"找最小"用一个 `for` 扫描，"交换"用第8.1节的三句话：

```c
#include <stdio.h>

// 选择排序：从小到大
void selectionSort(int a[], int n) {
    for (int i = 0; i < n - 1; i++) {        // i：未排区的第一个位置
        int minIdx = i;                      // 先假设未排区第一个就是最小的
        for (int j = i + 1; j < n; j++) {    // 在未排区里找真正最小的
            if (a[j] < a[minIdx]) {
                minIdx = j;                  // 找到更小的，更新位置
            }
        }
        if (minIdx != i) {                   // 最小的不在开头，才需要交换
            int tmp = a[i];
            a[i] = a[minIdx];
            a[minIdx] = tmp;
        }
    }
}

void printArray(int a[], int n) {
    for (int i = 0; i < n; i++) printf("%d ", a[i]);
    printf("\n");
}

int main() {
    int a[] = {5, 2, 9, 1, 7};
    int n = 5;
    printf("排序前："); printArray(a, n);
    selectionSort(a, n);
    printf("排序后："); printArray(a, n);
    return 0;
}
```

输出：
```
排序前：5 2 9 1 7
排序后：1 2 5 7 9
```

### 🔍 两层循环，各管什么？

| 循环 | 管的事 | 关键点 |
|------|--------|--------|
| 外层 `for (i...)` | 决定"这一趟把谁归位" | 共 `n-1` 趟 |
| 内层 `for (j...)` | 在 `a[i..n-1]` 里找最小 | 每趟都要**完整扫一遍未排区** |

> 🚨 **注意 `minIdx` 的初值：** 必须写成 `minIdx = i`（未排区的开头），不能写成 0。写 0 就会跑到"已排好区"里去找最小，把已经归位的数又翻出来，前功尽弃！

## 8.2.3 代价与收益：少交换，但没少比较

选择排序"省"在交换，但**不省**在比较：

- ✅ **交换次数少**：每趟最多 1 次，总共最多 n-1 次
- ⚠️ **比较次数照旧**：每趟都要把未排区扫一遍 → 总比较次数 ≈ n²/2，和冒泡一个级别（都是 O(n²)）

| | 冒泡 | 选择 |
|---|------|------|
| 一趟保证 | 最大数"冒"到末尾 | 最小数"挑"到开头 |
| 一趟交换次数 | 可能很多次 | **最多 1 次** |
| 一趟比较次数 | n-1-i | 每次都把未排区扫完（n-1-i） |
| 数据好坏 | 都一样慢 | 都一样慢（好坏不影响）|

> 💡 所以选择排序适合"**交换很贵**"的场景（比如数据是很大的结构体，搬一次很吃力）——它尽量少搬。但要说"最省比较"，它并不比冒泡强。

---

## 8.2.4 本节小结

这一节我们学了：

✅ **选择排序思路：** 两段式 + 每趟从"未排区"挑最小放到前面

✅ **代码套路：** 外层管趟数、内层找 `minIdx`、最后一步交换

✅ **关键细节：** `minIdx` 初值必须是 `i`，不能是 0

✅ **特点：** 一趟最多交换 1 次（省交换），但比较次数仍是 n²/2（O(n²)）

> 💡 **记住：选择排序 = 挑水果。每趟只挑一个最顺眼的放到最前面，一趟最多搬一次。**

### 三、改错题

**7. 以下选择排序有 3 个错误，请找出并改正：**

```c
#include <stdio.h>

void selectionSort(int a[], int n) {
    for (int i = 0; i < n; i++) {          // 错误区①：外层要几趟？i 到 n 会怎样？
        int minIdx = 0;                    // 错误区②：最小位置该从哪开始找？
        for (int j = i + 1; j < n; j++) {
            if (a[j] < a[minIdx]) {
                minIdx = j;
            }
        }
        int tmp = a[i];                    // 错误区③：交换的第三句话写对了吗？
        a[i] = a[minIdx];
        a[i] = tmp;
    }
}

int main() {
    int a[] = {4, 2, 5, 1, 3};
    int n = 5;
    selectionSort(a, n);
    for (int i = 0; i < n; i++) printf("%d ", a[i]);
    return 0;
}
```

> 正确输出应为：`1 2 3 4 5`。提示：①外层 i 要不要到 n-1？②minIdx 该从"未排区开头"（即 i）开始找！③交换的第三句该把 tmp 还给谁？
