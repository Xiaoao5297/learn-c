# 8.3 插入排序：像打扑克理牌

> 💬 **节前语：**
>
> 前两节学的冒泡、选择，都有同一个习惯：**一趟扫一遍全数组**。而且它们有个"死心眼"——哪怕数据已经基本有序，也要老老实实比完全部。
>
> 这一节换个**你在生活中天天用**的思路——**打扑克理牌**：
>
> 摸到一张新牌，你不会把整手牌重排一遍，而是**从右往左看看手里的牌，把比新牌大的都往后挪一格，空出位置，把新牌插进去**。
>
> 这个"一张张往前插"的排法叫 **插入排序（Insertion Sort）**。它的杀手锏是：**数据越接近有序，它越快**——这是冒泡和选择都做不到的。准备好了吗？开始吧！

---

## 8.3.1 思路：手里的牌已经有序，新牌插进来

把数组想象成：**左边 = 已经理好的牌，右边 = 还没摸的牌**。一开始只有 `a[0]` 算"手里"，然后从 `a[1]` 开始，一张张"摸牌"、往前插：

```
模拟：手里已排好 {2, 5, 7, 9}，摸到一张 6
从右往左比：9>6 → 9 往后挪一格 → 2 5 7 _ 9
           7>6 → 7 往后挪一格 → 2 5 _ 7 9
           5<6 → 停！→ 把 6 放进空位  → 2 5 6 7 9
```

对应到数组上（竖线左边 = 已排好）：

```
初始：5 | 2  9  1  7        （一开始只有 a[0] 算"手里"）

把 2 插进去：2  5 | 9  1  7
把 9 插进去：2  5  9 | 1  7
把 1 插进去：1  2  5  9 | 7
把 7 插进去：1  2  5  7  9   （完成）
```

> 📌 **一句话：从第 2 个元素起，把每个元素当"新牌"，往前插到已经排好的部分里。** 左边越理越长，右边越来越短，直到全部插完。

---

## 8.3.2 上代码

关键就三步：**拿新牌 → 往前挪出空位 → 放进去**：

```c
#include <stdio.h>

// 插入排序：从小到大
void insertionSort(int a[], int n) {
    for (int i = 1; i < n; i++) {      // i：当前要插入的"新牌"下标（从第2个开始）
        int key = a[i];                // ① 先把"新牌"拿出来
        int j = i - 1;
        while (j >= 0 && a[j] > key) { // ② 从右往左，比新牌大的统统往后挪一格
            a[j + 1] = a[j];
            j--;
        }
        a[j + 1] = key;                // ③ 把新牌放进空出来的位置
    }
}

void printArray(int a[], int n) {
    for (int i = 0; i < n; i++) printf("%d ", a[i]);
    printf("\n");
}

int main() {
    int a[] = {5, 2, 9, 1, 7};
    int n = 5;
    printf("排序前："); printArray(a, n);
    insertionSort(a, n);
    printf("排序后："); printArray(a, n);
    return 0;
}
```

输出：
```
排序前：5 2 9 1 7
排序后：1 2 5 7 9
```

### 🔍 走一遍"把 7 插进 {1,2,5,9}"

```
key = 7
j=3：a[3]=9 > 7 → 9 往后挪 → 1 2 5 _ 9      （空位在 3）
j=2：a[2]=5 > 7？否 → 停
把 key=7 放进空位（j+1=3）→ 1 2 5 7 9
```

> 🚨 **while 的两个条件都不能少：**
> - `j >= 0`：防止越界（新牌是最小的，会一路挪到最前面，j 变成 -1）
> - `a[j] > key`：决定"要不要把 a[j] 往后挪"
>
> 想通"最小牌 j 变 -1、放进 a[0]" 那一步，插入排序你就真正懂了！

## 8.3.3 插入排序的"隐藏超能力" 🎯

冒泡、选择无论数据什么情况，都要死心塌地比约 n²/2 次。但插入排序不一样——**数据越接近有序，它越快**：

- 数据**基本有序**时，每张"新牌"几乎不用往前挪，内层 while 一下就停 → 快得接近 O(n)
- 数据**完全乱序**时，和冒泡/选择一样慢（平均也是 O(n²)）

```
几乎有序：1 2 3 4 5 6 8 7 9     ← 只有 7 要往前挪一位，其余白拿！
```

> 💡 正因为这个特性，很多高级排序（比如快排）会把数据"差不多排好"之后，**改用插入排序来收尾**。它是"锦上添花"型选手。

---

## 8.3.4 三大"新手排序"大对决

把前三节放在一张表里对比，思路就立体了：

| | 冒泡（8.1） | 选择（8.2） | 插入 |
|---|------|------|------|
| 核心思路 | 相邻交换，大数冒上去 | 每趟挑最小，放到前面 | 像理牌，新牌往前插 |
| 每趟"保证" | 最大数归位 | 最小数归位 | 前 i+1 个有序 |
| 一趟交换次数 | 可能很多次 | **最多 1 次** | 可能很多次（挪动） |
| 比较次数（约） | n²/2 | n²/2 | 平均 n²/2（最好 n）|
| 对"几乎有序"的数据 | 仍要全比 | 仍要全比 | **特别快** ✅ |
| 好记点 | 像气泡 | 像挑水果 | 像理扑克牌 |

> 📌 **三兄弟都是 O(n²)：** 数据一大，三者都扛不住——所以我们 8.5 要去学快得多的**快速排序**。在那之前，8.4 先学一个同样"很快"的**查找**，给快排做铺垫。

## 8.3.5 本节小结

这一节我们学了：

✅ **插入排序思路：** 把每个元素当"新牌"，往前插到已排好的部分里

✅ **代码三步：** 拿 `key` → while 往前挪 → 放回空位（`a[j+1] = key`）

✅ **两个 while 条件：** `j >= 0` 防越界 + `a[j] > key` 决定挪不挪

✅ **隐藏超能力：** 数据几乎有序时接近 O(n)，快排也会用它收尾

✅ **三者对比：** 冒泡直观、选择少交换、插入"吃软饭"（越有序越快）

> 💡 **记住：插入排序 = 理扑克。它是"吃了上家软饭"的排序——数据越乖，它越快。**

### 三、改错题

**7. 以下插入排序有 3 个错误：**

```c
#include <stdio.h>

void insertionSort(int a[], int n) {
    for (int i = 0; i < n; i++) {          // 错误区①：新牌从第几个开始？
        int key = a[i];
        int j = i - 1;
        while (j >= 0 && a[j] < key) {     // 错误区②：升序排序该比什么？
            a[j + 1] = a[j];
            j--;
        }
        a[j + 1] = key;
    }
}

int main() {
    int a[] = {3, 1, 2};
    int n = 3;
    insertionSort(a, n);
    for (int i = 0; i < n; i++) printf("%d ", a[i]);
    return 0;
}
```

> 正确输出应为：`1 2 3`。提示：①新牌要从 a[1] 开始（a[0] 已经在"手里"）；②要"从小到大"，应该是把比 key **大**的往后挪。
