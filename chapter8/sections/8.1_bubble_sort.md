# 8.1 冒泡排序：让大数"冒"上去

> 💬 **节前语：**
>
> 现在，你的面前有一张乱糟糟的成绩单：
>
> ```
> 5, 2, 9, 1, 7
> ```
>
> 如果老师让你把它们按从小到大排好，你会怎么做？"挑出最小的放第一个，再挑剩下的里最小的……"——这是下节要学的"选择排序"的思路。
>
> 这一节我们先学一种**最直觉**的排法：**冒泡排序（Bubble Sort）**。
>
> 想象一缸水里有一串气泡——大的气泡会先"咕嘟咕嘟"冒到水面上。冒泡排序也是这个感觉：**一趟趟地扫过数组，把比较大的数一路"交换"着推到后面去**，就像气泡往上冒。
>
> 冒泡排序是理解排序的最佳起点：代码简单、思路直观，而且能让你第一次尝到"算法有快慢"的滋味。准备好了吗？开始吧！

---

## 8.1.1 核心思路：相邻两个比一比，大的往后走

冒泡排序只做一件事，反复做很多遍：**从前往后，把相邻的两个数比较，如果前面的比后面的大，就交换它们。**

看第一趟对 `5, 2, 9, 1, 7` 的处理：

```
第1步：5 和 2 比，5 > 2，交换 → 2, 5, 9, 1, 7
第2步：5 和 9 比，5 < 9，不换 → 2, 5, 9, 1, 7
第3步：9 和 1 比，9 > 1，交换 → 2, 5, 1, 9, 7
第4步：9 和 7 比，9 > 7，交换 → 2, 5, 1, 7, 9
```

**结果：最大的 9 被"冒"到了最后一位！** 第一趟结束，最后那个位置就是最大数，它已经"归位"了。

```
一趟之后：2, 5, 1, 7, |9|     （9 已归位，下一趟不用再碰它）
```

> 📌 **发现规律：** 每一趟，都会把"当前还没排好的部分"里最大的那个数，像气泡一样一路交换到最右边归位。**有 n 个数，最多需要 n−1 趟**（最后一趟只剩一个数，自然就位）。

---

## 8.1.2 完整地走一遍

对 `5, 2, 9, 1, 7` 全程模拟：

```
原始：  5  2  9  1  7

第1趟： 2  5  1  7  9     ← 9 冒到末尾归位
第2趟： 2  1  5  7  9     ← 7 归位（这一趟 9 不参与比较）
第3趟： 1  2  5  7  9     ← 5 归位
第4趟： 1  2  5  7  9     ← 2 归位，排序完成
```

> 💡 注意每趟的范围都在**缩短**：第2趟只比较到 7 前面为止，因为 9 已经不用管了。第3、4趟同理。这就是代码里 `j < n - 1 - i` 中那个 `- i` 的来历。

## 8.1.3 上代码

```c
#include <stdio.h>

// 冒泡排序：从小到大
void bubbleSort(int a[], int n) {
    for (int i = 0; i < n - 1; i++) {           // 外层：一共 n-1 趟
        for (int j = 0; j < n - 1 - i; j++) {   // 内层：相邻两两比较（范围每趟缩小）
            if (a[j] > a[j + 1]) {              // 前面的比后面的大？
                int tmp = a[j];                 // 是 → 交换（三句话交换法）
                a[j] = a[j + 1];
                a[j + 1] = tmp;
            }
        }
    }
}

void printArray(int a[], int n) {
    for (int i = 0; i < n; i++) {
        printf("%d ", a[i]);
    }
    printf("\n");
}

int main() {
    int a[] = {5, 2, 9, 1, 7};
    int n = 5;

    printf("排序前：");
    printArray(a, n);

    bubbleSort(a, n);

    printf("排序后：");
    printArray(a, n);
    return 0;
}
```

输出：
```
排序前：5 2 9 1 7
排序后：1 2 5 7 9
```

> 🎉 一个能真正排序的程序诞生了！注意 `bubbleSort(a, n)` 直接改的就是原数组——还记得第3章吗？**数组传给函数，传的是地址（首元素地址），函数里改，外面跟着变。**

### 🔍 两层循环，各管什么？

| 循环 | 管的事 | 范围 |
|------|--------|------|
| 外层 `for (i...)` | 控制"趟数"，即把几个数送到位 | 一共 `n-1` 趟 |
| 内层 `for (j...)` | 一趟里"相邻两两比较"，把最大数送到这趟的末尾 | `j` 从 0 到 `n-1-i` |

> 📌 **一句话记忆：** 外层管"第几趟"，内层管"这一趟比到哪"；内层上界要 `-i`，因为已经归位的 i 个数不用再碰。

## 8.1.4 交换，为什么一定要三句话？

```c
int tmp = a[j];      // ① 先把 a[j] 存到"临时盒"
a[j] = a[j + 1];     // ② a[j] 被覆盖前，值已经存好了
a[j + 1] = tmp;      // ③ 把临时盒里的旧值给 a[j+1]
```

想象两杯水要互换——**得先找个空杯子倒一下**，直接对着倒会把两杯水搞混。那个"空杯子"就是 `tmp`。

> 🚨 **千万别写成 `a[j] = a[j+1]; a[j+1] = a[j];`** ——第二步时 `a[j]` 已经被覆盖了，两个数会变成一样，另一个值就丢了！

## 8.1.5 冒泡快不快？—— 第一次感受"算法快慢" ⏱️

排 5 个数感觉不出来，但排 10000 个数呢？我们**数一数冒泡要比多少次**：

```
第1趟比 n-1 次
第2趟比 n-2 次
第3趟比 n-3 次
……
总比较次数 = (n-1) + (n-2) + ... + 1 = n(n-1)/2 ≈ n²/2
```

- n = 1000 → 约 **50 万**次比较
- n = 10000 → 约 **5000 万**次比较
- n = 100000 → 约 **50 亿**次比较！

> 📌 **规模每扩大 10 倍，冒泡的工作量膨胀约 100 倍（因为 10² = 100）。** 程序员用"大 O 记法"把它写成 O(n²)，读作"en 方"——意思是**工作量随 n 的平方增长**。这一章我们只用"数次数"来体会快慢，不深究记号，但你要记住这个感觉：**n² 级别的算法，数据一大就扛不住。**

这也解释了为什么我们后面要去学比 O(n²) 快得多的算法（8.5 的快速排序），而不是永远抱着冒泡不放。不过冒泡作为"理解排序原理"的入门，地位不可替代！

## 8.1.6 冒泡的小优化（选读，会加分）

如果数组**本来就已经排好了**，冒泡还是会傻傻地比完全部 n-1 趟。可以加一个"哨兵"：某趟**一次交换都没发生**，说明已经有序，直接停。

```c
void bubbleSortBetter(int a[], int n) {
    for (int i = 0; i < n - 1; i++) {
        int swapped = 0;                     // 哨兵：这一趟交换过吗？
        for (int j = 0; j < n - 1 - i; j++) {
            if (a[j] > a[j + 1]) {
                int tmp = a[j];
                a[j] = a[j + 1];
                a[j + 1] = tmp;
                swapped = 1;                 // 交换了，记一笔
            }
        }
        if (swapped == 0) break;             // 一趟没交换 → 已有序，提前结束
    }
}
```

对"几乎有序"的数据，这个版本会飞快。

## 8.1.7 本节小结

这一节我们学了：

✅ **冒泡思路：** 相邻两两比较，大的往后换，像气泡冒上去

✅ **每趟归位一个最大数：** 有 n 个数，最多 n−1 趟

✅ **两层循环：** 外层管趟数，内层相邻比较；内层上界 `n-1-i`

✅ **交换三句话：** `tmp = a[j]; a[j] = a[j+1]; a[j+1] = tmp;`

✅ **算法快慢：** 冒泡比较约 n²/2 次，规模×10 → 工作量×100（O(n²)）

✅ **小优化：** 加个"哨兵"，某趟没交换就提前结束

> 💡 **记住：冒泡的意义不在"快"，在于它是最直观地讲清了"排序到底在干什么"。**

### 三、改错题

**8. 以下冒泡排序有 3 个错误，请找出并改正：**

```c
#include <stdio.h>

void bubbleSort(int a[], int n) {
    for (int i = 0; i < n - 1; i++) {
        for (int j = 0; j < n - 1; j++) {      // 错误区①：内层每次到 n-1，把已归位的又比了一遍（浪费）
            if (a[j] < a[j + 1]) {             // 错误区②：要从小到大排，比较符号对吗？
                int tmp = a[j];
                a[j] = a[j + 1];                // 错误区③：这行应该把 tmp 给谁？
                a[j] = tmp;
            }
        }
    }
}

int main() {
    int a[] = {3, 1, 2};
    int n = 3;
    bubbleSort(a, n);
    for (int i = 0; i < n; i++) printf("%d ", a[i]);
    return 0;
}
```

> 正确输出应为：`1 2 3`。提示：三处分别在"比较方向 / 交换第三句 / 内层边界"上。
