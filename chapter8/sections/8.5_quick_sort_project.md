# 8.5 综合实战：快速排序

> 💬 **节前语：**
>
> 学了冒泡、选择、插入三种排序，又学了"一次砍一半"的二分查找——现在该把大招合体了：
>
> 二分查找能砍一半，是因为**每次比较都告诉我们是左半边还是右半边**。排序能不能也"砍"？——能！这就是本节的 **快速排序（Quick Sort）**：
>
> - 挑一个"**基准**"（pivot）
> - 一趟把数组分成两半：**左边全比基准小，右边全比基准大**
> - 左右两半再各自"快速排序"——**分而治之 + 递归**，全是第7章的功夫！
>
> 快速排序是 C 标准库 `qsort` 的老祖宗，也是面试、竞赛的常客。学完它，你的"排序宇宙"就正式从 O(n²) 跨进了 O(n log n)。准备好了吗？开始吧！

---

## 8.5.1 快排的"分"：一趟分区（Partition）

先不管递归，只看一趟"分区"能干什么。

假设数组是：

```
下标：  0   1   2   3   4   5
数值：  5   3   8   4   2   7
```

我们挑**最后一个元素 7** 当基准（pivot），然后"巡逻"整个数组：凡是比 7 小的，都换到左边去。一趟下来结果大概是这样：

```
3   2   4   5   8   7
└──都 ≤ 7──┘      │
              基准归位！
```

关键点：**这一趟之后，7 已经待在它"最终该在"的位置上了**——左边全比它小、右边全比它大。至于 7 两边是不是各自有序？不重要！因为接下来我们只要对**左右两半**各自再"快排"一遍就行了。

> 📌 **快排的"信仰之跃"（还记得第7章吗）：** 只要"分区"保证了"基准归位 + 左右一半比它小一半比它大"，那么**递归地**排好左右两半，整个数组就排好了。你不需要关心左右内部现在有多乱。

## 8.5.2 上代码：完整快排

### 交换小帮手

```c
// 交换数组里两个位置的值
void swap(int a[], int i, int j) {
    int tmp = a[i];
    a[i] = a[j];
    a[j] = tmp;
}
```

### 递归版快排

```c
#include <stdio.h>

void swap(int a[], int i, int j) {
    int tmp = a[i];
    a[i] = a[j];
    a[j] = tmp;
}

// 快速排序：排 a[low] 到 a[high]
void quickSort(int a[], int low, int high) {
    if (low >= high) {           // 出口：0 或 1 个元素，不用排
        return;
    }

    // —— ① 分区：让基准归位，返回基准最终位置 p ——
    int pivot = a[high];         // 挑最后一个元素当基准
    int i = low - 1;             // i 指向"最后一个 ≤ pivot 的位置"
    for (int j = low; j < high; j++) {
        if (a[j] <= pivot) {     // 比基准小/等 → 换到左边去
            i++;
            swap(a, i, j);
        }
    }
    swap(a, i + 1, high);        // 把基准放到中间 → 归位！
    int p = i + 1;               // 基准最终位置

    // —— ② 分而治之：左右两半各自快排 ——
    quickSort(a, low, p - 1);    // 排左边（全 ≤ pivot）
    quickSort(a, p + 1, high);   // 排右边（全 > pivot）
}

void printArray(int a[], int n) {
    for (int i = 0; i < n; i++) printf("%d ", a[i]);
    printf("\n");
}

int main() {
    int a[] = {5, 3, 8, 4, 2, 7};
    int n = 6;

    printf("排序前：");
    printArray(a, n);

    quickSort(a, 0, n - 1);

    printf("排序后：");
    printArray(a, n);
    return 0;
}
```

输出：
```
排序前：5 3 8 4 2 7
排序后：2 3 4 5 7 8
```

### 🔍 分区那段，到底在干嘛？

`pivot = a[high]`，我们让指针 `i` 站在"边界"上，`j` 从 low 一路走到 high-1：

```
凡是 a[j] <= pivot：
    i 前进一步，把 a[j] 换到 i 的位置（也就是"送进左边小部队"）

扫完后，a[low..i] 全是 ≤ pivot，a[i+1..high-1] 全是 > pivot
最后 swap(a, i+1, high)，把 pivot 放进 i+1 → 基准归位
```

对 `5 3 8 4 2 7`，pivot=7，一趟后变成 `5 3 4 2 7 8`……自己动手追一遍，比看十遍都强！

> 💡 **这个"巡逻交换"技巧叫 Lomuto 分区**，是最容易写对的一种。等熟练了，你还能挑战更快的"挖坑法"。现在先用它把"分而治之"的骨架搭起来。

## 8.5.3 快排为什么快？—— 图解"分而治之"

每次分区，数组被"对半切开"（理想情况），左右各 n/2；再各切一半……一共切约 **log₂n 层**。而每一层，所有元素总共大约被比较 n 次。所以总工作量：

```
快排 ≈ n × log₂n 次操作        （平均情况）
```

对比一下（n = 100 万时）：

| 算法 | 大约操作次数 | 感受 |
|------|-------------|------|
| 冒泡/选择/插入 | n²/2 ≈ 5000 亿 | 慢到怀疑人生 |
| 快速排序 | n log₂n ≈ 2000 万 | 眨眼间完成 |

> 📌 **差了约 25 万倍！** 这就是为什么大数据时代一定要学快排。把它写成记号就是 O(n log n)，读作"en log en"——**数据越大，它相对 O(n²) 的优势越夸张。**

> ⚠️ **快排的"隐藏弱项"：** 如果每次挑的基准都恰好是最小/最大（比如数组已经有序时还总挑最后一个当基准），分区就会"切偏"，退化到 O(n²)。工程上会加各种技巧（随机基准、三数取中）来避免。现在学到的是核心思想，够用且好懂。

## 8.5.4 综合实战：成绩排序 + 二分查找小系统 🎓

把这一章的本事串起来，做一个"学生成绩小工具"：

1. 有一串乱序成绩 `88, 62, 95, 70, 79`
2. **快排**从小到大排好
3. **二分查找**某位同学的成绩，报告排名（第几名 = 下标+1）
4. 再用二分查一个不存在的分数，看它怎么返回 -1

```c
#include <stdio.h>

void swap(int a[], int i, int j) {
    int tmp = a[i];
    a[i] = a[j];
    a[j] = tmp;
}

void quickSort(int a[], int low, int high) {
    if (low >= high) return;
    int pivot = a[high];
    int i = low - 1;
    for (int j = low; j < high; j++) {
        if (a[j] <= pivot) {
            i++;
            swap(a, i, j);
        }
    }
    swap(a, i + 1, high);
    int p = i + 1;
    quickSort(a, low, p - 1);
    quickSort(a, p + 1, high);
}

// 递归二分查找（第8.4节）
int binarySearch(int a[], int low, int high, int target) {
    if (low > high) return -1;
    int mid = low + (high - low) / 2;
    if (a[mid] == target) return mid;
    if (a[mid] < target) return binarySearch(a, mid + 1, high, target);
    return binarySearch(a, low, mid - 1, target);
}

void printArray(int a[], int n) {
    for (int i = 0; i < n; i++) printf("%d ", a[i]);
    printf("\n");
}

int main() {
    int scores[] = {88, 62, 95, 70, 79};
    int n = 5;

    printf("排序前：");
    printArray(scores, n);

    quickSort(scores, 0, n - 1);
    printf("快排后：");
    printArray(scores, n);

    // 查一位同学的成绩（名次 = 下标 + 1）
    int target = 79;
    int idx = binarySearch(scores, 0, n - 1, target);
    if (idx != -1) {
        printf("%d 分排第 %d 名\n", target, idx + 1);
    } else {
        printf("没有 %d 分\n", target);
    }

    // 查一个不存在的分数
    int miss = 100;
    int missIdx = binarySearch(scores, 0, n - 1, miss);
    printf("查 %d 分结果：%d（-1 = 没找到）\n", miss, missIdx);

    return 0;
}
```

输出：
```
排序前：88 62 95 70 79
快排后：62 70 79 88 95
79 分排第 3 名
查 100 分结果：-1（-1 = 没找到）
```

> 🎉 从"乱糟糟的成绩单"到"排好名次、秒查分数"——排序 + 查找，正是无数真实程序（排行榜、词典、通讯录、数据库索引）背后的基础功！

## 8.5.5 本章算法全家福 🧾

| 算法 | 一句话 | 大致速度 | 用在哪 |
|------|--------|---------|--------|
| 冒泡排序 | 相邻交换，大数冒上去 | O(n²) | 理解排序原理 |
| 选择排序 | 每趟挑最小放前面 | O(n²) | 少交换的场景 |
| 插入排序 | 像理牌，往前插 | 平均 O(n²)，近乎有序时 O(n) | 数据量小 / 基本有序 |
| 顺序查找 | 从头一个个比 | O(n) | 无序、数据少、只查一次 |
| 二分查找 | 每次砍一半 | O(log n) | **有序**、频繁查找 |
| 快速排序 | 基准分左右 + 递归 | 平均 O(n log n) | 数据量大时的主力排序 |

> 📌 **黄金搭档再强调一遍：** 排序 + 二分查找 = "一次排序，无限次秒查"。这是无数真实程序的经典组合。

## 8.5.6 本节小结

这一节我们学了：

✅ **快排思路：** 挑基准 → 一趟分区让基准归位（左小右大）→ 递归排左右两半

✅ **递归结构：** 出口 `low >= high`；`quickSort(左半)` + `quickSort(右半)`

✅ **分区写法：** Lomuto 巡逻法——比基准小的换到左边，最后把基准放进中间

✅ **为什么快：** 每层 O(n)，共约 log₂n 层 → O(n log n)，吊打 O(n²)

✅ **综合实战：** 快排 + 二分查找的成绩小系统——排序查找一套带走

> 💡 **记住：快排 = 第7章的"递归 + 分而治之" + 一个聪明的"分区"。你能走到这里，C 语言的核心已经相当扎实了！**

### 三、改错题

**8. 以下快排有 3 处错误，请找出并改正（排 `{4,1,3,2}`，期望 `1 2 3 4`）：**

```c
#include <stdio.h>

void swap(int a[], int i, int j) {
    int tmp = a[i];
    a[i] = a[j];
    a[j] = tmp;
}

void quickSort(int a[], int low, int high) {
    if (low > high) return;              // 错误区①：区间剩 1 个元素（low==high）该不该继续？
    int pivot = a[high];
    int i = low - 1;
    for (int j = low; j <= high; j++) {  // 错误区②：j 要不要扫到 high（pivot 自己）？
        if (a[j] <= pivot) {
            i++;
            swap(a, i, j);
        }
    }
    swap(a, i, high);                    // 错误区③：pivot 该放到 i 还是 i+1？
    int p = i;
    quickSort(a, low, p - 1);
    quickSort(a, p + 1, high);
}

int main() {
    int a[] = {4, 1, 3, 2};
    int n = 4;
    quickSort(a, 0, n - 1);
    for (int i = 0; i < n; i++) printf("%d ", a[i]);
    return 0;
}
```

> 提示：对照 8.5.2 的正确写法，逐行检查"出口条件 / j 的扫描范围 / pivot 归位位置"。
