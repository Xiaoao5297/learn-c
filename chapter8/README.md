# 第8章：排序与查找 —— 让数据"排好队"，让查找"快如闪电" ⚡

## 📖 本章导读

上一章结尾我们预告过：学完递归，就该去"算法世界"闯荡了。

想想你手里的数据现在是什么样：

```
成绩单：88, 62, 95, 70, 79   （乱糟糟，第一名是谁一眼看不出来）
```

乱糟糟的数据，**没法看、没法查、也没法比**。所以程序员最常做的两件事就是：

- 🗂️ **排序（Sort）**：把乱数据按从小到大（或从大到小）排整齐——就像整理书架、给扑克牌理牌
- 🔍 **查找（Search）**：在一堆数据里快速找到想要的那个——就像查字典、在通讯录里翻一个人的电话

而且它俩是好搭档：**先排好序，查找就能快得飞起**。排序 + 查找，正是"算法"的敲门砖。

在本章中，我们将一起：

- 🫧 **冒泡排序** —— 让大数像气泡一样"咕嘟咕嘟"冒上去
- 🍎 **选择排序** —— 每趟挑最小的放到前面，一趟只交换一次
- 🃏 **插入排序** —— 像打扑克理牌，新牌往前插；越有序越快
- 🎯 **二分查找** —— 像玩"猜数字"游戏，一次砍掉一半，快如闪电
- 🚀 **快速排序实战** —— 用第7章的"分而治之"，写出比冒泡快得多的排序

## 🎯 学习目标

完成本章后，你将能够：

1. ✅ 用冒泡、选择、插入三种排序给数组排序
2. ✅ 初步感受算法的"快慢"——会数"比较了多少次"
3. ✅ 用顺序查找和二分查找找数据，并知道二分有多快
4. ✅ 理解并写出"分而治之"的快速排序，完成排序+查找小应用

## 💡 学习建议

> 📌 **这一章教你"程序员最常用的两把刀"！**
>
> 排序和查找几乎出现在每一个真实程序里。
> 
> - 🖊️ **亲手模拟一遍**：拿几张纸条写上数字，按算法一步步手动排，比光看代码有用得多
> - 🐢 **先弄懂"思路"再背代码**：排序算法考的不是背，是"为什么这么移动"
> - 🔢 **学会数次数**：判断算法快慢，就数它"比较/移动了多少次"，这是以后学大 O 的基础
> - 🧪 **改改数据跑一跑**：换大数组、看看输出，感受不同算法的差别

准备好了吗？给数据"排队"去！👇
