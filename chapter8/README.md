# 第 8 章：排序与查找

前几章的程序处理数据时，从来没关心过数据的"顺序"。但真实程序几乎天天在和顺序打交道：排行榜要按分数从高到低、通讯录要按姓名排好才好翻、字典能快查靠的是有序。排序（sort）和查找（search）是程序员最常用的两个基本功，也是"算法"世界的敲门砖。

而且它俩是好搭档：**先排好序，查找就能快得飞起**。

本章会学到：

- 三种基础排序：冒泡、选择、插入，理解各自的思路、不变量和适用场景。
- 两种查找：线性查找与二分查找，体会"有序"换来的巨大加速。
- 分治思想的落地：手写快速排序，并认识标准库的 `qsort`。

## 前置知识

- 第 2 章：循环、`bool` 类型（2.6）。
- 第 3 章：数组、数组传参退化、`const` 参数、冒泡排序初见（3.5.5 和 3.5.6）。
- 第 4 章：指针参数、取地址（8.5 的交换函数要用）。
- 第 7 章：递归三步法、分而治之、信仰之跃（8.4 和 8.5 的递归要用）。

## 学完这一章，你应该能

1. 手写冒泡、选择、插入三种排序，说清每趟结束时的不变量。
2. 用 `swapped` 标志给冒泡加提前退出，并解释它对哪种数据有效。
3. 对比三种排序的比较次数与交换次数，为不同场景选出合适的一种。
4. 写出线性查找和二分查找，说清二分的有序前提、闭区间边界和 mid 防溢出写法。
5. 手写快速排序：分区、递归、出口一个不差，并说出它退化的条件和对策。
6. 说出标准库 `qsort` 的存在和比较函数的返回值约定（包括为什么不能直接相减）。

## 本章工程支线

第 7 章的工程支线是"用递归思考"，本章把它升级为"用不变量和复杂度思考"：

- **每节先讲不变量**：冒泡的"尾部已归位"、选择的"前缀是最终结果"、插入的"前缀内部有序"、二分的"目标必在 [left, right] 内"。想清楚循环每一步依赖什么性质，边界条件就不会靠猜。
- **数次数，感受复杂度**：三种 O(n²) 排序、O(n) 线性查找、O(log n) 二分、O(n log n) 快排。本章不引入大 O 记号的严格定义，但每次都把账算出来，第 9 章起这套直觉会一直用。
- **写法上的防坑习惯**：`mid = left + (right - left) / 2` 防溢出、砍半时排除已比较的 mid、比较函数用 `(a > b) - (a < b)` 规约返回值——都是真实工程里约定俗成的写法，第一次写就按规范来。

## 预计时间

- 只读一遍：4 到 6 小时。
- 做完每节练习和章末测试：8 到 12 小时。
- 建议分 3 次学习：8.1 到 8.3 一次（三种排序对照着学），8.4 一次，8.5 留一整段时间做项目。

## 学习建议

- 排序算法**动手模拟**比看代码有用得多：拿几张纸条写数字，按算法一步步排，再对照 8.1.2、8.2.1 的过程检查理解。
- 三种排序学完后，合上教程把 8.3.5 的对比表自己默写一遍——比较次数、交换次数、不变量三个维度。
- 二分查找的边界（8.4.2 的表）值得逐行读两遍；练习里有一道"改成 `left = mid` 会怎样"的题，认真推一遍比背结论强。
- 8.5 的快排先跑通 8.5.1 的单趟分区，确认理解了再加递归。
- 练习题先写，再展开答案。
