# 第6章：动态内存与链表 —— 让程序学会"变通" 🧠

## 📖 本章导读

回想一下我们之前用过的数组：

```c
int scores[100];    // 一上来就固定了：最多100个
```

有一个问题一直没解决：**如果运行前根本不知道会有多少个数据，怎么办？**

- 用户可能输入 3 个数，也可能输入 300 个
- 声明太小 → 不够用；声明太大 → 浪费内存

更麻烦的是，第3章的数组有个"死穴"：**往中间插入、删除一个元素，后面的元素全要挪动**，很麻烦。

这一章，我们学两样能"救场"的本事：

- 💾 **动态内存**：程序**运行时**才向系统申请内存，要多少给多少，用 `malloc`/`free`
- 🚂 **链表**：一种能"随便加节、随便减节"的数据结构——像火车一样，需要时**挂一节车厢**就行

在本章中，我们将一起：

- 💾 **认识动态内存**：malloc 申请、free 释放
- 🚨 **避开内存陷阱**：泄漏、悬垂指针、双重释放
- 🚂 **从零造链表**：节点、头插、尾插、遍历
- 🛠️ **链表进阶实战**：查找、删除、释放整条链

## 🎯 学习目标

完成本章后，你将能够：

1. ✅ 用 `malloc` 按需申请内存、用 `free` 释放
2. ✅ 识别并避开常见的内存错误（泄漏、悬垂、双重释放）
3. ✅ 理解链表的"节点 + 指针"结构，能手写一个单链表
4. ✅ 对链表做插入、查找、删除等操作，并正确释放整条链

## 💡 学习建议

> 📌 **这一章是"数据结构"的开端，也是面试最爱考的内容！**
>
> 链表几乎每个学编程的人都要手写一遍，就像学数学要背九九乘法表。
> 
> - 🖌️ **一定画图**：链表就是"箭头连箭头"，纸上画一画比空想强一万倍
> - 🐢 **一步步来**：先弄懂"节点"是什么，再想怎么连成链
> - 🧪 **跑起来看**：每次增删后 `printList` 打印一下，亲眼确认结果
