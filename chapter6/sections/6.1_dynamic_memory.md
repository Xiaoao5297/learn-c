# 6.1 动态内存基础：malloc 与 free

> 💬 **节前语：**
>
> 从第1章到第5章，我们用过的变量和数组，都有一个共同点：**程序一写好，内存就定死了**。
>
> ```c
> int scores[100];   // 无论用不用，都占着100个int的内存
> ```
>
> 但现实中经常要"运行时才知道要多少"：
> - 一个班今天有30人，明天有35人
> - 用户想存多少个数，他自己才知道
>
> 这时候就需要**动态内存**——让程序**运行的时候**向操作系统"现要"内存，用多少要多少，用完再"还"。
>
> 这一节，我们先学最核心的两个函数：`malloc`（要内存）和 `free`（还内存）。准备好了吗？开始吧！

---

## 6.1.1 为什么要"动态"分配内存？

### 🤔 静态数组的问题

```c
int scores[100];   // ① 最多100人
```

- 来了 101 个人 → 不够用！
- 只来了 5 个人 → 白白占用 100 人的内存（浪费）

**因为你是在"写代码时"就决定了大小，这叫"静态"。**

### ✅ 动态内存的思路

把"要多少"推迟到**运行时**决定：

```
程序运行 → 才知道 n=35 → 向系统申请"35个int"的内存 → 用完释放
```

**比喻：**
- 静态分配 = 不管来多少人，先把100个座位的教室订好
- 动态分配 = 看今天来了几个人，再决定订多大教室，用完退订

### 📌 两种内存：栈 与 堆

> 📖 **术语卡：栈（Stack）与堆（Heap）**
>
> C程序的变量，住在内存里两个不同的"区"：
>
> | | 栈（Stack） | 堆（Heap） |
> |------|------------|-----------|
> | 住着什么 | 普通局部变量、数组 | malloc 申请出来的空间 |
> | 谁分配 | 编译器自动安排 | **你手动申请** |
> | 谁释放 | 函数结束自动清理 | **你必须手动 free** |
> | 大小 | 较小，有上限 | 大得多 |
> | 特点 | 自动但死板 | 自由但要自己管 |
>
> ```c
> int a = 10;              // 在栈上（自动）
> int arr[100];            // 在栈上（自动）
> int *p = malloc(...);    // malloc 申请的空间在堆上（手动！）
> ```
>
> 这一节学的 malloc/free，操作的就是**堆**。

---

## 6.1.2 malloc：申请内存

### 📝 基本语法

```c
#include <stdlib.h>        // malloc 和 free 都声明在这里！

int *p = (int *)malloc(sizeof(int));   // 申请"1个int"大小的空间
```

| 部分 | 含义 |
|------|------|
| `malloc(...)` | memory allocate（分配内存） |
| `sizeof(int)` | 要多大：先算好一个 int 占几个字节 |
| `(int *)` | 把返回的地址"翻译"成 int* 类型（malloc 返回 `void*`） |
| `int *p` | 用一个指针，记住这块内存的地址 |

> 📌 **malloc 做了什么：** 在**堆**上找一块空闲内存，把它的地址返回给你。这块内存"没人管名字"，所以你**只能用指针**记住它。

### 🧩 为什么是 `sizeof(int)`，不直接写 4？

因为 int 占几个字节**因电脑而异**（通常4）。写成 `sizeof(int)`，编译器自动算，最保险。

### 📝 第一个动态内存程序

```c
#include <stdio.h>
#include <stdlib.h>

int main() {
    // 申请 1 个 int 的空间
    int *p = (int *)malloc(sizeof(int));
    
    // ⚠️ 铁律：malloc 之后必须检查是否成功！
    if (p == NULL) {
        printf("内存分配失败！\n");
        return 1;
    }
    
    *p = 42;               // 像普通变量一样用（通过指针）
    printf("*p = %d\n", *p);
    
    free(p);               // ✅ 用完释放！把内存还给系统
    return 0;
}
```

输出：
```
*p = 42
```

> 🚨 **malloc 可能失败吗？** 可能——比如内存真的不够了。失败时返回 `NULL`。所以**每次 malloc 后都要检查 `p == NULL`**（还记得第5章的 `fp == NULL` 吗？同一个道理！）

## 6.1.3 动态数组：要多少给多少

malloc 最常用的场景就是"**运行时才知道大小的数组**"：

```c
#include <stdio.h>
#include <stdlib.h>

int main() {
    // 实际场景中 n 可能来自用户输入、文件读取……
    // 这里为了演示，先直接定成 5
    int n = 5;
    
    // 申请 n 个 int 的空间（相当于动态的 int arr[n]）
    int *arr = (int *)malloc(n * sizeof(int));
    if (arr == NULL) {
        printf("内存分配失败！\n");
        return 1;
    }
    
    // 之后 arr[i] 用法和普通数组一模一样！
    for (int i = 0; i < n; i++) {
        arr[i] = i * i;          // 存平方数
    }
    
    for (int i = 0; i < n; i++) {
        printf("%d ", arr[i]);
    }
    printf("\n");
    
    free(arr);    // ✅ 用完释放
    return 0;
}
```

输出：
```
0 1 4 9 16 
```

**图解申请过程：**

```
malloc(n * sizeof(int))  → 在堆上找到一块能装 n 个 int 的空间
                              ┌────┬────┬────┬────┬────┐
arr 指向 → arr[0] arr[1] ...  │  0 │  1 │  4 │  9 │ 16 │
                              └────┴────┴────┴────┴────┘
```

> 📌 **注意：** `malloc` 申请的内存**不会清零**，里面是"垃圾值"。想要全0可以用下一节的 `calloc`，或者手动初始化。

### 📊 静态数组 vs 动态数组

| | 静态数组 | 动态数组 |
|---|---------|----------|
| 写法 | `int a[100];` | `int *a = malloc(100 * sizeof(int));` |
| 大小何时定 | 写代码时 | **运行时** |
| 在哪个区 | 栈 | 堆 |
| 用完要释放吗 | 不用 | **必须 free** |
| 下标用法 | `a[i]` | `a[i]`（一样） |

## 6.1.4 free：归还内存

### 📝 基本用法

```c
free(指针);    // 释放 malloc/calloc/realloc 申请的内存
```

```c
int *p = (int *)malloc(sizeof(int));
// ... 使用 ...
free(p);       // ✅ 用完归还
```

> 📌 **free 只做一件事：** 告诉系统"这块内存我不要了，你可以收回"。之后这个指针就不能再用了。

### 🚨 free 之后：把指针设为 NULL

```c
int *p = (int *)malloc(sizeof(int));
*p = 42;

free(p);       // 释放
p = NULL;      // ✅ 好习惯！让 p 不再指向"已释放的内存"
```

**为什么？** free 之后，p 还"记得"那块地址，但里面的内容已经作废——再用 `*p` 会读到垃圾、甚至崩溃。这种"指向已释放内存的指针"叫**悬垂指针**（下一节细讲）。设成 `NULL` 就安全了（能通过 `if (p != NULL)` 挡住误用）。

### ⚠️ 配对原则

| 申请 | 释放 |
|------|------|
| `malloc` | `free` |
| `fopen`（第5章） | `fclose` |

> 💡 **和 fopen/fclose 一个道理："拿"了就要"还"。** 程序里 malloc 和 free 应该成对出现。

## 6.1.5 为什么指针和动态内存是"天生一对"？

你可能好奇：为什么不能用普通变量接 malloc 的返回值？

```c
// ❌ 错误：普通变量不能"接住"地址
// int x = malloc(...);   // x 是个 int，malloc 给的是地址，塞不进去

// ✅ 必须用指针
int *p = malloc(...);      // p 记住这块堆内存的地址
```

**原因：** malloc 返回的是"堆内存的门牌号（地址）"。只有**指针**能存地址。这也解释了为什么第4章要先学指针——**没有指针，就没法用动态内存！**

---

## 6.1.6 本节小结

这一节我们学了：

✅ **为什么需要动态内存：** 运行时才知道要多大；不浪费、不短缺

✅ **栈 vs 堆：** 局部变量在栈（自动管理），malloc 申请的在堆（手动管理）

✅ **malloc：** `(类型 *)malloc(大小)`，配合 `sizeof`，返回指针

✅ **必须检查：** malloc 失败返回 NULL，一定要判断

✅ **free：** 用完释放，释放后建议把指针设 NULL

✅ **动态数组：** `int *arr = malloc(n * sizeof(int))`，用法和数组一样

> 💡 **记住：malloc 开锁拿房，free 还房关门；栈自动收拾，堆必须自己收拾！**

### 三、改错题

**6. 以下程序有4个错误，请找出并改正：**

```c
#include <stdio.h>

int main() {
    int *p = malloc(sizeof(int));       // 错误区①：缺头文件
    
    *p = 100;
    printf("%d\n", *p);
    
    int *q = malloc(sizeof(int));
    q = p;                              // 错误区②：丢了 q 原本申请的内存（泄漏）
    
    free(p);
    free(q);                            // 错误区③：p 和 q 指向同一块，重复释放！
    
    return 0;
}
```

> 提示：还差"malloc 后检查 NULL"这一步。
