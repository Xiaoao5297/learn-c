# 6.3 链表基础

> 💬 **节前语：**
>
> 上一节我们聊到：数组中间插一个元素，后面的全要挪，很痛苦。
>
> 想象一个更聪明的方案——**火车**！
>
> - 车厢之间用**挂钩**连起来
> - 想加人？在任意位置**挂一节新车厢**就行，其他车厢不用动
> - 想减人？**摘掉一节车厢**，前后一接就完事
>
> C语言里对应火车的结构，就是 **链表（Linked List）**。
>
> 这一节，我们从零开始造一辆"小火车"。这是数据结构的第一课，请一定动手敲、动手画。准备好了吗？开始吧！

---

## 6.3.1 数组 vs 链表：先想清楚为什么

### 📊 对比

| | 数组 | 链表 |
|---|------|------|
| 内存 | **连续**的一整块 | **分散**的，靠指针相连 |
| 找第 i 个 | 飞快：`arr[i]` 直接算地址 | 慢：必须从头一个个走 |
| 中间插入/删除 | 后面的全要挪 ❌ | 只改前后两个指针 ✅ |
| 大小 | 要么固定、要么 realloc | 天然"无限"，随时加节点 |

> 📌 **一句话：数组"存得快、改得慢"；链表"改得快、存得慢"。** 各有用处，不是谁取代谁。

---

## 6.3.2 链表的"车厢"：节点（Node）

链表的基本单位叫 **节点（Node）**，它由两部分组成：

```
┌───────────────┐
│  data（数据）  │
│  next（挂钩）  │  → 指向下一个节点的地址
└───────────────┘
```

| 部分 | 作用 | 比喻 |
|------|------|------|
| `data` | 真正存的数据 | 车厢里坐的乘客 |
| `next` | 指向**下一个节点**的指针 | 车厢后面的挂钩 |

### 📝 用结构体定义节点

```c
typedef struct Node {
    int data;              // 存的数据（这里先用整数）
    struct Node *next;     // 指向下一个节点
} Node;
```

> 📌 **注意写法：`struct Node *next`** —— 结构体里要指向"自己这种类型"，但 `Node` 这个名字还没定义完，所以必须用完整的 `struct Node` 来指。这是链表的固定写法。
> 
> 一句话：**每个节点里，既装着数据，又装着一个指向下一个节点的指针。**

### 🧩 一辆"三节火车"长这样

```
head
 │
 ▼
┌────┬────┐   ┌────┬────┐   ┌────┬─────┐
│ 10 │ ●──┼──►│ 20 │ ●──┼──►│ 30 │ NULL │
└────┴────┘   └────┴────┘   └────┴─────┘
 data next      data next      data next
```

- `head`：指向**第一个节点**的指针（记住它！）
- 每节车厢的 `next` 指向下一节
- **最后一节的 `next = NULL`**，表示"到站了"

> 📌 **链表只记住一个入口：`head`（头指针）。** 想访问第几个节点，只能从 head 出发，顺着 next 一个一个走过去。

## 6.3.3 创建节点：createNode

每个新节点都要用 malloc 在堆上申请：

```c
#include <stdio.h>
#include <stdlib.h>

typedef struct Node {
    int data;
    struct Node *next;
} Node;

// 创建一个新节点，返回它的地址
Node *createNode(int value) {
    Node *node = (Node *)malloc(sizeof(Node));
    if (node == NULL) {          // malloc 要检查！
        return NULL;
    }
    node->data = value;
    node->next = NULL;           // 新节点暂时不连别人
    return node;
}
```

> 💡 **这是链表的"地基函数"**，后面所有操作（插入、删除）都靠它造节点。注意它用到 malloc——所以 6.1、6.2 的内存知识是链表的前提！

---

## 6.3.4 头插法：push_front（插到最前面）

新节点插到链表最前面：

```c
// 在链表最前面插入一个值（head 可能被改 → 所以要传 Node **）
void push_front(Node **head, int value) {
    Node *node = createNode(value);
    if (node == NULL) return;
    
    node->next = *head;   // 新车厢挂到原来的第一辆车前面
    *head = node;         // 更新头指针：新车厢现在是第一辆
}
```

**图解头插 0 到 [10, 20]：**

```
原来：head → 10 → 20 → NULL
造好：node = 0 → NULL
第1步：node->next = *head    →  0 → 10 → 20 → NULL（此时 head 仍指向 10）
第2步：*head = node          →  head → 0 → 10 → 20 → NULL
```

> 🚨 **为什么参数是 `Node **head`（指针的指针）？**
> 
> 回想第4章的 swap：**想修改函数外面的变量，就要传它的地址。** 这里头指针 `head` 是 main 里的一个"变量"，头插要**改它**（让它指向新节点），所以传 `&head`，函数参数写 `Node **`。函数里用 `*head` 就相当于 main 里的 `head`。
> 
> 如果只传 `Node *head`，那只是复制一份指针，改了也白改（值传递的锅）！

---

## 6.3.5 尾插法：push_back（插到末尾）

新节点插到链表最后：

```c
void push_back(Node **head, int value) {
    Node *node = createNode(value);
    if (node == NULL) return;
    
    // 链表是空的 → 新节点直接当第一个
    if (*head == NULL) {
        *head = node;
        return;
    }
    
    // 否则，从头走到最后一个节点
    Node *tail = *head;
    while (tail->next != NULL) {
        tail = tail->next;       // 顺着 next 走到最后一节
    }
    tail->next = node;           // 挂在最后面
}
```

**图解尾插 30 到 [10, 20]：**

```
head → 10 → 20 → NULL

tail 从头走：
  tail = 10（next=20，没到末尾，继续）
  tail = 20（next=NULL，到末尾了！）

tail->next = node  →  10 → 20 → 30 → NULL
```

> 📌 尾插要先**从头走到尾**（O(n)），头插不用走（O(1)）——这也是为什么"频繁在头部插入"用头插更快。

---

## 6.3.6 遍历打印：printList

顺着 next 一路走，边走边打印：

```c
void printList(Node *head) {
    Node *cur = head;
    while (cur != NULL) {
        printf("%d -> ", cur->data);
        cur = cur->next;      // 走向下一个
    }
    printf("NULL\n");         // 打印末尾标记
}
```

> 📌 **遍历模板（背下来）：**
> ```c
> for (Node *cur = head; cur != NULL; cur = cur->next) {
>     // 处理 cur->data
> }
> ```
> 和数组的 `for (i=0; i<n; i++)` 结构几乎一样，只是把"下标 i++"换成了"指针 cur = cur->next"！

---

## 6.3.7 释放整条链：freeList

链表每个节点都是 malloc 出来的，**要逐个释放**：

```c
void freeList(Node *head) {
    Node *cur = head;
    while (cur != NULL) {
        Node *next = cur->next;   // 先记住下一个（不然 free 后就找不到了）
        free(cur);                // 释放当前节点
        cur = next;               // 走向下一个
    }
}
```

> ⚠️ **顺序很重要：必须先记住 `cur->next`，再 `free(cur)`！** 如果先 free 再读 cur->next，就是悬垂指针（读了已释放的内存）。

---

## 6.3.8 完整演示：造一辆小火车

```c
#include <stdio.h>
#include <stdlib.h>

typedef struct Node {
    int data;
    struct Node *next;
} Node;

Node *createNode(int value) {
    Node *node = (Node *)malloc(sizeof(Node));
    if (node == NULL) return NULL;
    node->data = value;
    node->next = NULL;
    return node;
}

void push_front(Node **head, int value) {
    Node *node = createNode(value);
    if (node == NULL) return;
    node->next = *head;
    *head = node;
}

void push_back(Node **head, int value) {
    Node *node = createNode(value);
    if (node == NULL) return;
    if (*head == NULL) {
        *head = node;
        return;
    }
    Node *tail = *head;
    while (tail->next != NULL) {
        tail = tail->next;
    }
    tail->next = node;
}

void printList(Node *head) {
    for (Node *cur = head; cur != NULL; cur = cur->next) {
        printf("%d -> ", cur->data);
    }
    printf("NULL\n");
}

void freeList(Node *head) {
    Node *cur = head;
    while (cur != NULL) {
        Node *next = cur->next;
        free(cur);
        cur = next;
    }
}

int main() {
    Node *head = NULL;         // 空链表：头指针先指向 NULL
    
    // 尾插 10、20、30：顺序是 10 → 20 → 30
    push_back(&head, 10);
    push_back(&head, 20);
    push_back(&head, 30);
    printf("尾插后：");
    printList(head);
    
    // 头插 0、5：新来的都在最前面
    push_front(&head, 5);
    push_front(&head, 0);
    printf("头插后：");
    printList(head);
    
    // 用 malloc 造的节点，用完必须整链释放！
    freeList(head);
    head = NULL;
    
    printf("程序结束，链表已释放。\n");
    return 0;
}
```

输出：
```
尾插后：10 -> 20 -> 30 -> NULL
头插后：0 -> 5 -> 10 -> 20 -> 30 -> NULL
程序结束，链表已释放。
```

> 🎉 跑起来了吗？恭喜，你已经亲手造出一辆"数据小火车"了！

## 6.3.9 本节小结

这一节我们学了：

✅ **链表是什么：** 分散的内存节点用指针连成链，像火车

✅ **节点：** `struct Node { 数据; struct Node *next; }`，`next` 指向自己这种类型

✅ **头指针 head：** 整个链表唯一的入口，空链表时 head == NULL

✅ **createNode：** malloc 造节点 + 检查 NULL

✅ **头插 push_front / 尾插 push_back：** 改头或走到底，注意用 `Node **`

✅ **遍历 printList / 释放 freeList：** 顺着 next 走；释放前先记下一个

> 💡 **记住：链表操作 90% 的功夫，都在"画箭头、改箭头"上。画图比死记代码有用一万倍！**
