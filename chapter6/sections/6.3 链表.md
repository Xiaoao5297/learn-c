# 6.3 链表

数组和动态数组都是连续存放的，往中间插入、删除一个元素，后面的所有元素都得挪动。这一节学一种新的组织方式——链表（linked list）：数据不要求连续，靠指针连成一串，想插就插、想删就删。

## 6.3.1 数组 vs 链表

| 对比项 | 数组 | 链表 |
|--------|------|------|
| 内存布局 | 连续一整块 | 分散，靠指针相连 |
| 访问第 i 个 | 快：`arr[i]` 一步到位 | 慢：必须从头一个个走 |
| 中间插入/删除 | 后面的元素全要挪 | 只改两个指针 |
| 大小 | 固定，或用 `realloc` 扩容 | 随时加节点，天然可长可短 |

一句话：数组"访问快、增删慢"，链表"增删快、访问慢"。各有舞台，不是谁取代谁。

## 6.3.2 节点：数据加指针

链表的基本单位叫**节点（node）**，每节车厢装两样东西：真正的数据，和一个指向下一节车厢的指针。

```c
struct node {
	int data;            /* 存的数据 */
	struct node *next;   /* 指向下一个节点 */
};
```

成员 `next` 的类型是 `struct node *`，指向"自己这种类型"。这里必须写完整的 `struct node`——结构体定义到 `next` 这一行时还没定义完，别名（如果有）也还没起，只能用结构体本身的类型名。这是链表节点的固定写法。

一串节点连起来，长这样：

```text
head ──► [10|next] ──► [20|next] ──► [30|next = NULL]
```

- **head（头指针）**：指向第一个节点，是整条链唯一的入口。要访问第几个节点，只能从 head 出发顺着 `next` 走。
- 最后一个节点的 `next` 是 `NULL`，表示"到头了"。
- 空链表就是 `head == NULL`，连一节车厢都没有。

链表操作 90% 的功夫都在"画箭头、改箭头"上。学这一节时准备一张纸，每看一个操作就画一遍节点和箭头，比空想快得多。

## 6.3.3 创建节点

节点在堆上，所以要 `malloc`。先写一个创建节点的地基函数，后面所有操作都靠它：

```c
// 6.3.3 create_node.c
#include <stdio.h>
#include <stdlib.h>

struct node {
	int data;
	struct node *next;
};

struct node *create_node(int value)
{
	struct node *n = malloc(sizeof(struct node));
	if (n == NULL) {
		return NULL;
	}
	n->data = value;
	n->next = NULL;    /* 新节点先不连任何人 */
	return n;
}

int main(void)
{
	struct node *head = create_node(10);
	if (head == NULL) {
		printf("内存分配失败\n");
		return 1;
	}

	printf("head->data = %d\n", head->data);
	printf("head->next = %s\n", head->next == NULL ? "NULL" : "非NULL");

	free(head);
	head = NULL;

	return 0;
}
```

<!-- output: 6.3.3 -->
```text
head->data = 10
head->next = NULL
```

两个细节：`malloc` 失败返回 `NULL`，`create_node` 检查后把这个结果如实转告调用者，让上层决定怎么办——这正是 5.1 讲过的"检查、如实上报"；新节点的 `next` 一定先置 `NULL`，绝不能留着垃圾值，否则之后遍历会顺着一个随机地址走进内存深处。

## 6.3.4 头插：插到最前面

头插（push front）把新节点插到链表最前面，只需两步：新节点的 `next` 指向原第一个节点，head 改指新节点。

```c
void push_front(struct node **head, int value)
{
	struct node *n = create_node(value);
	if (n == NULL) {
		return;
	}
	n->next = *head;    /* 新节点挂上原来的第一条链 */
	*head = n;          /* 新节点成为第一个 */
}
```

图解：把 5 头插进 `10 -> 20`：

```text
第 1 步  n->next = *head     n ──► 10 -> 20（head 仍指向 10）
第 2 步  *head = n           head ──► 5 ──► 10 -> 20
```

为什么参数是 `struct node **head`？因为头插要改 `main` 里的 `head` 变量。想改函数外面的变量，就要传它的地址（4.5.2 的规矩）——`head` 是 `struct node *`，它的地址就是 `struct node **`。只传 `head` 改的是副本，改了也白改。

先 `n->next = *head`、后 `*head = n` 的顺序不能反：一旦先改了 head，原来的链就断了，`n->next` 指不回去。

## 6.3.5 尾插：插到末尾

尾插（push back）把新节点挂到链表最后。空链表是特殊情况：没有"最后"，新节点直接当第一个：

```c
void push_back(struct node **head, int value)
{
	struct node *n = create_node(value);
	if (n == NULL) {
		return;
	}

	if (*head == NULL) {    /* 空链表：新节点就是第一个 */
		*head = n;
		return;
	}

	struct node *tail = *head;
	while (tail->next != NULL) {    /* 从头走到最后一个节点 */
		tail = tail->next;
	}
	tail->next = n;                 /* 挂在最后 */
}
```

尾插要先从头走到尾（走 n 步），头插一步到位。频繁往头部插入的场景，头插快得多。

两种插入都在改动头指针，所以都接收 `struct node **`。检查一下这两个函数面对**空链表**的表现：`push_front` 里 `*head` 是 `NULL`，`n->next = NULL` 成立，`*head = n` 正常；`push_back` 走空链表分支，也正常。空链表安全是链表函数的基本要求，后面每个操作都按这个标准自查。

## 6.3.6 遍历：顺着 next 走

遍历打印一遍，模板值得背下来：

```c
void print_list(struct node *head)
{
	for (struct node *cur = head; cur != NULL; cur = cur->next) {
		printf("%d -> ", cur->data);
	}
	printf("NULL\n");
}
```

和数组的 `for (int i = 0; i < n; i++)` 结构完全对应，只是把"下标自增"换成了"`cur` 走向下一个节点"。循环条件 `cur != NULL` 天然覆盖空链表——head 是 `NULL` 时循环一次都不进，直接打印 `NULL`。

把创建、头插、尾插、遍历、释放组装成完整的演示：

```c
// 6.3.6 list_basic.c
#include <stdio.h>
#include <stdlib.h>

struct node {
	int data;
	struct node *next;
};

struct node *create_node(int value)
{
	struct node *n = malloc(sizeof(struct node));
	if (n == NULL) {
		return NULL;
	}
	n->data = value;
	n->next = NULL;
	return n;
}

void push_front(struct node **head, int value)
{
	struct node *n = create_node(value);
	if (n == NULL) {
		return;
	}
	n->next = *head;
	*head = n;
}

void push_back(struct node **head, int value)
{
	struct node *n = create_node(value);
	if (n == NULL) {
		return;
	}

	if (*head == NULL) {
		*head = n;
		return;
	}

	struct node *tail = *head;
	while (tail->next != NULL) {
		tail = tail->next;
	}
	tail->next = n;
}

void print_list(struct node *head)
{
	for (struct node *cur = head; cur != NULL; cur = cur->next) {
		printf("%d -> ", cur->data);
	}
	printf("NULL\n");
}

void free_list(struct node *head)
{
	struct node *cur = head;
	while (cur != NULL) {
		struct node *next = cur->next;    /* 先记住下一个 */
		free(cur);                        /* 再释放当前 */
		cur = next;
	}
}

int main(void)
{
	struct node *head = NULL;

	push_back(&head, 10);
	push_back(&head, 20);
	push_back(&head, 30);
	printf("尾插后：");
	print_list(head);

	push_front(&head, 5);
	push_front(&head, 1);
	printf("头插后：");
	print_list(head);

	free_list(head);
	head = NULL;

	return 0;
}
```

<!-- output: 6.3.6 -->
```text
尾插后：10 -> 20 -> 30 -> NULL
头插后：1 -> 5 -> 10 -> 20 -> 30 -> NULL
```

头插是"后来居上"：先插 5 再插 1，1 反而在最前面。

## 6.3.7 释放整条链

每个节点都是 `malloc` 来的，用完整条链必须逐个释放：

```c
void free_list(struct node *head)
{
	struct node *cur = head;
	while (cur != NULL) {
		struct node *next = cur->next;    /* 先记住下一个 */
		free(cur);                        /* 再释放当前 */
		cur = next;
	}
}
```

关键在顺序：**先记住 `cur->next`，再 `free(cur)`**。反过来的话，free 之后再读 `cur->next` 就是悬垂指针（6.2.5）——读一块已经释放的内存。释放完最好把 `head` 置 `NULL`，让链表回到"空链"状态。

## 6.3.8 常见错误

| 错误写法 | 问题 | 正确写法 |
|----------|------|----------|
| `struct node { node *next; ... };` | 类型没定义完就用自己的别名 | `struct node *next;` |
| `create_node` 里不检查 `malloc` 失败 | 返回垃圾地址，后续全是未定义行为 | 检查后 `return NULL` |
| `push_front` 里写 `head = n;` | 改的是副本，外面毫无变化 | `*head = n;`，参数收 `struct node **` |
| 新节点 `next` 不置 `NULL` | 遍历走进随机地址 | `n->next = NULL;` |
| `free_list` 先 `free` 再读 `cur->next` | 悬垂指针 | 先存 `next` 再 `free` |
| 用完链表不释放 | 每个节点都泄漏 | `free_list` 逐个释放 |

## 6.3.9 小结

- 链表 = 分散的节点 + 指针；节点 = 数据 + `struct node *next`。
- head 是唯一入口，空链表就是 `head == NULL`，末节点的 `next` 是 `NULL`。
- 头插两步：新节点连旧链，head 改指新节点；尾插先特判空链表，再走到末尾挂上去。
- 遍历模板：`for (struct node *cur = head; cur != NULL; cur = cur->next)`。
- 释放整条链：先记住下一个，再 free 当前；释放完 head 置 `NULL`。
- 要改外面的 head 就传 `struct node **`——4.5.2 "想改什么就传它的地址"的直接应用。

## 练习

1. 节点的 `next` 成员为什么必须写成 `struct node *`，不能写成别名？
2. 空链表用什么表示？`print_list` 面对空链表会输出什么？
3. 头插和尾插，哪个要走到链表末尾？哪个不用？
4. 下面这个 `push_front` 有什么问题？

```c
void push_front(struct node *head, int value)
{
	struct node *n = create_node(value);
	n->next = head;
	head = n;
}
```

5. 写出下面程序片段执行后的链表内容（用 `10 -> 20 -> NULL` 的格式表示）。

```c
struct node *head = NULL;
push_front(&head, 20);
push_front(&head, 10);
push_back(&head, 30);
```

6. 编程题：用尾插法把 `{3, 1, 4, 1, 5}` 建成链表，遍历打印，数出节点个数，最后释放整条链。输出格式如下：

```text
3 -> 1 -> 4 -> 1 -> 5 -> NULL
节点个数：5
```

<details>
<summary>参考答案</summary>

1. 结构体定义进行到 `next` 这一行时，整个结构体还没定义完。如果起了别名，别名也要等定义结束才可用，所以这里只能写完整的 `struct node *`。
2. `head == NULL`。`print_list` 的循环条件 `cur != NULL` 一次都不成立，直接打印 `NULL` 一行。
3. 尾插要走到末尾（走 n 步）；头插不用，直接挂在 head 前面。
4. 三处问题。第一，参数是 `struct node *head`，函数内改 `head` 改的是副本，调用者的链表毫无变化——想改外面的 head 要收 `struct node **` 并写 `*head`。第二，`create_node` 可能返回 `NULL`，没检查。第三，函数名与行为不符之前，`n->next = head` 本身没错，但整个函数因参数问题完全失效。正确版本见 6.3.4。
5. `10 -> 20 -> 30 -> NULL`。先头插 20 得 `20`，再头插 10 得 `10 -> 20`，尾插 30 挂到末尾。
6. 参考代码：

```c
#include <stdio.h>
#include <stdlib.h>

struct node {
	int data;
	struct node *next;
};

struct node *create_node(int value)
{
	struct node *n = malloc(sizeof(struct node));
	if (n == NULL) {
		return NULL;
	}
	n->data = value;
	n->next = NULL;
	return n;
}

void push_back(struct node **head, int value)
{
	struct node *n = create_node(value);
	if (n == NULL) {
		return;
	}

	if (*head == NULL) {
		*head = n;
		return;
	}

	struct node *tail = *head;
	while (tail->next != NULL) {
		tail = tail->next;
	}
	tail->next = n;
}

void print_list(struct node *head)
{
	for (struct node *cur = head; cur != NULL; cur = cur->next) {
		printf("%d -> ", cur->data);
	}
	printf("NULL\n");
}

int list_length(struct node *head)
{
	int count = 0;
	for (struct node *cur = head; cur != NULL; cur = cur->next) {
		count++;
	}
	return count;
}

void free_list(struct node *head)
{
	struct node *cur = head;
	while (cur != NULL) {
		struct node *next = cur->next;
		free(cur);
		cur = next;
	}
}

int main(void)
{
	struct node *head = NULL;

	int values[] = {3, 1, 4, 1, 5};
	for (int i = 0; i < 5; i++) {
		push_back(&head, values[i]);
	}

	print_list(head);
	printf("节点个数：%d\n", list_length(head));

	free_list(head);
	head = NULL;

	return 0;
}
```
