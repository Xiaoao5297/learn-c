## 6.1 运行时才定的平方表 ⭐

**考察**：6.1 动态内存

固定位数的数组在编译时就写死了大小。这个程序要生成 1 到 8 的平方表，但表长用变量 `n` 决定——那就向堆申请一块大小刚好的内存。

**要求**：

- `int n = 8;`，用 `malloc` 申请 `n` 个 `int`，检查返回值。
- 存入 1² 到 8²，边存边求和。
- 输出最后一个元素的值和总和。
- 用完 `free` 并把指针置 `NULL`。

**示例运行**：

```text
最后一个是 64
总和是 204
```

## 6.2 三块内存的规范归还 ⭐

**考察**：6.1 动态内存、6.2 内存陷阱

分配和释放是一对好习惯的起点：一次程序要同时用三种不同类型的动态内存，用完一块还一块，绝不拖延。

**要求**：

- 分别 `malloc` 一块 `int`、一块 `double`、一块 10 字节的 `char` 数组，检查返回值（任何一个失败都要把已申请的都释放掉再退出）。
- `int` 存 42，`double` 存 3.14，`char` 数组用 `snprintf` 存 `hello`，然后打印三者。
- 逐块 `free`，每块释放后立刻置 `NULL`。

**示例运行**：

```text
42 3.14 hello
```

## 6.3 拼接两个动态数组 ⭐⭐

**考察**：6.1 动态内存、6.1 malloc/free 全检查

数据分开采集、最后合并输出是常见需求。前半段数据是 `{1, 2, 3}`，后半段是 `{4, 5, 6}`，分别装在两块动态内存里，请把它们拼进第三块动态内存。

**要求**：

- 用 `malloc` 申请 `a`（3 个 `int`，存 1~3）和 `b`（3 个 `int`，存 4~6），都检查返回值。
- 再 `malloc` 第三块能装 6 个 `int` 的 `merged`，检查返回值；把 `a`、`b` 依次复制进去。
- 打印 `merged` 的 6 个元素，然后三块内存逐一 `free` 并置 `NULL`。

**示例运行**：

```text
1 2 3 4 5 6 
```

## 6.4 链表倒数第 k 个节点 ⭐⭐

**考察**：6.3 链表、6.3 遍历与计数

排队叫号系统里，"倒数第 2 个"就是要办业务的那位。用尾插法建一条 `10 -> 20 -> 30 -> 40 -> 50` 的链表，找出倒数第 k 个节点的值。

**要求**：

- 实现 `create_node`、`push_back`、`print_list`、`free_list`（头指针参数用 `struct node **`），`malloc` 返回值全检查。
- 先遍历一遍数出总节点数，再从头走 `总数 - k` 步到达目标（k 取 2）。
- 输出整条链和 `倒数第 2 个：40`，最后释放整条链并把 `head` 置 `NULL`。

**示例运行**：

```text
10 -> 20 -> 30 -> 40 -> 50 -> NULL
倒数第 2 个：40
```

## 6.5 有序插入 ⭐⭐

**考察**：6.3 链表、6.4 链表进阶

维护一条始终升序的链表：新数据来一张插一张，插完还是有序的——这比"先乱插再排序"省事得多。

**要求**：

- 写函数 `void insert_sorted(struct node **head, int value);`：
  - 空链表或新值比头节点小时插在头部；
  - 否则一路找到最后一个"下一个值不小于新值"的节点，插在它后面。
- 依次插入 30、10、20、25，每次插入后链表都应有序。
- 打印最终链表 `10 -> 20 -> 25 -> 30 -> NULL`，最后释放整条链。

**示例运行**：

```text
10 -> 20 -> 25 -> 30 -> NULL
```

## 6.6 在指定节点后面插一个 ⭐⭐

**考察**：6.4 链表进阶、6.3 遍历

点歌系统的经典操作：在歌单里某首歌后面插一首新歌。往 `10 -> 20 -> 30 -> 40` 这条链中值为 20 的节点后面插入 25；指定的值不存在时要礼貌地失败。

**要求**：

- 写函数 `int insert_after(struct node *head, int target, int value);`：找到第一个值为 `target` 的节点，在其后插入新节点，成功返回 1；找不到返回 0（新节点 `malloc` 失败也返回 0）。
- 建链 `10 -> 20 -> 30 -> 40`，在 20 后插 25（成功），再试在 99 后插 5（失败并提示）。
- 每次操作后打印整条链，最后释放。

**示例运行**：

```text
10 -> 20 -> 30 -> 40 -> NULL
插入成功
没找到 99，插入失败
10 -> 20 -> 25 -> 30 -> 40 -> NULL
```

## 6.7 最大值在倒数第几站 ⭐⭐

**考察**：6.3 链表遍历、4.1 指针带回多个结果

公交调度想知道载客最多的一班车是当天第几班。用尾插法建链 `{12, 45, 7, 89, 23, 56}`，找出最大值并报告它是第几个节点（节点从 1 数起）。

**要求**：

- 写函数 `void find_max(struct node *head, int *max_out, int *pos_out);`，两个结果都通过指针参数带回；遍历一遍同时更新最大值和它的位置。
- 建链、打印、调用、输出 `最大值：89（第 4 个节点）`，最后释放整条链。
- 想一想：如果最大值出现多次，你的函数报的是哪一次的位置？

**示例运行**：

```text
12 -> 45 -> 7 -> 89 -> 23 -> 56 -> NULL
最大值：89（第 4 个节点）
```

## 6.8 删除所有目标节点 ⭐⭐⭐

**考察**：6.4 链表进阶（删除）、6.3 头删除与二级指针、6.2 悬垂防范

洗牌程序要删掉一副牌里所有的 3。链表删除单个值不难，难的是"删光所有"：头节点就可能连续中招，删完一个还得接着看下一个，指针一断链就丢。

**要求**：

- 写函数 `int delete_all(struct node **head, int target);`：删除链表中所有值为 `target` 的节点（头节点也要能删），返回删除个数。
- 建链 `{3, 7, 3, 3, 9, 3, 5, 3}`，删除所有 3。
- 打印删除前后的链表和删除个数，最后释放整条链。
- 提示：删头节点用循环处理最稳；中间删除时，前驱节点什么时候该前进、什么时候该原地不动？

**示例运行**：

```text
3 -> 7 -> 3 -> 3 -> 9 -> 3 -> 5 -> 3 -> NULL
删除了 5 个 3
7 -> 9 -> 5 -> NULL
```

## 6.9 用二级指针搭一个二维矩阵 ⭐⭐⭐

**考察**：6.1 动态内存、4.6 多级指针、6.2 释放顺序

运行时才能确定行列数的乘法表，得用"指针数组 + 每行一块内存"的方式搭：先申请 4 个 `int *` 组成的数组，再给每一行单独申请 5 个 `int`。它是本章二级指针最实在的练兵场。

**要求**：

- `int **matrix = malloc(rows * sizeof(int *));`（rows 为 4），检查返回值。
- 循环给每行 `malloc(cols * sizeof(int))`（cols 为 5），每一行都要检查；某一行失败时，把已经申请的行全部释放再退出。
- `matrix[i][j]` 存 `(i+1) * (j+1)`，按 4 行 5 列打印（每个数 `%3d` 宽度对齐）。
- 释放：先 `free` 每一行，最后 `free` 行指针数组，并把 `matrix` 置 `NULL`。
- 想一想：释放顺序反了会发生什么？

**示例运行**：

```text
  1  2  3  4  5
  2  4  6  8 10
  3  6  9 12 15
  4  8 12 16 20
```

## 6.10 学生名单管理器 🌟

**考察**：6.3 链表、6.4 链表进阶、5.3 安全输入（选）

学期结束了，写一个能交互操作的学生名单管理器：名单用链表存（每存一个申请一个节点），支持添加、按姓名删除、打印全部，退出时把整条链释放干净。这几乎是真实小程序的样子。

**要求**：

- 定义 `struct node { char name[20]; int score; struct node *next; };`。
- 交互命令（从键盘逐行读，`fgets` 读入后解析）：
  - `add 姓名 分数`：尾插一个学生，成功打印 `已添加 姓名 分数`；
  - `del 姓名`：按姓名删除（头节点也要能删），删掉打印 `已删除 姓名`，没有这个人打印 `没有 姓名`；
  - `list`：逐行打印全部学生；
  - `quit`：退出。
- 实现时可自由组合 `create_node`、`add_student`、`remove_student`、`print_list`、`free_list` 等函数，`malloc`/`free` 全检查，退出前释放整条链并把 `head` 置 `NULL`。
- 提示：解析命令用 `sscanf(line, "%15s", cmd)` 先取第一个单词，再按命令类型取参数；姓名解析记得 `%19s` 限宽。

**示例运行**（输入依次为 `add xiaoming 90`、`add xiaohong 85`、`list`、`del xiaoming`、`list`、`del zhangsan`、`add wang 92`、`list`、`quit`）：

```text
命令：add 姓名 分数 / del 姓名 / list / quit
已添加 xiaoming 90
已添加 xiaohong 85
xiaoming 90
xiaohong 85
已删除 xiaoming
xiaohong 85
没有 zhangsan
已添加 wang 92
xiaohong 85
wang 92
```
