## 7.1 递归打印二进制 ⭐

**考察**：7.1 递归入门、7.2 调用栈（归来时做事）

计算机的母语是二进制。写一个递归函数，把一个非负整数按二进制打印出来：先递归处理 `n / 2`（更高位），归来时再打印 `n % 2`（当前位）。

**要求**：

- 写函数 `void print_binary(unsigned int n);`：基线条件自己定（想想 n 为 0 或 1 时怎么办）。
- `printf` 放在递归调用之前还是之后？想清楚输出的顺序为什么是从高位到低位。
- `main` 里对 26 打印，结果应为 `11010`。

**示例运行**：

```text
11010
```

## 7.2 亲眼看看调用栈 ⭐

**考察**：7.2 调用栈与栈溢出

递归不是黑魔法：每次调用压一层栈帧，返回时弹一层。写一个函数把这件事"打印"出来——下去时报到，回来时也报到。

**要求**：

- 写函数 `void dive(int n);`：进入时打印 `进入第 n 层`，然后递归调用 `dive(n - 1)`，归来后打印 `离开第 n 层`；`n == 0` 时打印 `到底了，开始返回` 并返回。
- `main` 里调用 `dive(3)`。
- 对照输出想一想：打印的"进入"和"离开"顺序为什么正好相反？

**示例运行**：

```text
进入第 3 层
进入第 2 层
进入第 1 层
到底了，开始返回
离开第 1 层
离开第 2 层
离开第 3 层
```

## 7.3 递归逆序打印数组 ⭐⭐

**考察**：7.1 递归入门、7.2 顺序魔法（printf 放在递归之后）

第 4 章用双指针原地反转过数组，这次换个思路：数组一个元素都不动，只靠递归的"归来顺序"把 `10 20 30 40 50` 倒着打印成 `50 40 30 20 10`。

**要求**：

- 写函数 `void print_array_reverse(const int nums[], int count);`：参数用 `const`（函数只读），先递归处理"后面的 `count - 1` 个"，归来时再打印当前第一个元素。
- 基线条件：`count == 0` 时直接返回。
- `main` 里对 `{10, 20, 30, 40, 50}` 测试。

**示例运行**：

```text
50 40 30 20 10 
```

## 7.4 递归版 strlen ⭐⭐

**考察**：7.1 递归入门、4.3 指针与字符串

第 4 章用循环数过字符串长度，现在用递归再写一遍：当前字符不是 `'\0'`，长度就是"1 加上后面字符串的长度"。

**要求**：

- 写函数 `size_t my_strlen_rec(const char *s);`，基线条件是 `*s == '\0'` 时返回 0。
- 返回值类型用 `size_t`，参数加 `const`。
- `main` 里对 `"hello"`、`"c"`、空串 `""` 各测一次，用 `%zu` 打印。

**示例运行**：

```text
hello 有 5 个字符
c 有 1 个字符
空串有 0 个字符
```

## 7.5 递归找数组最大值 ⭐⭐

**考察**：7.1 递归入门、7.4 分治思想

"整组的最大值"可以拆成两半看：第一个元素，和"剩下那一组"的最大值，谁大谁是答案。用递归把这句话翻译成代码。

**要求**：

- 写函数 `int find_max_rec(const int nums[], int count);`：基线条件 `count == 1` 时返回 `nums[0]`；否则先递归求"剩下 `count - 1` 个"的最大值，再和 `nums[0]` 比大小。
- `main` 里对 `{34, 67, 12, 89, 45, 23}` 测试，输出 `最大值：89`。

**示例运行**：

```text
最大值：89
```

## 7.6 递归给数组集体翻倍 ⭐⭐

**考察**：7.1 递归入门、4.2 指针算术（递归推进指针）

这次递归要"动手"不只"动嘴"：把数组的每个元素就地翻倍。每层递归处理当前第一个元素，剩下的交给下一层——递归参数 `nums + 1` 正是第 4 章的指针算术。

**要求**：

- 写函数 `void double_all(int nums[], int count);`：基线条件 `count == 0` 返回；否则把 `nums[0]` 翻倍，再递归处理 `nums + 1`、`count - 1`。
- 参数不带 `const`（这次要写）；`main` 里对 `{1, 2, 3, 4, 5}` 处理后打印全部元素。

**示例运行**：

```text
2 4 6 8 10 
```

## 7.7 回文判断 ⭐⭐⭐

**考察**：7.1 递归入门、4.3 指针与字符串、7.2 基线条件设计

"上海自来水来自海上"正读反读都一样，这样的词叫回文。递归判断的思路很优雅：看首尾两个字符是否相等，相等就把中间那段当成新的问题继续判断。

**要求**：

- 写函数 `int is_palindrome(const char *s, size_t len);`（`s` 是当前待判断的起点，`len` 是它的长度）：
  - 基线条件一：`len <= 1`（0 或 1 个字符）必是回文，返回 1；
  - 首尾不等返回 0；否则递归判断 `s + 1`、长度 `len - 2`。
- `main` 里对 `"level"`、`"abcba"`、`"hello"`、`"a"` 各判断一次，分别输出 `是回文` 或 `不是回文`。
- 提示：`len` 每层减 2，想清楚为什么减的是 2 不是 1。

**示例运行**：

```text
level：是回文
abcba：是回文
hello：不是回文
a：是回文
```

## 7.8 递归二分查找 ⭐⭐⭐

**考察**：7.4 汉诺塔与分治、7.1 递归入门

字典查单词不会从头翻到尾：翻到中间，比一比，只查一半。这就是分治。对有序数组 `{3, 8, 15, 22, 31, 40, 57}` 实现递归二分查找。

**要求**：

- 写函数 `int binary_search(const int nums[], int target, int low, int high);`：
  - 基线条件：`low > high` 说明找遍了，返回 -1；
  - 取中点 `mid = low + (high - low) / 2`（先想一下：为什么不直接写 `(low + high) / 2` 也行、但这个写法更稳？）；
  - 中点正好是目标返回 `mid`；目标更小递归查左半，更大递归查右半。
- `main` 里查 22（应得下标 3）、查 40（应得下标 5）、查 25（应得 -1）。

**示例运行**：

```text
22 的下标：3
40 的下标：5
25 的下标：-1
```

## 7.9 递归反转链表 ⭐⭐⭐

**考察**：7.5 递归操作链表、6.3 链表

第 7 章见识了递归打印链表的威力，现在升级：用递归把整条链**反转**。核心直觉是——先把"后面的那条子链"反转好，再把当前头节点接到子链的尾巴上。

**要求**：

- 实现 `create_node`、`push_back`、`print_list`、`free_list`（`malloc` 全检查）。
- 写函数 `struct node *reverse_list(struct node *head);`：
  - 基线条件：空链表或只剩一个节点，直接返回 `head`；
  - 递归反转 `head->next` 得到新头；然后让 `head->next` 的 `next` 指回 `head`，再把 `head->next` 置 `NULL`；返回新头。
- 建链 `10 -> 20 -> 30 -> 40`，打印、反转、再打印，最后释放整条链。
- 提示：画图！`head->next->next = head` 这一行值得盯着看一分钟。

**示例运行**：

```text
10 -> 20 -> 30 -> 40 -> NULL
40 -> 30 -> 20 -> 10 -> NULL
```

## 7.10 爬楼梯的走法 🌟

**考察**：7.1 递归入门、7.3 递归代价与改进、7.2 基线条件

学校教学楼的楼梯有 5 阶，你每步要么跨 1 阶、要么跨 2 阶。一共有多少种不同的上法？每种上法具体是怎么走的？这个问题和斐波那契是失散多年的兄弟——先只算数目，再打印所有路径。

**要求**：

- 写函数 `int count_ways(int steps);` 递归求走法数：`steps == 0` 算一种走法（一步都不跨也是一种），`steps < 0` 是 0 种；否则等于"先跨 1 阶的走法数 + 先跨 2 阶的走法数"。
- 写函数 `void print_paths(int steps, int path[], int len);` 用数组 `path` 记录当前路径（`len` 是已走的步数），走到 0 时按 `1+2+1` 的格式打印整条路径；能跨 1 就先递归跨 1，能跨 2 再递归跨 2。
- `main` 里对 5 阶楼梯输出走法总数和全部 8 条路径。
- 提示：只求数目时，`count_ways` 的结构和 7.3 的 `fib` 几乎一样——体会一下"斐波那契就藏在楼梯里"。如果阶数很大，-count_ways 会像朴素 fib 一样爆炸，想想第 7.3 节的解救办法（循环或记忆化）。

**示例运行**：

```text
5 阶台阶共有 8 种走法
所有走法：
1+1+1+1+1
1+1+1+2
1+1+2+1
1+2+1+1
1+2+2
2+1+1+1
2+1+2
2+2+1
```
