## 9.1 倒着报数 ⭐

**考察**：9.1 栈、9.1.2 用数组实现栈

军训教官让 5 名同学依次报数，记录下报的数字后，要求**从最后一名同学倒着报回来**。用数组栈实现：依次压入 `{7, 3, 9, 1, 5}`，再全部弹出打印，正好完成倒报。

**要求**：

- 定义 `struct stack { int data[MAX]; int top; };`，实现 `init`、`push`、`pop`。
- `push` 满栈、`pop` 空栈时用返回值 `false` 报告，不越界。
- 依次压入 5 个数，再循环弹出打印。

**示例运行**：

```text
正着报：7 3 9 1 5
倒着报：5 1 9 3 7
```

## 9.2 队伍不插队 ⭐

**考察**：9.2 队列、9.2.3 循环队列

打印店用一个任务队列接活。任务编号 `{301, 302, 303, 304}` 依次提交，必须按提交顺序打印。用循环队列完成入队，再全部出队打印，验证先进先出。

**要求**：

- 定义循环队列结构体（`data`、`head`、`tail`、`size`），实现 `init`、`enqueue`、`dequeue`，入队出队都要检查返回值。
- `enqueue`、`dequeue` 里下标前进都用 `(下标 + 1) % MAX`。
- 依次入队 4 个编号，再循环出队打印。

**示例运行**：

```text
提交任务：301 302 303 304
打印顺序：301 302 303 304
```

## 9.3 回文鉴定 ⭐⭐

**考察**：9.1 栈的应用

回文是正读反读都一样的词，比如 `level` 和 `noon`。鉴定思路：把字符串**前半段**的字符依次压栈，然后从中间往右走，每遇到一个字符就弹栈比较——弹出来的正好是前半段的倒序，一一相等就是回文。写程序鉴定 `level`、`noon`、`abcba` 和 `abc` 四个词。

**要求**：

- 用字符栈（`char data[MAX]` + `top`）实现。
- 写 `bool is_palindrome(const char word[])`：用循环数出字符串长度，前半段压栈，后半段逐个与弹栈字符比较。
- 中间那个字符（长度为奇数时）不需要比较。
- 对四个词各鉴定一次，打印结果。

**示例运行**：

```text
level：是回文
noon：是回文
abcba：是回文
abc：不是回文
```

## 9.4 循环队列慢镜头 ⭐⭐

**考察**：9.2.3 循环队列、9.2.4 转圈全过程

容量 `MAX = 4` 的循环队列，按下面的顺序动作：入队 1、2、3 → 出队一次 → 入队 4、5（这时 `tail` 应该绕回开头）→ 出队两次 → 入队 6。每一步动作后都打印 `head`、`tail`、`size`，像 9.2.4 那样逐帧回放。

**要求**：

- 实现带 `head`、`tail`、`size` 的循环队列，动作合法性都检查（队满入不了、队空出不了要有提示）。
- 每个动作后打印一行 `动作：head = X, tail = Y, size = Z`。
- 全部动作结束后，把队列里剩余的数据按出队顺序打印，确认顺序没有乱。

**示例运行**：

```text
入队 1：head = 0, tail = 1, size = 1
入队 2：head = 0, tail = 2, size = 2
入队 3：head = 0, tail = 3, size = 3
出队 → 1：head = 1, tail = 3, size = 2
入队 4：head = 1, tail = 0, size = 3
入队 5：head = 1, tail = 1, size = 4
出队 → 2：head = 2, tail = 1, size = 3
出队 → 3：head = 3, tail = 1, size = 2
入队 6：head = 3, tail = 2, size = 3
剩余数据：4 5 6
```

## 9.5 数一数叶子 ⭐⭐

**考察**：9.3 二叉树、9.3.5 递归小工具

手动搭出下面这棵树，写一个递归函数 `int count_leaves(const struct tree_node *root)` 数出**叶子节点**（左右指针都是 `NULL` 的节点）的个数。

## 9.6 BST 查找路径回放 ⭐⭐

**考察**：9.4 二叉查找树、9.4.3 查找

往 BST 里依次插入 `{50, 30, 70, 20, 40, 60, 80}` 建树。然后查找一个值时，不再只报告"找到没找到"，而是把**走过的路径**打印出来，像导航回放：`50 -> 30 -> 40`。分别查找 `60`（存在）和 `55`（不存在）各一次。

**要求**：

- 实现递归 `insert`（返回子树根并接回去）和中序遍历，先打印建好的树（升序）。
- 写 `bool search_path(const struct tree_node *root, int value)`：沿查找路线每经过一个节点就打印它的值，找到返回 `true`、走到空返回 `false`。
- 打印路径时用 ` -> ` 连接；没找到时最后打印 `(没找到)`。

**示例运行**：

```text
中序遍历：20 30 40 50 60 70 80
查找 60：50 -> 70 -> 60（找到）
查找 55：50 -> 70 -> 60（没找到）
```

## 9.7 范围筛选 ⭐⭐

**考察**：9.4 二叉查找树、9.4.1 家规

BST 的家规不只是查找的捷径，还是**范围查询**的捷径：中序遍历到达某节点时，如果它已经比下界小，整个左子树都可以跳过；比上界大，整个右子树都可以跳过。往 BST 插入 `{50, 30, 70, 20, 40, 60, 80, 35, 65}`，打印 `[35, 65]` 范围内的所有值（升序）。

**要求**：

- 实现递归 `insert` 和释放函数。
- 写 `void print_range(const struct tree_node *root, int low, int high)`，递归实现并**利用家规剪枝**：`root->data > low` 时才递归左子树，`root->data < high` 时才递归右子树。
- 打印范围内的值，最后一并打印这棵树的中序全量，便于核对。

**示例运行**：

```text
[35, 65] 范围内：35 40 50 60 65
全量中序：20 30 35 40 50 60 65 70 80
```

## 9.8 一层一层点名 ⭐⭐⭐

**考察**：9.2 队列、9.3 二叉树遍历

三种遍历都是"一头扎到底"的深度优先。还有另一种走法：**层序遍历**——先访问根，再访问根的两个孩子，再访问孩子的孩子……像点名一样一层一层来。它的实现要借助队列：访问一个节点时把它的左右孩子**入队**；下一个要访问的节点永远从**队头**出队。

手动搭出这棵树，用循环队列实现层序遍历：

```text
        50
       /  \
     30    70
    /  \   / \
  20   40 60  80
```

**要求**：

- 循环队列里存的是 `struct tree_node *` 指针（`data` 数组的元素类型改成指针即可），容量取够，入队出队检查返回值。
- 访问节点就是打印它的值；出队一个、打印一个、再把它的非空孩子入队，直到队空。
- 顺便打印前序遍历的结果作对照，体会两种走法的不同。
- 程序结束前释放整棵树。

**示例运行**：

```text
前序：50 30 20 40 70 60 80
层序：50 30 70 20 40 60 80
整棵树已释放
```

## 9.9 镜像树 ⭐⭐⭐

**考察**：9.3 递归遍历、9.4 二叉查找树

照镜子：把树里**每个节点的左右子树互换**，得到的树叫原树的镜像。往 BST 插入 `{50, 30, 70, 20, 40, 60, 80}`，写递归函数 `void mirror(struct tree_node *root)` 把它翻转成镜像，然后利用一个有趣的性质验收：BST 的中序是升序，**镜像树的中序恰好是降序**。

**要求**：

- 实现 `mirror`：递归出口空树直接返回；先互换当前节点的 `left` 和 `right`，再递归处理两个子树（先换后递归、先递归后换都行，想清楚为什么结果一样）。
- 翻转前打印中序（应升序），翻转后打印中序（应降序），作为验收标准。
- 程序结束前释放整棵树。

**示例运行**：

```text
翻转前中序：20 30 40 50 60 70 80
翻转后中序：80 70 60 50 40 30 20
整棵树已释放
```

## 9.10 数字集合管理器 🌟

**考察**：9.4 BST 插入与查找、9.5 BST 的删除、交互式菜单

维护一个"数字集合"：集合里的数不重复、随时可增可删、随时能按升序查看。这正好是 BST 的本职工作。写一个交互式管理器，主循环用 `scanf("%d", ...)` 读命令（检查返回值，非法命令提示后继续）：

```text
1 X：把 X 插入集合（已存在则提示）
2 X：把 X 从集合删除（不存在则提示）
3   ：升序打印集合全部元素
4 X：查找 X，打印找到或没找到
0   ：退出
```

**要求**：

- BST 插入、查找、删除都用"返回子树根并接回去"的递归套路（9.4、9.5）；删除按叶子、独子、双子三种情况处理，双子用右子树最小节点当替身。
- 每个操作后给出反馈（插入了、删掉了、集合为空等），反馈要和实际行为一致。
- 提示：空集合时选 3 要友好提示而不是什么都不做；程序退出前释放整棵树。解法不唯一，功能齐、边界稳就算好。

**示例运行**（输入 `1 50`、`1 30`、`1 70`、`1 30`、`3`、`2 50`、`3`、`4 70`、`0`）：

```text
命令：已插入 50
命令：已插入 30
命令：已插入 70
命令：集合里已有 30，没有重复插入
命令：集合共 3 个：30 50 70
命令：已删除 50
命令：集合共 2 个：30 70
命令：找到 70
命令：再见
```
