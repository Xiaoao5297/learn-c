## 4.1 一个指针轮流指挥三个变量 ⭐

**考察**：4.1 指针基础

便利店搞促销：三种商品原价分别是 3 元、4 元、5 元，全部翻倍。收银程序里只有一个指针可用——让它先指向第一种商品改价格，再指向第二种、第三种，逐个把价格翻倍。

**要求**：

- 定义 `int a = 3; int b = 4; int c = 5;` 和一个 `int *p`。
- 只通过 `p`（配合取地址和解引用）把三个变量依次翻倍，不允许写 `a *= 2` 这样的直接赋值。
- 一行输出三个变量的最终值。

**示例运行**：

```text
6 8 10
```

## 4.2 指针遍历气温数组 ⭐

**考察**：4.2 指针与数组

气象站把一周前 6 天的日平均气温存进了 `double` 数组 `{12.5, 13.0, 11.5, 14.2, 13.8, 12.9}`。值班员想练习一下指针算术：整个求和过程不许用下标 `[ ]`，只能用指针从头走到尾。

**要求**：

- 定义 `double *p` 从数组首元素出发，用 `p < 数组名 + 6` 做循环条件，循环里用 `p++` 前进。
- 循环体内只允许出现 `*p`，不允许出现 `数组名[i]`。
- 输出平均气温，保留两位小数。

**示例运行**：

```text
平均气温：12.98
```

## 4.3 只留字母 ⭐⭐

**考察**：4.3 指针与字符串、4.2 指针算术

日志清洗工具的第一步：把一条记录里的标点、数字、空格统统去掉，只留下英文字母。要求在原数组上就地完成——准备一读一写两个指针，读指针负责侦察，写指针负责安放幸存的字符。

**要求**：

- 写函数 `void keep_letters(char *s);`，把 `s` 中所有非英文字母的字符删掉（就地压缩，末尾补 `'\0'`），字母顺序不变。
- `main` 里对 `"He said: \"Hi, C!\" in 2026."` 处理后打印。
- 想一想：为什么两个指针最后要分别做一次收尾工作？

**示例运行**：

```text
只留字母：HesaidHiCin
```

## 4.4 文具库存盘点 ⭐⭐

**考察**：4.4 结构体、4.4 结构体数组

文具店月底盘点。每种商品有名称、单价、库存数量，定义成结构体数组：

| 名称 | 单价（元） | 库存 |
|------|-----------|------|
| 笔记本 | 5.0 | 20 |
| 钢笔 | 25.0 | 8 |
| 橡皮 | 1.5 | 50 |
| 尺子 | 3.0 | 30 |

**要求**：

- 定义 `struct item { char name[20]; double price; int stock; };` 并按上表初始化。
- 遍历数组，计算库存总金额（单价 × 库存再累加）。
- 找出占用金额最大的商品（可以记下标，也可以记指针），输出总金额和该商品信息。

**示例运行**：

```text
库存总金额：465.0 元
占用金额最多：钢笔（200.0 元）
```

## 4.5 电子表走一秒 ⭐⭐

**考察**：4.5 结构体与指针、4.4 嵌套进位

电子表用 `struct time { int hour; int minute; int second; };` 表示时间。写一个 `tick` 函数让时间前进一秒——别小看这一秒：59 秒要进位分钟，59 分要进位小时，23 点之后要回到 0 点。

**要求**：

- 写函数 `void tick(struct time *t);` 通过指针修改原结构体，处理秒、分、时的进位（24 小时制）。
- 再写 `void print_time(const struct time *t);` 按 `%02d:%02d:%02d` 格式打印（只读参数记得加 `const`）。
- `main` 里从 `23:59:59` 出发走一秒；再从 `10:30:40` 出发走一秒，各打印前后状态。

**示例运行**：

```text
23:59:59
00:00:00
10:30:40
10:30:41
```

## 4.6 让指针改指最大值 ⭐⭐

**考察**：4.6 const 与多级指针、4.2 指针与数组

仓库管理员手里有一个指针，想让函数帮他把这个指针"改指"到数组里最大值所在的元素——不是把最大值抄回来，而是让指针本身换目标。这正是二级指针的用武之地。

**要求**：

- 写函数 `void point_to_max(int **pp, const int *nums, int count);`：函数内部找到最大元素后，通过二级指针修改调用方的指针，让它指向最大元素。数组参数加 `const`。
- `main` 里数组为 `{34, 67, 12, 89, 45, 23}`，定义 `int *p = NULL;`，调用函数后用 `*p` 打印最大值。
- 再做一步验证：通过 `*p` 把最大值减 1，然后打印 `nums[3]`，证明 `p` 指向的确实是原数组的元素。

**示例运行**：

```text
最大值：89
减 1 后 nums[3] = 88
```

## 4.7 长方形小工具（多文件工程）⭐⭐

**考察**：4.7 多文件工程与 Makefile、4.5 结构体与指针

把长方形计算拆成一个小工程，体会"声明与实现分开"的分工：

```text
shape.h     struct rect 定义 + 两个函数声明 + 头文件卫士
shape.c     两个函数的实现
main.c      定义 {3.0, 4.0}，调用函数打印面积和周长
```

**要求**：

- `struct rect { double width; double height; };`。
- 函数 `double rect_area(const struct rect *r);` 和 `double rect_perimeter(const struct rect *r);`，参数用指针并加 `const`。
- 三个文件内容完整写出，并给出手工编译命令（`-std=c11 -Wall -Wextra -Werror -pedantic`）。
- 有余力的话再写一个 Makefile（含 `%.o: %.c shape.h` 的模式规则和 `clean` 目标）。

**示例运行**：

```text
面积：12.0
周长：14.0
```

## 4.9 拆分单词（指针数组）⭐⭐⭐

**考察**：4.6 多级指针、4.3 指针与字符串

命令行工具的雏形：把一句英文按空格拆成一个个单词。我们不改字符串的存储位置，而是用一组 `char *` 指针"指"到每个单词的开头——这其实就是指针数组（`char *tokens[]`，本质是二级指针的用法）。

**要求**：

- 写函数 `void split_words(char *s, char *tokens[], int max, int *count_out);`：
  - 跳过连续空格，把每个单词的首地址记进 `tokens`；
  - 把每个单词后面的空格改成 `'\0'`，让 `tokens[i]` 正好是一个完整单词；
  - 单词个数通过 `*count_out` 带回；超过 `max` 个就停。
- `main` 里对 `"c is fun and fast"` 拆分（`tokens` 容量 10），打印单词个数和每个 `tokens[i]`。

**示例运行**：

```text
共 5 个单词
tokens[0] = c
tokens[1] = is
tokens[2] = fun
tokens[3] = and
tokens[4] = fast
```

## 4.10 水果店进货与售卖 🌟

**考察**：4.4 结构体、4.5 结构体与指针、4.5 常见错误自查、4.7 多文件工程（选做）

你帮学校门口的水果店写一个库存小程序。店里 3 种水果：苹果 5.5 元/斤剩 30 斤、香蕉 3.8 元/斤剩 40 斤、橙子 6.2 元/斤剩 25 斤。程序要能进货、能售卖、能盘点。

**要求**：

- 定义 `struct fruit { char name[20]; double price; int stock; };` 并初始化上表。
- 写函数 `void add_stock(struct fruit *f, int amount);` 进货（库存增加）。
- 写函数 `int sell_fruit(struct fruit *f, int amount);` 售卖：库存够就减掉并返回 1，不够就一个都不卖、返回 0。
- 写 `void print_fruit(const struct fruit *f);` 打印单种水果。
- `main` 里演示：给苹果进货 10 斤；卖 15 斤香蕉（应成功）；试图卖 100 斤香蕉（应失败并提示）；最后逐个打印 3 种水果和库存总价值（单价 × 库存求和）。
- 提示：检查一下每个指针参数该不该加 `const`——该加没加、不该加乱加都会被扣分哦。学有余力可以把程序拆成 `fruit.h`、`fruit.c`、`main.c` 加 Makefile。

**示例运行**：

```text
卖出 15 斤香蕉
香蕉库存不足，没卖成
苹果 5.5 元/斤，剩 40 斤
香蕉 3.8 元/斤，剩 25 斤
橙子 6.2 元/斤，剩 25 斤
库存总价值：470.0 元
```
