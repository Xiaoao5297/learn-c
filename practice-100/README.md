# 练习 100 题

这是配套《从零开始学 C 语言》的刷题场：每章 10 道编程题，全书共 100 题。题目全部取材于日常场景，覆盖前面章节学过的语法和思想；难度按 ⭐ → ⭐⭐ → ⭐⭐⭐ → 🌟 递增，每章固定 2 道简单、5 道普通、2 道较难、1 道灵活运用。建议先完成对应章的全部小节练习和章末测试，再来挑战本章题目；做完后再对照 `solutions/` 里的参考答案核对自己思路。

各章参考答案见 [solutions/](<solutions/>)。

使用建议：

- 按 1 到 10 章顺序做，题目只依赖出现过的知识点，不要跳章。
- 先自己写、自己编译、自己跑，卡住超过半小时再看提示或答案。
- 对照答案时重点关注思路和规范（缩进、命名、边界检查），而不是背代码。
- 带交互的题目可以用管道喂输入：`cc -std=c11 -Wall main.c && ./a.out < 输入.txt`。
