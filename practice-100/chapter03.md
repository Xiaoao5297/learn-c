## 3.1 值日表查询机 ⭐

**考察**：3.1 数组（声明、初始化、下标访问）

班里的值日表存在一个字符串数组里，下标 0 到 4 对应周一到周五。输入星期序号，输出当天谁值日。

**要求**：

- 定义 `const char *duty[5] = {"小明", "小红", "小刚", "小丽", "小强"};`（第 4 章会详细讲指针，这里照抄即可）。
- 读入一个 `int` 序号，检查 `scanf` 的返回值，不合法时输出 `输入格式不对` 并返回 1；超出 0 到 4 时输出 `没有这一天` 并返回 1。
- 输出 `周X 值日：名字`，其中星期几用"一 二 三 四 五"中的一个汉字表示（提示：也放进一个数组里查）。

**示例运行**：

```text
请输入星期序号（0 到 4）：
3
周四 值日：小丽
```

## 3.2 眼保健操节拍器 ⭐

**考察**：3.1 数组遍历、3.5 数组与函数（数组传参）

眼保健操每一节的拍数不同。把 8 节的拍数放进数组，用函数逐节打印。

**要求**：

- 定义 `const int beats[8] = {8, 8, 8, 16, 8, 8, 8, 16};`。
- 写函数 `void print_beats(const int beats[], int count);` 每节输出一行 `第 X 节：N 拍`（X 从 1 开始）。
- `main` 里调用它，并最后输出 `共 N 拍`（总拍数也用一个函数算，别在 `main` 里现算）。

**示例运行**（只展示前 3 行，实际输出 8 行加一行合计）：

```text
第 1 节：8 拍
第 2 节：8 拍
第 3 节：8 拍
...
共 80 拍
```

## 3.3 成绩段人数统计 ⭐⭐

**考察**：3.1 数组遍历、3.2 条件判断（结合第 2 章）

老师给一次测验做分段统计：优秀（90 及以上）、良好（80 到 89）、及格（60 到 79）、不及格（60 以下）。

**要求**：

- 定义 `const int scores[10] = {95, 58, 72, 88, 61, 90, 45, 83, 76, 66};`。
- 用四个计数器（也放进一个长度 4 的数组，下标对应四个档位）统计各段人数。
- 输出四行，格式如 `优秀：3 人`，顺序是优秀、良好、及格、不及格。
- 最后输出 `总人数：10 人`（用 `sizeof` 算出元素个数，不要写死 10）。

**示例运行**：

```text
优秀：2 人
良好：2 人
及格：4 人
不及格：2 人
总人数：10 人
```

## 3.4 座位表调换 ⭐⭐

**考察**：3.2 二维数组、3.1 数组遍历

教室座位是 3 行 4 列，每个位置坐一个学号。体育老师要把"前后相邻两行"整体对调（第 1 行和第 2 行互换，第 3 行不动），打印调换后的新座位表。

**要求**：

- 定义 `int seats[3][4] = {{11, 12, 13, 14}, {21, 22, 23, 24}, {31, 32, 33, 34}};`。
- 定义一个新的 3 行 4 列数组存放结果：新表的第 0 行放旧表第 1 行，新表第 1 行放旧表第 0 行，新表第 2 行照抄旧表第 2 行。
- 按行打印新座位表，每个学号占 3 位宽度（`%3d`），同一行的数字之间用空格分隔。
- 行数和列数用宏定义，别写死数字。

**示例运行**：

```text
 21  22  23  24
 11  12  13  14
 31  32  33  34
```

## 3.5 单词长度分布 ⭐⭐

**考察**：3.3 字符串基础（strlen、字符数组遍历）

语言课上要分析一句话里每个单词的长度。用 `fgets` 读入一行（单词之间只用一个空格分隔，没有标点），逐个单词统计长度并输出。

**要求**：

- 用 `fgets` 读一行（数组 128 字节），去掉行尾 `'\n'`。
- 从头到尾扫描字符数组（不要用 `string.h` 里的 strtok 等函数，本章还没教）：遇到空格说明一个单词结束，输出 `单词 N：长度 L`（N 从 1 开始，L 是该单词的字符数，用 `%zu` 打印）。
- 行尾的最后一个单词别忘了输出。
- 最后输出 `共 N 个单词`。

**示例运行**（输入 `I love C language`）：

```text
请输入一行英文：
单词 1：长度 1
单词 2：长度 4
单词 3：长度 1
单词 4：长度 8
共 4 个单词
```

## 3.6 谁在名单里 ⭐⭐

**考察**：3.4 字符串函数（strcmp）、3.1 数组遍历

班里点名系统：给一个名单数组和要查找的名字，输出他排第几，或者不在名单里。

**要求**：

- 定义 `const char *roster[6] = {"anna", "ben", "cindy", "david", "elena", "frank"};`。
- 读入一个要查找的名字（`char target[32];` 配 `scanf("%31s", ...)`），检查返回值。
- 写函数 `int find_name(const char *roster[], int count, const char target[]);` 用 `strcmp` 逐个比较，找到返回下标，找不到返回 -1。
- 找到输出 `ben 在名单第 2 位`（第几位从 1 数起），找不到输出 `ben 不在名单里`（名字换成实际输入）。
- 名单本题固定，不需要读入。

**示例运行**：

```text
请输入要查找的名字：
david
david 在名单第 4 位
```

## 3.7 身份证生日提取 ⭐⭐

**考察**：3.3 字符串基础、3.4 字符串函数（strncpy 或逐字符复制）

身份证号第 7 到 14 位是出生年月日。写程序从 18 位号码里把 `YYYY-MM-DD` 提取出来。

**要求**：

- 读入一个 18 位身份证号（`char id[32];` 配 `scanf("%31s", ...)`），检查返回值。
- 检查长度：`strlen` 不等于 18 时输出 `号码长度不对` 并返回 1。
- 用循环或 `strncpy` 把第 7 到 10 位、第 11 到 12 位、第 13 到 14 位分别复制到三个 `char` 数组（记得补 `'\0'`），再拼成 `YYYY 年 MM 月 DD 日` 输出。
- 拼接建议用 `snprintf`，目标数组至少 64 字节。

**示例运行**：

```text
请输入 18 位身份证号：
110101200808154321
出生日期：2008 年 08 月 15 日
```

## 3.8 拼接与裁剪 ⭐⭐⭐

**考察**：3.4 字符串函数（snprintf、strstr、strlen）

文件管理器要拼路径，还要判断路径里有没有 `tmp` 目录。

**要求**：

- 读入两个单词：目录名和文件名（各用 `char` 数组配 `%31s`），检查返回值。
- 用 `snprintf` 拼成 `目录名/文件名` 的形式（目录名和文件名之间插入 `/`），目标数组 96 字节。
- 输出拼接结果。
- 用 `strstr` 判断拼接结果里是否包含子串 `tmp`：包含输出 `路径包含 tmp`，否则输出 `路径不包含 tmp`。
- 再输出拼接结果的长度（`%zu`）。

**示例运行**：

```text
请输入目录名：
var
请输入文件名：
log.txt
拼接结果：var/log.txt
路径不包含 tmp
长度是 11
```

## 3.9 十字路口的红绿灯统计 ⭐⭐⭐

**考察**：3.1 数组、3.2 二维数组、3.5 数组与函数

一个路口 7 天里每天的红灯、绿灯、黄灯时长（秒）记录在一张 7 行 3 列的表里。写程序统计：每种灯 7 天总时长、每天三种灯合计时长，以及合计时长最少的一天。

**要求**：

- 定义 `const int lights[7][3] = {{120, 300, 30}, {110, 310, 25}, {130, 290, 35}, {115, 305, 28}, {125, 295, 32}, {140, 280, 40}, {105, 315, 22}};`（每行依次是红、绿、黄）。
- 写函数 `int column_sum(const int table[][3], int rows, int col);` 返回第 `col` 列 7 天之和。
- 写函数 `int row_sum(const int table[][3], int row);` 返回某一天三种灯的合计。
- 输出 3 行 `红灯总时长：N 秒`（绿、黄同理，顺序红绿黄）。
- 输出 7 行 `第 X 天合计：N 秒`（X 从 1 开始）。
- 输出 `合计最少的是第 X 天，共 N 秒`（用循环找出最小行）。
- 行列数用宏定义。

**示例运行**（只展示前 3 天合计行，实际要打满 7 行）：

```text
红灯总时长：845 秒
绿灯总时长：2095 秒
黄灯总时长：212 秒
第 1 天合计：450 秒
第 2 天合计：445 秒
第 3 天合计：455 秒
...
合计最少的是第 7 天，共 442 秒
```

## 3.10 文章编辑小助手 🌟

**考察**：3.3 字符串基础、3.4 字符串函数、3.1 数组遍历、3.5 数组与函数

你在写一个极简文本处理工具，读入一行英文（只有小写字母和空格），做三件事：

1. 统计字符总数（不含空格）和空格数。
2. 把每个单词的首字母改成大写（小写字母减 32 即可），输出改好的整行。
3. 统计长度超过 3 个字母的单词个数。

生活里的写作软件（字数统计、自动大写标题）就是这个套路的放大版。鼓励把"统计"和"改写"写成独立函数，`main` 只负责串流程。

**要求**：

- 用 `fgets` 读一行（数组 128 字节），去掉行尾 `'\n'`。
- 写函数 `void count_chars(const char line[], size_t *letters, size_t *spaces);` 统计字母和空格数。
- 写函数 `void capitalize(char line[]);` 原地把每个单词首字母改成大写（空格后的第一个字符，以及行首第一个字符）。
- 写函数 `size_t count_long_words(const char line[]);` 统计长度超过 3 的单词个数（逐字符扫描，不要用 `strtok`）。
- 依次输出：

```text
字母 N 个，空格 M 个
改写后：……
长单词 K 个
```

- 全程可以使用 `<string.h>` 里学过的函数（`strlen`、`strstr` 等），但单词切分必须自己逐字符扫描。

**示例运行**（输入 `the quick brown fox`）：

```text
请输入一行英文：
字母 16 个，空格 3 个
改写后：The Quick Brown Fox
长单词 2 个
```
