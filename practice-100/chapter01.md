## 1.1 自我介绍卡片 ⭐

**考察**：1.3 第一个 C 程序

小林想给新同学做一张纯文本的"自我介绍卡片"，全程只用 `printf` 完成，不需要读入任何东西。

**要求**：

- 第一行输出 `=== 自我介绍 ===`。
- 第二行输出 `名字：小林`。
- 第三行输出 `爱好："打篮球"和"听音乐"`（注意引号要原样打出来）。
- 第四行输出 `目标：`，随后用 `\t` 缩进另起两行，分别输出 `学会 C 语言` 和 `写出自己的小程序`。

**示例运行**：

```text
=== 自我介绍 ===
名字：小林
爱好："打篮球"和"听音乐"
目标：
	学会 C 语言
	写出自己的小程序
```

## 1.2 字符的左右邻居 ⭐

**考察**：1.4 变量与数据类型、1.5 scanf 与输入

`char` 本质上是整数，字符可以参与加减运算。这个性质可以做出一个"字符密码表"小游戏。

**要求**：

- 读入一个小写字母（`scanf` 的格式串写成 `"%c"` 前面带一个空格，即空格加 `%c`，用来跳过残留的回车）。
- 检查 `scanf` 的返回值，输入不合法时输出 `输入格式不对` 并返回 1。
- 输出它在字母表里的左邻和右邻：例如输入 `b`，输出 `左边邻居是 a，右边邻居是 c`。
- 不允许写 `if` 判断（下一章才学），直接用字符加减完成。

**示例运行**：

```text
请输入一个小写字母：
b
左边邻居是 a，右边邻居是 c
```

## 1.3 长方形面积与周长计算器 ⭐⭐

**考察**：1.4 变量与数据类型、1.5 scanf 与输入

帮小学弟写一个几何小工具：输入长方形的长和宽，算出面积和周长。

**要求**：

- 依次读入两个 `double`：长、宽。
- 每次读入都检查 `scanf` 的返回值，不合法时输出 `输入格式不对` 并返回 1。
- 输出面积和周长，都保留 2 位小数。
- 只用本章学过的四则运算，不使用条件判断。

**示例运行**：

```text
请输入长：
3.5
请输入宽：
2.0
面积是 7.00
周长是 11.00
```

## 1.4 找零钱计算器 ⭐⭐

便利店收银台要打一张"找零小票"：读入商品总价和顾客支付的金额，算出找零。

- 依次读入两个 `double`：总价、支付金额。

**示例运行**：

```text

12.5

20.0
总价 12.50 元，支付 20.00 元
```

## 1.6 温度双刻度表 ⭐⭐

**考察**：1.3 printf 占位符、1.4 常量、1.5 scanf 与输入

气象小组记录温度时同时需要摄氏和华氏两个刻度。华氏度公式是 `F = C * 9 / 5 + 32`。

**要求**：

- 读入一个 `double` 表示摄氏温度。
- 检查 `scanf` 的返回值，不合法时输出 `输入格式不对` 并返回 1。
- 用 `const double` 定义公式里的两个系数 9.0 和 5.0（不要直接把数字写进公式）。
- 用一行 `printf` 同时输出两个值，各保留 1 位小数，格式如 `21.5 C = 70.7 F`。

**示例运行**：

```text
请输入摄氏温度：
21.5
21.5 C = 70.7 F
```

## 1.7 大写字母的编号密码 ⭐⭐

**考察**：1.4 变量与数据类型（char 与 ASCII）、1.5 scanf 与输入

间谍组织用"字母编号"传递消息：`A` 的编号是 0，`B` 的编号是 1，以此类推（也就是字母与大写 `A` 的 ASCII 编码差）。

**要求**：

- 读入一个大写字母（`scanf` 的格式串同样要在 `%c` 前加一个空格）。
- 检查 `scanf` 的返回值，不合法时输出 `输入格式不对` 并返回 1。
- 输出 `它比 A 大 N 个编号`，其中 `N` 用字符减法算出来，不要背 ASCII 表写死数字。

**示例运行**：

```text
请输入一个大写字母：
F
它比 A 大 5 个编号
```

## 1.8 三人身高体重登记表 ⭐⭐⭐

**考察**：1.3 转义字符与 printf、1.4 变量与数据类型、1.5 scanf 与输入

体育老师要登记三个学生的身高和体重，并打出一张对齐的表格。表格用 `名字`、`身高(cm)`、`体重(kg)` 三列，列与列之间用 `\t` 分隔，最后输出三个人的平均身高和平均体重。

**要求**：

- 循环读入 3 组数据：每次先读姓名（`char name[32];` 配 `%31s`），再读身高和体重（`double`）。
- 每次读入都检查 `scanf` 的返回值，任何一个不合法就输出 `输入格式不对` 并返回 1。
- 表头一行输出 `名字	身高(cm)	体重(kg)`，随后每人一行，各列用 `\t` 分隔，身高体重保留 1 位小数。
- 最后一行输出 `平均身高 X.X cm，平均体重 Y.Y kg`，保留 1 位小数。
- 平均值要除以 `3.0`，避免整数除法问题。

**示例运行**：

```text
请依次输入第 1 位学生的姓名、身高、体重：
小明
172.5
60.0
请依次输入第 2 位学生的姓名、身高、体重：
Helen
165.0
52.5
请依次输入第 3 位学生的姓名、身高、体重：
大卫
180.0
75.0
名字	身高(cm)	体重(kg)
小明	172.5	60.0
Helen	165.0	52.5
大卫	180.0	75.0
平均身高 172.5 cm，平均体重 62.5 kg
```

## 1.9 批改作业的小助手 ⭐⭐⭐

**考察**：1.5 输入校验三件套（检查返回值、检查范围、清空缓冲区）

老师批改作业需要一个"安全读数"程序：反复读入一个 0 到 100 之间的整数分数，直到输入合法为止，然后输出一句评语信息（本题只输出分数本身，条件评语下一章再做）。

**要求**：

- 输入不是整数时：输出 `输入的不是整数，请重新输入`，用 `getchar` 循环清空一行缓冲区，继续等待输入。
- 输入的整数超出 0 到 100 时：输出 `范围不对，请重新输入`。
- 输入合法后输出 `分数是 N`。
- 全部用 `while` 循环完成。

**示例运行**（输入依次是 `abc`、`120`、`85`）：

```text
请输入一个 0 到 100 的整数：
输入的不是整数，请重新输入
请输入一个 0 到 100 的整数：
范围不对，请重新输入
请输入一个 0 到 100 的整数：
分数是 85
```

## 1.10 我的每周零花钱账本 🌟

**考察**：1.3 printf 对齐、1.4 变量与数据类型、1.5 scanf 与输入

小林每周领零花钱，想做一个记账小工具：输入本周每天的零花钱，输出一张对齐的账单，包括总金额和平均每天金额。

生活里类似的小工具还有：食堂一周饭钱统计、小组活动经费合计。它们的套路都一样——**读入一组数，算总和，算平均值，对齐输出**。

**要求**：

- 循环读入 7 个 `double`，代表周一到周日的零花钱，每次读入都检查 `scanf` 的返回值，不合法时输出 `输入格式不对` 并返回 1。
- 用 `const` 定义天数 7.0，不要在除法里直接写死数字。
- 先输出 7 行 `周X：N.N 元`（X 是一到日，保留 1 位小数）。
- 再输出 `本周合计：T.T 元` 和 `平均每天：A.A 元`，各保留 2 位小数。
- 全部只用本章知识：变量、`printf`、`scanf`、循环还不用写——可以用 7 组"读入 + 输出"顺序完成，鼓励你想想：有没有办法少写几行重复代码？（第 2 章的循环会给出正式答案，现在允许你"笨办法"先跑通。）

**示例运行**（以 3 天为例，题目要求 7 天，运行示例略作压缩，你按 7 天实现）：

```text
请输入周一的零花钱：
10.0
请输入周二的零花钱：
5.5
请输入周三的零花钱：
8.0
周X：10.0 元
```
