# 第7章：递归 —— 让函数学会"召唤自己" 🪆

## 📖 本章导读

还记得第6章结尾的预告吗？

> "第7章我们会用'递归'这种新思维方式，去优雅地解决很多问题（包括用递归写链表操作！）——链表和递归是天作之合。"

什么是**递归（Recursion）**？一句话：**函数自己调用自己**。

听起来像在"绕圈子"，但别小看它——生活中处处是递归：

- 🪆 **俄罗斯套娃**：打开一个娃娃，里面还是一个更小的娃娃，最小的娃娃里面什么都没有
- 🪞 **两面镜子对着照**：镜子里有镜子，镜子里的镜子里还有镜子……
- 📖 **查词典**：词的解释里又出现生词，再去查那个词……

这些事都有一个共同规律：**一件"大"的事，里面套着一件结构一模一样、只是"更小"的事**，小到不能再小就停下来。

递归正是抓住了这个规律：**把大问题拆成一个"小一号的自己"，交给函数自己处理，直到问题小到"一眼就能答出来"。**

在本章中，我们将一起：

- 🪆 **认识递归** —— 理解"自己调用自己"，学会写第一个递归函数
- 🧳 **看懂递归的"后台"** —— 计算机到底是怎么执行递归的？（调用栈）
- 🐰 **斐波那契** —— 体会递归的"甜"与"代价"，学会"该不该用递归"
- 🗼 **汉诺塔与分而治之** —— 挑战经典，体会"大事化小"与"分而治之"的威力
- 🔗 **用递归驯服链表** —— 逆序打印、数节点、释放整条链，一行递归顶十行循环

## 🎯 学习目标

完成本章后，你将能够：

1. ✅ 说出递归是什么，能找出递归的"出口"（基线条件）
2. ✅ 画出递归的执行过程，理解函数调用栈
3. ✅ 写出阶乘、求和、斐波那契、汉诺塔等经典递归
4. ✅ 用递归处理链表（逆序打印、数节点、释放），并知道何时该用循环

## 💡 学习建议

> 📌 **递归是思维方式的转变，不是新语法！**
>
> 递归用的还是普通函数，难的只是"换个角度看问题"。
> 
> - 🖌️ **一定画图**：把每次调用"摊开"画成一摞卡片，比空想清楚一百倍
> - 🐢 **先找出口**：写递归前，先问自己"最小的情况是什么、答案是什么"
> - ✋ **相信递归**：递归的一大难关是"不敢信任它"。认准两步——出口正确 + 参数在变小，就可以大胆让函数自己调用自己
> - 💻 **亲手敲一遍**：多改几行、多看几次输出，慢慢就"开窍"了

准备好了吗？让函数学会"召唤自己"！👇
