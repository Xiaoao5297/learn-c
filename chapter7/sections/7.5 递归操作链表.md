# 7.5 递归操作链表

第 6 章用循环操作链表：遍历要维护一个 `cur` 指针，释放要先记下 `next` 再 `free`。这一章快结束时回头看链表，会发现它和递归是天生一对——**一条链表，本身就是“一个节点 + 一条更短的链表”**。

```text
链表 = 第一个节点 + 剩下的链表
空链表（NULL） = 什么都不用做
```

前半句是递归步骤，后半句是基线条件。这一节把链表操作逐个改成递归写法，并和循环版对比。

## 7.5.1 自建节点类型

本章的编号示例都要独立编译运行，而且这一节不再依赖第 6 章的工程文件，每个示例在自己的文件里定义同一个节点类型：

```c
struct node {
	int data;
	struct node *next;
};
```

最简单的测试链表可以直接在栈上搭出来——先造最后一个节点，再往前接：

```c
struct node third = {30, NULL};
struct node second = {20, &third};
struct node first = {10, &second};
struct node *head = &first;
```

`head` 指向 `first`，`first` 的 `next` 指向 `second`，以此类推，一条 `10 -> 20 -> 30` 的链表就绪了。这种写法省去了 `malloc`，适合演示；动态建链（`malloc` + 尾插）在 7.5.5 会见到。

## 7.5.2 递归遍历：正序与逆序打印

先看正序打印，第 6 章的循环版长这样：

```c
for (struct node *cur = head; cur != NULL; cur = cur->next) {
	printf("%d -> ", cur->data);
}
printf("NULL\n");
```

递归版用一句话表达同一件事：**打印头节点，然后把“剩下的链表”交给递归；链表为空就换行结束。**

逆序打印只要把 `printf` 挪到递归调用**之后**（7.2.3 的顺序魔法）：先一路递归到链表末尾，归来时再打印，自然从后往前。

```c
// 7.5.2 list_print.c
#include <stdio.h>

struct node {
	int data;
	struct node *next;
};

void print_list(struct node *head)
{
	if (head == NULL) {
		printf("NULL\n");
		return;
	}
	printf("%d -> ", head->data);
	print_list(head->next);
}

void print_reverse(struct node *head)
{
	if (head == NULL) {
		return;
	}
	print_reverse(head->next);
	printf("%d -> ", head->data);
}

int main(void)
{
	struct node third = {30, NULL};
	struct node second = {20, &third};
	struct node first = {10, &second};
	struct node *head = &first;

	print_list(head);

	print_reverse(head);
	printf("NULL\n");

	return 0;
}
```

<!-- output: 7.5.2 -->
```text
10 -> 20 -> 30 -> NULL
30 -> 20 -> 10 -> NULL
```

递归版连 `cur` 指针都不需要——“下一个要处理的节点”就写在递归参数里，由调用栈替你记着。逆序打印尤其能看出差距：循环版想倒着来，得先把数据倒进数组再反向输出；递归版只是把 `printf` 挪了一行。

## 7.5.3 计数与求和

节点数：空链表 0 个；否则是 1 加上后面那条链的节点数。求和：空链表和为 0；否则是头节点的 `data` 加上后面那条链的和。

```c
// 7.5.3 list_stats.c
#include <stdio.h>

struct node {
	int data;
	struct node *next;
};

int count_nodes(struct node *head)
{
	if (head == NULL) {
		return 0;
	}
	return 1 + count_nodes(head->next);
}

int sum_list(struct node *head)
{
	if (head == NULL) {
		return 0;
	}
	return head->data + sum_list(head->next);
}

int main(void)
{
	struct node third = {30, NULL};
	struct node second = {20, &third};
	struct node first = {10, &second};
	struct node *head = &first;

	printf("节点数：%d\n", count_nodes(head));
	printf("总和：%d\n", sum_list(head));

	return 0;
}
```

<!-- output: 7.5.3 -->
```text
节点数：3
总和：60
```

答案是在**归来**的路上组装的：

```text
count_nodes(NULL) = 0
count_nodes(30)   = 1 + 0 = 1
count_nodes(20)   = 1 + 1 = 2
count_nodes(10)   = 1 + 2 = 3
```

这一节的三个函数长得越来越像了——出口都是 `head == NULL`，递归步骤都是“处理 `head->data` + 递归处理 `head->next`”。链表递归操作基本就是一个模板，换成不同的“处理动作”，就得到打印、计数、求和、查找等一排函数。

## 7.5.4 递归查找与整链释放

**查找**：空链表没有；头节点命中就返回 1；否则去后面的链里找。

**释放**：先递归释放后面的链，再 `free` 自己。顺序不能反——`free(head)` 之后 `head->next` 已经是悬垂访问（6.2 讲过的内存陷阱），而递归写法天然把“后面”放在前面处理。

```c
// 7.5.4 list_free.c
#include <stdio.h>
#include <stdlib.h>

struct node {
	int data;
	struct node *next;
};

int contains(struct node *head, int value)
{
	if (head == NULL) {
		return 0;
	}
	if (head->data == value) {
		return 1;
	}
	return contains(head->next, value);
}

int free_list(struct node *head)
{
	if (head == NULL) {
		return 0;
	}
	int count = free_list(head->next);
	free(head);
	return count + 1;
}

int main(void)
{
	struct node *n1 = malloc(sizeof(struct node));
	struct node *n2 = malloc(sizeof(struct node));
	struct node *n3 = malloc(sizeof(struct node));

	if (n1 == NULL || n2 == NULL || n3 == NULL) {
		free(n1);
		free(n2);
		free(n3);
		return 1;
	}

	n1->data = 10;
	n1->next = n2;
	n2->data = 20;
	n2->next = n3;
	n3->data = 30;
	n3->next = NULL;

	struct node *head = n1;
	printf("有 20 吗：%d\n", contains(head, 20));
	printf("有 99 吗：%d\n", contains(head, 99));

	int freed = free_list(head);
	printf("释放了 %d 个节点\n", freed);
	head = NULL;

	return 0;
}
```

<!-- output: 7.5.4 -->
```text
有 20 吗：1
有 99 吗：0
释放了 3 个节点
```

释放后把 `head` 置 `NULL` 是第 6 章的老规矩，防止悬垂指针。`free_list` 里 `free` 放在递归之后，和 7.5.2 的 `print_reverse` 同一个结构——“先处理剩下的，再处理自己”。

## 7.5.5 综合实战：递归链表工具箱

最后把动态建链和这一节的递归函数拼成一个完整程序：`malloc` 逐个建节点、尾插成链，递归打印、计数、查找，最后递归释放：

```c
// 7.5.5 list_tools.c
#include <stdio.h>
#include <stdlib.h>

struct node {
	int data;
	struct node *next;
};

struct node *create_node(int value)
{
	struct node *n = malloc(sizeof(struct node));
	if (n == NULL) {
		return NULL;
	}
	n->data = value;
	n->next = NULL;
	return n;
}

void print_list(struct node *head)
{
	if (head == NULL) {
		printf("NULL\n");
		return;
	}
	printf("%d -> ", head->data);
	print_list(head->next);
}

void print_reverse(struct node *head)
{
	if (head == NULL) {
		return;
	}
	print_reverse(head->next);
	printf("%d -> ", head->data);
}

int count_nodes(struct node *head)
{
	if (head == NULL) {
		return 0;
	}
	return 1 + count_nodes(head->next);
}

int contains(struct node *head, int value)
{
	if (head == NULL) {
		return 0;
	}
	if (head->data == value) {
		return 1;
	}
	return contains(head->next, value);
}

void free_list(struct node *head)
{
	if (head == NULL) {
		return;
	}
	free_list(head->next);
	free(head);
}

int main(void)
{
	struct node *head = NULL;
	struct node *tail = NULL;

	int values[4] = {10, 20, 30, 40};

	for (int i = 0; i < 4; i++) {
		struct node *n = create_node(values[i]);
		if (n == NULL) {
			free_list(head);
			return 1;
		}
		if (head == NULL) {
			head = n;
		} else {
			tail->next = n;
		}
		tail = n;
	}

	print_list(head);

	print_reverse(head);
	printf("NULL\n");

	printf("节点数：%d\n", count_nodes(head));
	printf("有 30 吗：%d\n", contains(head, 30));
	printf("有 99 吗：%d\n", contains(head, 99));

	free_list(head);
	head = NULL;

	return 0;
}
```

<!-- output: 7.5.5 -->
```text
10 -> 20 -> 30 -> 40 -> NULL
40 -> 30 -> 20 -> 10 -> NULL
节点数：4
有 30 吗：1
有 99 吗：0
```

建链部分（`create_node` 加循环尾插）用的是第 6 章的循环写法——建链本来就是一个“从头走到尾”的顺序过程，循环正合适。**递归用在该用的地方（打印、计数、查找、释放），而不是处处递归。**

## 7.5.6 递归还是循环：链表的答案

| 操作 | 递归版 | 循环版 | 建议 |
|------|--------|--------|------|
| 正序遍历 | 短，出口清晰 | 同样短，无调用开销 | 都可以，长链用循环 |
| 逆序打印 | 一行挪位置就搞定 | 要先存数组再反向 | 递归明显占优 |
| 计数、求和 | 出口 + 一行递推 | 循环 + 变量累加 | 都可以 |
| 释放整条链 | 先递归后 `free`，顺序自然 | 先存 `next` 再 `free` | 都可以，顺序都是生命线 |

关键变量是**链表长度**。递归每层压一个栈帧（7.2.6），链表有 1 万个节点，递归就深 1 万层——通常不会溢出，但几十万、上百万节点的长链就可能把栈撑爆。所以：**短链、教学、原型代码用递归，图它清晰；生产环境处理不定长链表，遍历类操作用循环更稳。** 这和 7.3 的结论呼应：选型看的是问题规模和结构，不是个人口味。

## 7.5.7 小结

- 链表天然是递归结构：链表 = 头节点 + 更短的链表，`NULL` 是基线条件。
- 递归遍历模板：出口 `head == NULL`，处理 `head->data`，递归 `head->next`。
- `printf` 放在递归调用之前是正序，放在之后是逆序——调用栈替你省了辅助数组。
- 计数、求和、查找是同一模板的变体，答案在归来路上组装。
- 递归释放必须先释放后面再 `free` 自己，顺序反了就是悬垂访问。
- 长链的递归深度等于链表长度，超长链表用循环防爆栈。

4. 下面这个释放函数错在哪？

void free_list(struct node *head)

		return;

5. 编程题：写递归函数 `int max_node(struct node *head);`，返回链表中的最大值（假定链表非空）。出口：只有一个节点时返回它的 `data`；递推：`max` 取“头节点 data”和“后面链表的最大值”中较大者。用 `10 -> 25 -> 7` 测试，预期输出 `最大值：25`。
6. 编程题：写递归函数 `int is_sorted(struct node *head);`，判断链表是否按从小到大排列。空链表或单节点链表返回 1；头节点大于下一个节点返回 0；否则递归检查后面的链。用 `1 -> 2 -> 3` 和 `1 -> 3 -> 2` 分别测试。

<details>
<summary>参考答案</summary>

1. 第一层：链表 = 节点 1 + 链表（2 -> 3）；第二层：链表（2 -> 3） = 节点 2 + 链表（3 -> NULL）；再拆下去，链表（3 -> NULL） = 节点 3 + 空链表。基线条件是空链表 `NULL`——不用再拆、直接返回。
2. 递去：一路调用 `print_reverse(head->next)` 直到最后一个节点，途中一个数字都不打印；归来：从最深的调用（节点 30）开始依次返回，每层返回时执行自己的 `printf`，于是 30、20、10 倒着出来。
3. 缺基线条件。走到最后一个节点后 `head` 是 `NULL`，`head->next` 是对空指针解引用，程序崩溃；就算侥幸，递归也永不停止，最终栈溢出。正确写法要加 `if (head == NULL) return 0;`。
4. 先 `free(head)` 再读 `head->next`——`head` 指向的内存已经归还系统，读它的成员是悬垂访问，未定义行为。必须先递归处理 `head->next`，再 `free(head)`：

```c
void free_list(struct node *head)
{
	if (head == NULL) {
		return;
	}
	free_list(head->next);
	free(head);
}
```

5. 参考代码：

```c
#include <stdio.h>

struct node {
	int data;
	struct node *next;
};

int max_node(struct node *head)
{
	if (head->next == NULL) {
		return head->data;
	}
	int rest_max = max_node(head->next);
	if (head->data > rest_max) {
		return head->data;
	}
	return rest_max;
}

int main(void)
{
	struct node third = {7, NULL};
	struct node second = {25, &third};
	struct node first = {10, &second};

	printf("最大值：%d\n", max_node(&first));

	return 0;
}
```

输出 `最大值：25`。

6. 参考代码：

```c
#include <stdio.h>

struct node {
	int data;
	struct node *next;
};

int is_sorted(struct node *head)
{
	if (head == NULL || head->next == NULL) {
		return 1;
	}
	if (head->data > head->next->data) {
		return 0;
	}
	return is_sorted(head->next);
}

int main(void)
{
	struct node c = {3, NULL};
	struct node b = {2, &c};
	struct node a = {1, &b};

	struct node x = {2, NULL};
	struct node y = {3, &x};
	struct node w = {1, &y};

	printf("1 -> 2 -> 3 有序吗：%d\n", is_sorted(&a));
	printf("1 -> 3 -> 2 有序吗：%d\n", is_sorted(&w));

	return 0;
}
```

输出 `1 -> 2 -> 3 有序吗：1`、`1 -> 3 -> 2 有序吗：0`。注意基线条件是 `head == NULL || head->next == NULL`，两个都要覆盖：空链表和单节点链表都算有序。
