# C 语言速查表

这一页是全书内容的速查表。写代码写到一半，忘了某个格式符、某个函数、某条优先级，翻这里就够了。

每张表都标注了对应的章节。不懂细节就点回去看，看完再回来。

## 1. 运算符优先级（高 → 低）

拿不准就加括号。但下面这几级最好记住：

| 优先级 | 运算符 | 说明 |
|--------|--------|------|
| 最高 | `()` `[]` `->` `.` | 函数调用 / 下标 / 成员访问 |
| 一元 | `!` `~` `++` `--` `-` `&` `*` `(类型)` | 逻辑非、取反、自增自减、负号、取地址、解引用、强转 |
| 乘除 | `*` `/` `%` | 乘、除、取余 |
| 加减 | `+` `-` | 加、减 |
| 移位 | `<<` `>>` | 左移、右移（第 10.2 节） |
| 关系 | `<` `<=` `>` `>=` | 大小比较 |
| 相等 | `==` `!=` | 相等比较 |
| 位与 | `&` | 按位与 |
| 位异或 | `^` | 按位异或 |
| 位或 | `\|` | 按位或 |
| 逻辑与 | `&&` | 短路 |
| 逻辑或 | `\|\|` | 短路 |
| 三目 | `? :` | 条件运算符 |
| 赋值 | `=` `+=` `-=` … | 赋值 |
| 最低 | `,` | 逗号 |

最容易错的三处：

1. `*` 可能是一元（解引用）也可能是二元（乘法），看它在几个操作数之间。
2. 位运算 `& | ^` 优先级低于 `==`：`if ((x & MASK) == 0)` 括号不能省。
3. 指针声明 `int *p[3]` 与 `int (*p)[3]` 天差地别（第 4.6 节）。

## 2. printf / scanf 格式符

| 格式符 | 用于 | printf 例子 | scanf 例子 |
|--------|------|------------|-----------|
| `%d` | `int` | `printf("%d", n)` | `scanf("%d", &n)` |
| `%ld` | `long` | `printf("%ld", x)` | `scanf("%ld", &x)` |
| `%f` | `float`（printf 也用于 double） | `printf("%f", f)` | `scanf("%f", &f)` |
| `%lf` | `double` | `printf("%.2f", d)` 也行 | `scanf("%lf", &d)` |
| `%c` | `char` | `printf("%c", ch)` | `scanf(" %c", &ch)`（空格防回车残留） |
| `%s` | 字符数组 | `printf("%s", s)` | `scanf("%29s", s)`（不加 `&`） |
| `%zu` | `size_t` | `printf("%zu", n)` | — |
| `%x` | 十六进制 | `printf("%x", n)` | — |
| `%p` | 指针地址 | `printf("%p", (void *)p)` | — |
| `%%` | 打印一个 `%` | `printf("100%%")` | — |

常用修饰：

- `%5d`：占 5 格右对齐；`%-5d` 左对齐。
- `%.2f`：保留 2 位小数；`%8.2f`：占 8 格且保留 2 位。
- `%29s`：最多读 29 个字符。**宽度 = 数组大小 − 1**（剩下的 1 个字节放 `'\0'`）。`scanf("%s")` 不带宽度是缓冲区溢出隐患，全书示例都带宽度。

速记：double 输入必须 `%lf`，输出 `%f` 就够（第 1.5 节）。`%s` 读到空格就停，想读一行用 `fgets`（第 5.3 节）。

转义字符：`\n` 换行、`\t` Tab、`\\` 反斜杠、`\"` 双引号、`'\''` 单引号、`\0` 空字符（字符串结束符）。

## 3. 常用 ASCII

| 字符 | 值 | 字符 | 值 |
|------|-----|------|-----|
| `'0'` | 48 | `'A'` | 65 |
| `'1'` | 49 | `'B'` | 66 |
| `' '`（空格） | 32 | `'a'` | 97 |
| `'\n'` | 10 | `'z'` | 122 |

大写 `A`（65）到小写 `a`（97）差 32：`'a' - 'A'` 是常量 32。

## 4. string.h 常用函数

记得 `#include <string.h>`；目标数组要够大（留 `'\0'`）。

| 函数 | 作用 | 注意 |
|------|------|------|
| `strlen(s)` | 长度（不含 `'\0'`） | 循环、边界常用 |
| `strcpy(d, s)` | 把 s 复制到 d | 工程上不用，见下方安全写法 |
| `strncpy(d, s, n)` | 最多复制 n 个字符 | `src` 不短于 `n` 时**不补 `'\0'`**，要自己补，见下方 |
| `strcat(d, s)` | 把 s 接到 d 后面 | 工程上不用，用 `strncat` 代替 |
| `strncat(d, s, n)` | 最多追加 n 个字符 | 追加完一定会补 `'\0'`，比 `strncpy` 贴心 |
| `strcmp(a, b)` | 比较：相等返回 0 | 别用 `==` 比字符串 |
| `strchr(s, c)` | 找字符，返回指针 | 没找到返回 `NULL` |
| `strstr(a, b)` | 找子串，返回指针 | 没找到返回 `NULL` |
| `strcspn(s, "\n")` | 找第一个匹配位置 | 常用它去掉行尾换行 |

判断字符串相等：`strcmp(a, b) == 0`，不是 `if (strcmp(a, b))`（那表示“不相等”，正好相反）。（第 3.4 节）

复制字符串的安全写法（第 3.4 节）：

```c
/* 首选 snprintf：自动补 '\0'，放不下就截断 */
snprintf(dst, sizeof(dst), "%s", src);

/* strncpy 要自己补结束符，两行配合才安全 */
strncpy(dst, src, sizeof(dst) - 1);
dst[sizeof(dst) - 1] = '\0';

/* strncat 的 n 是“还能追加多少字节”：剩余空间减 1 */
strncat(dst, src, sizeof(dst) - strlen(dst) - 1);
```

## 5. stdlib.h 常用函数

| 函数 | 作用 |
|------|------|
| `atoi(s)` / `atof(s)` | 字符串 → int / double |
| `rand()` / `srand(seed)` | 随机数 / 随机种子 |
| `abs(n)` | 整数绝对值 |
| `malloc(n)` / `calloc(n, sz)` / `realloc(p, n)` | 动态申请内存（第 6.1 节） |
| `free(p)` | 释放内存 |
| `exit(码)` | 结束程序 |
| `qsort(数组, 个数, 大小, 比较器)` | 排序（第 10.4 节） |

`malloc` 返回后要检查是否为 `NULL`；每个 `malloc` 都要配一个 `free`。

## 6. 文件操作

fopen 模式：

| 模式 | 含义 |
|------|------|
| `"r"` / `"w"` / `"a"` | 读 / 写（清空）/ 追加 |
| `"r+"` / `"w+"` | 可读可写 |
| `"rb"` / `"wb"` | 二进制读 / 二进制写（存结构体用） |

常用函数：

| 想干什么 | 用哪个 |
|----------|--------|
| 打开 / 关闭 | `fopen`（要检查 NULL）/ `fclose` |
| 按格式读写 | `fprintf` / `fscanf` |
| 一个字符 | `fgetc`（返回 int）/ `fputc` |
| 一整行 | `fgets`（会带上 `\n`）/ `fputs` |
| 整块结构体 | `fread` / `fwrite` |
| 跳位置 | `rewind`（回开头）/ `fseek(fp, 偏移, SEEK_SET/CUR/END)` |
| 报错 | `perror("说明")` |

`fopen` 之后永远先判断 `fp == NULL`；拿到的资源记得还（`fclose`）。（第 5 章）

## 7. 编译命令与警告

```bash
gcc -Wall -Wextra -g -o 程序 源文件.c   # 日常开发
gcc -o 程序 源文件.c                    # 最快（不推荐日常用）
./程序                                  # 运行
```

| 选项 | 作用 |
|------|------|
| `-Wall -Wextra` | 打开警告，把 bug 消灭在编译期 |
| `-g` | 生成调试信息（gdb 需要） |
| `-D名字` | 相当于在代码开头写 `#define 名字`（如 `-DDEBUG`） |

警告尽量清零。很多运行期 bug 在编译警告里就被“剧透”了。

## 8. gdb 常用命令

用 gdb 前编译要带 `-g`，否则 gdb 不知道“第几行”。Linux 和 macOS 通常自带或随编译工具链安装；Windows 上 MinGW-w64 需要单独安装 gdb（MSYS2 里 `pacman -S gdb`），没有 gdb 时可以用 Visual Studio 的调试器，思路相同。

| 命令 | 缩写 | 作用 |
|------|------|------|
| `gdb ./程序` | — | 启动 gdb |
| `break 行号/函数` | `b` | 设断点 |
| `run` | `r` | 运行到断点（或到崩溃） |
| `next` / `step` | `n` / `s` | 单步（不进入 / 进入函数） |
| `print 变量` | `p` | 看变量 |
| `continue` | `c` | 继续到下一个断点 |
| `list` | `l` | 显示附近源码 |
| `backtrace` | `bt` | 崩溃后看函数调用链，定位崩在谁手里 |
| `quit` | `q` | 退出 |

两个最常用的套路：

- **抓崩溃**：直接 `run`，程序段错误时 gdb 会停在出错的行，并显示各参数的值。参数里出现 `0x0`，十有八九是空指针被解引用。
- **抓逻辑错**：`break main` → `run` → `next` 一步步走，每走几步 `print` 一下关键变量，看它在哪一步开始“变坏”。找到第一个值不对的地方，bug 基本就在它前一行。

不想开 gdb 时，也可以在代码里埋检查点：

- `assert(条件)`：条件为假立刻终止并指出行号，适合检查“前置条件”（除数不为 0、指针非空、下标在范围内）。发布版在文件开头加 `#define NDEBUG` 可让所有 `assert` 失效。
- `printf` 打桩：在关键位置临时打印中间值，定位完记得删掉。

排查心法：复现 → 定位 → 修复。让 bug 稳定出现（输入固定、数据固定），再逐步缩小范围。

## 11. 代码质量自查

写完一段代码、提交之前，按两张清单过一遍。完整的表格和解释在 [2.6 代码规范](<../chapter2/sections/2.6 代码规范.md>)。

格式和结构（2.6.12）：

- Tab 缩进、行宽 100 列、大括号位置、`switch` 的 `case` 对齐。
- 命名小写加下划线、注释解释“为什么”、函数只做一件事。
- 通过 `clang-format` 检查。

质量和习惯（2.6.13）：

- 每个可能失败的地方都检查了（`fopen`、`malloc`、除数）。
- 数组边界想过、循环条件是 `i < n`。
- 每个“打开/申请”有配对的“关闭/释放”。
- 指针解引用前确认不是 `NULL`。
