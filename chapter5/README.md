# 第5章：文件读写与实战 —— 让程序与现实世界"对话" 📡

## 📖 本章导读

到目前为止，我们的程序都有一个"致命弱点"：

> 程序一运行，数据就没了；程序一结束，一切归零。

想想看——你写了一个"学生成绩管理系统"，辛辛苦苦录入了数据，可**关掉程序再打开，数据全没了**！

这不就像一本会自动清空内容的笔记本吗？太没用了。

怎么办？——把数据**存进文件**！文件可以长期保存在硬盘上：

- 📝 成绩单存成 `scores.txt`，下次打开还能读回来
- 🗒️ 写一个"记事本"，随手记的东西关掉程序也不丢
- 📊 让程序生成报表文件，发给别人看

而在和"文件"这类现实世界打交道时，**出错是家常便饭**（文件不存在、磁盘满了、权限不够...）。所以本章前半部分，我们先学会C语言处理错误的方法，再学文件读写。

在本章中，我们将一起：

- 🛡️ **学会处理错误** —— 没有"异常机制"的C语言，靠什么发现并处理错误
- 📂 **文件读写基础** —— 打开、写入、读取、关闭文件
- 🔤 **逐字符与逐行读写** —— fgetc/fputc、复制文件、fgets/fputs
- 🎯 **文件定位与结构体整存** —— rewind/fseek、fwrite/fread 二进制存盘
- 🎓 **综合实战** —— 做一个数据永不丢失的"文件版学生管理系统"

## 🎯 学习目标

完成本章后，你将能够：

1. ✅ 理解C语言的错误处理约定（返回值、NULL、errno/perror）
2. ✅ 打开、写入、读取、关闭文件
3. ✅ 逐字符/逐行处理文件，把结构体数据存盘再读回
4. ✅ 综合使用本章知识，写出能"记住数据"的程序
