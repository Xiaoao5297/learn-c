# 第 5 章：文件读写与实战

前四章的程序有一个共同限制：数据活在内存里，程序一结束就全没了。辛苦录入的成绩、通讯录，关闭程序再打开，一片空白。

这一章解决这个问题：把数据写进硬盘上的文件，也把硬盘上的数据读回来。学完之后，你的程序第一次拥有"记忆"。

本章会学到：

- 用 `fopen`/`fclose` 打开和关闭文件，理解 `r`、`w`、`a` 等模式的区别。
- 用 `fprintf`/`fscanf`、`fgetc`/`fputc` 按格式和按字符读写文件。
- 用 `fgets`/`fputs` 逐行处理文件，并处理 `fgets` 保留的换行符。
- 用 `fseek`/`ftell`/`rewind` 定位文件，用 `fwrite`/`fread` 整块存取结构体。
- 把这一切组装成一个能存盘、能加载的通讯录程序。

## 前置知识

- 第 3 章：字符串、`fgets` 安全读入、`strcspn` 去换行。
- 第 4 章：结构体、结构体数组。

## 学完这一章，你应该能

1. 用 `fopen` 打开文件、选择正确的模式、检查失败、用完关闭。
2. 说清楚 `"w"` 和 `"a"` 的区别，避免误清空文件。
3. 用 `fprintf`/`fscanf` 读写带格式的数据，并检查 `fscanf` 的返回值。
4. 用 `fgets` 逐行读文件，用 `strcspn` 去掉行尾换行符。
5. 用 `fseek`/`ftell` 求文件大小，用 `fwrite`/`fread` 整块存取结构体，并知道二进制文件为什么不可跨平台移植。
6. 写出"启动时加载、修改后存盘"的小工具，并对文件内容做范围校验和限宽读入。

## 本章工程支线

第 3 章的工程支线是"安全读入"，这一章把它推广到"安全读写文件"：

- **5.1 的失败检查**：`fopen` 返回 `NULL` 必须处理。文件操作出错是常态，检查是最基本的防御。
- **5.2 和 5.3 的限宽与返回值**：`fscanf` 限宽 `%29s`、`fgetc` 用 `int` 接 `EOF`、`fgets` 模板判断 `NULL`。读键盘的纪律在文件上一条都不能少。
- **5.4 的返回值检查与可移植性**：`fwrite`/`fread` 检查搬运的元素个数；二进制文件受填充字节和端序影响，只在本机存，不做跨平台交换。
- **5.5 的防御式加载**：校验文件头的个数（返回值 + 范围），失败就拒绝整个文件。这套"不信任外部输入"的思路，是第 6 章动态内存、第 10 章毕业项目会反复用到的地基。

## 预计时间

- 只读一遍：4 到 6 小时。
- 做完每节练习和章末测试：8 到 12 小时。
- 建议分 3 次学习：5.1 和 5.2 打底，5.3 和 5.4 处理细节，5.5 留一整段时间做项目。

## 学习建议

- 每个示例都动手运行，然后到当前目录里打开生成的文件看看——看着文件从无到有，概念才落地。
- 故意制造错误：把文件删了再读、往文件里塞一行乱码再加载，观察程序的反应。
- 5.4.3 的二进制可移植性警告值得读慢一点，它决定了"什么时候可以用 `fwrite` 存东西"。
- 5.5 的项目建议先抄通、跑通，再合上教程自己默写 `save_contacts` 和 `load_contacts`。
