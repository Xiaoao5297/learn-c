# 5.2 读写文件

上一节会打开和关闭文件了，这一节开始真正读写：用 `fprintf`/`fscanf` 处理带格式的数据，用 `fgetc`/`fputc` 一个字符一个字符地处理。

## 5.2.1 fprintf 和 fscanf：带格式的读写

`fprintf` 和 `printf` 的关系、`fscanf` 和 `scanf` 的关系，都是"多一个 `FILE *` 参数"：

| 函数 | 从哪读/往哪写 | 例子 |
|------|---------------|------|
| `printf("%d", x)` | 屏幕 | `printf("总分：%d\n", sum);` |
| `fprintf(fp, "%d", x)` | `fp` 指向的文件 | `fprintf(fp, "%d\n", sum);` |
| `scanf("%d", &x)` | 键盘 | `scanf("%d", &x);` |
| `fscanf(fp, "%d", &x)` | `fp` 指向的文件 | `fscanf(fp, "%d", &x);` |

下面的程序先把两个成绩写进 `scores.txt`，再读回来做统计。这就是文件最典型的用法：**先写后读**。

```c
// 5.2.1 fprintf_fscanf.c
#include <stdio.h>

int main(void)
{
	int chinese = 0;
	int math = 0;

	FILE *fp = fopen("scores.txt", "w");
	if (fp == NULL) {
		printf("写入打开失败\n");
		return 1;
	}
	fprintf(fp, "%d %d\n", 92, 85);
	fclose(fp);

	fp = fopen("scores.txt", "r");
	if (fp == NULL) {
		printf("读取打开失败\n");
		return 1;
	}
	if (fscanf(fp, "%d %d", &chinese, &math) != 2) {
		printf("文件格式不对，读不到两个整数\n");
		fclose(fp);
		return 1;
	}
	fclose(fp);

	printf("语文：%d\n", chinese);
	printf("数学：%d\n", math);
	printf("总分：%d\n", chinese + math);

	return 0;
}
```

<!-- output: 5.2.1 -->
```text
语文：92
数学：85
总分：177
```

两个要点：

1. **检查 `fscanf` 的返回值**。它返回成功读到的项目数，这里期望是 2。文件内容残缺、格式不对时返回值会小于 2，检查它才能发现文件坏了，而不是拿着没读到的垃圾值继续算。
2. 写和读要**对称**。写入时是 `"%d %d\n"`，两个整数用空格隔开；读取时的格式串就要能匹配这个布局。这就像你按固定格式填一张表格交上去，回来查的时候也得按同样的格式找——自己定的格式自己要记得。

和第 1 章的 `scanf` 一样，`fscanf` 读字符串时 `%s` 也必须限宽，比如缓冲区 30 字节就写 `%29s`。这一点在 5.3 和 5.5 会反复用到。

## 5.2.2 fgetc 和 fputc：一个字符一个字符处理

`fgetc(fp)` 从文件读一个字符，读到文件末尾返回 `EOF`；`fputc(ch, fp)` 把一个字符写进文件。先看用 `fgetc` 数字符：

```c
// 5.2.2 fgetc_count.c
#include <stdio.h>

int main(void)
{
	FILE *fp = fopen("note.txt", "w");
	if (fp == NULL) {
		return 1;
	}
	fprintf(fp, "abc\ndef\n");
	fclose(fp);

	fp = fopen("note.txt", "r");
	if (fp == NULL) {
		return 1;
	}

	int count = 0;
	int ch;
	while ((ch = fgetc(fp)) != EOF) {
		count++;
		printf("%c", ch);
	}
	fclose(fp);

	printf("一共 %d 个字符\n", count);

	return 0;
}
```

<!-- output: 5.2.2 -->
```text
abc
def
一共 8 个字符
```

`abc\ndef\n` 是 3 + 1 + 3 + 1 = 8 个字符，`\n` 也算一个。数文件字符数这类工具，本质就是这个循环。

三个细节：

1. **`ch` 的类型是 `int`，不是 `char`**。`EOF` 是一个负整数常量，`char` 不一定装得下，用 `int` 接住才不会出错。可以想象成查库清点：每本书都有编号，但管理员还需要一个"特殊号码"表示"架子上没书了"——`char` 的号码本里放不下这个特殊号码，`int` 的才放得下。
2. `while ((ch = fgetc(fp)) != EOF)` 是固定写法：先读，再拿读到的值判断。注意括号，写成 `while (ch = fgetc(fp) != EOF)` 意思就全变了。
3. `EOF` 表示"读到头了"，也可能表示读出了错，对初学者来说统一按"结束"处理即可。

## 5.2.3 综合示例：复制文件

把 `fgetc` 和 `fputc` 拼在一起，就是文件复制的全部原理：**从源文件读一个字符，往目标文件写一个字符，直到读不到为止**。这就像抄作业式的搬运：左手从原书揭起一个字，右手把它写到新本子上，揭到没有字为止。

```c
// 5.2.3 copy_file.c
#include <stdio.h>

int main(void)
{
	FILE *src = fopen("origin.txt", "w");
	if (src == NULL) {
		return 1;
	}
	fprintf(src, "line one\n");
	fprintf(src, "line two\n");
	fclose(src);

	src = fopen("origin.txt", "r");
	if (src == NULL) {
		printf("打开源文件失败\n");
		return 1;
	}

	FILE *dest = fopen("backup.txt", "w");
	if (dest == NULL) {
		printf("打开目标文件失败\n");
		fclose(src);
		return 1;
	}

	int ch;
	int count = 0;
	while ((ch = fgetc(src)) != EOF) {
		fputc(ch, dest);
		count++;
	}

	fclose(src);
	fclose(dest);

	printf("复制完成，共 %d 个字符\n", count);

	dest = fopen("backup.txt", "r");
	if (dest == NULL) {
		return 1;
	}
	printf("backup.txt 的内容：");
	while ((ch = fgetc(dest)) != EOF) {
		printf("%c", ch);
	}
	fclose(dest);

	return 0;
}
```

<!-- output: 5.2.3 -->
```text
复制完成，共 18 个字符
backup.txt 的内容：line one
line two
```

这个例子里同时打开了两个文件，每个都单独检查、单独关闭。注意打开目标文件失败时，先 `fclose(src)` 再退出——已经成功打开的资源，退出前要放掉。

这个"一个字符一个字符搬运"的循环，就是 `cp` 命令这类工具的最简核心。按块复制会快得多，那是 5.4 `fread`/`fwrite` 的事。

## 5.2.4 常见错误

| 错误写法 | 问题 | 正确写法 |
|----------|------|----------|
| `fscanf(fp, "%d", &x);` 不看返回值 | 文件残缺时拿到垃圾值 | `if (fscanf(fp, "%d", &x) != 1) { ... }` |
| `char ch = fgetc(fp);` | `char` 可能耗不尽 `EOF` | `int ch = fgetc(fp);` |
| `while (fgetc(fp) != EOF) { count++; }` 之后又 `fgetc` | 没回开头，读不到内容 | 重新打开，或 `rewind(fp)`（见 5.4） |
| `fscanf(fp, "%s", name);` | `%s` 不限宽，越界风险 | `char name[30]; fscanf(fp, "%29s", name);` |

## 5.2.5 小结

- `fprintf`/`fscanf` 就是带 `fp` 的 `printf`/`scanf`，用于按格式读写文件。
- `fscanf` 返回成功读到的项目数，必须检查。
- `fgetc` 一次读一个字符，末尾返回 `EOF`；接收变量用 `int`。
- `fputc(ch, fp)` 一次写一个字符。
- 读和写的格式要对称：写入时怎么排布，读取时就怎么匹配。
- `fgetc` + `fputc` 的循环可以实现文件复制。

## 练习

1. `fscanf` 的返回值表示什么？读 `"%d %d"` 两个整数时，正常情况返回值是多少？
2. `fgetc` 的返回值为什么要用 `int` 接，用 `char` 有什么隐患？
3. 写一个循环，统计文件里有多少个换行符（核心两三行即可）。
4. 下面代码想复制文件，有什么问题？

```c
FILE *src = fopen("a.txt", "r");
FILE *dest = fopen("b.txt", "w");

int ch;
while ((ch = fgetc(src)) != EOF) {
	fputc(ch, dest);
}
```

5. 写出下面程序运行后 `nums.txt` 的内容。

```c
FILE *fp = fopen("nums.txt", "w");
for (int i = 1; i <= 3; i++) {
	fprintf(fp, "%d ", i);
}
fclose(fp);
```

<details>
<summary>参考答案</summary>

1. 表示成功读到的项目数。`"%d %d"` 正常时返回 2；文件里不够两个整数时小于 2。
2. `EOF` 是负整数，`char` 不一定装得下，可能把 `EOF` 误判成普通字符，循环永远停不下来。`int` 足够容纳所有字符值和 `EOF`。
3. 例如：

```c
int lines = 0;
int ch;

while ((ch = fgetc(fp)) != EOF) {
	if (ch == '\n') {
		lines++;
	}
}
```

4. 两个 `fopen` 都没检查 `NULL`。`a.txt` 打不开（不存在）时，`fgetc(NULL)` 会让程序崩溃。应分别检查后再使用。
5. 内容是 `1 2 3` 加一个尾随空格（三个数字各跟一个空格，没有换行）。循环里写的是 `"%d "`，格式串里的空格会原样写进文件。

</details>
