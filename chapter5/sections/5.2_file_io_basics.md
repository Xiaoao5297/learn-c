# 5.2 文件读写基础

## 5.2.1 文件和文件指针

### 📂 文件是什么？

文件就是**存在硬盘上的一堆数据**，有自己的名字。比如：

```
scores.txt   （文本文件：里面是一行行的文字）
photo.jpg    （图片文件：一堆字节）
data.bin     （二进制文件）
```

### 🤔 程序怎么"抓"住一个文件？

C语言用一个 `FILE` 类型的指针来"握住"文件：

```c
FILE *fp;    // fp 是一个"文件句柄"，用来操作文件
```

`FILE *` 可以理解成**你和文件之间的一根"电话线"**——有了它，才能读写。

> 📌 `FILE` 类型来自 `<stdio.h>`（你从第1章就 include 的那个），文件操作函数也都在里面。

## 5.2.2 打开文件 fopen

### 📝 基本语法

```c
FILE *fp = fopen("文件名", "模式");
```

| 参数 | 含义 |
|------|------|
| `"文件名"` | 要打开哪个文件 |
| `"模式"` | 打开来干什么（读？写？追加？） |

### 📊 文件打开模式

| 模式 | 含义 | 文件不存在时 | 原有内容 |
|------|------|-------------|----------|
| `"r"` | 只读（read） | 出错，返回NULL | 保留 |
| `"w"` | 只写（write） | 自动创建 | **清空重写** |
| `"a"` | 追加（append） | 自动创建 | 保留，从末尾追加 |
| `"r+"` | 读写 | 出错 | 保留 |
| `"w+"` | 读写 | 自动创建 | 清空 |

> ⚠️ **特别注意 `"w"`！** 它是"清空重写"——如果文件已有内容，一打开就被清掉了！

### 📝 打开并检查

```c
#include <stdio.h>

int main() {
    FILE *fp = fopen("hello.txt", "w");
    
    if (fp == NULL) {        // 铁律：必须检查！
        printf("打开文件失败！\n");
        return 1;            // 非0退出，表示"出错了"
    }
    
    // ... 使用文件 ...
    
    fclose(fp);              // 用完关闭
    printf("文件打开并关闭成功。\n");
    return 0;
}
```

## 5.2.3 打开失败怎么办？errno 和 perror

### 🤔 只知道"失败"不够，想知道"为什么"

`fp == NULL` 只告诉我们失败，但用户想知道**具体原因**：文件不存在？还是没权限？

C语言把"上次错误的原因"记在一个全局变量 `errno` 里（来自 `<errno.h>`），用 `perror` 可以打印出来：

```c
#include <stdio.h>
#include <errno.h>

int main() {
    FILE *fp = fopen("不存在.txt", "r");   // 故意打开不存在的文件
    
    if (fp == NULL) {
        perror("打开文件失败");     // 打印：打开文件失败: No such file or directory
        // 相当于：先打印你的话，再打印 errno 对应的错误描述
        return 1;
    }
    
    fclose(fp);
    return 0;
}
```

> 📖 **术语卡：`return 1;` 和"退出码"（Exit Code）**
> 
> 在 `main` 里 `return 0;` 表示"一切正常"，`return 1;`（或任何非0值）表示"出错了"。这个值会返回给操作系统，叫**退出码**。
> 
> 在终端里可以用 `echo $?` 查看上一个程序的退出码：
> 
> ```bash
> ./my_program
> echo $?     # 输出 0 → 正常；非 0（如 1）→ 出错
> ```
> 
> 所以**遇到严重错误就 `return 1;`（非0）**，是好习惯——别人（或脚本）能据此知道你的程序失败了。

输出类似：
```
打开文件失败: No such file or directory
```

> 📌 **errno 和 perror 小词典：**
> 
> | 东西 | 作用 |
> |------|------|
> | `errno` | 全局变量，记录"上次错误"的编号（需 `<errno.h>`） |
> | `perror("前缀")` | 打印 "前缀: 错误描述" 到屏幕（stdio.h 就有） |
> | `strerror(errno)` | 把错误编号转成文字描述（需 `<string.h>`） |
> 
> **最常见的错误：**
> - `No such file or directory`：文件不存在
> - `Permission denied`：没有权限
> - `Is a directory`：把目录当文件开了

> 💡 **代码习惯：** 以后打开文件，失败时别只打印"失败"，顺手 `perror("...")` 让用户知道真实原因！

## 5.2.4 写入文件：fprintf

### 🤔 printf 和 fprintf 什么区别？

| 函数 | 往哪写 |
|------|--------|
| `printf(...)` | 写到**屏幕** |
| `fprintf(fp, ...)` | 写到 **fp 指向的文件** |

用法几乎一样，只是多了第一个参数 `fp`！

### 📝 把三个学生成绩写入文件

```c
#include <stdio.h>

int main() {
    FILE *fp = fopen("students.txt", "w");
    
    if (fp == NULL) {
        perror("打开文件失败");
        return 1;
    }
    
    // 用 fprintf 写入文件（和 printf 一样，但多了 fp）
    fprintf(fp, "小明 85.5\n");
    fprintf(fp, "小红 92.0\n");
    fprintf(fp, "小刚 76.5\n");
    
    fclose(fp);
    
    printf("写入完成！请打开 students.txt 看看。\n");
    return 0;
}
```

运行后，**同目录下会生成 `students.txt`**，内容：

```
小明 85.5
小红 92.0
小刚 76.5
```

> 📌 **`\n` 在文件里也一样是换行！** 文件内容和我们 printf 到屏幕的样子是一样的。

## 5.2.5 读取文件：fscanf

### 🤔 scanf 和 fscanf 什么区别？

| 函数 | 从哪读 |
|------|--------|
| `scanf(...)` | 从**键盘**读 |
| `fscanf(fp, ...)` | 从 **fp 指向的文件**读 |

### 📝 读回刚才的文件

```c
#include <stdio.h>

int main() {
    FILE *fp = fopen("students.txt", "r");
    
    if (fp == NULL) {
        perror("打开文件失败");
        return 1;
    }
    
    char name[30];
    double score;
    
    // fscanf 返回成功读到的"项数"。读到文件末尾时返回 EOF（-1）
    while (fscanf(fp, "%s %lf", name, &score) == 2) {
        printf("%s：%.1f分\n", name, score);
    }
    
    fclose(fp);
    return 0;
}
```

输出：
```
小明：85.5分
小红：92.0分
小刚：76.5分
```

### 🔍 理解循环条件

```c
while (fscanf(fp, "%s %lf", name, &score) == 2) {
    // ...
}
```

> 📌 **`fscanf` 的返回值 = 成功读到的数据个数。**
> 
> 每次成功读到一个名字+一个分数 → 返回 2 → 继续循环
> 读到文件末尾（没东西可读）→ 返回 EOF（即 -1）→ 不等于 2 → 退出循环
> 
> **"== 想读的个数" 是读文件的经典安全写法**，不会多读也不会漏读。

> ⚠️ 注意 `fscanf` 读名字用的是 `%s`，它会跳过空格，读到空白就停。如果名字本身含空格（如 "小明同学"没问题，但 "Mary Jane" 会出问题），更稳妥的是用下一节的 `fgets` 整行读取。

## 5.2.6 追加模式："a" —— 保留旧内容

用 `"w"` 会清空旧内容。如果只想**在文件末尾接着写**（比如写日志），用 `"a"`：

```c
#include <stdio.h>

int main() {
    FILE *fp = fopen("log.txt", "a");    // 追加模式
    
    if (fp == NULL) {
        perror("打开文件失败");
        return 1;
    }
    
    fprintf(fp, "程序运行了一次，时间：第3次\n");
    
    fclose(fp);
    printf("已追加到 log.txt\n");
    return 0;
}
```

多运行几次，`log.txt` 会不断变长：

```
程序运行了一次，时间：第1次
程序运行了一次，时间：第2次
程序运行了一次，时间：第3次
```

> 💡 **模式选择口诀：** 只读用 `r`，重写用 `w`，追加用 `a`——先想清楚"要不要保留旧内容"再选模式！

## 5.2.7 为什么用完必须 fclose？

### 🤔 不关闭会怎样？

你可能觉得：程序结束反正会自己关。但有两个问题：

**问题1：数据可能还没真正写进硬盘！**

C的写文件是先写进内存的"缓冲区"，攒到一定程度才真正写入文件（为了效率）。调用 `fclose` 会**强制把缓冲区内容全部写入文件**。

> ⚠️ 如果程序在写入后**没关闭就崩溃/被杀**，缓冲区里没来得及写入的数据可能**丢失**！

**问题2：文件是"稀缺资源"**

操作系统能同时打开的文件数量有限。总不关闭，总有一天会"文件打开太多"报错。

> 📌 **规则：** fopen 和 fclose 永远是**成对出现**的。打开一个，用完必须关一个！

> 📖 **术语卡：缓冲区（Buffer）和"刷新"（Flush）**
> 
> 为什么写完不是立刻进硬盘，而是先攒在内存里？因为**每次写硬盘都挺慢**，攒一批一次性写，效率高得多。这块"临时的中转内存"就叫**缓冲区**。
> 
> | 触发"真正写入硬盘"的方式 | 说明 |
> |------|------|
> | `fclose(fp)` | 关闭时自动把剩余缓冲数据写出去 |
> | `fflush(fp)` | 手动"强制刷新"缓冲区（不关闭也能先写出去） |
> | 缓冲满了 | 自动写一批 |
> | 程序正常结束 | 也会自动清理 |
> 
> ```c
> fprintf(fp, "重要数据\n");
> fflush(fp);     // 想立刻写进硬盘？手动刷新一下
> ```
> 
> 理解了缓冲，就明白为什么"写完不 close/不 fflush，程序崩溃会丢数据"了。

> 📖 **术语卡：文件路径 —— 写出的文件到底在哪？**
> 
> `fopen("numbers.txt", "w")` 里的 `"numbers.txt"` 叫**相对路径**——它是相对于"当前工作目录"（你运行程序时所在的文件夹）找文件的。
> 
> ```bash
> cd ~/Desktop      # 把"当前目录"切到桌面
> ./my_program      # 程序在这里写出的 numbers.txt，就在桌面！
> ```
> 
> 与之相对的是**绝对路径**，从根目录写起：
> ```c
> fopen("/home/me/data.txt", "r");   // Linux/Mac：从根目录 / 开始
> fopen("C:\\data\\a.txt", "r");      // Windows：从盘符开始（反斜杠要写两个 \\）
> ```
> 
> > 💡 **如果程序"找不到文件"，先想想：这个文件真的在当前目录下吗？** 这是新手最常见的困惑。

## 5.2.8 综合示例：一个"写后读回"的小程序

把这一节学的串起来：写入3个数 → 读回来算总和。

```c
#include <stdio.h>

int main() {
    // 第一步：写入
    FILE *fp = fopen("numbers.txt", "w");
    if (fp == NULL) {
        perror("写入失败");
        return 1;
    }
    
    int nums[] = {10, 20, 30, 40, 50};
    for (int i = 0; i < 5; i++) {
        fprintf(fp, "%d\n", nums[i]);   // 每个数一行
    }
    fclose(fp);                          // 写完立刻关闭
    
    // 第二步：读回
    fp = fopen("numbers.txt", "r");
    if (fp == NULL) {
        perror("读取失败");
        return 1;
    }
    
    int x, sum = 0;
    while (fscanf(fp, "%d", &x) == 1) {  // 每次成功读1个整数
        sum += x;
    }
    fclose(fp);
    
    printf("总和：%d\n", sum);
    return 0;
}
```

输出：
```
总和：150
```

> 🧠 **写文件的标准三步：** fopen → fprintf / fscanf → fclose，每一步都检查失败！

## 5.2.9 本节小结

这一节我们学了：

✅ **文件指针：** `FILE *fp` 用来操作文件

✅ **打开文件：** `fopen("名字", "模式")`，模式有 r / w / a 等

✅ **必须检查：** 打开失败返回 `NULL`，用 `perror` 打印原因（errno）

✅ **写入：** `fprintf(fp, ...)`；**读取：** `fscanf(fp, ...)`

✅ **读文件循环：** `while (fscanf(fp, ...) == 想读的个数)`，读到末尾自动停

✅ **追加模式：** `"a"` 在末尾接着写，`"w"` 会清空重写

✅ **关闭文件：** `fclose` 把缓冲数据写入硬盘、释放资源

> 💡 **记住：fopen 和 fclose 成对出现，打开一定检查 NULL！**

**6. 以下程序想把三个整数写入文件再读回来，有4个错误，请找出并改正：**

```c
#include <stdio.h>

    FILE *fp = fopen("data.txt", "w");
