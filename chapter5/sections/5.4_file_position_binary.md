# 5.4 文件定位与结构体整存

> 💬 **节前语：**
>
> 上一节我们学会了"逐字符、逐行"地读文件——像拿着书签一页页往后翻。
>
> 但有些需求还要更"骚"的操作：
>
> - 🎯 **跳着读**：文件读到一半，想"回开头再看一遍"，或者直接"跳到某个位置"
> - 📦 **整块存**：手里有个结构体数组，不想一行行手写文字，而是"一次性整个存进文件、再整个读回来"
>
> 这一节学四件套：`rewind`（回开头）、`fseek`（任意定位）、`fwrite` / `fread`（二进制整块读写）。准备好了吗？开始吧！

## 5.4.1 文件位置：rewind / fseek

每个打开的文件内部都有个"**当前位置**"（读到哪了）。就像书签。

### 📝 rewind：把书签拨回开头

```c
#include <stdio.h>

int main() {
    FILE *fp = fopen("numbers.txt", "w");
    fprintf(fp, "1 2 3 4 5\n");
    fclose(fp);
    
    // 读两遍：第一遍求和，rewind 回开头，第二遍数个数
    fp = fopen("numbers.txt", "r");
    int x, sum = 0, count = 0;
    
    while (fscanf(fp, "%d", &x) == 1) {
        sum += x;
    }
    printf("第一遍读完，和=%d\n", sum);
    
    rewind(fp);                       // 回到文件开头
    printf("rewind 之后，重新读：\n");
    while (fscanf(fp, "%d", &x) == 1) {
        count++;
    }
    printf("一共 %d 个数\n", count);
    
    fclose(fp);
    return 0;
}
```

输出：
```
第一遍读完，和=15
rewind 之后，重新读：
一共 5 个数
```

### 📝 fseek：跳到任意位置

```c
fseek(fp, 偏移, 起始点);
```

| 起始点 | 常量 | 含义 |
|--------|------|------|
| 从文件头 | `SEEK_SET` | 从开头算 |
| 从当前位置 | `SEEK_CUR` | 从当前位置算 |
| 从文件尾 | `SEEK_END` | 从末尾算 |

```c
fseek(fp, 0, SEEK_SET);   // 跳到开头（等于 rewind）
fseek(fp, 0, SEEK_END);   // 跳到末尾
fseek(fp, 10, SEEK_SET);  // 跳到"从头数第10个字节"的位置
```

> 📌 `fseek` 单位是**字节**。文本文件按字节数跳不一定正好对准"某个字符的开头"，一般用于二进制文件或定位整块数据。

## 5.4.2 把结构体整个存盘：fwrite / fread

### 🤔 问题：很多学生的数据怎么存？

用文本方式一行行写也可以，但更"整"的做法是：**把整个结构体数组，一下子存进二进制文件**。

```c
fwrite(数组名, 单个大小, 个数, fp);   // 写入
fread(数组名, 单个大小, 个数, fp);     // 读出
```

### 📝 学生档案存盘再读回

```c
#include <stdio.h>

typedef struct {
    char name[20];
    int age;
    double score;
} Student;

int main() {
    Student class[3] = {
        {"小明", 18, 95.5},
        {"小红", 19, 88.0},
        {"小刚", 20, 76.5}
    };
    
    // 第一步：写入二进制文件
    FILE *fp = fopen("students.bin", "wb");    // "wb" = write + binary
    if (fp == NULL) {
        perror("写入失败");
        return 1;
    }
    fwrite(class, sizeof(Student), 3, fp);     // 一次写入3个完整结构体
    fclose(fp);
    
    // 第二步：从二进制文件读回
    fp = fopen("students.bin", "rb");          // "rb" = read + binary
    if (fp == NULL) {
        perror("读取失败");
        return 1;
    }
    Student loaded[3];
    fread(loaded, sizeof(Student), 3, fp);
    fclose(fp);
    
    // 第三步：打印读回的数据，验证没丢
    printf("读回的学生：\n");
    for (int i = 0; i < 3; i++) {
        printf("%s：%d岁，%.1f分\n", loaded[i].name, loaded[i].age, loaded[i].score);
    }
    
    return 0;
}
```

输出：
```
读回的学生：
小明：18岁，95.5分
小红：19岁，88.0分
小刚：76.5分
```

> 📌 **二进制模式（"wb"/"rb"）vs 文本模式（"w"/"r"）**
> 
> | | 文本模式 | 二进制模式 |
> |------|---------|-----------|
> | 存的是 | 人类能读的文字 | 和内存一模一样的字节 |
> | 适合 | 配置文件、日志、文章 | 结构体、图片、音视频 |
> | 用记事本打开 | 能看懂 | 乱码（正常！） |
> 
> **存结构体用二进制最省事**——整块写、整块读，不会丢字段、不会格式错乱。

### 🧮 一个神秘数字：fwrite 的返回值

```c
size_t n = fwrite(class, sizeof(Student), 3, fp);
// n = 实际成功写入了几个"元素"（这里希望是3）
```

成功时应等于想写的个数，小于则说明出错了（比如磁盘满了）。**好的习惯是检查它。**

## 5.4.3 本节小结

这一节我们学了：

✅ **rewind：** 把"书签"拨回文件开头

✅ **fseek：** `fseek(fp, 偏移, SEEK_SET/CUR/END)` 跳到任意位置；单位是字节

✅ **二进制模式：** `"wb"` / `"rb"`，存的是和内存一模一样的字节

✅ **fwrite / fread：** `fwrite(数组, 单个大小, 个数, fp)` 一次存一整个结构体数组，再整块读回

✅ **fwrite 返回值：** 实际写入的元素个数，小于预期说明出错（要检查）

> 💡 **记住：文本靠 fprintf/fgets 好读，结构体靠 fwrite/fread 省事！**

### 三、改错题

**6. 以下程序想写一个结构体数组到二进制文件，有 3 个错误：**

```c
#include <stdio.h>

typedef struct { char name[20]; int age; } Person;

int main() {
    Person p[2] = {{"Tom", 20}, {"Amy", 21}};

    FILE *fp = fopen("people.bin", "w");      // 错误区①：二进制写入用什么模式？
    if (fp == NULL) return 1;

    fwrite(p, sizeof(Person *), 2, fp);       // 错误区②：单个大小该写什么？
    fclose(fp);                               // 错误区③：写成功了吗？要不要检查返回值？

    return 0;
}
```

> 提示：①用 `"wb"`；②单个大小是 `sizeof(Person)`（不是指针）；③可检查 `fwrite` 返回值是否等于 2。
