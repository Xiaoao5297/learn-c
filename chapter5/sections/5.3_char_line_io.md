# 5.3 逐字符与逐行读写

> 💬 **节前语：**
>
> 上一节我们用 `fprintf` / `fscanf` 按"格式"读写文件——适合"有结构的记录"。
>
> 但现实里还有一种更常见的文件：**文章、日志、源代码**。它们没有固定格式，你常常需要：
>
> - 📖 **一行一行**读（读文章、统计行数）
> - 🔤 **一个字符一个字符**处理（复制文件、统计字数）
>
> 这一节我们就补上这两把工具：`fgetc` / `fputc`（字符级）和 `fgets` / `fputs`（行级）。准备好了吗？开始吧！

## 5.3.1 逐字符读写：fgetc / fputc

### 📝 fgetc：读一个字符

```c
int c = fgetc(fp);    // 从文件读一个字符
```

> ⚠️ **注意返回值类型是 `int`，不是 `char`！**
> 
> 因为读到文件末尾时，`fgetc` 会返回一个特殊的 **`EOF`**（值是 -1）。用 `char` 存不下 -1 的特殊状态，所以要用 `int`。

### 📝 fputc：写一个字符

```c
fputc('A', fp);    // 往文件写一个字符
```

### 📝 逐字符打印文件内容

```c
#include <stdio.h>

int main() {
    FILE *fp = fopen("poem.txt", "r");
    if (fp == NULL) {
        perror("打开文件失败");
        return 1;
    }
    
    int c;
    while ((c = fgetc(fp)) != EOF) {    // 读到末尾返回 EOF，循环结束
        putchar(c);                     // putchar 把字符显示到屏幕
    }
    
    fclose(fp);
    return 0;
}
```

假设 `poem.txt` 内容：
```
床前明月光
疑是地上霜
```
运行输出：
```
床前明月光
疑是地上霜
```

> 📌 **经典写法：`while ((c = fgetc(fp)) != EOF)`**
> 
> 先读一个字符存进 c，再判断是不是 EOF。**注意括号不能少**，否则优先级就错了！

## 5.3.2 实战：复制文件

用 fgetc + fputc，就可以**一个字符一个字符**地把文件复制一份：

```c
#include <stdio.h>

int main() {
    // 打开源文件（只读）
    FILE *src = fopen("source.txt", "r");
    if (src == NULL) {
        perror("源文件打开失败");
        return 1;
    }
    
    // 打开目标文件（写入）
    FILE *dst = fopen("copy.txt", "w");
    if (dst == NULL) {
        perror("目标文件打开失败");
        fclose(src);
        return 1;
    }
    
    // 一个字符一个字符地复制
    int c;
    while ((c = fgetc(src)) != EOF) {
        fputc(c, dst);
    }
    
    fclose(src);
    fclose(dst);
    
    printf("文件复制完成！\n");
    return 0;
}
```

假设 `source.txt` 是：
```
Hello, C!
```
运行后生成 `copy.txt`，内容一模一样：
```
Hello, C!
```

> 💡 **像不像"人肉复印机"？** 计算机就是靠这种逐字符搬运，复制任何文件的。图片、音乐（二进制文件）也一样，只是处理字节。

## 5.3.3 逐行读写：fgets / fputs

### 📝 fgets：读一整行

```c
char line[100];
fgets(line, sizeof(line), fp);
```

| 参数 | 含义 |
|------|------|
| `line` | 把读到的内容放哪 |
| `sizeof(line)` | 最多读这么多-1个字符（防越界） |
| `fp` | 从哪个文件读 |

> 📌 **fgets 会连换行符 `\n` 一起读进来！** 如果一行末尾有 `\n`，line 里就包含它。
> 
> 读失败（到文件末尾）返回 `NULL`。

### 📝 一行行读取并统计行数

```c
#include <stdio.h>

int main() {
    FILE *fp = fopen("poem.txt", "r");
    if (fp == NULL) {
        perror("打开文件失败");
        return 1;
    }
    
    char line[200];
    int lineCount = 0;
    
    while (fgets(line, sizeof(line), fp) != NULL) {   // 读不到返回 NULL，退出
        lineCount++;
        printf("第%d行：%s", lineCount, line);        // line 自带 \n，所以不用再加
    }
    
    fclose(fp);
    printf("共 %d 行\n", lineCount);
    return 0;
}
```

假设 `poem.txt`：
```
床前明月光
疑是地上霜
举头望明月
低头思故乡
```
输出：
```
第1行：床前明月光
第2行：疑是地上霜
第3行：举头望明月
第4行：低头思故乡
共 4 行
```

> 💡 **为什么用 `fgets` 而不是 `fscanf("%s")`？** 因为 `%s` 遇空格就停；`fgets` 能一口气读一整行（含空格）。读"文章、日志"这种文本，`fgets` 是首选。

### 📝 想去掉行尾的 \n？

```c
#include <string.h>

line[strcspn(line, "\n")] = '\0';   // 找到换行符的位置，把它替换成 '\0'
```

> 📌 如果不想保留行尾的 `\n`，用上面这一行把它去掉。（`strcspn` 返回"第一个匹配字符的位置"，现在是选读内容，能理解用途即可。）

## 5.3.4 本节小结

这一节我们学了：

✅ **fgetc / fputc：** 读/写一个字符；`fgetc` 返回 `int`（要用它装 EOF）

✅ **读完整个文件：** `while ((c = fgetc(fp)) != EOF)`

✅ **复制文件：** 逐字符从源文件搬到目标文件（图片音乐也一样，只是处理字节）

✅ **fgets / fputs：** 读/写一整行；`fgets` 会把 `\n` 一起读进来，读到末尾返回 NULL

✅ **fgets vs fscanf("%s")：** `%s` 遇空格停，`fgets` 能读含空格的一整行

> 💡 **记住：读"文章、日志"优先用 fgets；按字节搬运优先用 fgetc/fputc。字符和行，两把尺子都要会。**

**6. 以下程序想逐字符显示文件内容，有 2 个明显错误：**

```c
#include <stdio.h>
```
