# 5.3 行读写与安全输入

第 3 章学过：`scanf("%s")` 读不了带空格的整行，安全的选择是 `fgets`。读文件时同样的道理成立，这一节把 `fgets`/`fputs` 搬到文件上，并处理好 `fgets` 最出名的一个细节：它会保留换行符。

## 5.3.1 fgets：从文件读一行

```c
fgets(字符数组, 数组大小, fp);
```

`fgets` 从 `fp` 读一行（最多 `数组大小 - 1` 个字符，给 `'\0'` 留位置）：

- 读到了返回同一个数组地址（不是 `NULL`）。
- 一行都没读到（比如已在文件末尾）返回 `NULL`。

所以"逐行读完整个文件"的模板是：

```c
char line[64];

while (fgets(line, sizeof(line), fp) != NULL) {
	/* 处理一行 */
}
```

看一个例子。文件里有三行字，用 `fgets` 逐行读出。为了看清每行到底有什么，把读到的内容放进方括号里打印：

```c
// 5.3.1 fgets_lines.c
#include <stdio.h>

int main(void)
{
	char line[64];

	FILE *fp = fopen("lines.txt", "w");
	if (fp == NULL) {
		return 1;
	}
	fprintf(fp, "first\nsecond\nthird\n");
	fclose(fp);

	fp = fopen("lines.txt", "r");
	if (fp == NULL) {
		return 1;
	}

	while (fgets(line, sizeof(line), fp) != NULL) {
		printf("[%s]\n", line);
	}
	fclose(fp);

	return 0;
}
```

<!-- output: 5.3.1 -->
```text
[first
]
[second
]
[third
]
```

方括号被"拆开"了——`]` 掉到了下一行。这说明读到的字符串末尾带着换行符 `\n`。这就是 `fgets` 的著名特性，下一小节专门处理它。

## 5.3.2 处理 fgets 保留的换行符

`fgets` 读到换行符时**会把它原样存进数组**，不会丢掉。可以把它想成从传送带上取整盘菜：连着盘子底下垫的那张纸（换行符）一起端给你。这一设计有它的道理（遇到超长行被截断时，检查末尾有没有 `\n` 就能知道），但多数时候我们只想拿到干净的菜，需要手动把垫纸抽掉。

去掉换行符最稳妥的一招：

```c
line[strcspn(line, "\n")] = '\0';
```

`strcspn(line, "\n")` 返回"从头开始，遇到 `\n` 之前的字符个数"——正好是换行符的下标。把这个位置改成 `'\0'`，换行符及其后的一切都被截掉。没有换行符时它返回整行的长度，改的是 `'\0'` 自己，也不会出错。

```c
// 5.3.2 strip_newline.c
#include <stdio.h>
#include <string.h>

int main(void)
{
	char line[64];

	FILE *fp = fopen("words.txt", "w");
	if (fp == NULL) {
		return 1;
	}
	fprintf(fp, "apple\nbanana\n");
	fclose(fp);

	fp = fopen("words.txt", "r");
	if (fp == NULL) {
		return 1;
	}

	while (fgets(line, sizeof(line), fp) != NULL) {
		printf("去掉换行前：[%s]，长度 %zu\n", line, strlen(line));
		line[strcspn(line, "\n")] = '\0';
		printf("去掉换行后：[%s]，长度 %zu\n", line, strlen(line));
	}
	fclose(fp);

	return 0;
}
```

<!-- output: 5.3.2 -->
```text
去掉换行前：[apple
]，长度 6
去掉换行后：[apple]，长度 5
去掉换行前：[banana
]，长度 7
去掉换行后：[banana]，长度 6
```

`apple` 本身 5 个字符，带着 `\n` 长度是 6。去掉之后长度正好少 1。

初学者常见的土办法是 `line[strlen(line) - 1] = '\0';`——它在"行末尾刚好是 `\n`"时没问题，但最后一行如果没有换行符（文件常见这样），就会误删最后一个有用的字符。就像闭着眼睛撕日历：正常情况撕掉的是过去的一天，可要是日历本来就翻到了今天，你撕掉的就成了今天本身。`strcspn` 的写法是先找到 `\n` 的确切位置再动手，没有 `\n` 就不撕，没有这个坑，推荐固定用它。

## 5.3.3 fputs：往文件写一行

```c
fputs(字符串, fp);
```

`fputs` 把整个字符串写进文件。和 `puts` 不同，**它不自动加换行**，想换行要自己在字符串里写 `\n`——它是个只管抄写、不管抬笔换行的抄写员，想另起一行得你自己说。

```c
// 5.3.3 fputs_write.c
#include <stdio.h>
#include <string.h>

int main(void)
{
	char line[64];

	FILE *fp = fopen("todo.txt", "w");
	if (fp == NULL) {
		return 1;
	}
	fputs("buy milk\n", fp);
	fputs("read book\n", fp);
	fclose(fp);

	fp = fopen("todo.txt", "r");
	if (fp == NULL) {
		return 1;
	}

	int number = 1;
	while (fgets(line, sizeof(line), fp) != NULL) {
		line[strcspn(line, "\n")] = '\0';
		printf("%d. %s\n", number, line);
		number++;
	}
	fclose(fp);

	return 0;
}
```

<!-- output: 5.3.3 -->
```text
1. buy milk
2. read book
```

写的时候 `fputs` 自己不加换行，读回来之后用 `strcspn` 截掉换行再加行号输出——`fgets` 保留换行、输出前手动去掉，这套配合写熟了，逐行处理文件就顺手了。

## 5.3.4 常见错误

| 错误写法 | 问题 | 正确写法 |
|----------|------|----------|
| 忘了 `fgets` 会保留 `\n` | 拿 `line` 去 `strcmp` 总是不相等 | 先 `line[strcspn(line, "\n")] = '\0';` |
| `line[strlen(line) - 1] = '\0';` 去换行 | 末尾没有 `\n` 时误删最后一个字符 | 用 `strcspn` 的写法 |
| `fgets(line, 64, fp)` 数字写死 | 数组改成 32 后忘了改，可能越界 | `fgets(line, sizeof(line), fp)` |
| `fputs("text", fp)` 想换行 | `fputs` 不自动加换行 | 字符串里自己写 `\n` |
| 用 `gets(line)` 读 | `gets` 无法限制长度，C11 已删除 | 永远用 `fgets` |

## 5.3.5 小结

- `fgets(数组, 大小, fp)` 从文件读一行，返回 `NULL` 表示读不到，逐行读文件的固定模板是 `while (fgets(...) != NULL)`。
- `fgets` 会把换行符一起读进数组；用 `line[strcspn(line, "\n")] = '\0';` 去掉。
- `fputs(字符串, fp)` 写整个字符串，不自动加换行。
- `fgets` 第二个参数固定写 `sizeof(line)`，数组扩缩容时不用改代码。
- 读回来的内容和文件里的格式一一对应，处理前先想清楚 `\n` 在不在。

#### 三、改错题

6. 三处错误：

- 第一处：想读文件却用 `"w"` 模式打开。`"w"` 只写不清不楚不说，还会把原文件清空，读取也读不到东西。应改为`"r"`。
- 第二处：`line == "quit"` 比较的是两个地址，不是字符串内容，永远不相等。应使用`strcmp`。
- 第三处：即使换成 `strcmp`，`fgets` 读到的`"quit"` 后面跟着`\n`，仍然不相等。比较前要先用`line[strcspn(line, "\n")] = '\0';` 去掉换行符。

```c
#include <stdio.h>
#include <string.h>

int main(void)
{
	char line[32];

	FILE *fp = fopen("cmd.txt", "r");
	if (fp == NULL) {
		return 1;
	}

	while (fgets(line, sizeof(line), fp) != NULL) {
		line[strcspn(line, "\n")] = '\0';
		if (strcmp(line, "quit") == 0) {
			printf("收到退出命令\n");
		}
	}
	fclose(fp);

	return 0;
}
```
