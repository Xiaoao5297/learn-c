# 5.1 文件与 FILE

到目前为止，我们的程序有个共同的弱点：程序一结束，内存里的数据就全没了。变量、数组、结构体都住在内存里，内存是"断电即忘"的。

这一节介绍文件：让程序把数据写进硬盘，也把硬盘上的数据读回来。

## 5.1.1 为什么需要文件

程序运行时的数据和文件里的数据，区别就在这里：

| 对比项 | 内存中的变量 | 硬盘上的文件 |
|--------|--------------|--------------|
| 程序结束后 | 数据消失 | 数据还在 |
| 容量 | 有限（几个 GB） | 很大 |
| 读写的函数 | 直接用变量名 | 要经过 `FILE` 和一堆 `f` 开头的函数 |
| 适合 | 运算过程的临时数据 | 需要长期保存的数据 |

想让"学生成绩""通讯录"这类数据在程序关闭后依然存在，就必须借助文件。这套思路有个专门的名字：**持久化（persistence）**——让数据活得比程序久。

## 5.1.2 打开与关闭：fopen 和 fclose

C 语言用一个 `FILE` 类型的指针代表"一个打开的文件"：

可以把它想成图书馆的**借书证**：办证（`fopen`）只是拿到一张凭证，书还留在图书馆里；后面所有操作都凭这张证进行，还证（`fclose`）之后凭证作废。凭证不等于书本身。

```c
FILE *fp = fopen("文件名", "模式");
```

| 函数 | 作用 |
|------|------|
| `fopen("hello.txt", "w")` | 打开文件，返回 `FILE *`；失败返回 `NULL` |
| `fclose(fp)` | 关闭文件，把缓冲区里的数据真正写进硬盘 |
| `fprintf(fp, ...)` | 往文件里写，用法和 `printf` 几乎一样，多一个 `fp` 参数 |

看第一个完整的例子：往 `hello.txt` 里写两行字。

```c
// 5.1.1 first_write.c
#include <stdio.h>

int main(void)
{
	FILE *fp = fopen("hello.txt", "w");
	if (fp == NULL) {
		printf("打开失败\n");
		return 1;
	}

	fprintf(fp, "你好，文件！\n");
	fprintf(fp, "这行字存在硬盘上。\n");
	fclose(fp);

	printf("已写入 hello.txt\n");

	return 0;
}
```

<!-- output: 5.1.1 -->
```text
已写入 hello.txt
```

运行后，当前目录会多出一个 `hello.txt`，用记事本打开就能看到写进去的两行字。

三个要点：

1. **文件写在当前目录**。`"hello.txt"` 是相对路径，程序在哪个目录下运行，文件就出现在哪里。
2. **写完必须 `fclose`**。`fprintf` 写的数据先放在缓冲区里，`fclose` 才保证它们落到硬盘。忘了关闭，轻则数据不完整，重则文件损坏。这就像你往快递柜里塞了东西但没关柜门——东西还在柜口搁着，没真正锁进去。
3. 文件打开后只能按打开时的"模式"使用：`"w"` 模式只能写，不能读。这好比食堂窗口的分工——"只出餐"的窗口不收餐盘，模式就是窗口上挂的那块牌子。

## 5.1.3 打开失败：永远检查 NULL

`fopen` 不一定成功：文件可能不存在，路径可能写错，磁盘可能满了，权限可能不够。失败时它返回 `NULL`，而不是报错崩溃。就像借书证办不下来——窗口没给你证，只递出来一张"没办成"的空凭证（`NULL`）。拿着空凭证还想进出书库，是要出事的。

```c
// 5.1.2 open_fail.c
#include <stdio.h>

int main(void)
{
	FILE *fp = fopen("不存在的目录/data.txt", "r");

	if (fp == NULL) {
		printf("打开失败，fp 是 NULL\n");
		printf("先处理错误，再正常退出\n");
		return 0;
	}

	fclose(fp);
	return 0;
}
```

<!-- output: 5.1.2 -->
```text
打开失败，fp 是 NULL
先处理错误，再正常退出
```

如果不检查就往下用，把 `NULL` 交给 `fprintf` 这类函数，程序会直接崩溃。所以请把下面的模板变成肌肉记忆：

```c
FILE *fp = fopen("data.txt", "r");
if (fp == NULL) {
	/* 处理错误：提示用户、返回错误码，总之别再往下用 fp */
}
```

对文件操作来说，"每次打开都检查"不是好习惯，而是最低要求。

## 5.1.4 打开模式：r、w、a 和带 + 的模式

`fopen` 的第二个参数决定"打开这个文件想干什么"：

| 模式 | 含义 | 文件不存在时 | 文件已存在时 |
|------|------|--------------|--------------|
| `"r"` | 只读 | 打开失败 | 从头读，内容保留 |
| `"w"` | 只写 | 创建新文件 | **清空**原有内容 |
| `"a"` | 追加 | 创建新文件 | 从末尾追加，内容保留 |
| `"r+"` | 读和写 | 打开失败 | 从头开始，内容保留 |
| `"w+"` | 读和写 | 创建新文件 | 清空原有内容 |
| `"a+"` | 读和追加 | 创建新文件 | 写永远追加到末尾 |

最容易踩的坑是 `"w"`：它一打开就清空整个文件，相当于拿到一本新笔记本就先把旧页全撕掉——哪怕你一个字还没写。想保留旧内容、只在后面加东西，要用 `"a"`。

下面的程序演示三种最常用模式的配合：先 `"w"` 写第一行，再 `"a"` 追加第二行，最后 `"r"` 读回来。

```c
// 5.1.3 modes_demo.c
#include <stdio.h>

int main(void)
{
	char line[64];

	FILE *fp = fopen("diary.txt", "w");
	if (fp == NULL) {
		return 1;
	}
	fprintf(fp, "第一天：学了 fopen\n");
	fclose(fp);

	fp = fopen("diary.txt", "a");
	if (fp == NULL) {
		return 1;
	}
	fprintf(fp, "第二天：学了 fprintf\n");
	fclose(fp);

	fp = fopen("diary.txt", "r");
	if (fp == NULL) {
		return 1;
	}
	while (fgets(line, sizeof(line), fp) != NULL) {
		printf("%s", line);
	}
	fclose(fp);

	return 0;
}
```

<!-- output: 5.1.3 -->
```text
第一天：学了 fopen
第二天：学了 fprintf
```

两行都在，说明 `"a"` 没有破坏 `"w"` 写下的内容。`fgets` 逐行读文件的细节在 5.3 详细讲，这里只需要知道它能一行一行读。

## 5.1.5 FILE 是什么

`FILE` 是 `stdio.h` 里定义的一种结构体类型，里面记录了文件的全部状态：读写到了哪个位置、缓冲区里还有什么、有没有出错。你不需要知道它的内部结构，只需要掌握三条使用规则：

1. 一个 `FILE *` 对应一个打开的文件，操作文件永远带着这个指针——就像借书证要随身带着，每次借还书都出示它。
2. 用完必须 `fclose`，一个文件打开两次（比如各拿一个 `fp`）也各有各的状态，就像同一个人办了两张证，各自记录各自的借阅情况。
3. 读写函数都会更新文件里的"当前位置"，读完一个字符再读，得到的是下一个字符——就像翻书页：你看完第 10 页，下次翻开自然就是第 11 页。

## 5.1.6 常见错误

| 错误写法 | 问题 | 正确写法 |
|----------|------|----------|
| `FILE *fp = fopen("a.txt", "r"); fprintf(fp, ...);` | 没检查 `NULL`，失败就崩溃 | 打开后先 `if (fp == NULL)` |
| `"w"` 模式打开旧文件再写入 | 原内容被清空 | 想保留就用 `"a"` 或 `"r+"` |
| `fprintf` 完不 `fclose` | 缓冲区没落盘，文件可能不完整 | 写完立即 `fclose` |
| `fclose` 后继续用 `fp` | 使用已关闭的文件，未定义行为 | `fclose` 之后不再碰 `fp` |

## 5.1.7 小结

- 内存断电即忘，文件长期保存；把数据存进文件叫持久化。
- `FILE *fp = fopen(文件名, 模式);` 打开文件，失败返回 `NULL`，**必须检查**。
- 用完 `fclose(fp);`，否则缓冲区里的数据可能没真正写进硬盘。
- `"r"` 只读、`"w"` 清空重写、`"a"` 末尾追加；`+` 表示同时可读可写。
- `fprintf(fp, ...)` 往文件写，用法和 `printf` 一样，只是多了第一个参数 `fp`。
