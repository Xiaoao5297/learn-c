# 第 0 章：计算机是怎样跑起来的

这一章不教 C 语言。

它只回答几个看起来简单、但后面每天都会遇到的问题：

- 按下电源键以后，计算机到底做了什么？
- 内存和硬盘有什么区别？
- 源代码是怎样变成能运行的程序？
- 为什么中文在 Windows 控制台里会变成乱码？
- 终端、编译器、调试器、Make 各自是干什么的？

如果你已经比较熟悉这些内容，可以快速浏览，或者直接跳到第 1 章。不过建议至少读一遍 0.2 和 0.3，因为后面讲编译、指针和文件时，会反复用到这些概念。

## 学完这一章，你应该能

1. 用自己的话说清楚 CPU、内存、硬盘各自负责什么。
2. 说清楚“程序”和“进程”的区别。
3. 判断一个错误是编译错误还是运行错误。
4. 解释中文乱码最常见的原因。
5. 知道终端、编译器、调试器、构建工具分别解决什么问题。

## 怎么读这一章

这一章没有需要背诵的代码，也没有必须安装的软件。遇到不熟悉的词，先知道它大概负责什么即可，不需要一次记住所有细节。

每节末尾有少量自测题，答案默认折叠。先自己想，再展开对照。
