# 从零开始学 C 语言（Learn-C 第 1 卷）🚀

一套手把手、面向零基础的 C 语言图文教程。全系列主线共 **10 章**，外加一套"写出好代码"的**阶段复习**。所有小节都配代码、输出、练习题与章末测试，跟着敲、跟着练，就能从 `Hello World` 一路走到能写出"数据不丢失"的小型管理系统。

> 💡 **怎么用这份教程最有效**
>
> - 📖 **按顺序读**：内容有严格的前后依赖（指针依赖数组、链表依赖指针与内存…），不建议跳读
> - ⌨️ **边看边敲**：每个代码块都自己敲一遍并运行，别只看
> - 🧪 **做练习**：每节末有练习题，每章末有 `test/` 章末测试（答案藏在"🔑 点击展开"里）
> - 🐢 **卡住就回头**：每节都标了用到的"前置小节"，不懂就点回去复习

## 🛠️ 先准备什么

1. 按 **第 1.2 节** 装好编译器（gcc/clang）
2. 一个趁手的编辑器（VS Code / 记事本都行，教程里会教）
3. 一个能跑命令的终端

遇到"编译报错看不懂"？先去复习章的 [编写 Makefile](review/5_makefile.md) 和 [工程好习惯](review/4_good_habits.md)。

准备好了？从第一句 `Hello World` 出发吧！👇
