# 从零开始学 C 语言

一套面向零基础的 C 语言教程。内容从计算机基础开始，经过语法、数组、指针、文件、内存和数据结构，最后完成一个可以保存数据的通讯录项目。

教程按“先能运行，再讲清楚，最后写得规范”的顺序组织。示例尽量保持完整、可编译；代码风格统一放在第 2.6 节说明。

## 怎么用这份教程

1. 从第 0 章开始。它不教 C 语法，只解释计算机、程序、编码和终端这些后面每天都会遇到的概念。
2. 按顺序阅读。指针依赖数组，链表依赖指针和内存，跳读容易留下空洞。
3. 每个示例都自己敲一遍并运行。示例代码的第一行有编号和文件名，代码块后面是对应的输出。
4. 先做练习，再展开答案。章末测试用来检查是否真的掌握，不用追求一次全对。
5. 遇到编译错误，先看文件名、行号和第一条错误，不要从最后一条开始读。

## 先准备什么

- 一台能安装编译器的电脑。教程以 Linux 为主，Windows 用户使用 MinGW-w64，关键差异会单独提示。
- 一个文本编辑器。VS Code 可以，系统自带的编辑器也可以。
- 一个终端。Linux 用系统终端，Windows 用 PowerShell、CMD 或 Windows Terminal。

具体安装步骤见 [1.2 搭建开发环境](<chapter1/sections/1.2 搭建开发环境.md>)。

## 代码约定

- 缩进使用 Tab，显示宽度按 4 列。
- 控制语句的左大括号不换行，函数定义的大括号另起一行。
- 变量和函数使用小写加下划线，例如 `student_count`。
- 完整示例使用 `int main(void)`。
- 每章正文中的完整示例都带编号，例如 `2.1.1 arithmetic.c`。

详细规则和工具配置见 [2.6 代码规范](<chapter2/sections/2.6 代码规范.md>)。
