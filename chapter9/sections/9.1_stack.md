# 9.1 栈：后进先出的"叠盘子" 🥞

> 💬 **节前语：**
>
> 你有没有在食堂叠过盘子？——**后放上去的盘子，总是先被拿走**。先放的在最底下，反而最后才轮到它。
>
> 这种"**后进先出（Last In First Out，LIFO）**"的规矩，在计算机里无处不在：
>
> - 🔢 **函数调用**：还记得第7章吗？`fact(3)` 调用 `fact(2)`，后调用的先返回——函数调用靠的就是"栈"
> - ↩️ **浏览器的"后退"**：你点开的网页一层层压进去，点"后退"时总是回到**最近**看过的那个
> - ⌨️ **撤销（Ctrl+Z）**：撤销的总是"最近一次操作"
>
> 这一节，我们就把这个大名鼎鼎的"规矩"亲手实现成一个数据结构——**栈（Stack）**，并顺手用它写一个超实用的**括号匹配检查器**。准备好了吗？开始吧！

---

## 9.1.1 栈长什么样？就四个动作

把栈想象成一摞盘子（或一筒羽毛球），我们只在**最顶上**动手：

```
   push(10)      push(20)      push(30)      pop()  → 30
   ┌────┐        ┌────┐        ┌────┐
   │ 10 │        │ 20 │        │ 30 │◄──── 栈顶
   └────┘        │ 10 │        │ 20 │
                 └────┘        │ 10 │
                               └────┘
   （空）          （两个）      （三个）       弹出一个 → 剩下 10、20
```

栈的操作永远只有这几个：

| 操作 | 英文 | 干什么 | 比喻 |
|------|------|--------|------|
| 压栈 | `push` | 把数据放到栈顶 | 往上叠一个盘子 |
| 弹栈 | `pop` | 取出栈顶并删除 | 拿走最上面的盘子 |
| 看栈顶 | `peek` / `top` | 只看不取 | 瞄一眼最上面的盘子 |
| 判空 | `isEmpty` | 栈里有没有东西 | 盘子摞是空的吗 |

> 📌 **核心纪律：只能在栈顶操作。** 不能从中间抽，也不能从底下掏——这就是"后进先出"。

## 9.1.2 数组怎么实现栈？

栈本质是"一串数据 + 一个指向栈顶的标记"。用数组最直接：**数组存数据，一个整型 `top` 记住栈顶下标。**

```
数组： data[0] data[1] data[2] ... data[MAX-1]
       ┌────┬────┬────┬───┬───┐
       │ 10 │ 20 │ 30 │   │   │
       └────┴────┴────┴───┴───┘
              top = 2 （栈顶是 data[2] = 30）
```

- 空栈：`top = -1`（一个都没有）
- 压栈：`top` 加 1，把数放进 `data[top]`
- 弹栈：取走 `data[top]`，`top` 减 1

用结构体把"数组 + 栈顶"打包（复习第4章），写起来最整洁：

```c
#include <stdio.h>

#define MAX 100

typedef struct {
    int data[MAX];
    int top;                 // 栈顶下标；空栈时 top = -1
} Stack;

// 初始化：空栈
void init(Stack *s) {
    s->top = -1;
}

int isEmpty(Stack *s) {
    return s->top == -1;
}

int isFull(Stack *s) {
    return s->top == MAX - 1;      // 数组放满了
}

// 压栈
void push(Stack *s, int value) {
    if (isFull(s)) {
        printf("栈满了，%d 压不进去！\n", value);
        return;
    }
    s->top++;              // 栈顶往上走一格
    s->data[s->top] = value;
}

// 弹栈：返回栈顶值，并把它删除
int pop(Stack *s) {
    if (isEmpty(s)) {
        printf("栈是空的，弹不出东西！\n");
        return -1;          // 约定：空栈弹不出，返回 -1
    }
    int value = s->data[s->top];
    s->top--;               // 栈顶往下退一格 = 把最上面的盘子拿走
    return value;
}

// 看栈顶（不删除）
int peek(Stack *s) {
    return s->data[s->top];
}

int main() {
    Stack s;
    init(&s);

    push(&s, 10);
    push(&s, 20);
    push(&s, 30);

    printf("栈顶是：%d\n", peek(&s));
    printf("弹出：%d\n", pop(&s));
    printf("弹出：%d\n", pop(&s));
    printf("弹出：%d\n", pop(&s));

    if (isEmpty(&s)) {
        printf("现在栈是空的\n");
    }
    return 0;
}
```

输出：
```
栈顶是：30
弹出：30
弹出：20
弹出：10
现在栈是空的
```

> 📌 **观察：后压进去的 30 先弹出来**——这就是"后进先出"。函数参数为什么传 `Stack *s`？——因为 `push`/`pop` 要**修改** `s.top`，必须传地址（第4章 swap 的道理）！

## 9.1.3 小试牛刀：括号匹配检查器

学栈的经典应用：检查表达式里的括号是不是**成对且嵌套正确**。比如：

```
正确： (1+2) * [3 - {4/5}]
错误： (1+2]        ← 括号类型对不上
错误： ([)]         ← 交叉嵌套，不对
错误： (1+2))       ← 多了一个右括号
```

思路用一个"等待配对"的栈：

- 遇到**左括号** `(` `[` `{` → 压栈（它还在等一个右括号来配对）
- 遇到**右括号** `)` `]` `}` → 从栈里弹出**最近**的左括号，看配不配得上：
  - 栈是空的 → 这个右括号没人配 → 错误
  - 配不上（`(` 对上了 `]`）→ 错误
- 全部扫完，栈里**还剩下**左括号 → 也有没配上的 → 错误

```c
#include <stdio.h>

#define MAX 100

typedef struct {
    int data[MAX];
    int top;
} Stack;

void init(Stack *s) { s->top = -1; }
int isEmpty(Stack *s) { return s->top == -1; }

void push(Stack *s, int value) {
    if (s->top == MAX - 1) return;    // 简化：满了就忽略（演示用）
    s->top++;
    s->data[s->top] = value;
}

int pop(Stack *s) {
    if (isEmpty(s)) return -1;
    return s->data[s->top--];
}

// 判断一对括号是否配得上
int match(char open, char close) {
    return (open == '(' && close == ')') ||
           (open == '[' && close == ']') ||
           (open == '{' && close == '}');
}

// 判断字符串里的括号是否配对正确
int isBalanced(const char *str) {
    Stack s;
    init(&s);

    for (int i = 0; str[i] != '\0'; i++) {
        char ch = str[i];
        if (ch == '(' || ch == '[' || ch == '{') {
            push(&s, ch);                 // 左括号：压栈等配对
        } else if (ch == ')' || ch == ']' || ch == '}') {
            if (isEmpty(&s)) return 0;    // 没有左括号等它 → 错误
            char open = (char)pop(&s);
            if (!match(open, ch)) return 0; // 类型对不上 → 错误
        }
    }
    return isEmpty(&s);                   // 栈还空着 → 全配完了，正确
}

int main() {
    printf("(1+2)*[3-{4}] ：%s\n", isBalanced("(1+2)*[3-{4}]") ? "配对正确" : "配对错误");
    printf("(1+2]        ：%s\n", isBalanced("(1+2]") ? "配对正确" : "配对错误");
    printf("([)]         ：%s\n", isBalanced("([)]") ? "配对正确" : "配对错误");
    printf("(1+2))       ：%s\n", isBalanced("(1+2))") ? "配对正确" : "配对错误");
    printf("((1+2)       ：%s\n", isBalanced("((1+2)") ? "配对正确" : "配对错误");
    return 0;
}
```

输出：
```
(1+2)*[3-{4}] ：配对正确
(1+2]        ：配对错误
([)]         ：配对错误
(1+2))       ：配对错误
((1+2)       ：配对错误
```

> 🎉 五句判语，全对！编译器检查代码里括号是否成对，用的就是这套"栈"的思路。**后遇到的右括号，要配的是最近压进去的那个左括号**——天然就是 LIFO。

## 9.1.4 栈还能用链表做？—— 两个选择

栈的底层"容器"，数组和链表都能当：

| | 数组版 | 链表版 |
|---|--------|--------|
| 弹栈/压栈 | 只要动 `top`，O(1) 飞快 | 头插/头删，O(1) 飞快 |
| 大小 | 固定（MAX），满了要扩容 | 想多大就多大（节点是 malloc 的） |
| 内存 | 连续一块，可能有浪费 | 每节点一点开销 |
| 适合 | 栈的规模基本确定 | 栈的规模不确定/会很大 |

> 💡 **一句话：** 栈"只在头顶动手"，数组和链表都能做到 O(1)。数组简单，链表灵活。我们在 9.2 用链表做队列时，会再见到"节点 + 指针"的老朋友。

> 🔎 **顺手复习：** 第7章那个"函数调用栈"，底层和这里的数组栈是同一个"栈"思想——后调用的先返回，后压入的先弹出。学会了数据结构"栈"，再回头看函数调用，是不是通透多了？

## 9.1.5 本节小结

这一节我们学了：

✅ **栈是什么：** 后进先出（LIFO），只在栈顶操作

✅ **四个动作：** push 压栈 / pop 弹栈 / peek 看顶 / isEmpty 判空

✅ **数组实现：** 数组存数据 + `top` 记栈顶；空栈 `top = -1`

✅ **经典应用：** 括号匹配——左括号压栈等配对，右括号弹栈来配对

✅ **数组版 vs 链表版：** 都是 O(1)，数组简单、链表灵活

> 💡 **记住：栈 = "一摞盘子"。后放的先拿，只动最上面那一个。**

#include <stdio.h>
