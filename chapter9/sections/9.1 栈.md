# 9.1 栈

第 7 章讲递归时提过一句：每次函数调用，系统都会往一个叫"栈"的记账本顶上压一条记录，返回时再弹出。当时只当名词用。这一节，我们把这个"栈"亲手造出来——你会发现它并不神秘，就是一个**只准在顶上动手**的数组。

## 9.1.1 后进先出：一摞盘子

食堂打饭窗口有一个叠盘子的弹簧架：洗干净的盘子**从顶上一个一个压上去**，取盘子的人也是**从顶上一个一个拿走**。最后放上去的那只盘子，最先被拿走；最先放上去的，反而压在最底下，最后才轮到它。

这种"后进先出"（Last In First Out，LIFO）的规矩，就是**栈（stack）**。它像第 7 章的调用栈：后调用的函数先返回；也像一摞作业本：老师改的总是最上面那份。

栈只允许一套极少的动作：

| 操作 | 名字 | 干什么 | 盘子架上的对应动作 |
|------|------|--------|--------------------|
| 压栈 | `push` | 把数据放到栈顶 | 往顶上压一只盘子 |
| 弹栈 | `pop` | 取走栈顶的数据 | 拿走最上面的盘子 |
| 看栈顶 | `peek` | 只看不取 | 瞄一眼最上面的盘子 |
| 判空 | `is_empty` | 栈里还有没有数据 | 架子上还有没有盘子 |

核心纪律只有一条：**只能在栈顶操作**。不能从中间抽，也不能从底下掏。正是这条限制，让栈的每个操作都极快——不用挪动任何其他数据。

## 9.1.2 用数组实现栈

栈的本质是"一串数据 + 一个记着顶在哪的下标"。用数组最直接：数组存数据，一个整型 `top` 记录栈顶的下标。

- 空栈：`top = -1`（一个数据都没有）
- 压栈：`top` 加 1，把数据放进 `data[top]`
- 弹栈：取出 `data[top]`，`top` 减 1

把"数组 + 栈顶下标"打包进一个结构体（第 4 章的老办法），就得到一个栈类型：

```c
// 9.1.1 stack_basic.c
#include <stdio.h>
#include <stdbool.h>

#define MAX 100

struct stack {
	int data[MAX];    /* 存数据的数组 */
	int top;          /* 栈顶下标，空栈时为 -1 */
};

void init(struct stack *s)
{
	s->top = -1;
}

bool is_empty(const struct stack *s)
{
	return s->top == -1;
}

bool is_full(const struct stack *s)
{
	return s->top == MAX - 1;
}

bool push(struct stack *s, int value)
{
	if (is_full(s)) {
		return false;    /* 满了压不进，报告失败 */
	}
	s->top++;
	s->data[s->top] = value;
	return true;
}

bool pop(struct stack *s, int *value)
{
	if (is_empty(s)) {
		return false;    /* 空栈弹不出 */
	}
	*value = s->data[s->top];
	s->top--;
	return true;
}

int main(void)
{
	struct stack s;

	init(&s);

	for (int i = 10; i <= 40; i += 10) {
		push(&s, i);
	}
	printf("压入了 10 20 30 40\n");

	int value;
	pop(&s, &value);
	printf("弹出：%d\n", value);

	printf("看一眼栈顶：%d\n", s.data[s.top]);

	while (pop(&s, &value)) {
		printf("弹出：%d\n", value);
	}

	if (is_empty(&s)) {
		printf("栈已经空了\n");
	}

	return 0;
}
```

<!-- output: 9.1.1 -->
```text
压入了 10 20 30 40
弹出：40
看一眼栈顶：30
弹出：30
弹出：20
弹出：10
栈已经空了
```

最后压进去的 40 最先弹出来——这就是后进先出。

三个设计决定值得停下来看：

- **函数都传 `struct stack *`**。`push`、`pop` 要修改 `s.top`，必须传地址（第 4 章讲过的道理：想改什么，就传它的地址）。`is_empty`、`is_full` 只读，参数加 `const`。
- **`push` 和 `pop` 用返回值报告成败，而不是打印**。栈满、栈空不是"程序出错"，只是正常动作被拒绝；打印到屏幕是调用者的事，数据结构本身只负责"做了没有"。`pop` 里栈顶的值通过指针参数 `int *value` 带出去，返回值空出来报告成败。
- **`init` 不要省**。局部变量的 `top` 初值是随机的，忘了设成 -1，一切判断全乱。

## 9.1.3 慢镜头：top 怎么走

把 `top` 的变化记录下来，栈就不抽象了。对 MAX 为 3 的小栈连续压入，再全部弹出：

```c
// 9.1.2 stack_trace.c
#include <stdio.h>
#include <stdbool.h>

#define MAX 3

struct stack {
	int data[MAX];
	int top;
};

void init(struct stack *s)
{
	s->top = -1;
}

bool push(struct stack *s, int value)
{
	if (s->top == MAX - 1) {
		printf("栈满，%d 压不进\n", value);
		return false;
	}
	s->top++;
	s->data[s->top] = value;
	printf("压入 %d，top 变成 %d\n", value, s->top);
	return true;
}

bool pop(struct stack *s, int *value)
{
	if (s->top == -1) {
		printf("栈空，弹不出\n");
		return false;
	}
	*value = s->data[s->top];
	s->top--;
	printf("弹出 %d，top 变成 %d\n", *value, s->top);
	return true;
}

int main(void)
{
	struct stack s;

	init(&s);
	push(&s, 10);
	push(&s, 20);
	push(&s, 30);
	push(&s, 40);

	int value;
	while (pop(&s, &value)) {
	}

	return 0;
}
```

<!-- output: 9.1.2 -->
```text
压入 10，top 变成 0
压入 20，top 变成 1
压入 30，top 变成 2
栈满，40 压不进
弹出 30，top 变成 1
弹出 20，top 变成 0
弹出 10，top 变成 -1
栈空，弹不出
```

对照着读：`top` 就是"最上面那只盘子的位置"。压栈它上移一格，弹栈它退回一格；`top` 走到 `MAX - 1` 说明盘子压满了，退到 -1 说明架子空了。数组的容量是固定的，满了就是满了——数组栈要提前把 `MAX` 定够大，或改用第 6 章的 `malloc` 动态分配。

## 9.1.4 应用：括号匹配检查器

栈最经典的应用之一：检查一段表达式里的括号是否成对、且嵌套正确。

```text
正确： (1+2)*[3-{4/5}]
错误： (1+2]        类型对不上
错误： ([)]         交叉嵌套
错误： (1+2))       多了一个右括号
```

为什么栈能干这件事？关键在于：**每个右括号要配对的，永远是"离它最近的那个左括号"**——也就是最后遇到的、还没被配走的那个左括号。后遇到的先配走，正是后进先出。

思路像这样：桌上放一叠纸条（栈），从左到右读字符——

- 遇到左括号 `(` `[` `{`：写一张纸条压上去，等右括号来领。
- 遇到右括号：看一眼纸条最顶上那张。没有纸条（栈空）→ 右括号没人配，错；纸条上的类型对不上 → 错；配上了 → 取走纸条。
- 全部读完：纸条还剩 → 左括号没等到配对，错；一张不剩 → 全配上了，对。

```c
// 9.1.3 bracket_check.c
#include <stdio.h>
#include <stdbool.h>

#define MAX 100

struct bracket_stack {
	char data[MAX];
	int top;
};

void init(struct bracket_stack *s)
{
	s->top = -1;
}

bool push(struct bracket_stack *s, char ch)
{
	if (s->top == MAX - 1) {
		return false;
	}
	s->top++;
	s->data[s->top] = ch;
	return true;
}

bool pop(struct bracket_stack *s, char *ch)
{
	if (s->top == -1) {
		return false;
	}
	*ch = s->data[s->top];
	s->top--;
	return true;
}

/* 一对左右括号类型是否配得上 */
bool is_pair(char open, char close)
{
	return (open == '(' && close == ')') ||
	       (open == '[' && close == ']') ||
	       (open == '{' && close == '}');
}

bool is_balanced(const char str[])
{
	struct bracket_stack s;

	init(&s);

	for (int i = 0; str[i] != '\0'; i++) {
		char ch = str[i];

		if (ch == '(' || ch == '[' || ch == '{') {
			push(&s, ch);
		} else if (ch == ')' || ch == ']' || ch == '}') {
			char open;
			if (!pop(&s, &open)) {
				return false;    /* 右括号没人配 */
			}
			if (!is_pair(open, ch)) {
				return false;    /* 类型对不上 */
			}
		}
	}

	return s.top == -1;    /* 左括号全配完才对 */
}

void check(const char str[])
{
	printf("%-16s：%s\n", str,
	       is_balanced(str) ? "配对正确" : "配对错误");
}

int main(void)
{
	check("(1+2)*[3-{4/5}]");
	check("(1+2]");
	check("([)]");
	check("(1+2))");
	check("((1+2)");

	return 0;
}
```

<!-- output: 9.1.3 -->
```text
(1+2)*[3-{4/5}] ：配对正确
(1+2]           ：配对错误
([)]            ：配对错误
(1+2))          ：配对错误
((1+2)          ：配对错误
```

五个结果全对。注意数据结构没换，只是 `data` 的类型从 `int` 改成 `char`，压的是括号字符本身。`check` 里用 `%-16s` 左对齐输出字符串（宽度固定 16），纯粹是为了让五行的冒号对齐好看。

编译器检查你代码里的括号、编辑器做语法高亮、文本编辑器判断"缺右括号"，用的都是这一套思路。**后遇到的右括号，要配最近遇到的左括号**——问题天然就是 LIFO 的，用栈写起来自然就短。

## 9.1.5 栈与函数调用的呼应

回头看第 7 章：递归调用 `fact(3)` 时，`fact(3)`、`fact(2)`、`fact(1)` 的栈帧一层层压上去；递归到头，又是 `fact(1)` 先返回、`fact(2)` 次之——**后调用的先返回**。那个"调用栈"和我们刚才写的数组栈，是同一个思想在两个地方的落地：

| | 函数调用栈 | 我们的数组栈 |
|------|-----------|--------------|
| 压入 | 调用函数时，压入栈帧 | `push` |
| 弹出 | 函数返回时，弹出栈帧 | `pop` |
| 只在顶上动手 | 系统的规矩 | 我们自己写的规矩 |
| 溢出 | 递归太深，栈溢出（7.2 讲过） | `top` 撞上 `MAX - 1` |

两处连"溢出"都对应得上：递归没有出口，调用栈一层层压到极限就崩；我们的栈没有检查 `is_full`，`top` 也会越过数组边界写出错误内存。数据结构的纪律，就是防住这些"越界"。

## 9.1.6 小结

- 栈：后进先出（LIFO），只准在栈顶操作。
- 四个动作：`push` 压栈、`pop` 弹栈、`peek` 看顶、`is_empty` 判空。
- 数组实现：数组存数据 + `top` 记栈顶；空栈 `top = -1`，满栈 `top = MAX - 1`。
- `push`/`pop` 返回 `bool` 报告成败，取出的值经指针参数带回；栈满、栈空必须检查。
- 括号匹配：左括号压栈等配对，右括号弹栈配对，读完全部时栈必须空。
- 第 7 章的函数调用栈，就是这套思想的系统版。

#### 一、选择题

1. B。栈只准在栈顶进出，最后进的最先出。
2. C。`-1` 表示"还没有任何数据"；数组合法下标从 0 开始，-1 不可能与真实栈顶混淆。
3. C。3 是最后压入的，在栈顶，先弹出。

#### 二、填空题

4. 栈顶。
5. 压栈（push）；空。

#### 三、改错题

6. 三处错误：

- 第一处：`init` 里 `s->top = 0` 应为 `s->top = -1`。空栈时没有任何数据，`top` 为 0 会让第一次 `push` 直接写到 `data[1]`，`data[0]` 空着，逻辑全乱。
- 第二处：`pop` 应先取值再 `s->top--`，正确写法见下面的修正程序。原代码取走 `data[s->top]` 后 `top` 没有减 1，连续三次 `pop` 返回同一个值，栈也永远"不空"。
- 第三处：`printf("%d %d %d\n", pop(&s), pop(&s), pop(&s))` 的求值顺序没有约定，C 标准不保证三个 `pop` 从左到右执行，输出可能是 `3 2 1` 也可能乱序。应先弹出存进变量，再按顺序打印。

修正后的完整程序：

```c
#include <stdio.h>

#define MAX 5

struct stack {
	int data[MAX];
	int top;
};

void init(struct stack *s)
{
	s->top = -1;
}

void push(struct stack *s, int value)
{
	if (s->top == MAX - 1) {
		return;
	}
	s->top++;
	s->data[s->top] = value;
}

int pop(struct stack *s)
{
	int value = s->data[s->top];
	s->top--;
	return value;
}

int main(void)
{
	struct stack s;

	init(&s);
	push(&s, 1);
	push(&s, 2);
	push(&s, 3);

	int a = pop(&s);
	int b = pop(&s);
	int c = pop(&s);
	printf("%d %d %d\n", a, b, c);

	return 0;
}
```

输出 `3 2 1`。

#### 四、编程题

7. 参考代码：

```c
#include <stdio.h>
#include <stdbool.h>

#define MAX 32

struct stack {
	int data[MAX];
	int top;
};

void init(struct stack *s)
{
	s->top = -1;
}

bool push(struct stack *s, int value)
{
	if (s->top == MAX - 1) {
		return false;
	}
	s->top++;
	s->data[s->top] = value;
	return true;
}

bool pop(struct stack *s, int *value)
{
	if (s->top == -1) {
		return false;
	}
	*value = s->data[s->top];
	s->top--;
	return true;
}

int main(void)
{
	struct stack s;

	init(&s);

	int n = 13;
	while (n > 0) {
		push(&s, n % 2);
		n /= 2;
	}

	printf("13 的二进制是 ");
	int bit;
	while (pop(&s, &bit)) {
		printf("%d", bit);
	}
	printf("\n");

	return 0;
}
```

输出：

```text
13 的二进制是 1101
```

除 2 求余得到的余数是从低位到高位产生的（13 → 余 1、6 → 余 0、3 → 余 1、1 → 余 1），先产生的是二进制最低位；压栈后弹出顺序正好反过来，最低位最后出——栈天生会"倒序"。

8. 参考代码（`MAX` 取 8，每个元素是 `char page[16]`）：

```c
#include <stdio.h>
#include <stdbool.h>
#include <string.h>

#define MAX 8
#define PAGE_LEN 16

struct history {
	char page[MAX][PAGE_LEN];
	int top;
};

void init(struct history *h)
{
	h->top = -1;
}

bool push(struct history *h, const char *page)
{
	if (h->top == MAX - 1) {
		return false;
	}
	h->top++;
	snprintf(h->page[h->top], PAGE_LEN, "%s", page);
	return true;
}

bool back(struct history *h, char *page)
{
	if (h->top <= 0) {
		return false;    /* 至少留一个"当前页面" */
	}
	snprintf(page, PAGE_LEN, "%s", h->page[h->top]);
	h->top--;
	return true;
}

const char *current(const struct history *h)
{
	if (h->top == -1) {
		return "无";
	}
	return h->page[h->top];
}

int main(void)
{
	struct history h;

	init(&h);
	push(&h, "A");
	push(&h, "B");
	push(&h, "C");
	printf("当前页面：%s\n", current(&h));

	char page[PAGE_LEN];
	if (back(&h, page)) {
		printf("后退到 %s\n", current(&h));
	}
	if (back(&h, page)) {
		printf("后退到 %s\n", current(&h));
	}

	return 0;
}
```

输出：

```text
当前页面：C
后退到 B
后退到 A
```

每访问一个新页面就压栈，"后退"就是弹栈——最后访问的最先退回。
