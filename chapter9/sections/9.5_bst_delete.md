# 9.5 二叉查找树的删除：三种情况分而治之

> 💬 **节前语：**
>
> 9.4 里我们让 BST 学会了"插入"和"查找"，但一直留着一个大难题没说——**删除**。
>
> 链表删除只要改一两个指针；可 BST 删除要小心：删掉一个节点之后，还得保证剩下的树**仍然满足"左小右大"**，仍然是一棵合法的 BST。
>
> 好消息是：想清楚之后，删除其实也就**三种情况**：
>
> 1. 🍃 **删的是叶子** —— 没有孩子，摘掉就行
> 2. 🧒 **删的是独生子节点** —— 只有一个孩子，让孩子顶上来
> 3. 👨‍👩‍👦 **删的是"两娃"节点** —— 两个娃都在，需要找一个"替身"来顶班
>
> 这一节我们把三张图和三段代码讲透。它是 BST 操作里最考验"拆解思维"的一步，也是面试常客。准备好了吗？开始吧！

---

## 9.5.1 先看一棵要动手的树

以下面的 BST 为例（`50, 30, 70, 20, 40, 60, 80`）：

```
        50
       /  \
     30    70
    /  \   /  \
   20  40 60  80
```

它的中序遍历永远是升序：`20 30 40 50 60 70 80`。**每次删除后，我们都要让中序仍然升序**——这是检验删除对不对的"金标准"。

---

## 9.5.2 情况一：删叶子 🍃

比如删 `40`。它没有孩子，**直接 free 掉，让父亲的指针指向 NULL 即可**：

```
        50                       50
       /  \                     /  \
     30    70      删 40      30    70
    /  \   /  \    ─────►    /     /  \
   20  40 60  80            20    60  80
```

代码（这是整个删除函数的"最小单元"）：

```c
if (root->left == NULL && root->right == NULL) {
    free(root);       // 没有孩子：直接释放
    return NULL;      // 父亲那边会收到 NULL，正好"断线"
}
```

> 💡 注意 `return NULL` 会被上一层的 `root->left = deleteNode(...)` 接住——父亲的左指针就自动变成 NULL 了。**"把结果接回去"这套路（9.4）在这继续发光。**

---

## 9.5.3 情况二：只有一个孩子 🧒

比如想删 `30`，而它只有一个左孩子 `20`。这时不能直接 free——否则 `20` 也跟着"断线"了。做法是：**让唯一的孩子顶替自己的位置**。

```
        50                       50
       /  \                     /  \
     30    70      删 30      20    70
    /      /  \    ─────►           /  \
   20     60  80                  60  80
```

代码：

```c
// 只有右孩子
else if (root->left == NULL) {
    TreeNode *child = root->right;   // 记下唯一的孩子
    free(root);                      // 释放自己
    return child;                    // 让孩子顶上（父亲收到 child）
}
// 只有左孩子
else if (root->right == NULL) {
    TreeNode *child = root->left;
    free(root);
    return child;
}
```

> 📌 一句话：**有孩子就"立太子"——让唯一的孩子继承位置**。孩子的左右关系没被破坏，所以 BST 规则依然成立。

---

## 9.5.4 情况三：有两个孩子 👨‍👩‍👦（最巧妙的一步）

比如删 `50`。它有左子树也有右子树，直接让某个孩子顶上来？——都不行：左孩子 `30` 顶上来，右子树里可还有比它大的；右孩子 `70` 顶上来，左子树又有比它小的，乱套。

怎么办？**找个"替身"来顶班**。替身必须满足：**比左子树所有值都大，比右子树所有值都小**。谁最合适？

> 答案是：**右子树里最小的那个节点**，学名叫"**后继（successor）**"——它是比被删节点大一点点的那个值。

看 `50` 的右子树 `{60, 70, 80}`，最小的是 `60`。用 `60` 顶替 `50`：

```
        50                         60
       /  \                       /  \
     30    70       删 50       30    70
    /     /  \     ─────►      /     /  \
   20    60  80               20        80
           （60 先顶上来，再从右子树里删掉原来的 60）
```

步骤拆成两半：

```
① 用后继的值覆盖 root：    root->data = succ->data（这里 50 变成了 60）
② 去右子树里删掉那个后继：  root->right = deleteNode(root->right, succ->data)
```

代码：

```c
else {   // 左右孩子都有
    TreeNode *succ = findMin(root->right);      // 找右子树最小 = 后继
    root->data = succ->data;                    // 用后继的值顶替
    root->right = deleteNode(root->right, succ->data);  // 删掉右子树里那个后继
}
```

配套的 `findMin`（一路往左走到底）：

```c
// 返回 root 这棵子树里值最小的节点
TreeNode *findMin(TreeNode *root) {
    while (root->left != NULL) root = root->left;
    return root;
}
```

> 🎯 **为什么用"后继"就安全？** 它比 `50` 大一点点、且是右子树里最小的——放进 `50` 的位置后，左边（全 <50<60）右边（全 >60）都还成立。而且后继在右子树里必然是"叶子或只有一个孩子"，删起来正好落回情况一/二，不会无限递归！

---

## 9.5.5 完整代码：一个函数吃下三种情况

把三情况装进同一个递归函数——**先递归找到目标，再分情况处理**：

```c
#include <stdio.h>
#include <stdlib.h>

typedef struct TreeNode {
    int data;
    struct TreeNode *left;
    struct TreeNode *right;
} TreeNode;

TreeNode *createNode(int value) {
    TreeNode *node = (TreeNode *)malloc(sizeof(TreeNode));
    if (node == NULL) return NULL;
    node->data = value;
    node->left = NULL;
    node->right = NULL;
    return node;
}

TreeNode *insert(TreeNode *root, int value) {
    if (root == NULL) return createNode(value);
    if (value < root->data) root->left = insert(root->left, value);
    else if (value > root->data) root->right = insert(root->right, value);
    return root;
}

TreeNode *findMin(TreeNode *root) {       // 一路往左走到底
    if (root == NULL) return NULL;
    while (root->left != NULL) root = root->left;
    return root;
}

TreeNode *deleteNode(TreeNode *root, int value) {
    if (root == NULL) return NULL;                       // 没找到，原样返回

    if (value < root->data) {
        root->left = deleteNode(root->left, value);      // 去左子树删
    } else if (value > root->data) {
        root->right = deleteNode(root->right, value);    // 去右子树删
    } else {
        // 找到了！三情况分而治之
        if (root->left == NULL && root->right == NULL) { // ① 叶子
            free(root);
            return NULL;
        } else if (root->left == NULL) {                 // ② 只有右孩子
            TreeNode *child = root->right;
            free(root);
            return child;
        } else if (root->right == NULL) {                // ② 只有左孩子
            TreeNode *child = root->left;
            free(root);
            return child;
        } else {                                         // ③ 两个孩子
            TreeNode *succ = findMin(root->right);
            root->data = succ->data;
            root->right = deleteNode(root->right, succ->data);
        }
    }
    return root;
}

void inorder(TreeNode *root) {
    if (root == NULL) return;
    inorder(root->left);
    printf("%d ", root->data);
    inorder(root->right);
}

void freeTree(TreeNode *root) {
    if (root == NULL) return;
    freeTree(root->left);
    freeTree(root->right);
    free(root);
}

int main() {
    TreeNode *root = NULL;
    int values[] = {50, 30, 70, 20, 40, 60, 80};
    for (int i = 0; i < 7; i++) root = insert(root, values[i]);

    printf("原始（中序）：");
    inorder(root); printf("\n");

    root = deleteNode(root, 40);   // 叶子
    printf("删除 40（叶子）：");
    inorder(root); printf("\n");

    root = deleteNode(root, 30);   // 此时 30 只剩一个孩子 20
    printf("删除 30（独子）：");
    inorder(root); printf("\n");

    root = deleteNode(root, 50);   // 两个孩子，后继 60 顶替
    printf("删除 50（双子）：");
    inorder(root); printf("\n");

    freeTree(root);
    root = NULL;
    return 0;
}
```

输出：
```
原始（中序）：20 30 40 50 60 70 80
删除 40（叶子）：20 30 50 60 70 80
删除 30（独子）：20 50 60 70 80
删除 50（双子）：20 60 70 80
```

> 🎉 每删完一步，中序仍然升序——BST 的"家规"从未被破坏。三种情况，一套递归，一次搞定！

---

## 9.5.6 删除的时间 & 一个"提醒"

- **效率：** 删除要先"找"（沿树走），最坏要走一整条路径 → 平衡时 O(log n)，退化成链时 O(n)。和第9.4节查找一个道理。
- **真的删对了吗？** 用一个很土但很灵的办法验证：**删除前后都做一次中序遍历**，看删完是不是"少了那个数、其余仍然升序"。

> ⚠️ **关于"两个孩子时用谁顶替"**：教科书也有用"**前驱**（左子树里最大的）"的——后继、前驱都合法，选一个并保持全书一致即可。我们这里统一用"后继"。

---

## 9.5.7 本节小结

这一节我们学了：

✅ **删除三情形：** 叶子直接摘、独子让娃顶、双子找"后继"顶班

✅ **后继：** 右子树里最小的节点（一路往左走到底），用它顶替最稳妥

✅ **递归套路：** 先找到目标，再分情况处理；"删了就把新根接回去"

✅ **验证金标准：** 删除后中序遍历仍应升序、且只少了目标那一个值

> 💡 **记住：BST 删除不难，难在"删完还要守规矩"。三种情况对号入座，剩下的交给递归。**

### 三、改错题

**8. 以下删除函数有两处明显错误（假设 `findMin` 已实现）：**

```c
TreeNode *deleteNode(TreeNode *root, int value) {
    if (root == NULL) return NULL;
    if (value < root->data) {
        root->left = deleteNode(root->left, value);
    } else if (value > root->data) {
        root->right = deleteNode(root->right, value);
    } else {
        // 找到要删的节点
        if (root->left == NULL && root->right == NULL) {   // ① 叶子：正确
            free(root);
            return NULL;
        }
        if (root->left == NULL) {                          // 只有右孩子：正确
            TreeNode *child = root->right;
            free(root);
            return child;
        }
        // 错误区①：漏掉了"只有左孩子（right == NULL）"的分支！
        //           这种节点会一路滑到下面，却因为 right==NULL 什么也不做 → 删除无效

        if (root->right != NULL) {                          // 错误区②：两个孩子的判断/顺序
            TreeNode *succ = findMin(root->right);
            root->data = succ->data;
            root->right = deleteNode(root->right, succ->data);
        }
    }
    return root;
}
```

> 提示：对照 9.5.5 的正确版本——三情况要"一个都不能少"：叶子、**只有左孩子**、只有右孩子、双子。漏掉"只有左孩子"，删这种节点时树不会变！
