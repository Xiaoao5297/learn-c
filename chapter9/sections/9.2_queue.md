# 9.2 队列：先进先出的"排队" 🚌

> 💬 **节前语：**
>
> 上一节的栈是"后进先出"——后放的盘子先拿。可现实里还有另一条更常见的规矩：
>
> - 🍚 **食堂打饭**：先来的人先打到饭
> - 🖨️ **打印任务**：谁先提交，谁先被打印
> - 🎫 **银行叫号**：先取号的先进柜台
>
> 这种"**先进先出（First In First Out，FIFO）**"的规矩，对应的数据结构叫 **队列（Queue）**——就是"排队"。
>
> 队列是操作系统的"亲儿子"：打印机队列、键盘输入的缓冲、消息队列……全用它。这一节，我们把它实现出来，并且解决一个"数组排队的头疼问题"。准备好了吗？开始吧！

---

## 9.2.1 队列长什么样？从"头"进，从"头"出？

和栈一样，队列的动作也极少，只不过换了个方向：

```
   入队 enqueue(1)    enqueue(2)    enqueue(3)     出队 dequeue → 1
   队尾→             队尾→         队尾→
  ┌────┬────┬────┐  ┌────┬────┬────┐   ┌────┬────┬────┐
  │ 1  │    │    │  │ 1  │ 2  │    │   │ 1  │ 2  │ 3  │
  └────┴────┴────┘  └────┴────┴────┘   └────┴────┴────┘
   队头→             队头→            队头→
```

| 操作 | 英文 | 干什么 | 比喻 |
|------|------|--------|------|
| 入队 | `enqueue` | 从**队尾**加一个 | 排到队伍最后面 |
| 出队 | `dequeue` | 从**队头**取走一个 | 队伍最前面的人办完走了 |
| 看队头 | `front` | 看看队头是谁，不删 | 看看下一个轮到谁 |
| 判空 | `isEmpty` | 队伍里有没有人 | — |

> 📌 **和栈的区别：栈"一头进一头出"（同一个口）；队列"一头进、另一头出"（排成一条线）。** 栈像叠盘子，队列像排队。

---

## 9.2.2 用数组直接排队？—— 出队几次就"浪费了"

最直观的数组队列：`head` 指队头（下次出队位置），`tail` 指队尾（下次入队位置）。

```
入队 1 2 3： data[0]=1 data[1]=2 data[2]=3，head=0，tail=3
出队一次：   拿走 data[0]=1，head=1     ← 前面空出 data[0]，但永远用不上了
再出队：     拿走 data[1]=2，head=2     ← data[0]、data[1] 都成了"废位"
```

糟糕！如果一直"入队 + 出队"，数组前面的空位就**白白浪费**，而且 tail 很快会撞到数组末尾——哪怕整个数组其实没装多少东西，也报"队满"了。

> 📌 **病根：队列只用一次，"头"越走越靠后，空出来的前面回不去。**

---

## 9.2.3 解药：循环队列 —— 让数组"转圈" 🔄

既然"头"走到头就废了，那不如……**到头了绕回开头**！这就是**循环队列（Circular Queue）**：

```
想象数组首尾相接成一个"环"：

              data[0] ←── head/tail 绕回这里
           ┌──────────┐
   data[4] │          │ data[1]
   ┌───────┘          └───────┐
   │                          │
 数据从这里                  数据往这里
  出队(头)                   入队(尾)
   └───────┐          ┌───────┘
   data[3] │          │ data[2]
           └──────────┘
```

**"下一个位置"不是 `+1`，而是 `(位置+1) % MAX`**——走到 MAX-1 后再 +1 就绕回 0。这样前面出队空出来的格子，后面的入队又能用上了！

### 📝 完整实现（用一个 `size` 记录当前人数，区分空和满）

```c
#include <stdio.h>

#define MAX 5

typedef struct {
    int data[MAX];
    int head;      // 队头：下一次出队的位置
    int tail;      // 队尾：下一次入队的位置
    int size;      // 当前有多少人（用 size 判断空/满，最省心）
} Queue;

void init(Queue *q) {
    q->head = 0;
    q->tail = 0;
    q->size = 0;
}

int isEmpty(Queue *q) { return q->size == 0; }
int isFull(Queue *q)  { return q->size == MAX; }

// 入队：从队尾进
void enqueue(Queue *q, int value) {
    if (isFull(q)) {
        printf("队满了，%d 排不进去！\n", value);
        return;
    }
    q->data[q->tail] = value;
    q->tail = (q->tail + 1) % MAX;    // 队尾转圈！
    q->size++;
}

// 出队：从队头出
int dequeue(Queue *q) {
    if (isEmpty(q)) {
        printf("队是空的，没人可出！\n");
        return -1;
    }
    int value = q->data[q->head];
    q->head = (q->head + 1) % MAX;    // 队头也转圈！
    q->size--;
    return value;
}

// 看队头
int front(Queue *q) { return q->data[q->head]; }

int main() {
    Queue q;
    init(&q);

    enqueue(&q, 1);
    enqueue(&q, 2);
    enqueue(&q, 3);
    printf("队头：%d\n", front(&q));

    printf("出队：%d\n", dequeue(&q));
    printf("出队：%d\n", dequeue(&q));

    // 前面出队空出来的格子，正好被后面入队"转圈"用上
    enqueue(&q, 4);
    enqueue(&q, 5);
    enqueue(&q, 6);

    while (!isEmpty(&q)) {
        printf("出队：%d\n", dequeue(&q));
    }
    return 0;
}
```

输出：
```
队头：1
出队：1
出队：2
出队：3
出队：4
出队：5
出队：6
```

> 🎉 注意：出队 1、2 之后，又入队了 4、5、6——`tail` 已经从数组中间一路**绕回数组开头**，把前面空出来的格子重新用上了！这正是"循环"的威力。

> 📌 **为什么用 `size` 判断满？** 循环队列里 `head == tail` 既可能是"空"也可能是"满"，容易分不清。多存一个 `size`（当前人数）就一清二楚。这也是工程里很常用的做法。

## 9.2.4 队列的链表版（选读）

链表做队列也很自然：**front 指向队头，rear 指向队尾**。入队挂到 rear 后面，出队摘掉 front 那个节点。

```c
#include <stdio.h>
#include <stdlib.h>

typedef struct Node {
    int data;
    struct Node *next;
} Node;

typedef struct {
    Node *front;    // 队头（出队这边）
    Node *rear;     // 队尾（入队这边）
} Queue;

void init(Queue *q) {
    q->front = NULL;
    q->rear = NULL;
}

int isEmpty(Queue *q) {
    return q->front == NULL;
}

// 入队：新节点挂到队尾
void enqueue(Queue *q, int value) {
    Node *node = (Node *)malloc(sizeof(Node));
    if (node == NULL) return;
    node->data = value;
    node->next = NULL;
    if (q->rear == NULL) {        // 空队列：新节点既是头也是尾
        q->front = node;
        q->rear = node;
    } else {
        q->rear->next = node;     // 挂到旧队尾后面
        q->rear = node;           // 更新队尾
    }
}

// 出队：摘掉队头节点
int dequeue(Queue *q) {
    if (isEmpty(q)) return -1;
    Node *tmp = q->front;
    int value = tmp->data;
    q->front = q->front->next;    // 队头后移
    if (q->front == NULL) {       // 出光了，队尾也置空
        q->rear = NULL;
    }
    free(tmp);
    return value;
}

int main() {
    Queue q;
    init(&q);
    enqueue(&q, 10);
    enqueue(&q, 20);
    enqueue(&q, 30);
    while (!isEmpty(&q)) {
        printf("出队：%d\n", dequeue(&q));
    }
    return 0;
}
```

输出：
```
出队：10
出队：20
出队：30
```

> 📌 **链表队列入队出队都是 O(1)**（不用像循环数组那样担心"满"），代价是每个节点要 malloc、还要记得 free。**数组版适合规模确定、追求速度；链表版适合规模不定、随手增减。**

## 9.2.5 栈 vs 队列：一眼分清

| | 栈 Stack | 队列 Queue |
|---|---------|-----------|
| 顺序 | **后进先出** LIFO | **先进先出** FIFO |
| 出入口 | 同一个口（栈顶） | 一头进（尾）、一头出（头） |
| 比喻 | 叠盘子 / 羽毛球筒 | 排队打饭 / 打印任务 |
| 主要操作 | push / pop / peek | enqueue / dequeue / front |
| 经典用途 | 括号匹配、函数调用、撤销 | 打印队列、消息队列、广度优先搜索 |

> 💡 **记忆口诀：** 栈 = 一摞盘子（后拿先放的）；队列 = 一条队伍（先来先办的）。

## 9.2.6 本节小结

这一节我们学了：

✅ **队列是什么：** 先进先出（FIFO），队尾进、队头出

✅ **朴素数组队列的毛病：** 出队后前面空位浪费，队尾还容易撞墙

✅ **循环队列：** `(位置 + 1) % MAX` 让数组"首尾相接"转圈，空位复用

✅ **空/满判断：** 用 `size` 记录人数最清晰；`head==tail` 会分不清空和满

✅ **链表版队列：** front / rear 两个指针，入队挂尾、出队摘头，灵活但每个节点要 malloc/free

> 💡 **记住：队列排的是一条"先来后到"的队；转圈的数组 + size 计数，是最常见的实现。**

### 三、改错题

**8. 以下循环队列有 3 个错误：**

```c
#include <stdio.h>
#define MAX 5

typedef struct {
    int data[MAX];
    int head;
    int tail;
    int size;
} Queue;

void init(Queue *q) {
    q->head = 0;
    q->tail = 0;
    q->size = MAX;          // 错误区①：初始人数该是几？
}

void enqueue(Queue *q, int value) {
    if (q->size == 0) {     // 错误区②：判断"队满"的条件对吗？
        printf("队满了！\n");
        return;
    }
    q->data[q->tail] = value;
    q->tail++;              // 错误区③：tail 到数组末尾后还能 +1 吗？
    q->size++;
}

int dequeue(Queue *q) {
    int v = q->data[q->head];
    q->head++;
    q->size--;
    return v;
}

int main() {
    Queue q;
    init(&q);
    enqueue(&q, 10);
    enqueue(&q, 20);
    printf("%d\n", dequeue(&q));   // 期望 10
    return 0;
}
```

> 提示：三处分别是"初始 size""满的判断""下标转圈"。
