# 9.3 二叉树：会"分叉"的链表 🌳

> 💬 **节前语：**
>
> 链表是"一节车厢挂一节"的火车——**每个节点只有一个 next，串成一条线**。
>
> 可现实里的关系，远不止"一条线"：
>
> - 📂 **文件夹**：一个目录下可以有好几个子目录
> - 👨‍👩‍👧 **家谱**：一对父母可以有好几个孩子
> - 🧮 **表达式**：`1 + 2 × 3` 里的运算，也是一层套一层的树
>
> 最基础、也最重要的"多叉"结构，是**二叉树（Binary Tree）**——每个节点最多**两个**分叉，叫 **左孩子（left）** 和 **右孩子（right）**。
>
> 好消息是：**它就是把链表节点的"1 个 next"升级成"2 个指针"**——结构体、malloc、递归，全是我们学过的老熟人！这一节我们把它画出来、造出来，并用递归轻松搞定三种遍历。准备好了吗？开始吧！

---

## 9.3.1 从"车厢"到"分叉"：节点的升级

还记得第6章链表的节点吗？

```c
typedef struct Node {
    int data;
    struct Node *next;    // 只指向"下一个"
} Node;
```

二叉树的节点只多了一根"叉"：

```c
typedef struct TreeNode {
    int data;
    struct TreeNode *left;    // 左孩子
    struct TreeNode *right;   // 右孩子
} TreeNode;
```

```
链表节点：                二叉树节点：
┌───────────────┐        ┌───────────────────┐
│  data         │        │      data         │
│  next ───────►│        │  left    right    │
└───────────────┘        │   │        │      │
                         └───┼────────┼──────┘
                             ▼        ▼
                          左孩子    右孩子
```

> 📌 **二叉树三件套：** 每个节点都有——① 自己的数据 `data`，② 指向**左孩子**的指针，③ 指向**右孩子**的指针。没有孩子的孩子叫 **NULL**。

**看图认名：**

```
       ①  ←── 根（root）
      / \
     ②   ③  ←── ②③ 是 ① 的孩子（②是左孩子，③是右孩子）
    / \
   ④   ⑤  ←── ④⑤ 是 ② 的孩子
```

| 名词 | 意思 |
|------|------|
| 根（root） | 最顶上的节点，整棵树的入口 |
| 孩子 / 父亲 | 直接相连的下一层 / 上一层 |
| 叶子（leaf） | 没有孩子的节点（④⑤③） |
| 子树 | 任意节点连同它的后代，都是一棵"小二叉树" |

> 🔎 **最妙的递归视角：** 二叉树 = 根 + 一棵**左子树** + 一棵**右子树**；而子树又 = 根 + 自己的左子树 + 右子树……直到 NULL。这不就是第7章的套娃吗？！所以处理二叉树，递归几乎是"天选之子"。

## 9.3.2 造一棵二叉树

先写老朋友 `createNode`（malloc 造节点，第6章同款思路），再手动把指针接起来：

```c
#include <stdio.h>
#include <stdlib.h>

typedef struct TreeNode {
    int data;
    struct TreeNode *left;
    struct TreeNode *right;
} TreeNode;

// 造一个"孤儿节点"（暂时没有孩子）
TreeNode *createNode(int value) {
    TreeNode *node = (TreeNode *)malloc(sizeof(TreeNode));
    if (node == NULL) return NULL;
    node->data = value;
    node->left = NULL;
    node->right = NULL;
    return node;
}

int main() {
    // 先造 5 个孤立节点
    TreeNode *n1 = createNode(1);
    TreeNode *n2 = createNode(2);
    TreeNode *n3 = createNode(3);
    TreeNode *n4 = createNode(4);
    TreeNode *n5 = createNode(5);

    // 再接起来：
    n1->left = n2;
    n1->right = n3;
    n2->left = n4;
    n2->right = n5;

    // 现在整棵树是：
    //        1
    //       / \
    //      2   3
    //     / \
    //    4   5

    printf("根的值：%d\n", n1->data);
    printf("根的左孩子：%d\n", n1->left->data);
    printf("根的右孩子：%d\n", n1->right->data);
    printf("n2 的右孩子：%d\n", n2->right->data);
    if (n3->left == NULL && n3->right == NULL) {
        printf("n3 是叶子：它没有孩子\n");
    }

    // 用完别忘了释放（完整版见下一段的 freeTree）
    return 0;
}
```

输出：
```
根的值：1
根的左孩子：2
根的右孩子：3
n2 的右孩子：5
n3 是叶子：它没有孩子
```

> 💡 手动 `n1->left = n2` 这样一个个接线，树一大就累死人了。**9.4 的二叉查找树会教我们"自动插进去"**——现在先手动接线，把结构本身弄明白。

> 📌 **malloc 出来的节点用完都要 free。** 上面这段为了先讲清"接线"省去了释放，完整的 `freeTree`（后序释放）在下面 9.3.3 的完整程序里，请以那个程序为准。

## 9.3.3 三种遍历：前序、中序、后序

"遍历"就是**把树里每个节点都访问一遍**。二叉树遍历的经典问题是：**按什么顺序访问根、左子树、右子树？** 三种主流约定：

| 遍历 | 顺序 | 记忆 |
|------|------|------|
| **前序** preorder | 根 → 左 → 右 | "根"最先 |
| **中序** inorder | 左 → 根 → 右 | "根"在中间 |
| **后序** postorder | 左 → 右 → 根 | "根"最后 |

递归写起来，**每个都只有 3 行**——把 printf 的位置挪一挪而已（还记得第7章"打印放哪决定顺序"吗？这次挪的是"根"！）：

```c
#include <stdio.h>
#include <stdlib.h>

typedef struct TreeNode {
    int data;
    struct TreeNode *left;
    struct TreeNode *right;
} TreeNode;

TreeNode *createNode(int value) {
    TreeNode *node = (TreeNode *)malloc(sizeof(TreeNode));
    if (node == NULL) return NULL;
    node->data = value;
    node->left = NULL;
    node->right = NULL;
    return node;
}

// 前序：根 左 右
void preorder(TreeNode *root) {
    if (root == NULL) return;
    printf("%d ", root->data);
    preorder(root->left);
    preorder(root->right);
}

// 中序：左 根 右
void inorder(TreeNode *root) {
    if (root == NULL) return;
    inorder(root->left);
    printf("%d ", root->data);
    inorder(root->right);
}

// 后序：左 右 根
void postorder(TreeNode *root) {
    if (root == NULL) return;
    postorder(root->left);
    postorder(root->right);
    printf("%d ", root->data);
}

// 节点总数：空树 0，否则 1 + 左子树 + 右子树
int countNodes(TreeNode *root) {
    if (root == NULL) return 0;
    return 1 + countNodes(root->left) + countNodes(root->right);
}

// 树高：空树 0，否则 max(左高, 右高) + 1
int treeHeight(TreeNode *root) {
    if (root == NULL) return 0;
    int leftH = treeHeight(root->left);
    int rightH = treeHeight(root->right);
    return (leftH > rightH ? leftH : rightH) + 1;
}

// 后序释放：先把左右子树都释放光，再 free 自己
void freeTree(TreeNode *root) {
    if (root == NULL) return;
    freeTree(root->left);
    freeTree(root->right);
    free(root);
}

int main() {
    //        1
    //       / \
    //      2   3
    //     / \
    //    4   5
    TreeNode *n1 = createNode(1);
    TreeNode *n2 = createNode(2);
    TreeNode *n3 = createNode(3);
    TreeNode *n4 = createNode(4);
    TreeNode *n5 = createNode(5);
    n1->left = n2;
    n1->right = n3;
    n2->left = n4;
    n2->right = n5;

    printf("前序（根左右）：");
    preorder(n1);
    printf("\n");

    printf("中序（左根右）：");
    inorder(n1);
    printf("\n");

    printf("后序（左右根）：");
    postorder(n1);
    printf("\n");

    printf("节点总数：%d\n", countNodes(n1));
    printf("树高：%d\n", treeHeight(n1));

    freeTree(n1);
    return 0;
}
```

输出：
```
前序（根左右）：1 2 4 5 3
中序（左根右）：4 2 5 1 3
后序（左右根）：4 5 2 3 1
节点总数：5
树高：3
```

> 🎉 三行递归，搞定整棵树的遍历！**每个函数都只在"递归左、递归右"之间挪一行 `printf` 的位置**——这就是第7章"递去归来"顺序魔法在树上的完美应用。

### 🔍 中序结果暗藏玄机

看看中序输出：`4 2 5 1 3`——把树**"按从左到右"**读出来就是这个顺序！更妙的是：**如果一棵树满足"左小右大"，中序就会输出升序**——这正是 9.4 二叉查找树的杀手锏，先记在心里。

## 9.3.4 为什么递归是树的"天选之子"？

对比一下你就懂：

- **链表的递归**：`处理当前 + 递归剩下的链表`（只有一个方向）
- **二叉树的递归**：`处理根 + 递归左子树 + 递归右子树`（两个方向分叉）

```c
// 链表（第7章）：一条线
void f(Node *head) {
    if (head == NULL) return;
    处理(head);
    f(head->next);          // 只有一个 next 要递归
}

// 二叉树：一个根，两条支路
void g(TreeNode *root) {
    if (root == NULL) return;
    处理(root);
    g(root->left);          // 左路
    g(root->right);         // 右路
}
```

> 📌 **结构决定写法：** 树的分叉，恰好对应递归的两次自我调用。**"遇到递归结构就写递归"**，代码会短到不可思议；硬用循环遍历树，反而要自己维护一堆栈，又长又容易错。

## 9.3.5 本节小结

这一节我们学了：

✅ **二叉树节点：** `data + left + right` 三个成员——链表节点的"升级版"

✅ **三件套概念：** 根、孩子、叶子；子树也是二叉树（递归结构！）

✅ **三种遍历：** 前序（根左右）、中序（左根右）、后序（左右根）——只挪 `printf` 的位置

✅ **递归就是天选之子：** 结构分叉 ⇄ 递归调两次

✅ **顺手的工具：** countNodes / treeHeight / freeTree（后序释放）

> 💡 **记住：树 = 递归的舞台。** 前中后序"挪 printf"，9.4 我们让树的"插入"和"查找"也用递归自动完成！
