# 9.2 队列

上一节的栈是"后进先出"——最后压的盘子最先被拿走。可现实里更常见的规矩恰恰相反：食堂打饭，先来的人先打到饭；打印店接活，先提交的文件先打印。这种"先进先出"（First In First Out，FIFO）的规矩，对应的数据结构叫**队列（queue）**——就是排队。

## 9.2.1 队列：一头进，另一头出

排队只有两个动作：**新来的人排到队尾**，**队头的人办完事离开**。队列照搬这条规矩：

| 操作 | 名字 | 干什么 | 排队的对应动作 |
|------|------|--------|----------------|
| 入队 | `enqueue` | 从队尾加入一个数据 | 新来的人排到队尾 |
| 出队 | `dequeue` | 从队头取走一个数据 | 队头的人办完走了 |
| 看队头 | `front` | 只看不取 | 看看下一个轮到谁 |
| 判空 | `is_empty` | 队列里有没有数据 | 队伍里还有没有人 |

和栈对比着记：栈是"一个口进、同一个口出"（盘子架）；队列是"一头进、另一头出"（队伍）。进出方向不同，数据的出场顺序就完全不同。

## 9.2.2 朴素数组队列的一个毛病

用数组实现队列最直接的想法：`head` 记队头下标（下次出队的位置），`tail` 记队尾下标（下次入队的位置）。入队写到 `data[tail]` 再 `tail++`；出队取走 `data[head]` 再 `head++`。

问题出在"取走"这一头。队头不断后移，数组前面的格子一个个空出来，却**再也没人用**：

```text
数组容量 5，入队 1 2 3：      head=0  tail=3
出队一次，拿走 1：            head=1  tail=3    data[0] 废了
出队一次，拿走 2：            head=2  tail=3    data[0]、data[1] 都废了
```

只要这个系统一直在"又进又出"（打印任务、叫号系统都是这样），`tail` 很快撞上数组末尾报"队满"，可数组前面明明空着一排格子。病根就一句话：**队头走到哪，前面的空位就废到哪**。

## 9.2.3 循环队列：让数组首尾相接

解法很巧：让数组"转圈"。下标走到 `MAX - 1` 之后，下一个位置不继续加，而是**绕回 0**——像操场跑道，跑过最后一米又回到起点。写出来就是把"加 1"换成"加 1 之后取余"：

```text
tail = (tail + 1) % MAX
head = (head + 1) % MAX
```

`% MAX` 的效果：`0` 到 `MAX - 1` 之间的数加 1 后照常加，`MAX - 1` 加 1 后变成 `MAX`，一取余就落回 `0`。这样出队空出来的格子，后面入队转一圈又能用上。

还有一个判断上的坑：循环队列里 `head == tail` 时，可能是"空"（进出的次数一样多），也可能是"满"（转了一圈追上了）——光看两个下标分不清。最省心的办法是再记一个 `size`（当前有几个数据）：`size == 0` 空，`size == MAX` 满。

```c
// 9.2.1 circular_queue.c
#include <stdio.h>
#include <stdbool.h>

#define MAX 5

struct queue {
	int data[MAX];
	int head;    /* 队头：下次出队的位置 */
	int tail;    /* 队尾：下次入队的位置 */
	int size;    /* 当前数据个数 */
};

void init(struct queue *q)
{
	q->head = 0;
	q->tail = 0;
	q->size = 0;
}

bool is_empty(const struct queue *q)
{
	return q->size == 0;
}

bool is_full(const struct queue *q)
{
	return q->size == MAX;
}

bool enqueue(struct queue *q, int value)
{
	if (is_full(q)) {
		return false;
	}
	q->data[q->tail] = value;
	q->tail = (q->tail + 1) % MAX;    /* 队尾转圈 */
	q->size++;
	return true;
}

bool dequeue(struct queue *q, int *value)
{
	if (is_empty(q)) {
		return false;
	}
	*value = q->data[q->head];
	q->head = (q->head + 1) % MAX;    /* 队头转圈 */
	q->size--;
	return true;
}

int main(void)
{
	struct queue q;

	init(&q);

	for (int i = 1; i <= 3; i++) {
		enqueue(&q, i);
	}
	printf("入队 1 2 3，size = %d\n", q.size);

	int value;
	dequeue(&q, &value);
	printf("出队：%d\n", value);
	dequeue(&q, &value);
	printf("出队：%d\n", value);

	enqueue(&q, 4);
	enqueue(&q, 5);
	enqueue(&q, 6);
	printf("又入队 4 5 6，size = %d，tail 绕回了 %d\n", q.size, q.tail);
	while (dequeue(&q, &value)) {
		printf("出队：%d\n", value);
	}

	return 0;
}
```

<!-- output: 9.2.1 -->
```text
入队 1 2 3，size = 3
出队：1
出队：2
又入队 4 5 6，size = 4，tail 绕回了 1
出队：3
出队：4
出队：5
出队：6
```

盯住 `tail` 的脚步：入队 1、2、3 后 `tail` 走到 3；出队两次，`head` 走到 2；再入队 4、5 时 `tail` 从 3 走到 4、绕回 0，入队 6 时写进 `data[0]`、`tail` 变成 1——打印出来的 `tail 绕回了 1` 正是这一步。出队扔掉的格子被入队捡了回来，队列里始终是最早还没出队的 3 和后来的 4、5、6，顺序一点没乱。

`% MAX` 是这一节的钥匙。它在第 2 章只是"取余数"，到了这里成了"让下标在环上行走"的工具——同一个运算符，换个角度就是新武器。

## 9.2.4 慢镜头：转一圈的全过程

把 9.2.1 的例子逐帧回放，下标和格子的变化一目了然（容量 MAX = 5）：

```text
动作          head  tail  size   数组内容（只列有数据的格子）
入队 1         0     1     1    [0]=1
入队 2         0     2     2    [0]=1 [1]=2
入队 3         0     3     3    [0]=1 [1]=2 [2]=3
出队 → 1       1     3     2    [1]=2 [2]=3          data[0] 空了
出队 → 2       2     3     1    [2]=3                data[1] 也空了
入队 4         2     4     2    [2]=3 [3]=4
入队 5         2     0     3    [2]=3 [3]=4 [4]=5    tail 绕回 0
入队 6         2     1     4    [2]=3 [3]=4 [4]=5 [0]=6   填进 data[0]
```

入队 5 之后 `tail` 计算成 `(4 + 1) % 5 = 0`，入队 6 写进 `data[0]`、`tail` 变成 1。**出队扔掉的格子被入队捡了回来**，这就是"循环"的全部含义。

`size` 的存在感也在这里：入队 6 之后 `head = 2`、`tail = 1`，两个下标"交叉"着，单看它们完全猜不出队里有几个数据；`size = 4` 一句话报清楚。

## 9.2.5 应用：模拟打印队列

队列最常见的舞台是各种"任务排队"：打印任务、消息队列、叫号系统。它们共同的特点是**到达有先后、处理有先后，且顺序不能乱**。写一个最小的打印队列模拟：

```c
// 9.2.2 print_queue.c
#include <stdio.h>
#include <stdbool.h>

#define MAX 8

struct queue {
	int task[MAX];    /* 打印任务的编号 */
	int head;
	int tail;
	int size;
};

void init(struct queue *q)
{
	q->head = 0;
	q->tail = 0;
	q->size = 0;
}

bool enqueue(struct queue *q, int task_id)
{
	if (q->size == MAX) {
		return false;
	}
	q->task[q->tail] = task_id;
	q->tail = (q->tail + 1) % MAX;
	q->size++;
	return true;
}

bool dequeue(struct queue *q, int *task_id)
{
	if (q->size == 0) {
		return false;
	}
	*task_id = q->task[q->head];
	q->head = (q->head + 1) % MAX;
	q->size--;
	return true;
}

int main(void)
{
	struct queue q;

	init(&q);

	int new_tasks[] = {101, 202, 303};
	for (int i = 0; i < 3; i++) {
		enqueue(&q, new_tasks[i]);
		printf("提交任务 %d，排队中（共 %d 个）\n",
		       new_tasks[i], q.size);
	}

	printf("--- 开始打印 ---\n");

	int task_id;
	while (dequeue(&q, &task_id)) {
		printf("打印任务 %d，剩余 %d 个\n", task_id, q.size);
	}

	printf("全部打印完成\n");

	return 0;
}
```

<!-- output: 9.2.2 -->
```text
提交任务 101，排队中（共 1 个）
提交任务 202，排队中（共 2 个）
提交任务 303，排队中（共 3 个）
--- 开始打印 ---
打印任务 101，剩余 2 个
打印任务 202，剩余 1 个
打印任务 303，剩余 0 个
全部打印完成
```

先提交的 101 先打印，顺序和提交时一致——先进先出。这类模拟程序的关键是：**入队只发生在队尾，出队只发生在队头，谁也不插队**。把 9.2.1 的 `enqueue`/`dequeue` 原样搬过来就能用，这正是"数据结构"的价值：规矩定好一次，到处复用。

## 9.2.6 栈和队列：一张表分清

| 对比项 | 栈 stack | 队列 queue |
|--------|----------|------------|
| 出入顺序 | 后进先出 LIFO | 先进先出 FIFO |
| 出入口 | 一个口（栈顶） | 两头：队尾进、队头出 |
| 比喻 | 食堂的盘子架 | 食堂打饭排队 |
| 核心操作 | `push` / `pop` | `enqueue` / `dequeue` |
| 关键下标 | `top` 一个 | `head`、`tail` 两个 |
| 典型用途 | 括号匹配、函数调用、撤销 | 打印任务、消息队列、叫号 |

两者实现的骨架几乎一样：数组 + 下标 + `is_empty`/`is_full` 检查。差别只在"从哪进、从哪出"。把这两个写熟了，"用数组造规矩"这件事你就入门了——数据结构 = 数据 + 一套被严格遵守的规矩。

## 9.2.7 小结

- 队列：先进先出（FIFO），队尾入队，队头出队。
- 朴素数组队列的毛病：出队后前面的格子永远空着，`tail` 很快撞到数组末尾。
- 循环队列：`(下标 + 1) % MAX` 让下标到头绕回开头，空位循环复用。
- `head == tail` 分不清空和满，额外记一个 `size` 最省心。
- 栈与队列一字之差：一个口还是两个口；各有各的舞台。

#### 三、改错题

6. 三处错误：

- 第一处：`init` 里 `q->size = MAX` 应为 `q->size = 0`。空队列的 size 是 0；写成 MAX 会让队列一出生就被当成"满"的，第一次 `enqueue` 直接被拒。
- 第二处：`enqueue` 的判满条件 `q->size == 0` 应为 `q->size == MAX`。size 等于 0 是"空"，等于容量才是"满"，条件写反了。
- 第三处：`enqueue` 里 `q->tail++` 应为 `q->tail = (q->tail + 1) % MAX`。循环队列的 tail 到达数组末尾后必须绕回 0，直接加会越界。

修正后的完整程序：

```c
#include <stdio.h>

#define MAX 4

struct queue {
	int data[MAX];
	int head;
	int tail;
	int size;
};

void init(struct queue *q)
{
	q->head = 0;
	q->tail = 0;
	q->size = 0;
}

void enqueue(struct queue *q, int value)
{
	if (q->size == MAX) {
		return;
	}
	q->data[q->tail] = value;
	q->tail = (q->tail + 1) % MAX;
	q->size++;
}

int dequeue(struct queue *q)
{
	int value = q->data[q->head];
	q->head = (q->head + 1) % MAX;
	q->size--;
	return value;
}

int main(void)
{
	struct queue q;

	init(&q);
	enqueue(&q, 10);
	enqueue(&q, 20);
	printf("%d\n", dequeue(&q));
	printf("%d\n", dequeue(&q));

	return 0;
}
```

输出两行 `10` 和 `20`。

8. 参考代码：

```c
#include <stdio.h>
#include <stdbool.h>

#define MAX 8

struct stack {
	int data[MAX];
	int top;
};

void init(struct stack *s)
{
	s->top = -1;
}

bool push(struct stack *s, int value)
{
	if (s->top == MAX - 1) {
		return false;
	}
	s->top++;
	s->data[s->top] = value;
	return true;
}

bool pop(struct stack *s, int *value)
{
	if (s->top == -1) {
		return false;
	}
	*value = s->data[s->top];
	s->top--;
	return true;
}

struct queue {
	struct stack in;     /* 只管入队的栈 */
	struct stack out;    /* 只管出队的栈 */
};

void init(struct queue *q)
{
	init(&q->in);
	init(&q->out);
}

/* 先把 in 里的数据倒进 out，再从 out 弹出 */
bool dequeue(struct queue *q, int *value)
{
	if (q->out.top == -1) {
		int v;
		while (pop(&q->in, &v)) {
			push(&q->out, v);
		}
	}
	return pop(&q->out, value);
}

int main(void)
{
	struct queue q;

	init(&q);

	int a[] = {1, 2, 3};
	for (int i = 0; i < 3; i++) {
		push(&q.in, a[i]);
	}

	int value;
	dequeue(&q, &value);
	printf("%d ", value);
	dequeue(&q, &value);
	printf("%d ", value);

	push(&q.in, 4);

	dequeue(&q, &value);
	printf("%d ", value);
	dequeue(&q, &value);
	printf("%d\n", value);

	return 0;
}
```

输出：

```text
1 2 3 4
```

两个栈串起来，数据被"倒"了一次手：第一次压栈把顺序翻了一遍，第二次压栈又翻回来——翻两遍就是原顺序，先进先出。

#### 五、思考题

9. 开放性引导，参考方向：一对多的关系，一条线串不起来——链表的 `next` 只能指向"一个"下一家；让每个节点带两个指针，就能从每个节点分出两条岔路，长成"树枝"的形状；递归处理这种节点时，一次自我调用会变成两次——递归左半边和递归右半边，两次调用各自再分叉。下一节我们就造这个"每节点两个指针"的结构：二叉树。
