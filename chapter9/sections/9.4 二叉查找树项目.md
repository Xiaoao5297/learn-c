# 9.4 二叉查找树项目

上一节会"画"树了，但节点还是手动接线。这一节给树注入灵魂——加一条"左小右大"的规矩，让插入和查找变成自动的。这条规矩诞生的结构叫**二叉查找树（binary search tree，BST）**，它把第 8 章二分查找的"每步砍一半"和树的递归结构合在了一起。

## 9.4.1 家规：左小右大

二叉查找树只有一条规矩：

```text
对树里的任何一个节点：
  左子树里所有的值 < 这个节点的值 < 右子树里所有的值
```

注意是**整个子树**，不只是左孩子和右孩子自己。按顺序插入 `50, 30, 70, 20, 40, 60, 80`，会长成：

```text
        50
       /  \
     30    70
    /  \   /  \
  20   40 60   80
```

验收一下家规：50 的左子树 `{30, 20, 40}` 全比 50 小，右子树 `{70, 60, 80}` 全比 50 大；再看 30 那棵子树，同样成立。**家规对每个节点都成立，一棵 BST 的每棵子树也一定是 BST**——递归的结构，配递归的规矩。

这条家规立刻兑现两个好处：

- **查找快**。找 40：40 < 50 往左，40 > 30 往右，两步就到。每走一步，就整棵排除掉另一边的子树——第 8 章的二分查找每次排除一半区间，这里是每次排除一半节点。
- **中序自动升序**。中序是"左 → 根 → 右"：先走完全部较小的，再访问根，最后走全部较大的。对任意 BST 做中序遍历，输出必然从小到大。

## 9.4.2 插入：一路走到空位

往 BST 里插入一个新值，走法和查找一样：比当前节点小就往左走，大就往右走，**走到空位（NULL）就把新节点放那儿**。相等的情况本书约定不重复插入。

递归写法的关键设计是**返回值**：函数返回"插入之后，这棵子树的根"。空位处返回新节点，其余情况返回原来的根：

```c
struct tree_node *insert(struct tree_node *root, int value)
{
	if (root == NULL) {
		return create_node(value);      /* 空位：新节点放这里 */
	}
	if (value < root->data) {
		root->left = insert(root->left, value);
	} else if (value > root->data) {
		root->right = insert(root->right, value);
	}
	return root;                        /* 根没变，原样还回去 */
}
```

`root->left = insert(root->left, value)` 这一句是全函数的枢纽：递归去左子树插入，插完把左子树的根**接回来**。大多数情况接回去的还是原来的节点；只有走到空位时，接回来的是一个新节点——树就在那一瞬间长出了一个新叶子。"改了子树就把子树接回去"，这是树上递归的固定套路，9.5 的删除还会再用一次。

先单独验证插入，把树长出来、中序打印出来看形状对不对：

```c
// 9.4.1 bst_insert.c
#include <stdio.h>
#include <stdlib.h>

struct tree_node {
	int data;
	struct tree_node *left;
	struct tree_node *right;
};

struct tree_node *create_node(int value)
{
	struct tree_node *node = malloc(sizeof(struct tree_node));
	if (node == NULL) {
		return NULL;
	}
	node->data = value;
	node->left = NULL;
	node->right = NULL;
	return node;
}

struct tree_node *insert(struct tree_node *root, int value)
{
	if (root == NULL) {
		return create_node(value);
	}
	if (value < root->data) {
		root->left = insert(root->left, value);
	} else if (value > root->data) {
		root->right = insert(root->right, value);
	}
	return root;
}

void inorder(const struct tree_node *root)
{
	if (root == NULL) {
		return;
	}
	inorder(root->left);
	printf("%d ", root->data);
	inorder(root->right);
}

int main(void)
{
	struct tree_node *root = NULL;

	/* 依次插入，第一个数 50 成为根 */
	int values[] = {50, 30, 70, 20, 40, 60, 80};
	for (int i = 0; i < 7; i++) {
		root = insert(root, values[i]);
	}

	printf("中序遍历：");
	inorder(root);
	printf("\n");

	/* 再故意乱序插一棵，验证结果一样有序 */
	struct tree_node *root2 = NULL;
	int shuffled[] = {70, 20, 50, 40, 80, 30, 60};
	for (int i = 0; i < 7; i++) {
		root2 = insert(root2, shuffled[i]);
	}

	printf("乱序插入后：");
	inorder(root2);
	printf("\n");

	return 0;
}
```

<!-- output: 9.4.1 -->
```text
中序遍历：20 30 40 50 60 70 80
乱序插入后：20 30 40 50 60 70 80
```

第一个数 50 第一个到达，占住根的位置；之后每个数从根出发找位子。第二个循环故意把插入顺序打乱——长出来的树形状不同，但**中序输出一模一样**：家规只关心"谁在谁左边"，不关心来的先后。BST 天生自带排序功能。

`main` 里 `root = insert(root, value)` 的 `root =` 不能省：往空树插第一个节点时，全靠这个返回值把新根带出来。之后每次赋值虽然接回来的都是同一个根，但"统一接回来"让代码不需要为空树写特判。

## 9.4.3 查找：每步扔掉一半

查找和插入走同一条路，只是不用"放下新节点"，找到就报告成功，走到空位就报告失败：

```c
struct tree_node *search(const struct tree_node *root, int value)
{
	if (root == NULL) {
		return NULL;                  /* 走到空位：没有 */
	}
	if (value == root->data) {
		return (struct tree_node *)root;   /* 找到了 */
	}
	if (value < root->data) {
		return search(root->left, value);
	}
	return search(root->right, value);
}
```

和 8.4 的二分查找对照着看：数组二分靠 `mid` 把区间砍成两半；BST 靠家规把节点分成两半。找到、没找到、往哪边走——三个出口一一对应。`const` 的加法有一点讲究：查找不修改树，参数加 `const`；但 `const struct tree_node *` 返回时要写 `(struct tree_node *)root` 去掉 const——为了简单，项目版里我们让 search 直接用不带 const 的参数。

查找的代价由树的形状决定：家规执行得好、树长得匀称，n 个节点深度约 log₂n，查找只要十来步；要是插入的数据恰好一直递增（1、2、3、4……），每个新数都往右走到底，树会退化成一条链，查找就得一个个数——和链表没区别。9.5 的对比表会再把这笔账算一遍。

## 9.4.4 完整项目：一棵会排序、会查找的树

把插入、查找、中序遍历、释放组装成完整程序，故意乱序插入数据，验证"排序"和"秒查"两件事同时发生：

```c
// 9.4.2 bst_project.c
#include <stdio.h>
#include <stdlib.h>
#include <stdbool.h>

struct tree_node {
	int data;
	struct tree_node *left;
	struct tree_node *right;
};

struct tree_node *create_node(int value)
{
	struct tree_node *node = malloc(sizeof(struct tree_node));
	if (node == NULL) {
		return NULL;
	}
	node->data = value;
	node->left = NULL;
	node->right = NULL;
	return node;
}

struct tree_node *insert(struct tree_node *root, int value)
{
	if (root == NULL) {
		return create_node(value);
	}
	if (value < root->data) {
		root->left = insert(root->left, value);
	} else if (value > root->data) {
		root->right = insert(root->right, value);
	}
	return root;
}

struct tree_node *search(struct tree_node *root, int value)
{
	if (root == NULL) {
		return NULL;
	}
	if (value == root->data) {
		return root;
	}
	if (value < root->data) {
		return search(root->left, value);
	}
	return search(root->right, value);
}

void inorder(const struct tree_node *root)
{
	if (root == NULL) {
		return;
	}
	inorder(root->left);
	printf("%d ", root->data);
	inorder(root->right);
}

void free_tree(struct tree_node *root)
{
	if (root == NULL) {
		return;
	}
	free_tree(root->left);
	free_tree(root->right);
	free(root);
}

int main(void)
{
	struct tree_node *root = NULL;

	/* 故意乱序插入，模拟"边来边存"的真实场景 */
	int values[] = {50, 30, 70, 20, 40, 60, 80};
	for (int i = 0; i < 7; i++) {
		root = insert(root, values[i]);
	}

	printf("中序遍历（自动升序）：");
	inorder(root);
	printf("\n");

	struct tree_node *found = search(root, 40);
	if (found != NULL) {
		printf("查找 40：找到了，值是 %d\n", found->data);
	}

	if (search(root, 100) == NULL) {
		printf("查找 100：没找到\n");
	}

	free_tree(root);
	root = NULL;

	printf("整棵树已释放\n");

	return 0;
}
```

<!-- output: 9.4.2 -->
```text
中序遍历（自动升序）：20 30 40 50 60 70 80
查找 40：找到了，值是 40
查找 100：没找到
整棵树已释放
```

逐个功能核对：

- **乱序进、有序出**：数据来的顺序是 `50, 30, 70, 20, 40, 60, 80`，中序输出 `20 30 40 50 60 70 80`。插入和排序在同一个动作里完成了。
- **查找命中**：`search(root, 40)` 返回节点的地址，直接读它的 `data`。返回节点而不是 `bool` 的好处：找到之后还能拿到、改这个节点（如果数据是结构体，改它的字段）。
- **查找未命中**：走到空位返回 `NULL`，用 `== NULL` 判断。空指针是"没找到"的标准答案，第 6 章链表查找就是这么约定的。
- **收尾**：`free_tree` 后序释放整棵树，再把 `root` 置 `NULL`——6.2 的纪律一条不少。

## 9.4.5 小结

- BST 家规：任何节点，左子树全比它小，右子树全比它大；每棵子树也是 BST。
- 插入：比大小往左/右走，空位放新节点；函数返回子树根，`root->left = insert(...)` 接回去。
- 查找：同样的走法，找到返回节点，走到空返回 `NULL`；匀称的树约 log₂n 步。
- 中序遍历 BST 输出升序——插入即排序。
- 数据退化成一条链时，查找退化成 O(n)；这是 BST 的软肋。

#### 三、改错题

6. 三处错误：

- 第一处：`create_node` 里 `malloc` 之后没有检查返回值。分配失败时直接解引用空指针会崩溃，应加上 `if (node == NULL) { return NULL; }`。
- 第二处：`insert` 的左分支少了接回动作，`insert(root->left, value)` 应为 `root->left = insert(root->left, value)`。不接回去，插到左边的新节点会成为"没人指向"的孤儿，树根本没长出来。
- 第三处：`inorder` 写成了"右 → 根 → 左"，输出会从大到小。应为先递归 `root->left`，再打印，再递归 `root->right`。

		return 0;

5 个节点深度却是 5——树退化成了一条只往右长的链。每插一个递增的新数都一路向右走到底，查找再没有"砍一半"可赚，退化成 O(n)。这就是 BST 的软肋，真实工程用"平衡树"防止它长歪。
