# 9.4 二叉查找树的插入与查找

> 💬 **节前语：**
>
> 上一节我们学了二叉树的"形"，这一节给它注入"灵魂"。
>
> 想一想：二分查找为什么快？因为每次比较都能**决定往左还是往右**。如果……我们让二叉树也遵守一条规矩——
>
> > **任何节点，左边子树里所有值都比它小，右边子树里所有值都比它大。**
>
> 那这棵树就天生"有序"，而且**查找就像在树上玩二分**：比根小就去左边，比根大就去右边，每走一步都砍掉一半！
>
> 这就是大名鼎鼎的 **二叉查找树（Binary Search Tree，BST）**，C 语言编译器、数据库索引、通讯录背后的常客。
>
> 更妙的是，我们只需要第7章的递归 + 第9.3节那棵树的骨架。准备好了吗？种树去！🌱

## 9.4.1 BST 的"家规"：左小右大

建树时我们只守一条规矩：

```
插入规则：
  比当前节点小  → 往左子树走
  比当前节点大  → 往右子树走
  相等          → 不重复插入（或按你的需求处理）
  走到空位(NULL) → 在这里放新节点
```

按顺序插入 `50, 30, 70, 20, 40, 60, 80`，会长成：

```
        50
       /  \
     30    70
    /  \   /  \
   20  40 60  80
```

**验证家规：** 50 的左子树 `{30,20,40}` 全比 50 小，右子树 `{70,60,80}` 全比 50 大；对 30 这棵子树同样成立。每棵子树都是 BST！

> 📌 **家规带来的两大好处：**
> 1. **查找快**：找 40，从 50 → 30 → 40，只走 3 步，每次砍掉一半（像二分查找）
> 2. **天生有序**：对 BST 做**中序遍历**，输出的就是**从小到大**的序列！

## 9.4.2 递归插入：一路走到空位

插入用递归非常顺——"把 value 插到以 root 为根的树里，返回这棵树的新根"：

```c
#include <stdio.h>
#include <stdlib.h>

typedef struct TreeNode {
    int data;
    struct TreeNode *left;
    struct TreeNode *right;
} TreeNode;

TreeNode *createNode(int value) {
    TreeNode *node = (TreeNode *)malloc(sizeof(TreeNode));
    if (node == NULL) return NULL;
    node->data = value;
    node->left = NULL;
    node->right = NULL;
    return node;
}

// 插入：返回插入后这棵（子）树的根
TreeNode *insert(TreeNode *root, int value) {
    if (root == NULL) {                  // 出口：走到空位，放新节点
        return createNode(value);
    }
    if (value < root->data) {
        root->left = insert(root->left, value);   // 去左子树放
    } else if (value > root->data) {
        root->right = insert(root->right, value); // 去右子树放
    }
    // value == root->data：已存在，不重复插入
    return root;                         // 根没变，原样还回去
}
```

> 🔍 **`root->left = insert(root->left, value)` 这句是关键：** 递归往左子树插，插完把"可能长出新根"的左子树**接回** root->left。整条路上的根一路 return 回来，最终 main 里 `root = insert(root, value)` 拿到新树根。**"改了子树就把子树接回去"**，是树上递归的固定套路。

插入过程示意（插入 40）：

```
        50                50              50              50
       /  \    40<50     /  \    40<30   /  \    40>30   /  \
     30    70 ───────► 30    70 ──────► 30    70 ──────► 30    70
    /                 /                /  \             /  \
   20                20               20    40         20   40    ← 放这里！
```

## 9.4.3 递归查找：像二分一样"砍"

```c
// 查找：返回"装着 value 的节点"，找不到返回 NULL
TreeNode *search(TreeNode *root, int value) {
    if (root == NULL) {
        return NULL;                     // 出口：走到空，说明没有
    }
    if (value == root->data) {
        return root;                     // 出口：找到了！
    }
    if (value < root->data) {
        return search(root->left, value);   // 比根小 → 去左边
    }
    return search(root->right, value);      // 比根大 → 去右边
}
```

查找 60 的过程：`60 > 50 → 右边` → `60 < 70 → 左边` → 找到了。三步搞定，**每次都扔掉一半**——这棵树的"树高"就是最坏查找步数。

> 📌 **BST 查找 = 二分查找的"树版"。** 数组二分靠下标砍半；BST 靠"左小右大"的指针往下走。平衡的 BST，查找约 O(log n)；退化成一条直线时（一直插递增的数）会退到 O(n)，工程上会用"平衡树"来防止——我们先把基础版掌握好。

## 9.4.4 中序输出：一行递归，自动排序 🎯

还记得 9.3 吗？中序是"左 → 根 → 右"。BST 里左都小、右都大，所以中序自然就是**从小到大**：

```c
// 中序遍历：BST 的中序输出 = 升序！
void inorder(TreeNode *root) {
    if (root == NULL) return;
    inorder(root->left);
    printf("%d ", root->data);
    inorder(root->right);
}
```

> 💡 哪怕你**乱序**插入 `{70, 20, 50, 40, 80, 30, 60}`，只要遵守"左小右大"，中序输出永远是 `20 30 40 50 60 70 80`——BST 自带的排序功能！

## 9.4.5 收尾工具：节点数 & 后序释放

```c
int countNodes(TreeNode *root) {
    if (root == NULL) return 0;
    return 1 + countNodes(root->left) + countNodes(root->right);
}

int treeHeight(TreeNode *root) {
    if (root == NULL) return 0;
    int l = treeHeight(root->left);
    int r = treeHeight(root->right);
    return (l > r ? l : r) + 1;
}

void freeTree(TreeNode *root) {          // 后序释放：先子后己
    if (root == NULL) return;
    freeTree(root->left);
    freeTree(root->right);
    free(root);
}
```

## 9.4.6 完整程序：一棵会"排序 + 查找"的神树

```c
#include <stdio.h>
#include <stdlib.h>

typedef struct TreeNode {
    int data;
    struct TreeNode *left;
    struct TreeNode *right;
} TreeNode;

TreeNode *createNode(int value) {
    TreeNode *node = (TreeNode *)malloc(sizeof(TreeNode));
    if (node == NULL) return NULL;
    node->data = value;
    node->left = NULL;
    node->right = NULL;
    return node;
}

TreeNode *insert(TreeNode *root, int value) {
    if (root == NULL) return createNode(value);
    if (value < root->data) {
        root->left = insert(root->left, value);
    } else if (value > root->data) {
        root->right = insert(root->right, value);
    }
    return root;
}

TreeNode *search(TreeNode *root, int value) {
    if (root == NULL) return NULL;
    if (value == root->data) return root;
    if (value < root->data) return search(root->left, value);
    return search(root->right, value);
}

void inorder(TreeNode *root) {
    if (root == NULL) return;
    inorder(root->left);
    printf("%d ", root->data);
    inorder(root->right);
}

int countNodes(TreeNode *root) {
    if (root == NULL) return 0;
    return 1 + countNodes(root->left) + countNodes(root->right);
}

int treeHeight(TreeNode *root) {
    if (root == NULL) return 0;
    int l = treeHeight(root->left);
    int r = treeHeight(root->right);
    return (l > r ? l : r) + 1;
}

void freeTree(TreeNode *root) {
    if (root == NULL) return;
    freeTree(root->left);
    freeTree(root->right);
    free(root);
}

int main() {
    TreeNode *root = NULL;

    // 故意打乱顺序插入，验证 BST 照样能排序
    int values[] = {50, 30, 70, 20, 40, 60, 80};
    for (int i = 0; i < 7; i++) {
        root = insert(root, values[i]);
    }

    printf("中序遍历（自动升序）：");
    inorder(root);
    printf("\n");

    TreeNode *found = search(root, 40);
    printf("查找 40：%s\n", found != NULL ? "找到了" : "没找到");

    TreeNode *miss = search(root, 100);
    printf("查找 100：%s\n", miss != NULL ? "找到了" : "没找到");

    printf("节点总数：%d\n", countNodes(root));
    printf("树高：%d\n", treeHeight(root));

    freeTree(root);
    root = NULL;
    return 0;
}
```

输出：
```
中序遍历（自动升序）：20 30 40 50 60 70 80
查找 40：找到了
查找 100：没找到
节点总数：7
树高：3
```

> 🎉 恭喜！你用**结构体 + malloc + 递归**，亲手种出了一棵能"自动排序、秒速查找"的树——它就是把第4章指针、第6章链表、第7章递归、第8章二分查找**全部串起来**的结晶！

## 9.4.7 数据结构全家福 🧾

一路学到现在，我们的"容器"越来越强：

| 结构 | 规矩 | 实现主力 | 最擅长 |
|------|------|---------|--------|
| 数组 | 按下标取 | 编译器 | 按下标秒取 |
| 链表 | 顺着 next 走 | malloc + 指针 | 任意位置增删 |
| 栈 | 后进先出 | 数组/链表 | 撤销、匹配、函数调用 |
| 队列 | 先进先出 | 循环数组/链表 | 排队、缓冲 |
| 二叉树 | 一个根两个叉 | 递归 + 指针 | 分叉结构 / 遍历 |
| 二叉查找树 | 左小右大 | 递归 + 指针 | 排序 + 秒查 |

> 📌 **学习路径提示：** BST 已经是"树"家族的基石。在此基础上加规则，还能长出 **AVL 平衡树、红黑树、堆（完全二叉树）**……它们都是大厂面试和真实系统的常客。你现在的地基，够用了！

## 9.4.8 本节小结

这一节我们学了：

✅ **BST 家规：** 左子树全 < 根 < 右子树；每棵子树也是 BST

✅ **递归插入：** 比根小走左、大走右、空位放新节点；把子树"接回去"

✅ **递归查找：** 像二分查找，比大小决定走左还是走右，平衡时 O(log n)

✅ **中序 = 升序：** 一行递归自动排序，插入顺序乱也不怕

✅ **收尾：** countNodes / treeHeight / freeTree（后序释放）

> 💡 **记住：BST = 二叉树 + 左小右大。它让"排序"和"查找"在一棵树上同时发生——这是数据结构最优雅的组合之一。**

### 三、改错题

**8. 以下 BST 插入有 3 个错误：**

```c
#include <stdio.h>
#include <stdlib.h>

typedef struct TreeNode {
    int data;
    struct TreeNode *left;
    struct TreeNode *right;
} TreeNode;

TreeNode *createNode(int value) {
    TreeNode *node = (TreeNode *)malloc(sizeof(TreeNode));
    node->data = value;                      // 错误区①：malloc 之后要不要检查？
    node->left = NULL;
    node->right = NULL;
    return node;
}

TreeNode *insert(TreeNode *root, int value) {
    if (root == NULL) return createNode(value);
    if (value < root->data) {
        insert(root->left, value);           // 错误区②：插完要不要"接回"左子树？
    } else {
        root->right = insert(root->right, value);  // 错误区③：大于等于都走右？相等会怎样？
    }
    return root;
}

int main() {
    TreeNode *root = NULL;
    root = insert(root, 5);
    root = insert(root, 3);
    root = insert(root, 8);
    return 0;
}
```

> 提示：①检查 NULL；②改子树必须接回 `root->left = ...`；③注意"相等"该不该再插一次。
