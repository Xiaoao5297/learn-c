# 9.3 二叉树

栈和队列都是"一条线"：数据一个挨着一个，每个数据最多和前后两个邻居打交道。可现实里大量关系不是一条线——文件夹里一个目录套好几个子目录，公司里一个经理管两个组长。这一节把链表的"一个 next"升级成"两个指针"，得到计算机里最重要的分叉结构：**二叉树（binary tree）**。

## 9.3.1 从链表到二叉树：多带一根指针

第 6 章的链表节点，用寻宝游戏的话说就是一张纸条：正面写数据，背面写"下一张在哪"——只有一条路可走。现在给每张纸条的背面写**两个**地址："往左走去哪"和"往右走去哪"：

```c
struct tree_node {
	int data;                  /* 存的数据 */
	struct tree_node *left;    /* 左边那一张 */
	struct tree_node *right;   /* 右边那一张 */
};
```

和 6.3 的 `struct node` 对比，只多了一个指针成员。`left` 和 `right` 各指向一个节点，也可能什么都不指——那就是 `NULL`。类型名必须写完整的 `struct tree_node`，理由和链表一样：定义还没完成，只能引用结构体本身的名字。

一张张纸条靠左右两个地址连起来，就长成了一棵**倒着画的树**：从最顶上的一个节点出发，每个节点往下分出左右两条岔路。

## 9.3.2 看图认名

先约定一套叫法，后面全靠它交流：

```text
        50          ← 根（root）：最顶上的节点，整棵树的入口
       /  \
     30    70       ← 30、70 是 50 的孩子；50 是它们的父亲
    /  \   /  \
  20   40 60   80   ← 20、40、60、80 都是叶子
```

| 名词 | 意思 |
|------|------|
| 根（root） | 最顶上的节点，没有父亲，整棵树唯一的入口 |
| 孩子 / 父亲 | 直接相连的下一层 / 上一层节点 |
| 叶子（leaf） | 没有孩子的节点：`left` 和 `right` 都是 `NULL` |
| 子树 | 任意一个节点，连同它下面的所有后代，自己就是一棵树 |
| 深度 | 从根出发，走到某节点要经过的层数；根的深度是 1 |

最要紧的是**子树**这个视角：盯着 30 往下看，`30、20、40` 这一小坨自己就是一棵完整的树——30 是它的根，20 和 40 是它的叶子。**二叉树 = 根 + 一棵左子树 + 一棵右子树**，而左右子树又各自是"根 + 左 + 右"……一层层套下去，直到 `NULL`。

这正是第 7 章递归的味道：**一个大的结构，由一个根和两个更小的同类结构组成**。所以处理二叉树，几乎天生就该用递归。

## 9.3.3 造一棵树：先手动接线

先老老实实把节点一个个 malloc 出来、手动接上指针，把结构看明白。9.4 再学"自动插入"：

```c
// 9.3.1 build_tree.c
#include <stdio.h>
#include <stdlib.h>

struct tree_node {
	int data;
	struct tree_node *left;
	struct tree_node *right;
};

struct tree_node *create_node(int value)
{
	struct tree_node *node = malloc(sizeof(struct tree_node));
	if (node == NULL) {
		return NULL;
	}
	node->data = value;
	node->left = NULL;
	node->right = NULL;
	return node;
}

int main(void)
{
	/* 目标形状：
	 *       50
	 *      /  \
	 *    30    70
	 */
	struct tree_node *root = create_node(50);
	struct tree_node *left_child = create_node(30);
	struct tree_node *right_child = create_node(70);

	if (root == NULL || left_child == NULL || right_child == NULL) {
		printf("内存分配失败\n");
		return 1;
	}

	root->left = left_child;
	root->right = right_child;

	printf("根：%d\n", root->data);
	printf("根的左孩子：%d\n", root->left->data);
	printf("根的右孩子：%d\n", root->right->data);

	printf("左孩子是叶子吗：");
	if (root->left->left == NULL && root->left->right == NULL) {
		printf("是，left 和 right 都是 NULL\n");
	}

	free(left_child);
	left_child = NULL;
	free(right_child);
	right_child = NULL;
	free(root);
	root = NULL;

	return 0;
}
```

<!-- output: 9.3.1 -->
```text
根：50
根的左孩子：30
根的右孩子：70
左孩子是叶子吗：是，left 和 right 都是 NULL
```

`create_node` 是 6.3 里 `create_node` 的翻版：`malloc` 一个节点、检查返回值、填数据、两个指针都置 `NULL`——新造的节点暂时是片叶子。`root->left->data` 读起来有点绕，其实就是"顺着根的左指针走到下一个节点，再读它的数据"，和链表的 `head->next->data` 一模一样，只是多了一个方向。

释放整棵树不能像上面这样手动一个个 free——节点一多必然漏。等下有了遍历，再学"整棵释放"。

## 9.3.4 三种遍历

**遍历**就是把树里每个节点访问一遍。链表只有一种遍历——从头顺着 `next` 走；二叉树每个节点有两条岔路，先走哪边、什么时候"过问"节点本身，就有了讲究。约定"永远先左后右"，剩下的只是**根在什么时机被访问**：

| 遍历 | 顺序 | 口诀 |
|------|------|------|
| 前序 | 根 → 左 → 右 | 根最先 |
| 中序 | 左 → 根 → 右 | 根居中 |
| 后序 | 左 → 右 → 根 | 根最后 |

三个函数，每个只有三行，差别只是 `printf` 挪的位置：

```c
// 9.3.2 traversals.c
#include <stdio.h>
#include <stdlib.h>

struct tree_node {
	int data;
	struct tree_node *left;
	struct tree_node *right;
};

struct tree_node *create_node(int value)
{
	struct tree_node *node = malloc(sizeof(struct tree_node));
	if (node == NULL) {
		return NULL;
	}
	node->data = value;
	node->left = NULL;
	node->right = NULL;
	return node;
}

void preorder(const struct tree_node *root)
{
	if (root == NULL) {
		return;
	}
	printf("%d ", root->data);
	preorder(root->left);
	preorder(root->right);
}

void inorder(const struct tree_node *root)
{
	if (root == NULL) {
		return;
	}
	inorder(root->left);
	printf("%d ", root->data);
	inorder(root->right);
}

void postorder(const struct tree_node *root)
{
	if (root == NULL) {
		return;
	}
	postorder(root->left);
	postorder(root->right);
	printf("%d ", root->data);
}

int main(void)
{
	/*       50
	 *      /  \
	 *    30    70
	 *   /  \
	 *  20   40
	 */
	struct tree_node *n50 = create_node(50);
	struct tree_node *n30 = create_node(30);
	struct tree_node *n70 = create_node(70);
	struct tree_node *n20 = create_node(20);
	struct tree_node *n40 = create_node(40);

	if (n50 == NULL || n30 == NULL || n70 == NULL ||
	    n20 == NULL || n40 == NULL) {
		printf("内存分配失败\n");
		return 1;
	}

	n50->left = n30;
	n50->right = n70;
	n30->left = n20;
	n30->right = n40;

	printf("前序：");
	preorder(n50);
	printf("\n");

	printf("中序：");
	inorder(n50);
	printf("\n");

	printf("后序：");
	postorder(n50);
	printf("\n");

	return 0;
}
```

<!-- output: 9.3.2 -->
```text
前序：50 30 20 40 70
中序：20 30 40 50 70
后序：20 40 30 70 50
```

拿前序手工推一遍，确认递归确实在干我们想的事。递归出口是"空指针直接返回"，这是整棵递归的刹车：

```text
preorder(50)：打印 50，然后递归左、递归右
  preorder(30)：打印 30，递归左、递归右
    preorder(20)：打印 20，左是 NULL 返回，右是 NULL 返回
    preorder(40)：打印 40，两边都是 NULL 返回
  preorder(70)：打印 70，两边都是 NULL 返回
```

输出 `50 30 20 40 70`——根、整棵左子树、整棵右子树。三个函数放在一起看，唯一的不同是 `printf` 夹在两次递归调用的前、中、后；第 7 章说过"打印放在递归前后决定输出顺序"，在这里同样成立，而且更整齐。

中序输出 `20 30 40 50 70`——正好是**从左到右**读这棵树的顺序。这不是巧合，它马上要变成 9.4 的主角。

## 9.3.5 递归小工具：计数、深度、释放

三种遍历的套路一通，顺手就能写出一批实用小函数。它们都不需要新的知识，只是把"打印"换成别的动作：

- **数节点**：整棵树的节点数 = 1（根）+ 左子树的节点数 + 右子树的节点数。空树是 0。
- **量深度**：树的深度 = 1 + 左右子树深度的较大者。空树是 0。
- **释放整棵树**：必须先把左右子树都释放光，**最后** free 根——这就是"后序"的顺序。要是先 free 了根，左右指针就再也够不着了。

```c
// 9.3.3 tree_tools.c
#include <stdio.h>
#include <stdlib.h>

struct tree_node {
	int data;
	struct tree_node *left;
	struct tree_node *right;
};

struct tree_node *create_node(int value)
{
	struct tree_node *node = malloc(sizeof(struct tree_node));
	if (node == NULL) {
		return NULL;
	}
	node->data = value;
	node->left = NULL;
	node->right = NULL;
	return node;
}

int count_nodes(const struct tree_node *root)
{
	if (root == NULL) {
		return 0;
	}
	return 1 + count_nodes(root->left) + count_nodes(root->right);
}

int tree_depth(const struct tree_node *root)
{
	if (root == NULL) {
		return 0;
	}
	int left_depth = tree_depth(root->left);
	int right_depth = tree_depth(root->right);
	return (left_depth > right_depth ? left_depth : right_depth) + 1;
}

int sum_tree(const struct tree_node *root)
{
	if (root == NULL) {
		return 0;
	}
	return root->data + sum_tree(root->left) + sum_tree(root->right);
}

void free_tree(struct tree_node *root)
{
	if (root == NULL) {
		return;
	}
	free_tree(root->left);
	free_tree(root->right);
	free(root);
}

int main(void)
{
	/*       50
	 *      /  \
	 *    30    70
	 *   /  \
	 *  20   40
	 */
	struct tree_node *n50 = create_node(50);
	struct tree_node *n30 = create_node(30);
	struct tree_node *n70 = create_node(70);
	struct tree_node *n20 = create_node(20);
	struct tree_node *n40 = create_node(40);

	if (n50 == NULL || n30 == NULL || n70 == NULL ||
	    n20 == NULL || n40 == NULL) {
		printf("内存分配失败\n");
		return 1;
	}

	n50->left = n30;
	n50->right = n70;
	n30->left = n20;
	n30->right = n40;

	printf("节点数：%d\n", count_nodes(n50));
	printf("深度：%d\n", tree_depth(n50));
	printf("数据和：%d\n", sum_tree(n50));

	free_tree(n50);
	n50 = NULL;

	printf("整棵树已释放\n");

	return 0;
}
```

<!-- output: 9.3.3 -->
```text
节点数：5
深度：3
数据和：210
整棵树已释放
```

三个函数的形状完全一样：**空树给一个基线值，否则"根 + 递归左 + 递归右"**。数节点加的是 1，求和加的是 `root->data`，量深度取的是较大者再加 1。看懂这一个模式，就等于看懂了树上递归的一大半。

`free_tree` 值得多说一句：它就是后序遍历，把 `printf` 换成了 `free`。**先放孩子、再放自己**，和"先收拾抽屉、最后搬柜子"是一个道理——柜子（根）先搬走，抽屉就没地方搁了。这是第 6 章"释放堆内存"的纪律在树上的版本：每个 malloc 出来的节点都必须被 free 恰好一次。

## 9.3.6 小结

- 二叉树节点 = 数据 + `left` 指针 + `right` 指针；链表节点多带一根指针的结果。
- 名词：根、孩子与父亲、叶子、子树、深度。
- 二叉树是递归结构：根 + 左子树 + 右子树，空指针是天然的递归出口。
- 三种遍历只是 `printf` 的位置不同：前序（根左右）、中序（左根右）、后序（左右根）。
- `count_nodes`、`tree_depth`、`sum_tree`、`free_tree` 共享同一个递归模式；释放整棵树必须用后序。

```c
	inorder(n1);
	printf("\n");

	printf("后序：");
	postorder(n1);
	printf("\n");

	free_tree(n1);
	n1 = NULL;

	return 0;
}
```

输出：

```text
前序：1 2 4 3 5
中序：4 2 1 3 5
后序：4 2 5 3 1
```

这棵树 3 的左孩子是空、5 挂在 3 的右边，递归走到空就返回，输出比满树少一层。

8. 参考代码（`create_node` 和建树部分与第 7 题相同，只列关键函数和 main）：

```c
#include <stdio.h>
#include <stdlib.h>

struct tree_node {
	int data;
	struct tree_node *left;
	struct tree_node *right;
};

struct tree_node *create_node(int value)
{
	struct tree_node *node = malloc(sizeof(struct tree_node));
	if (node == NULL) {
		return NULL;
	}
	node->data = value;
	node->left = NULL;
	node->right = NULL;
	return node;
}

int max_value(const struct tree_node *root)
{
	if (root == NULL) {
		return -2147483648;    /* 哨兵：int 的最小值 */
	}

	int best = root->data;
	int left_max = max_value(root->left);
	int right_max = max_value(root->right);

	if (left_max > best) {
		best = left_max;
	}
	if (right_max > best) {
		best = right_max;
	}
	return best;
}

void free_tree(struct tree_node *root)
{
	if (root == NULL) {
		return;
	}
	free_tree(root->left);
	free_tree(root->right);
	free(root);
}

int main(void)
{
	/*       50
	 *      /  \
	 *    30    70
	 *   /  \      \
	 *  20   40     90
	 */
	struct tree_node *n50 = create_node(50);
	struct tree_node *n30 = create_node(30);
	struct tree_node *n70 = create_node(70);
	struct tree_node *n20 = create_node(20);
	struct tree_node *n40 = create_node(40);
	struct tree_node *n90 = create_node(90);

	if (n50 == NULL || n30 == NULL || n70 == NULL ||
	    n20 == NULL || n40 == NULL || n90 == NULL) {
		printf("内存分配失败\n");
		return 1;
	}

	n50->left = n30;
	n50->right = n70;
	n30->left = n20;
	n30->right = n40;
	n70->right = n90;

	printf("最大值：%d\n", max_value(n50));

	free_tree(n50);
	n50 = NULL;

	return 0;
}
```

输出：

```text
最大值：90
```

`max_value` 和 `sum_tree` 是同一个模式：根、递归左、递归右三个候选值里挑一个。空树返回 int 的最小值当哨兵，保证任何真实数据都能"赢"过它。
