# 第9章：栈、队列与二叉树 —— 给数据搭个"骨架" 🏗️

## 📖 本章导读

第8章结尾我们预告过：学完排序与查找，该去看看"数据结构"了。

到目前为止，我们见过的"装数据的方式"有：数组（第3章）、结构体（第4章）、链表（第6章）。它们都是"容器"——但现实世界里，数据排队的规矩各不相同：

- 🍽️ **食堂的盘子**：后放的盘子先被拿走（后进先出）
- 🚶 **打饭的队伍**：先来的人先打到饭（先进先出）
- 🌳 **家族的家谱 / 文件夹目录**：一个节点往下分出好几个分支（一对多）

每一种"规矩"，都有对应的**数据结构**去高效地实现它：

- 🥞 **栈（Stack）**：后进先出，就像叠盘子、函数调用
- 🚌 **队列（Queue）**：先进先出，就像排队、打印任务
- 🌲 **二叉树（Binary Tree）**：每个节点最多分两个叉，是链表升级成"分叉结构"的第一步

这一章，是"**数据结构篇**"的正式开篇——栈、队列、树，再加上第10章以后的进阶内容，你就能写出真正有"骨架"的大程序了！

在本章中，我们将一起：

- 🥞 **造一个栈** —— 理解"后进先出"，顺手做个括号匹配检查器
- 🚌 **造一个队列** —— 理解"先进先出"和"循环队列"的妙处
- 🌳 **认识二叉树** —— 复习链表+递归，写出前序/中序/后序遍历
- 🔎 **二叉查找树** —— 一棵"天生有序、查找飞快"的神树：插入、查找
- ✂️ **BST 删除与进阶** —— 最难也最经典的"删节点"三情形

## 🎯 学习目标

完成本章后，你将能够：

1. ✅ 说出栈和队列的区别，并分别用数组实现 push/pop、入队/出队
2. ✅ 理解"循环队列"为什么能循环利用数组空间
3. ✅ 画出二叉树，能用递归写出前序、中序、后序遍历
4. ✅ 理解二叉查找树的"左小右大"规则，实现插入、查找、中序排序输出
5. ✅ 实现二叉查找树的删除（叶子 / 独子 / 双子三种情况）

## 💡 学习建议

> 📌 **数据结构 = 数据的"存放规矩" + 配套的"操作方法"。**
>
> - 🖌️ **画图！画图！画图！** 栈就画一摞盘子，队列就画一条队伍，树就画一棵倒长的树——图比代码好懂一万倍
> - 🧩 **操作就那几个：** 栈（压/弹/看顶），队列（进/出/看头），树（遍历）。记熟名字再写代码
> - 🔗 **别忘老知识：** 本章到处是第4章结构体、第6章 malloc 链表、第7章递归——它们会全派上用场
> - 🐢 **一个结构一个结构来：** 栈最简单先吃透，队列要懂"转圈"，树要会"递归遍历"，最后 BST 是全场压轴
